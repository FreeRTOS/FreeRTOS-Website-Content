**Changing an existing FreeRTOS IAR demo to use IAR V5.x**

This page has been superseded as from FreeRTOS V4.7.1 all IAR projects for ARM devices are saved using 
the IAR Embedded Workbench **V5.x** format. These will not open from V4.x versions. FreeRTOS V4.7.0 and 
earlier are still available from SourceForge and can be used with Embedded Workbench V4.x.
