[[RTOS Implementation Building Blocks](/Documentation/02-Kernel/05-RTOS-implementation-tutorial/02-Building-blocks/01-Building-blocks)]

A goal of FreeRTOS is that it is simple and easy to understand. To this end the majority of the RTOS source code is written in C,
not assembler. The example presented here uses the [WinAVR development tools](http://sourceforge.net/projects/winavr). WinAVR is
a free Windows to AVR cross compiler based on GCC.
