AWS Reference Integrations are pre-integrated FreeRTOS projects ported to microcontroller-based evaluation 
boards that demonstrate end to end connectivity to the cloud. AWS Reference Integrations help save months 
of development effort and accelerate time to market.   


### Choosing an AWS Reference Integration

The AWS Reference Integrations below demonstrate end to end connectivity 
to [AWS IoT Core](https://aws.amazon.com/iot-core/). You can find more details in 
the [AWS Partner Device Catalog](https://devices.amazonaws.com/search?sv=freertos). If you wish to qualify a 
board as an AWS Reference Integration, please refer to 
the [AWS Device Qualification Program](https://aws.amazon.com/partners/dqp/).

LTSThese are boards that use FreeRTOS LTS libraries. [Learn more about LTS](/Documentation/03-Libraries/01-Library-overview/03-LTS-libraries/01-LTS-libraries).
