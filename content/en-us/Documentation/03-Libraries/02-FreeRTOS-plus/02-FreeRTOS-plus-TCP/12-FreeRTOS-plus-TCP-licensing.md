From version 2.0.0 FreeRTOS-Plus-TCP is provided under the [same MIT license as the FreeRTOS kernel](/Documentation/03-Libraries/01-Library-overview/04-Licensing). 
Note the latest version of FreeRTOS is found in the [main FreeRTOS download](/Documentation/02-Kernel/01-About-the-FreeRTOS-kernel/03-Download-freeRTOS/01-DownloadFreeRTOS). The FreeRTOS 
labs download may contain an older FreeRTOS-Plus-TCP version to demonstrate FreeRTOS-Plus-FAT and FreeRTOS-Plus-TCP 
working together to create an FTP server and an HTTP server.
