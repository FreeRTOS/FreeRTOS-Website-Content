Getting started with the RTOS's open source TCP/IP stack


### Context

The [embedded TCP/IP networking basics and glossary](/Documentation/03-Libraries/02-FreeRTOS-plus/02-FreeRTOS-plus-TCP/02-Networking-basics/01-Networking-basics)
pages provide an introduction to embedded TCP/IP networking concepts. The [API reference](/Documentation/03-Libraries/02-FreeRTOS-plus/02-FreeRTOS-plus-TCP/09-API-reference/01-FreeRTOS-plus-TCP-APIs)
provides detailed information on each FreeRTOS-Plus-TCP API function. The [configuration reference](/Documentation/03-Libraries/02-FreeRTOS-plus/02-FreeRTOS-plus-TCP/06-Configuration)
describes the FreeRTOS-Plus-TCP configuration file and options.
This page provides links to pages that provide a top level overview of the steps required to build and use FreeRTOS-Plus-TCP in a
network enabled embedded RTOS application. Complete buildable and executable [example projects](/Documentation/02-Kernel/01-About-the-FreeRTOS-kernel/03-Download-freeRTOS/01-DownloadFreeRTOS)
are also available from this website.
