## 可选 FreeRTOS 商业许可

来自我们战略合作伙伴 [WITTENSTEIN high integrity systems](http://www.highintegritysystems.com/openrtos/)。



* ![](/media/2018/openrtos.gif)  [OpenRTOS™](http://www.highintegritysystems.com/openrtos/) 
  FreeRTOS 内核的商业授权版本，包括赔偿和专门支持。 
  FreeRTOS 和 OpenRTOS 共享相同的代码库。OpenRTOS 由 WITTENSTEIN high integrity systems 根据 AWS 授权提供 
  （作为 AWS 战略合作伙伴）。
  
* ![](/media/2018/srsmall.gif)  [SAFERTOS™](http://www.highintegritysystems.com/safertos/)
  是 FreeRTOS 内核的衍生版本，经过分析、记录和测试， 
  符合工业（IEC 61508 SIL 3）、医疗（IEC 62304 和 FDA 510(K)）、汽车 
  （ISO 26262）和其他国际安全标准的严格要求。SafeRTOS 包括经过独立审核的安全生命周期文档工件。 
  SafeRTOS 由 AWS 战略合作伙伴 WITTENSTEIN high integrity systems 提供 
  。


## FreeRTOS 内核许可比较

|  | FreeRTOS 内核 MIT 许可 | [OpenRTOS](http://www.highintegritysystems.com/openrtos/) 商业许可 |
| --- | --- | --- |
| 是否免费？  | 是 | 否 |
| 可以在商业应用中使用吗？  | 是 | 是 |
| 是否免收版税？ | 是 | 是 |
| 是否提供保修？ | 否 | **是** |
| 可以在商业基础上获得专业技术支持吗？ | 是 | 是 |
| 是否提供法律保护？ | 否 | **是**，提供知识产权侵权保护 |
| 必须开源使用 FreeRTOS 服务的应用程序代码吗？ | 否 | 否 |
| 必须开源 FreeRTOS 内核的更改吗？  | 否 | 否 |
| 需要证明我的产品使用 FreeRTOS 吗？ | 否 | 否 |
| 必须向我的应用程序的用户提供 FreeRTOS 代码吗？  | 否 | 否 |
