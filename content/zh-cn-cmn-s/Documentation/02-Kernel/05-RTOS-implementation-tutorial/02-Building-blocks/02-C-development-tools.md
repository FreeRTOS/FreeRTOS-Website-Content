FreeRTOS 的其中一个目标就是简单易理解。为此，RTOS 源代码主要是用 C 语言编写的，
而不是汇编语言。此处示例使用 [WinAVR 开发工具](http://sourceforge.net/projects/winavr)。WinAVR 是
一款免费的基于 GCC 的从 Windows 到 AVR 的交叉编译器。
