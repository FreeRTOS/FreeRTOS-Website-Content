借助 [GCC 开发工具](http://gcc.gnu.org/)，可以使用 C 语言编写中断。
可以使用以下语法编写 AVR 定时器 1 外设上的比较匹配事件。

```c
void SIG_OUTPUT_COMPARE1A( void ) __attribute__ ( ( signal ) );

void SIG_OUTPUT_COMPARE1A( void )
{
    /* ISR C code for RTOS tick. */
    vPortYieldFromTick();
}
```

函数原型上的 _'\_\_attribute\_\_ ( ( signal ) )'_ 指令会通知编译器该函数是一个 ISR，
并导致编译器输出发生两项重要变化。

1. "signal" 属性可确保在 ISR 退出时，每个在 ISR 期间经过修改的处理器寄存器
   都还原到初始值。这是必需操作，因为编译器无法
   对何时执行中断做出任何假设，因此无法优化
   需要保存和无需保存的处理器寄存器。
1. "signal" 属性还强制使用“从中断返回”指令 (RETI) 代替
   本来要使用的“返回”指令 (RET)。AVR 微控制器
   在进入 ISR 时禁用中断，退出时需要 RETI 指令重新启用中断。
