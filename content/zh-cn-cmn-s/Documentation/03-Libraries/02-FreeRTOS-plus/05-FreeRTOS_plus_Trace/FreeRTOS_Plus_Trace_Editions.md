FreeRTOS-Plus-Trace 有 3 种版本（包括免费版）。
专业版提供 30 天试用期供用户评估其全部功能。
版本功能对比如下表所示。


| **功能** | **免费版** | **标准版** | **专业版** |
| --- | --- | --- | --- |
|  跟踪视图  |  是  |  是  |  是  |
|  跟踪长度超过 1024 个事件  |  否  |  是  |  是  |
| [CPU 负载图](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/cpuloadgraph.png) |  否  |  是  |  是  |
| [调度强度](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/scheduling_intensity.png) |  否  |  否  |  是  |
| [Kernel call intensity](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/Kernel_Service_Calls_Referencing_Any_Object_(By_Service).png) |  否  |  否  |  是  |
|  内核阻塞时间  |  否  |  否  |  是  |
| [Task/ISR timing graphs](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/Actor_Instances_(Response_Time).png) |  否  |  否  |  是  |
| [内核事件](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/events.png) |  否  |  是  |  是  |
| [通信流图](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/commflow.png) |  否  |  否  |  是  |
| [队列利用率](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/Kernel_Object_Utilization.png) |  否  |  否  |  是  |
| [内核对象历史](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/objecthistoryview.png) |  否  |  否  |  是  |
| [连接相关的内核事件](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/relatedevents.png) |  否  |  否  |  是  |
| [用户事件](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/signalplot.png) |  否  |  是  |  是  |
| [用户数据图](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/signalplot.png) |  否  |  否  |  是  |
| [用户事件日志](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/User_Event_Log.png) |  否  |  否  |  是  |
| [统计报告](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/stats_and_finder.png) |  否  |  受限  |  完整  |
| [Multiple synchronized views](http://percepio.com/docs/FreeRTOS/images/FreeRTOS/Kernel_Service_Calls_Referencing_Any_Object_(By_Service).png) |  否  |  受限  |  是  |
