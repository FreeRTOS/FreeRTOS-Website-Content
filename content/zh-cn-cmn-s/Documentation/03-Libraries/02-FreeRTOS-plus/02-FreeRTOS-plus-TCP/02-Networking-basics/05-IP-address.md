同一 [IP 网络](internet_protocol.md)上的不同节点
由其 IP 地址标识
。例如，您阅读本文所使用的计算机上的每个网络接口
具有不同的 IP 地址，
您的计算机所连接的网络上的每个远程接口也具有不同的 IP 地址。

常用的 IP 地址格式有两种。目前，绝大多数
远程地址采用 IPv4 格式，这是一个 32 位
数字，但通常写法为用点分隔的四个单独的八位字节
（8 位数字），例如“192.168.0.32”。

另请参阅[静态 IP 地址](static_ip_address.md)
和 [DHCP](DHCP.md)。
