### 子网

子网允许将 [IP 地址](IP_address.md)的最重要位
转译为路由信息，而将 IP 地址的最不重要位
转译为本地 [IP 网络](internet_protocol.md)上的唯一节点地址。本地
 IP 网络（子网）
无需使用[网关或路由器](router.md)便可寻址。子网之间的流量必须通过
路由器。


### 网络掩码

被转译为包含路由信息的位数
由网络掩码确定。在网络掩码中设置位表示
将该位转译为路由信息。例如，如果 IP 地址为
10.134.134.10，网络掩码为 255.255.0.0，则 10.134
提供了路由信息，134.10 提供了
本地地址信息。以 10.134 开头的 IP 地址可以
直接发送到其在本地网络中的目的地。
以任何其他数字开头的 IP 地址不在
本地网络中，因此必须发送到路由器。
