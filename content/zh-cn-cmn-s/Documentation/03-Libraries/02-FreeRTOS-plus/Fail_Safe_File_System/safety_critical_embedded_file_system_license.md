Reliance Edge 拥有双开源/商业许可：

 * **开源许可**

   Reliance Edge 根据标准 GNU GPL V2 许可条款与 FreeRTOS 
   [](http://www.gnu.org/licenses/old-licenses/gpl-2.0.txt)一同提供（与 FreeRTOS 不同， 
   后者使用修改后的 GPL 许可）。

* **商业许可**

  出于商业或其他原因无法遵守 GPLv2 许可条款的企业和个人，
  可在将 Reliance Edge 整合入专有软件并以任何形式发布之前，[获得商业许可](http://www.datalight.com/products/embedded-file-systems/reliance-edge-commercial-license-packages)
  。商业 
  发行版还包括 GPLv2 版本未包含的额外测试和工具。
