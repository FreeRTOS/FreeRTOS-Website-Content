**用于 FreeRTOS** 的事务性嵌入式文件系统

[![Tuxera 徽标](/media/2021/tuxera_logo.png)](https://www.tuxera.com/) 
[![故障安全嵌入式文件系统](/media/2021/Reliance_Edge_logo.png)](https://www.tuxera.com/products/reliance-edge/) 

[**Reliance Edge**™](https://www.tuxera.com/products/reliance-edge/freertos/) 
是 [Tuxera 的](http://www.tuxera.com/company/about-us)  可移植、开源及符合 MISRA 的 
故障安全事务性  文件系统。它保护关键数据免受损坏，即便  在电源故障发生时。

Reliance 文件系统的  Tuxera 的作用范围设定了数据安全标准。它们  运用于数以百万计的 
产品中，甚至包括那些部署在最恶劣  和苛刻的环境下的产品， 
例如位于  海洋和太空的深处。

Reliance Edge 故障安全文件系统  专为受资源限制的小型嵌入式 
系统而设计  。它可以被配置为所使用的  RAM 最小为 4K 字节，而代码空间最小为 12K 字节 
。

Reliance Edge 提供对 FreeRTOS 的预先移植，  并可在 
PC 上[**立即评估**](Fail_Safe_Embedded_File_System_demo)，  使用功能丰富的 
免费开发工具，且无需  FreeRTOS Windows 移植。

**[下载 Tuxera 的出色开发人员指南](https://www.tuxera.com/resources/reliance-edge-developers-guide/)**  
，了解 Reliance Edge 中使用的事务处理技术  如何实现真正的故障安全。


### 重要特性

+ 为商业许可证持有人提供 MISRA C:2012 Design Assurance Package   
+ 元数据和用户数据均稳定可靠   
+ 操作可靠，且媒体无需具备原子扇区写入功能
+ 非常适合资源受限的环境
+ 简单易懂的架构使带来快速高效的实现
+ 即使在意外停机或断电后，也能快速如常启动
+ 包含用于在基于 Microsoft Windows 的工作站上创建磁盘映像的工具
+ 替换其他文件系统或与其他文件系统共存
+ 在 PC 上使用图像复制工具即可访问存储在可移动媒体上的数据
+ 适用于任何块设备驱动程序，以支持 NAND 闪存、NOR 闪存、eMMC、SD/MMC、NV RAM、USB 大容量 
  存储和 SATA（或 PATA）等
