*安全令牌*   
AWS 安全令牌服务 (AWS STS) 提供的临时、有限特权凭据，用于验证 IAM 用户的身份 
。


*凭据提供程序*   
AWS IoT Core 有一个凭据提供程序，让您可以将 
内置的 [X.509 证书](https://docs.aws.amazon.com/iot/latest/developerguide/x509-client-certs.html) 
作为对 AWS 请求进行身份验证的唯一设备标识。因此无需在您的设备上储存访问键 ID 和秘密访问密钥 
。
