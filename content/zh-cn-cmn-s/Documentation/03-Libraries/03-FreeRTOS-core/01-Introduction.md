## 简介

FreeRTOS Core 库实现基于开放标准的连接、安全性和相关功能。 
这些库适用于构建连接到云端的基于微控制器的智能设备。 
与 [FreeRTOS-Plus 库](/Documentation/03-Libraries/02-FreeRTOS-plus/01-Introduction)不同， 
FreeRTOS Core 库除了标准 C 库没有其他依赖项，因此 FreeRTOS Core 库 
并不依赖于 [FreeRTOS RTOS 内核](/Documentation/02-Kernel/01-About-the-FreeRTOS-kernel/01-FreeRTOS-kernel)。
