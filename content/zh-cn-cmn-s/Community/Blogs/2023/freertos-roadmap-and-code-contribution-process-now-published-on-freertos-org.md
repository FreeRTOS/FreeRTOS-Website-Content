从今天开始，FreeRTOS 路线图已在 [freertos.org](../../roadmap.md) 
和 GitHub 上发布。经过这次更新，您可以透明地获取有关特定 FreeRTOS 功能的信息，并且可以综合查看即将推出、 
正在进行和已发布的 FreeRTOS 项目，从而相应地规划自己的项目。此外，您还可以跟踪自己提出的 FreeRTOS 功能请求 
或自愿参与的项目。


[FreeRTOS](https://freertos.org/) 是一款开源实时操作系统， 
适用于微控制器和小型微处理器，能够简化小型低功耗边缘设备的编程、部署、保护、连接和管理工作。要想 
下载 FreeRTOS 源代码，请前往 [GitHub](https://github.com/freertos/freertos) 
和 [FreeRTOS.org](http://freertos.org/)。


如需详细了解并查看 FreeRTOS 路线图，请参阅 [FreeRTOS 路线图](../../roadmap.md) 
（位于 [freertos.org](http://freertos.org/)）。有关代码贡献流程的详细信息，请访问 
 [freertos.org](http://freertos.org/) 上的[贡献页面](../../community/contributions.md)。
