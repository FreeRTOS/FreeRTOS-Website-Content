One of the request tries to figure out which thread is currently active. To do so with MingW, the command &#8220;info threads&#8221; is executed. But after this command a segmentation fault occurs. I have removed this command from the integration so I do not have the problem any more but I thought that might be useful to someone else. Please find below what I get when I debug manually:
