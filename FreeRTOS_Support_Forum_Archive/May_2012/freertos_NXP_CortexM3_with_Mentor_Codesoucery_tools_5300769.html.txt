</div></div><div class="thread-post"><h3 class="thread-post-title">NXP CortexM3  with Mentor/Codesoucery tools</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on May 25, 2012</div><div class="thread-post-content">There should not be any differences to the standard library functions. The output in your post does not look like the wrong library is being used, but that no library is being used at all. Normally it would pick the right library automatically based on the&nbsp; other compiler options, so compare your command line with other examples that use the same compiler in the FreeRTOS demo directory. Unless code sourcery provide their own library for small devices, consider providing your own implementation of these functions anyway, as GCC libraries are not microcontroller friendly.  
If you are using a Cortex-M3 then you will have to use the thumb libraries, as Cortex only has thumb2.  
Have you looked at the demo provided for FreeRTOS+IO which builds an lwIP web server for an LPC1769 using GCC?
