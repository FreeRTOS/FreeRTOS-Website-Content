  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS Port to TI LM4F232 (Cortex-M4F)</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kpettit1">kpettit1</a> on May 20, 2012</div><div class="thread-post-content">Hey Richard,  
I just finished porting FreeRTOS to the TI / Stellaris LM4F232 micro controller using Code Composer Studio 4.&nbsp; I started with the Ti Stellaris Cortex-M3 port and made updates so it runs on TI&#8217;s veal kit for the lm4f and also added UART support with a small command line.  
If you &#40;or anyone else&#41; are interested, I could post the port under the TI section of the contributed ports.&nbsp; Would I need a different login to post that or does it use the same username / password as the forum?  
Ken
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS Port to TI LM4F232 (Cortex-M4F)</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 20, 2012</div><div class="thread-post-content">Yes &#8211; please do post it.  
If you copied the M3 port exactly then the code will run on an M4 provided the FPU is not used.&nbsp; If you want to use &#40;or even just enable&#41; the FPU then there are several Cortex-M4F ports that are available as a reference for your CCS port too.  
Unfortunately the passwords are all a bit discombobulated as these sites are hosted in different places.&nbsp; The forum password logs you onto SourceForge, whereas the Interactive forums are hosted somewhere completely different.&nbsp; I believe you can log on using OpenID or Twitter credentials on both sites.  
Thanks for your &#40;imminent&#41; contribution.  
Regards.

Ken
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS Port to TI LM4F232 (Cortex-M4F)</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 23, 2012</div><div class="thread-post-content">If you go to the <a href="http://interactive.freertos.org/">http://interactive.freertos.org</a> site, in the right hand corner there is a sign up link.&nbsp; That takes you to <a href="http://interactive.freertos.org/registration.">http://interactive.freertos.org/registration.</a>&nbsp; Once registered you can create a forum post, to which you can attach the code.
