Depending on your Ethernet driver, uip&#95;buf is often just a pointer into an Ethernet DMA buffer so no copying of data is actually performed. uip&#95;appdata is normally a pointer to a location <strong>within uip&#95;buf</strong> so writing to uip&#95;appdata writes data directly into uip&#95;buf so I would not expect to see data copied from uip&#95;appdata into uip&#95;buf explicitly. fsdata.c should not be compiled, but included as if it was a header file.&nbsp; In fact, it is included as if it were a header file in some of the standard uIP web server code.&nbsp; I have no idea why it was given a .c file extension.
