</div></div><div class="thread-post"><h3 class="thread-post-title">Question about Stack</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on April 26, 2012</div><div class="thread-post-content">The stack allocated in this case is 2000 words, which on your chip is 4000 bytes. That is a big stack for such a tiny device.  
The stack given to the task is no different to a normal stack. When a function is called the compiler will put the return address and possibly the function parameters on the stack itself. Any local variables inside the function will also get put on the stack by the compiler. This is just the same as what happens when you call a function from main&#40;&#41;. FreeRTOS does not do this, the compiler and hardware do, using the chips stack pointer.
