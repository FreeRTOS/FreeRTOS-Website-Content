</div></div><div class="thread-post"><h3 class="thread-post-title">Invoking timers after certain seconds</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on October 12, 2018</div><div class="thread-post-content">You need to be 100% sure of the frequency of the clock that is feeding 
the SysTick timer on your MCU, then set the constant configCPU<em>CLOCK</em>HZ 
to that frequency in FreeRTOSConfig.h &#8211; not the frequency that feeds the 
timer may be divided down from the frequency at which the rest of the 
core executes.
You can then test very crudely by having a single task that does nothing 
but toggle an LED every second, and time 60 toggles using a stopwatch. 
If the timing is correct, then the stop watch you say one minute at the 
end &#8211; plus or minus whatever your reaction time is hitting the stopwatch 
button.  Just something like this is fine if there is only one task:
<pre>
void vTest( void *pvParameters )
{
/* Using unmodified pdMS_TO_TICKS() macro* /
const TickType_t xPeriod = pdMS_TO_TICKS( 1000 );
     for( ;; )
     {
         vTaskDelay( xPeriod );
         ToggleLED(); /* write this yourself */
     }
}
