</div></div><div class="thread-post"><h3 class="thread-post-title">P&#038;E ICD Resetting for HCS12 Banked</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on June 7, 2012</div><div class="thread-post-content">When both priorities are the same the scheduler will time slice both tasks &#40;round robin with time slicing&#41;. When one task has a priority higher than the other then the scheduler will run the highest priority task whenever the high priority task can run. The high priority task can run if it is not blocked or suspended. I assume then that your A2D&#95;INPUT task never blocks, but you have not posted its code, so I cannot be certain. Does it ever block on a queue or semaphore, or ever call vTaskDelay&#40;&#41; or vTaskDelayUntil&#40;&#41;?
