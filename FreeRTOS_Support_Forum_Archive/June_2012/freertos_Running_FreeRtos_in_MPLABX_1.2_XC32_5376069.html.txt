</code></pre>

<pre><code>FreeRTOSEx                                -&gt; Project Dir

</div></div><div class="thread-post"><h3 class="thread-post-title">Running FreeRtos  in MPLABX 1.2 + XC32</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on June 23, 2012</div><div class="thread-post-content">FreeRTOS V7.1.1 includes MPLAB X and MPLAB 8 projects in FreeRTOS/Demo/PIC32MX&#95;MPLAB.&nbsp; You could use those as a reference.  
The MPLAB X project is in a directory called RTOSDemo.x, off the directory that contains the FreeRTOSConfig.h directory.&nbsp; I have just checked, and the include path has &#8220;../&#8221; in it to locate FreeRTOSConfig.h.&nbsp; Have you tried that?  
eg.  
Demo<br />
-&gt;main.c<br />
-&gt;FreeRTOSConfig.h<br />
-&gt;-&gt;RTOSDemo.x&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &lt;&#45; project directory is one directory higher than FreeRTOSConfig.h.  
Hope that helps.
