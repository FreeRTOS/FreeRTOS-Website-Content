  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">How to enter power save?</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 8, 2006</div><div class="thread-post-content">Hi,
I would like to enter power save mode after e.g 5 second, when nothing has happend.
How to implement this in smart way?
Nothing has happend does not mean that the system has been in the idle task all the time, only that no key has been pressed, no data arived thru USB and serial port.
regards, Frank
</div></div><div class="thread-post"><h3 class="thread-post-title">How to enter power save?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 8, 2006</div><div class="thread-post-content">You can place the system into sleep mode whenever the idle task runs.&nbsp; This way you do not have to keep a timer to say when the last event occurs.&nbsp; You just have to ensure that the sleep mode used will wake the task when an interrupt occurs &#40;USB, Keyboard, timer interrupt, etc&#41;.
Set configUSE&#95;IDLE&#95;HOOK to 1 in FreeRTOSConfig.h, then write the idle hook as:
void vApplicationIdleHook&#40; void &#41;
&#123;
 // Set sleep mode here.
&#125;
</div></div><div class="thread-post"><h3 class="thread-post-title">How to enter power save?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 9, 2006</div><div class="thread-post-content">Well, I want to be able to control the time elapsed before entering sleep mode.
So how do I ensure that the idle&#95;hook is not running?
regards, Frank 
</div></div><div class="thread-post"><h3 class="thread-post-title">How to enter power save?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 9, 2006</div><div class="thread-post-content">Could you use a tick hook?&nbsp; A function that runs each time the context switch occurs.&nbsp; From there you could reset a counter each time a function that is not the idle task runs.&nbsp; Then in the idle task you could check this counter and when it reaches your timeout, it can call sleep function.
</div></div><div class="thread-post"><h3 class="thread-post-title">How to enter power save?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 10, 2006</div><div class="thread-post-content">Yes, but not all task that are made runing by a context switch, means that anything has happend.
If I could somehow reset the counter only when a context switch to a task of certain priority is made, I think it could work. 
But is that possible?
regards, Frank.
</div></div><div class="thread-post"><h3 class="thread-post-title">How to enter power save?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 10, 2006</div><div class="thread-post-content">You can do this from a tick hook.&nbsp; The priority of the task that will run at the end of the tick is given by pxCurrentTCB-&gt;uxPriority.&nbsp; You can use this to do what you want &#40;I think?&#41;.
