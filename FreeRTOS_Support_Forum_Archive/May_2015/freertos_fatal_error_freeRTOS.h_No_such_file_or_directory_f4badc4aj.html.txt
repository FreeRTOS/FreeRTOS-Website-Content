</div></div><div class="thread-post"><h3 class="thread-post-title">fatal error: freeRTOS.h: No such file or directory</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on May 3, 2015</div><div class="thread-post-content">Hello Mahendra,
The header file <code>FreeRTOS.h</code> is part of the FreeRTOS kernel and it is located in:
<pre><code>&lt;FreeRTOS source&gt;includeFreeRTOS.h
</code></pre>
It is included as :
<pre><code>#include "FreeRTOS.h"
</code></pre>
so you will have to tell the compiler where to find this header file. Right-click on your project &#8220;mahendra&#8221; and look for &#8220;paths and symbols&#8221; or &#8220;include directories&#8221;.
It must have an entry like <code>&lt;FreeRTOS source&gt;include</code> where <code>&lt;FreeRTOS source&gt;</code> is some environment variable pointing to a directory in your projec space, or an absolute path.
Good luck.

You might want to add the path as
<pre><code>C:/FreeRTOSV8.2.1/FreeRTOS/Source/include

Richard suggested a more portable way:
<pre><code>"${workspace_loc:/${ProjName}/FreeRTOS_Source/include}"
</code></pre>
When using variables like <code>${ProjName}</code>, it is possible to move your project later on to another location.
PS. If you are more experienced using <code>Make</code> and <code>Makefile</code> (like I am), then I would advice to import a Makefile project into Eclipse (see import Makefile Project). In that case Eclipse will call Make to execute your Makefile and then run the created .ELF
