</div></div><div class="thread-post"><h3 class="thread-post-title">Issue in Running multiple Tasks</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on January 23, 2018</div><div class="thread-post-content">If you are calling a FreeRTOS API function from an interrupt then the 
priority of the interrupt must be at or below 
configMAX<em>SYSCALL</em>INTERRUPT_PRIORITY &#8211; which on an ARM means a 
numerically lower number.  All interrupts default to a priority of 0 &#8211; 
which is the highest priority &#8211; so you must manually set the interrupt&#8217;s 
priority to a lower logical (higher numerical) value before using it. 
More information is here (this is more complex than it needs to be on a 
Cortex-M):
https://www.freertos.org/RTOS-Cortex-M3-M4.html
