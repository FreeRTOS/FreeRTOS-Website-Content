  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Amazon FreeRTOS &#8211; How To Add Target; other questions&#8230;</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/westmorelandeng">westmorelandeng</a> on December 10, 2017</div><div class="thread-post-content">Hello All (Richard),
I just accessed the Amazon FreeRTOS interface under AWS on Amazon.
I was wondering &#8211; under Create New -> Hardware Platform &#8211; is there a way to add a microcontroller family to this vs. an IoT module &#8211; but maybe this is IoT module only now (and currently sparse).  
Just want to know is there a demarcation of FreeRTOS v10.x (here) and FreeRTOS v10.x (Amazon IoT)?
I suspect kernel files and existing (and future microcontroller) ports will still originate here?  Does Amazon plan on &#8216;forking&#8217; the &#8216;master/base&#8217; &#8211; or will all kernel files still be 100% here?  I suppose some of us can fear the dreaded feature creep that seems inevitable.  (Ha &#8211; tongue in cheek of course, hopefully.)
Good idea for the IoT stuff; but as long as the &#8216;bare metal&#8217; stuff can be accessed here (or via SVN/git) &#8211; guess that&#8217;s OK.
But, this is progress and all-in-all a good thing &#8211; so congrats are in order also!
Thanks,
John W.
</div></div><div class="thread-post"><h3 class="thread-post-title">Amazon FreeRTOS &#8211; How To Add Target; other questions&#8230;</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on December 10, 2017</div><div class="thread-post-content">Hi John,
The kernel code you received as part of Amazon FreeRTOS is the same as the kernel code you receive via SourceForge. No divergence.  The FreeRTOS.org website and download remains the home of the FreeRTOS kernel itself, as can be seen by v10 being released as normal here.
