</div></div><div class="thread-post"><h3 class="thread-post-title">LPC2387 with Keil uvison3</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on January 22, 2009</div><div class="thread-post-content">This page provides some info on moving from one dev board to another:
http://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html
As far as moving from an LPC21xx to an LPC23xx here are some notes:
&#43; The timer setup is different on the LPC23xx so prvSetupTimerInterrupt&#40;&#41; in port.c will need some modification.&nbsp; There is a GCC port for both the LPC21xx and the LPC23xx so inspect the differences in SourceportableGCCARM7&#95;LPC2000port.c and SourceportableGCCARM7&#95;LPC23xxport.c to find the differences.
&#43; The linker file needs changing to be correct for the LPC23xx.&nbsp; Keil comes with linker scripts for most LPC2000 devices so you just have to find the right one.
&#43; You may also like to see what differences there are in the startup code between the two GCC versions too, you have to be careful as some settings depend on the the revision of the chip you are using.
I don&#8217;t think there should be much else to do.
Regards.
