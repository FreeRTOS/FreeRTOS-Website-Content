</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7x Web Server MAC address Problem</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dksquires">dksquires</a> on November 19, 2008</div><div class="thread-post-content">As I recall from my past experience with the lwip demo for the ARM7, the MAC address is configured in file SAM7&#95;EMAC.h. This seems to still be true in the latest FreeRTOS download as well. I&#8217;ve used the lwip demo from earlier FreeRTOS versions on a SAM7X-EK board, upgraded to have the SAM7X512 CPU &#40;for our network-intensive application we needed more RAM&#41;.
Here&#8217;s a snippet from SAM7&#95;EMAC.h from FreeRTOS V5.1.0:
/&#42; MAC address definition.&nbsp; The MAC address must be unique on the network. &#42;/
&#35;define emacETHADDR0 0
&#35;define emacETHADDR1 0xbd
&#35;define emacETHADDR2 0x33
&#35;define emacETHADDR3 0x06
&#35;define emacETHADDR4 0x68
&#35;define emacETHADDR5 0x22
These constants are then used in file SAM7&#95;EMAC.c
I&#8217;m not sure how you&#8217;re seeing 00:00:00:00:00:00 as the MAC address, however, since the defaults are otherwise &#40;as shown above&#41;.
