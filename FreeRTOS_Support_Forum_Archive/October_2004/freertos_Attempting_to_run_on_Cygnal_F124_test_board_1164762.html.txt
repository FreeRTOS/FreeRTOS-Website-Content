  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Attempting to run on Cygnal F124 test board</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 20, 2004</div><div class="thread-post-content">New to FreeRTOS &#40;and SDCC&#41;. Loaded both up to start running on Cygnal&#8217;s F124-TB. Firstly, when I make the demo program, the following error is posted : &#8216;No rule to make target.. &#8216;..sourceportalblesdcccygnalportmacro.h&#8217;, needed by main. Stop.&nbsp;&nbsp;&nbsp; What does this mean???
Secondly, never used UnxUtils before, so how do you set the path for&#8217; make&#8217;
Thanks in advance&#8230;Green
</div></div><div class="thread-post"><h3 class="thread-post-title">Attempting to run on Cygnal F124 test board</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 20, 2004</div><div class="thread-post-content">It sounds like the paths on your machine are not correct.
From your build directory &#40;which should be Demo/Cygnal&#41;, does the path ..sourceportalblesdcccygnalportmacro.h exist?&nbsp; The build needs to be able to find this file.
Are you running make from the Demo/Cygnal directory?
Both SDCC and UnxUtils need to be included in your PATH environment variable.&nbsp; Open a DOS prompt and type &quot;path&quot;.&nbsp; This will print the entire path variable &#8211; are the required SDCC and UnxUtils paths included in the list?
If these paths are not included in the environment you need to add them using a command such as &#40;this can be placed in a .bat file for ease&#41;:
set PATH=C:SDCCbin;C:UnxTools;%PATH%
&#40;the paths in this sample command are just for demonstration and should be replaced with the actual paths for your installation&#41;
</div></div><div class="thread-post"><h3 class="thread-post-title">Attempting to run on Cygnal F124 test board</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 26, 2004</div><div class="thread-post-content">The conclusion of this was
1&#41; The SDCC version was 1.4 &#8211; which as mentioned on the WEB site cannot be used.
2&#41; For some reason it would not compile on Win98 &#40;the compiler hung&#41;, but WinXP was fine.
