</div></div><div class="thread-post"><h3 class="thread-post-title">periodic reset, no source code lines were found</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on October 13, 2014</div><div class="thread-post-content"><blockquote>

</blockquote>
The address depends on the the chip. Does it have RAM at address 0? The size depends on your linker script.
In any case if you are using any of the heap implementations other than heap_3 you don&#8217;t need a heap to be defined by the compiler.
