  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">portBYTE_ALIGNMENT_MASK</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kenmosher">kenmosher</a> on October 10, 2014</div><div class="thread-post-content">Hopefully this is a &#8220;forehead slap&#8221; type of question&#8230;
We&#8217;ve been moving an ARM7 project using FreeRTOS 5.4.0 that was previously on CrossWorks 2.0 to a new repository and build environment using CrossWorks 2.1.1 starting with a new Project template and imported everything.
We&#8217;ve sorted through a bunch of stuff with the includes for the project, setting ANSI checking to NO and arm-unknown-elf for the GCC Target.  All compiles and then when it gets to heap_2.c in the linker we get 
<h1>&#8220;error: portBYTE<em>ALIGNMENT</em>MASK undeclared (first use in this function)&#8221;</h1>
I can&#8217;t for the life of me find where portBYTE<em>ALIGNMENT</em>MASK is declared, so I&#8217;m not sure if we are missing something or if I still have a path that&#8217;s not included in the project (most likely).  I have found portBYTE_ALIGNMENT in portmacro.h (which makes perfect sense).
Once I get this to build cleanly and test out on the target, then I can introduce the next level of the port to get it up to a later version of FreeRTOS.
Thanks for any insights!
</div></div><div class="thread-post"><h3 class="thread-post-title">portBYTE_ALIGNMENT_MASK</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/markwrichardson">markwrichardson</a> on October 10, 2014</div><div class="thread-post-content">In my port I have a section in &#8220;portable.h&#8221; that decodes portBYTE_ALIGNMENT into a mask value.
~~~~~~
<h1>if portBYTE_ALIGNMENT == 8</h1>
<pre><code>#define portBYTE_ALIGNMENT_MASK ( 0x0007 )
</code></pre>
<h1>endif</h1>
<h1>if portBYTE_ALIGNMENT == 4</h1>
<pre><code>#define portBYTE_ALIGNMENT_MASK ( 0x0003 )
</code></pre>
<h1>endif</h1>
<h1>if portBYTE_ALIGNMENT == 2</h1>
<pre><code>#define portBYTE_ALIGNMENT_MASK ( 0x0001 )
</code></pre>
<h1>endif</h1>
<h1>if portBYTE_ALIGNMENT == 1</h1>
<pre><code>#define portBYTE_ALIGNMENT_MASK ( 0x0000 )
</code></pre>
<h1>endif</h1>
<h1>ifndef portBYTE<em>ALIGNMENT</em>MASK</h1>
<pre><code>#error "Invalid portBYTE_ALIGNMENT definition"
</code></pre>
<h1>endif</h1>
