</div></div><div class="thread-post"><h3 class="thread-post-title">Link Issue</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 4, 2016</div><div class="thread-post-content">These are coming from the library, which is expecting the host to provide implementations of the functions that are missing.  The functions should not actually be called, not by FreeRTOS or printf-stdarg.c in any case, so can be stubbed out.  Just provide an implementation of the function (you can get the prototypes from the header files or a Google search) and just an infinite loop or an assert() in the functions implementations &#8211; that way if it actually does get called you will know because it will stop your code executing.
Regards.
