  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Cortex-M4 Hard Float ABI Issue</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/namcho">namcho</a> on February 24, 2016</div><div class="thread-post-content">Hello,
I&#8217;m using stm32f429 which is cortex-m4 based also it has got <strong>hardware FPU **unit. I&#8217;m using Eclipse Luna 4.4.2 with ARM GNU GCC **C++</strong> compiler and GNU-ARM plugin. The version of GNU GCC is  5_2-2015q4.
I&#8217;m choosing GCC/ARM<em>CM4F as porting files and my freertos version is 8.2.3.
The completion is done without any errors but in run-time when I trying to create any task and let it to start than program suddenly goes into HardFault</em>Handler().
Here is my simple code:
~~~~
static LedClass led1(LED1, 300), led2(LED2, 600);
int
main(int argc, char* argv[])
{
  HAL_Init();
  /* Configure the system clock */
  SystemInit();
  SystemClock_Config();
  MX<em>GPIO</em>Init();
  led1.Create(&#8220;LED1&#8221;, configMINIMAL<em>STACK</em>SIZE, 1);
  led2.Create(&#8220;LED2&#8221;, configMINIMAL<em>STACK</em>SIZE, 1);
  FreertosAbstract::PortSysTickHandler();
  while(1){
      //Error handler
  }
}
/*
 * @brief         : 1ms systick timer
 */
void SysTick_Handler(void)
{
    HAL_IncTick();
    FreertosAbstract::PortSysTickHandler();
}
~~~~
The problem occurs after PortSysTickHandler() function was executed.
Here is the other simple code which is working well: Leds are blinking&#8230;
~~~~
int
main(int argc, char* argv[])
{
  HAL_Init();
  SystemClock_Config();
  MX<em>GPIO</em>Init();
  led1.Create(&#8220;LED1&#8221;, configMINIMAL<em>STACK</em>SIZE, 1);
  led2.Create(&#8220;LED2&#8221;, configMINIMAL<em>STACK</em>SIZE, 1);
  //FreertosAbstract::TaskStartScheduler();
  while(1){
      HAL<em>Delay(100);
      led1.LedOff(LED1);
      HAL</em>Delay(200);
      led1.LedOn(LED1);
  }
}
/*
 * @brief         : 1ms systick timer
 */
void SysTick_Handler(void)
{
    HAL_IncTick();
//  FreertosAbstract::PortSysTickHandler();
}
~~~~
Other problemed example is:
~~~~
int
main(int argc, char* argv[])
{
  HAL_Init();
  SystemClock_Config();
  MX<em>GPIO</em>Init();
  led1.Create(&#8220;LED1&#8221;, configMINIMAL<em>STACK</em>SIZE, 1);
  led2.Create(&#8220;LED2&#8221;, configMINIMAL<em>STACK</em>SIZE, 1);
  //FreertosAbstract::TaskStartScheduler();
  FreertosAbstract::PortSysTickHandler();  //Program is going to HardFault after this statement
  while(1){
      HAL<em>Delay(100);
      led1.LedOff(LED1);
      HAL</em>Delay(200);
      led1.LedOn(LED1);
  }
}
/*
 * @brief         : 1ms systick timer
 */
void SysTick_Handler(void)
{
    HAL_IncTick();
//  FreertosAbstract::PortSysTickHandler();
}
~~~~
So the problem&#8217;s cause is the xPortSysTickHandler() function.
Compiler Settings are:
Float ABI: FP Instruction hard
FPU Type: fpv4-sp-d16
I can share my whole code if necessary.
</div></div><div class="thread-post"><h3 class="thread-post-title">Cortex-M4 Hard Float ABI Issue</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 24, 2016</div><div class="thread-post-content"><blockquote>
  The problem occurs after PortSysTickHandler() function was executed.
</blockquote>
Please place a break point on that line, then step through the code to see at which point the hard fault is triggered.  It may also be possible to use the technique described on this link: http://www.freertos.org/Debugging-Hard-Faults-On-Cortex-M-Microcontrollers.html to get additional information.
I note you are using a C++ wrapper, which will not of come from us, so people reading the post will first assume there is a problem there, and will not be able to support that directly as its unknown code.  You can also try using the native API without the wrapper, or obtaining support whoever supplied the wrapper.
