</div></div><div class="thread-post"><h3 class="thread-post-title">Binary Semaphore not working on STM32F03R* Cortex M0 Controller from ISR</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 4, 2016</div><div class="thread-post-content">What is not working if you use (>= 1)?  Do you mean myBinarySem01Handle becomes NULL?  That would seem unlikely.
You only need to call portYIELD<em>FROM</em>ISR() or portEND<em>SWITCHING</em>ISR(), not both.  They equate to exactly the same thing.
By the way &#8211; if you are always unblocking the same task, or you can store the task&#8217;s handle if it is sometimes a different task, then you can achieve the same thing 40% faster and with less RAM using a task notification: http://www.freertos.org/RTOS<em>Task</em>Notification<em>As</em>Counting_Semaphore.html
