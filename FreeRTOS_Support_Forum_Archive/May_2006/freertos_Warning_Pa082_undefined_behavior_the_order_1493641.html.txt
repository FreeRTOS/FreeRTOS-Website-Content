</div></div><div class="thread-post"><h3 class="thread-post-title">Warning[Pa082]: undefined behavior: the order</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 9, 2006</div><div class="thread-post-content">This is one of the pains in supporting so many different compilers.&nbsp; Some will warn if you assign a volatile pointer to a non volatile pointer, so a cast is required to keep the compiler quiet.&nbsp; Some will do the opposite and warn if you cast.&nbsp; To keep the compiler quite it is sometimes therefore necessary to just disable the warning in the project.
The warning is correct, but changing the code to remove it will just cause warning in other ports :-&#40;
It is not going to cause you a problem &#40;I don&#8217;t think&#41;.
Regards,
Richard.
