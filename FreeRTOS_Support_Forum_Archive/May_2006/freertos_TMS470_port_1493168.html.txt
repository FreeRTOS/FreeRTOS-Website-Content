</div></div><div class="thread-post"><h3 class="thread-post-title">TMS470 port </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 1, 2018</div><div class="thread-post-content">It sounds like the stack is getting corrupted, probably because you are 
using the compiler&#8217;s interrupt entry code to enter the interrupt and the 
RTOS&#8217;s interrupt exit code to exit the interrupt.  I&#8217;m pretty sure you 
have to have the interrupt entry code in assembler so the context is 
saved as the scheduler expects and the stack frame is also as the 
scheduler expects.  See 
https://sourceforge.net/p/freertos/code/HEAD/tree/trunk/FreeRTOS/Source/portable/IAR/LPC2000/portasm.s79 
for the handler (as you probably have, and 
https://sourceforge.net/p/freertos/code/HEAD/tree/trunk/FreeRTOS/Source/portable/IAR/LPC2000/ISR_Support.h 
for interrupt entry and exit code (for the LPC2000) that must execute as 
the first thing (before any C code that manipulates the stack as you 
have it).
</div></div><div class="thread-post"><h3 class="thread-post-title">TMS470 port </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/wintuvogga">wintuvogga</a> on November 1, 2018</div><div class="thread-post-content">Hi Richard, 
   Thank you. Yes you were right. I removed the timer ISR callback from C and put the vPortPreemptiveTickEntry directly from startup.asm vector address. Now I can run the tasks as expected.  
<pre><code>       SECTION .intvec:CODE:NOROOT(2)
    PUBLIC  __vector
    PUBLIC  __iar_program_start
    EXTERN UndefinedInstruction
    EXTERN vPortYieldProcessor
    EXTERN vPortPreemptiveTickEntry
    ARM
</code></pre>
__vector:
        ;;
        ldr   pc,[pc,#+24]              ;; Reset
        ldr   pc,[pc,#+24]              ;; Undefined instructions<br />
        b vPortYieldProcessor           ;; Software interrupt (SWI/SVC)
        ldr   pc,[pc,#+24]              ;; Prefetch abort
        ldr   pc,[pc,#+24]              ;; Data abort
        ldr   pc,[pc,#+24]              ;; Reserved
        b vPortPreemptiveTickEntry                   ;; IRQ
        ldr   pc,[pc,#+24]              ;; FIQ
<pre><code> Once I clean up the code I can share this port so that you could add it in the supported processors. 
  But this chip is rare. It's Texas instruments SM470R1B1M High Temperature ARM7TDMI&#x2122; Flash Microcontroller. Used only in Oil and Gas / Space / millitary applications.  http://www.ti.com/product/sm470r1b1m-ht/description
  Regards,
    Winston 
</code></pre>
