</div></div><div class="thread-post"><h3 class="thread-post-title">Relacatable vector, error address MTUX</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/ofont">ofont</a> on October 6, 2011</div><div class="thread-post-content">Hi. Thanks for your reply.  
The problem is not here. the problem is that from vector adress 0x019C to 0x01C4 should be reserved because in hardware manual is reserved. In this code generate with KPIT GNU generator this adrees are filled with other interrupts that no correspond with this vector adress.  
In good code should be:  
<pre><code>//;0x019C  Reserved
    (fp)0,                                      
//;0x01A0  Reserved
    (fp)0,
//;0x01A4  Reserved
    (fp)0,  
//;0x01A8  Reserved
    (fp)0,
//;0x01AC  Reserved
    (fp)0,
//;0x01B0  Reserved
    (fp)0,  
//;0x01B4  Reserved
    (fp)0,                      
//;0x01B8  Reserved
    (fp)0,
//;0x01BC  Reserved
    (fp)0,  
//;0x01C0  Reserved
    (fp)0,
//;0x01C4  Reserved
    (fp)0,
//;0x01C8  MTU0_TGIA0
    (fp)INT_Excep_MTU0_TGIA0,
</code></pre>
but in the code with KPIT gnu generator is:  
<pre><code>//;0x019C  Reserved
    (fp)0,
//;0x01A0  TPU0_TGI0A
    (fp)INT_Excep_TPU0_TGI0A,
//;0x01A4  TPU0_TGI0B
    (fp)INT_Excep_TPU0_TGI0B,
//;0x01A8  TPU0_TGI0C
    (fp)INT_Excep_TPU0_TGI0C,
//;0x01AC  TPU0_TGI0D
    (fp)INT_Excep_TPU0_TGI0D,
//;0x01B0  TPU0_TCI0V
    (fp)INT_Excep_TPU0_TCI0V,
//;0x01B4  Reserved
    (fp)0,
//;0x01B8  Reserved
    (fp)0,
//;0x01BC  TPU1_TGI1A
    (fp)INT_Excep_TPU1_TGI1A,
//;0x01C0  TPU1_TGI1B
    (fp)INT_Excep_TPU1_TGI1B,
//;0x01C4  Reserved
    (fp)0,
</code></pre>
