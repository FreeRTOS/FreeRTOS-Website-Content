</div></div><div class="thread-post"><h3 class="thread-post-title">Kinetis K60 and CodeWarrior</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on September 2, 2012</div><div class="thread-post-content">Cortex-M3 and Cortex-M4 devices are supported with IAR, Keil and GCC.&nbsp; Cortex-M4 devices are additionally supported with Tasking.  
If you CodeWarrior uses GCC, then it is supported, it is just that there is not a pre-configured demo that will work &#8220;out of the box&#8221;.&nbsp; It is impossible to provide demos for every combination of chip and compiler &#40;31 chips and 14 tool chains supported, plus numerous development boards per chip&#33;&#41; &#8211; but there are lots of GCC demos for other ports that can be used as a reference.&nbsp;   
&#43; Create a project in CodeWarrior,<br />
&#43; Check it runs,<br />
&#43; Add in the FreeRTOS code &#40;FreeRTOS/Source, FreeRTOS/source/portable/GCC/ARM&#95;CM3, FreeRTOS/source/portable/MemMang/heap&#95;x.c&#41;,<br />
&#43; Copy a FreeRTOSConfig.h file from another project<br />
&#43; Add the FreeRTOS interrupt handlers into the vector table<br />
&#43; Compiler and work out the include paths required to remove the errors &#40;FreeRTOS/Source/include FreeRTOS/Source/portable/GCC/ARM&#95;CM3 &#40;or CM4&#41;, and the directory that has the FreeRTOSConfig.h header file as starters&#41;.  
There three links were posted recently about the required interrupt vectors:  
<a href="http://www.freertos.org/FreeRTOS_Support_Forum_Archive/September_2011/freertos_FreeRTOS_on_Atmel_SAM3U_in_CrossStudio_4694403.html">http://www.freertos.org/FreeRTOS_Support_Forum_Archive/September_2011/freertos_FreeRTOS_on_Atmel_SAM3U_in_CrossStudio_4694403.html</a>  
<a href="http://www.freertos.org/FreeRTOS_Support_Forum_Archive/June_2012/freertos_FreeRTOS_on_energymicro_GiantGeko_sourcery_5364965.html">http://www.freertos.org/FreeRTOS_Support_Forum_Archive/June_2012/freertos_FreeRTOS_on_energymicro_GiantGeko_sourcery_5364965.html</a>  
<a href="http://www.freertos.org/FreeRTOS_Support_Forum_Archive/January_2012/freertos_LPC1768_FreeRTOS_4964917.html">http://www.freertos.org/FreeRTOS_Support_Forum_Archive/January_2012/freertos_LPC1768_FreeRTOS_4964917.html</a>  
Regards.
