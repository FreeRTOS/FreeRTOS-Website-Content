  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">porting FreeRTOS on raspberry pi2 </h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/divakarrajr">divakarrajr</a> on August 27, 2016</div><div class="thread-post-content">Hey there, I am new to raspbian/FreeRTOS environments. I want to port FreeRTOS into my raspberry pi2 board.
The raspberry pi2 board now runs at raspbian OS from the SD card. My idea is to build the FreeRTOS demo source at the raspbian environment. Then replace the FreeRTOS kernel image file with raspbian kernel img file, at the SD card. Finally boot the pi2 using FreeRTOS kernel &#8211; then to start the game all over. 
But the problem is in building FreeRTOS source at raspbian environment. Its giving this error, 
<strong>Syntax error: word unexpected (expecting &#8220;)&#8221;)</strong>
All I did was&#8230;. 
1. downloaded FreeRTOS demo source from below link &#8211; to the path /home/pi/FreeRTOS/ &#8211; Got it untar-ed at the same path.
    https://github.com/jameswalmsley/RaspberryPi-FreeRTOS
2. downloaded gcc-arm-none-eabi-4<em>9-2015q3 tool chain from the below link. Untar-ed it to /usr/lib/gcc/ &#8211; coz this is path used at the makefile of FreeRTOS demo source.
    https://launchpad.net/gcc-arm-embedded/4.9/4.9-2015-q3-update/+download/gcc-arm-none-eabi-4</em>9-2015q3-20150921-linux.tar.bz2
3. exported the tool chain PATH,
<strong>export PATH=&#8221;$PATH:/usr/lib/gcc/gcc-arm-none-eabi-4_9-2015q3/bin&#8221;</strong>
4. run the &#8216;make&#8217; command. 
But all it gave me was&#8230;
<strong>/usr/lib/gcc/gcc-arm-none-eabi-4<em>9-2015q3/bin/arm-none-eabi-gcc: 1: /usr/lib/gcc/gcc-arm-none-eabi-4</em>9-2015q3/bin/arm-none-eabi-gcc: Syntax error: word unexpected (expecting &#8220;)&#8221;)
/home/pi/FreeRTOS/RaspberryPi-FreeRTOS-master/.dbuild/c-objects.mk:25: recipe for target &#8216;/home/pi/FreeRTOS/RaspberryPi-FreeRTOS-master/build/FreeRTOS/Source/portable/GCC/RaspberryPi/port.o&#8217; failed
make: * [/home/pi/FreeRTOS/RaspberryPi-FreeRTOS-master/build/FreeRTOS/Source/portable/GCC/RaspberryPi/port.o] Error 2</strong>
Please guide me further. What am I missing ?
