  Since I couldn&#8217;t find FreeRTOS port for the Cortex-A8 in the net, I&#8217;m

</blockquote>
I just did a search for &#8220;FreeRTOS Beaglebone Black&#8221; and there were lots
of hits, including near the top https://github.com/steve-kim/BeagleBone
<blockquote>
  What&#8217;s a &#8220;central interrupt handler&#8221;?
</blockquote>
Some interrupt controllers have a separate vector for each interrupt. 
When this is the case, assuming the interrupt vectors have been 
populated correctly, the interrupt controller will automatically call 
the correct interrupt service routine for any interrupt it accepts. 
That means there are multiple interrupt entry points &#8211; one for each vector.
Other interrupt controllers do not have the capability to directly 
vector to the correct handler for any particular interrupt as they only 
support a single interrupt entry point &#8211; what is referred to in the text 
you reference as the &#8220;central interrupt handler&#8221;.  When this is the case 
the software implementation of the central interrupt handler has to 
inspect the interrupt controller registers to determine which interrupt 
was accepted, and then branch the the appropriate interrupt handler 
accordingly.

The AM335x has a vector table for interrupts. I&#8217;m inializing the table as follows:
~~~
static unsigned int const vecTbl[14]=
{
    0xE59FF018,    /* Opcode for loading PC with the contents of [PC + 0x18] <em>/
    0xE59FF018,    /</em> Opcode for loading PC with the contents of [PC + 0x18] <em>/
    0xE59FF018,    /</em> Opcode for loading PC with the contents of [PC + 0x18] <em>/
    0xE59FF018,    /</em> Opcode for loading PC with the contents of [PC + 0x18] <em>/
    0xE59FF014,    /</em> Opcode for loading PC with the contents of [PC + 0x14] <em>/
    0xE24FF008,    /</em> Opcode for loading PC with (PC &#8211; 8) (eq. to while(1)) <em>/
    0xE59FF010,    /</em> Opcode for loading PC with the contents of [PC + 0x10] <em>/
    0xE59FF010,    /</em> Opcode for loading PC with the contents of [PC + 0x10] */
    (unsigned int)Entry,

</div></div><div class="thread-post"><h3 class="thread-post-title">[HELP] FreeRTOS port for BeagleBone Black/AM335x </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on August 13, 2016</div><div class="thread-post-content">This looks like a typical Cortex-A vector table, where there is only one
