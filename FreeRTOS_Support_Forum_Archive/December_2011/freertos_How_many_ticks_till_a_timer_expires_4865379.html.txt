  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">How many ticks till a timer expires?</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/destremps">destremps</a> on December 5, 2011</div><div class="thread-post-content">Hi,  
Let&#8217;s say I&#8217;ve created and started a timer for period X ticks. Now, some unknown number of ticks later I want to change it&#8217;s period to Y and restart it. But ONLY do this if the new period Y will cause the timer to expire later than the presently ticking down balance of the original period X. I may have missed it but I didn&#8217;t see an obvious way to do this.  
I was hoping to avoid creating and running a whole slew of timers. As in my case this will take up to 24 timers. Even though they all can reference a single callback function.  
Thanking…
</div></div><div class="thread-post"><h3 class="thread-post-title">How many ticks till a timer expires?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on December 6, 2011</div><div class="thread-post-content">There is no way of doing that currently, but you could add something like the following to timers.c :  
<pre><code>portTickType xTimerGetExpireTime( xTimerHandle xTimer )
{
xTIMER *pxTimer = ( xTIMER * ) xTimer;
portTickType xTimeNow, xExpireTime, xReturn;
const portTickType xMaxTime = -1;
    vTaskSuspendAll();
    {
        configASSERT( pxTimer );
        xTimeNow = xTaskGetTickCount();
        xExpireTime = listGET_LIST_ITEM_VALUE( &amp;( pxTimer-&gt;xTimerListItem ) );
        if( xExpireTime &gt;= xTimeNow )
        {
            xReturn = xExpireTime - xTimeNow;
        }
        else
        {
            xReturn = ( xMaxTime - xTimeNow ) + xExpireTime;
        }
    }
    xTaskResumeAll();
}
</code></pre>
Caveats:  
1&#41; This code is completely untested, not even compiled, it is here for demonstration of how it could be done only.  
2&#41; You have to take into account that time may pass between calling this function and the function returning &#8211; especially if it is called from a low priority task.  
Hope that helps.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">How many ticks till a timer expires?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/destremps">destremps</a> on December 6, 2011</div><div class="thread-post-content">Yes Richard. That surely helps. I pictured something like that, including the suspends, but wasn&#8217;t sure how to get at the expiration time. I&#8217;ll try to work with this. But for safety sake may end up with the brute force approach with an array of timers waiting for the last one to expire.  
Thanks for your help.
