</div></div><div class="thread-post"><h3 class="thread-post-title">Porting Problem with FreeRTOS v7.0.2 on IAR </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on December 1, 2011</div><div class="thread-post-content">I don&#8217;t think this can be classed as porting, it is just setting up a new project to use the existing IAR/Cortex-M3 port.&nbsp; You should be able to take an existing IAR/Cortex-M3 project and just re-target it to your chip, then you would have the project set up correctly already.  
<blockquote>
  1&#46; Compile Error on porting FreeRTOS.<br />
  File =&gt;&nbsp; portasm.s &#40;Line. 57&#41;<br />
  Message =&gt; Error:Failed to open &#35;include &lt;FreeRTOSConfig.h&gt;
</blockquote>
Just like the compiler, you need to set the include path for your assembler so it can find the file.&nbsp; In the project options, choose the assembler category, then the preprocessor tab, and add &#8220;$PROJ&#95;DIR$&#8221; &#40;without the quotes&#41; to the &#8220;Additional Include Directories&#8221; &#45; assuming FreeRTOSConfig.h is in the same directory as your IAR project file.  
<blockquote>
  2&#46; The task is not work.
</blockquote>
<pre><code>* SysTick intialization Function  =====================================================
void SYSTickInit(void)
{
  /* Setup SysTick Timer for 1 msec interrupts  */
  if (SysTick_Config(SystemCoreClock/1000))
  { 
    /* Capture error */ 
    while (1);
  }  
}
</code></pre>
Do you ever call this function?&nbsp; If so, <strong>please don&#8217;t&#33;</strong>.&nbsp; The kernel needs exclusive access to the SysTick &#40;including the interrupt&#41; and configures the SysTick when when the scheduler is started.&nbsp; I presume you have installed the correct SysTick interrupt handler for the kernel?&nbsp; Again, if not, look at existing projects.  
<pre><code>int main(void)
{
  SYSTickInit();
  AppGPIOInit();
  AppUARTInit();
  printf("%s", MESSAGE1);
  /* Create Task */
  xTaskCreate( Task1, "Task1", /*TASK_SIZE*/ 240 , NULL, 1, /*&amp;task1*/ NULL);       
  /* Start the scheduler. */
  vTaskStartScheduler();
  return 0;
}
</code></pre>
Does the printf&#40;&#41; call after the call to AppUARTInit&#40;&#41; work?  
Regards.
