  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">GPIO interrupt question in MSP430X of freeRTO</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/sch0bert">sch0bert</a> on December 29, 2011</div><div class="thread-post-content">Hello,  
This is my first time that I&#8217;m working with a RTOS so I&#8217;m not sure if what I&#8217;m doing is correct. I&#8217;m using a MSP430FG4618 and I want to comunicate with an ADS1194 analog converter but this chip has a DRDY port &#40;Data Ready port&#41; so I&#8217;m wondering how could I manage the interrupts becase the freeRTOS just handle 1 &#40;Timer interrupt&#41; as far as I know.  
I&#8217;m planning to enable the uC port interrupts once that I&#8217;m inside this task and then disable it once that I have finished all but I think that if a timer interrupt occurs it will affect the system, isn&#8217;t it?  
Just as a cultural information, the ADS1194 converter gives the information through SPI with 8 bits packages. I suppose to receive 6 packages in 1 cycle task. &#40;so 6 DRDY ports interrupts will occur&#41;  
So any I idea how could I manage this constant interrupt that will be made by the interrupt port?   
Best Regards,<br />
Pascal.
</div></div><div class="thread-post"><h3 class="thread-post-title">GPIO interrupt question in MSP430X of freeRTO</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on January 3, 2012</div><div class="thread-post-content">FreeRTOS uses only a single interrupt itself &#40;to generate the time base&#41;, but does not limit your use of any other interrupts.&nbsp; It provides an API that allows tasks and interrupts to synchronise, and for data to be passed into and out of interrupts.&nbsp; Take a look at the &#8220;Interrupt Service Routines&#8221; section of the documentation page for the port you are using, and the API reference for any function that ends in &#8220;FromISR&#8221;.&nbsp; You must not use an API function that does not end in FromISR in an interrupt.  
Also look at the demo application that comes for the port you are using.&nbsp; Each demo has an example of at least one interrupt being used.&nbsp; In the MSP430X case, take a look at the serial.c file to find examples.  
Regards.
