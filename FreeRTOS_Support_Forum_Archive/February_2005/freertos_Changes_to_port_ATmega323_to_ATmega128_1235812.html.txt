My demo application with two tasks seems to work fine in the simulator in AVRStudio.
</div></div><div class="thread-post"><h3 class="thread-post-title">Changes to port ATmega323 to ATmega128</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 23, 2005</div><div class="thread-post-content">The adaptor for the STK500 that allows the use of the ATMega128 is a little prohibitive, so I have never tried it, but I know there are several people using the 128.
Here is a copy of the WEB documentation on useing a different device:
&#43; Change the MCU definition at the top of the makefile. 
&#43; Set the correct clock frequency in PortMacro. h 
Ensure the portTOTAL&#95;HEAP&#95;SIZE definition is set to fit within the available RAM. 
&#43; The tick ISR is generated from a compare match on timer 1. Timer configuration is not identical across all AVR devices. Check the function prvSetupTimerInterrupt&#40;&#41; in SourceportableGCCATMega323port.c to see if any modifications are required for your chosen device. 
&#43; Whichever part is used, ensure the MCU fuses are blown to provide the correct clock frequency &#40;this can be done from the AVR Studio development tools&#41;.
The 323 is one of the older devices and I am told that the timer and serial port register settings are a bit different on the newer versions.&nbsp; You might just need to check that the timer gets setup correctly for the 128 &#40;as mentioned above&#41;.&nbsp; Having said that I got an ATMega32 &#40;newer version of the 323&#41; to try this out and found the code executed without any changes at all &#8211; which defeated the object of getting it&#33;
There was once a thread that said the integer math demo tasks generated some incorrect calculation results on the 128 &#8211; but I don&#8217;t know what the resolution of this was.&nbsp; The thread was never completed so I assume the author found the problem.
</div></div><div class="thread-post"><h3 class="thread-post-title">Changes to port ATmega323 to ATmega128</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rapurvey">rapurvey</a> on February 23, 2005</div><div class="thread-post-content">As I said it seems to work ok just using the 323 port in the AVRStudio simulator.&nbsp; Will double check the timer configuration though.
Cheers
</div></div><div class="thread-post"><h3 class="thread-post-title">Changes to port ATmega323 to ATmega128</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rapurvey">rapurvey</a> on March 3, 2005</div><div class="thread-post-content">Just to confirm for anybody else looking at this thread that the timer configuration is fine and the ATmega323 port works on the ATmega128 without any changes, apart from the clock frequency.
