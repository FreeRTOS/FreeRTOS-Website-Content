</div></div><div class="thread-post"><h3 class="thread-post-title">first project usig FreeRTOS with PIC32MX</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on January 29, 2014</div><div class="thread-post-content">configTICK<em>RATE</em>MS is the tick rate, in ms.  Therefore, if your tick frequency is 1000, then there is one tick every ms to make the 1000 ticks in a second, so 1 is the expected value.  The latest FreeRTOS version in SVN has renamed the constant configTICK<em>PERIOD</em>MS (with backward compatibility maintained so configTICK<em>RATE</em>MS is #defined to configTICK<em>PERIOD</em>MS so both work).
Did you start your project by adapting the existing MPLAB X project found in the FreeRTOS download?  There is a build configuration for the pic32MX795, the following page shows how to select it &#8211; http://www.freertos.org/port<em>PIC32</em>MIPS_MK4.html  
I would suggest starting with that, with mainCREATE<em>SIMPLE</em>BLINKY<em>DEMO</em>ONLY set to 1, that will give you a very simple two task example that is configured correctly for your part.
Once you have that building and running you can replace the two tasks with your own task, and take it from there.
