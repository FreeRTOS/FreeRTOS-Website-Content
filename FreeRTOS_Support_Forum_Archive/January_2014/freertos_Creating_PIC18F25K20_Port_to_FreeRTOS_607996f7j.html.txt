In port.c ,
I needed to make the following changes:
&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;..
Include defines to config: 
<h1>pragma config WDTEN = OFF</h1>
<h1>pragma config FOSC = INTIO2</h1>
<h1>pragma config XINST = OFF</h1>
&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;&#8230;..
Because there are slight difference in register:
Line 561    if( PIR1bits.CCP1IF )    to     if( PIR3bits.CCP1IF )
Line 602        PIR1bits.CCP1IF = 0;     to     PIR3bits.CCP1IF = 0;
Line 643        PIE1bits.CCP1IE = portBIT<em>SET;  to  PIE3bits.CCP1IE = portBIT</em>SET;
Line 651        OpenTimer1( T1<em>16BIT</em>RW &amp; T1<em>SOURCE</em>INT &amp; T1<em>PS</em>1<em>1 &amp; T1</em>CCP1<em>T3</em>CCP2 ); to
<pre><code>            OpenTimer1(T1_SOURCE_FOSC_4 &amp; T1_PS_1_1 &amp; T1_OSC1EN_ON &amp; T1_SYNC_EXT_OFF &amp; T1_16BIT_RW , TIMER_GATE_OFF &amp; TIMER_GATE_POL_HI &amp;    TIMER_GATE_TOGGLE_OFF &amp; TIMER_GATE_1SHOT_OFF &amp; TIMER_GATE_INT_OFF);
</code></pre>
///////////////////////////////////////////////////////////////////
In ParTest.c:
Modified     PortD to PortB
             PortE to PortC
////////////////////////////////////////////////////////////////////
Renamed :   timers.h in C:FreeRTOSV7.6.0<em>PIC18F25K80FreeRTOSSourceinclude to timers</em>.h because
           there are a conflict with timers.h in C:Program FilesMicrochipMPLABC18v3.46h
           during compilation.
////////////////////////////////////////////////////////////////////
Before compilation it is necessary to set the &#8220;Build Options&#8221; of MPLAB:
<pre><code>        Hex format : INHX32
        Memory Model:
                      Code Model -&gt; Small Code Model
                      Data Model -&gt; Large Data Model
                      Stack Model-&gt; Multi Bank Model
        Generate Command Line -&gt; uncheck -&gt; Extended Mode
</code></pre>
