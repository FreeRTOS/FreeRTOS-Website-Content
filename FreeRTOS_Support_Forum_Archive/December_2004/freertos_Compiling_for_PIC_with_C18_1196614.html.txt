</div></div><div class="thread-post"><h3 class="thread-post-title">Compiling for PIC with C18</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on December 17, 2004</div><div class="thread-post-content">It looks like your problem is that the definition MPLAB&#95;PIC18F&#95;PORT is not defined.&nbsp; If this is not defined then the correct portmacro.h file will not get included, the type portSTACK&#95;TYPE will not get defined, and you will get the error as per your post.
The demo projects should have this defined already.&nbsp; Below is the sample command line I get when building the demo exactly as downloaded.
Executing: &quot;D:DEVTOOLSmcc18binmcc18.exe&quot; -p=18F452 &quot;tasks.c&quot; -fo=&quot;tasks.o&quot; /i&quot;D:DevToolsmcc18h&quot; /i&quot;e:devfreertosdemocommoninclude&quot; /i&quot;e:devfreertossourceinclude&quot; /i&quot;e:devfreertossourceportablemplabPIC18F&quot; -DMPLAB&#95;PIC18F&#95;PORT -Ls -Opa-
Note the -DMPLAB&#95;PIC18F&#95;PORT option.
The paths require changing in the project file unfortunately.&nbsp; Have you changed anything else other than this?&nbsp; With most ports it is important that the compiler switches and definitions are all set up correctly.&nbsp; The demo project files should be used as examples.
Regards.
