</div></div><div class="thread-post"><h3 class="thread-post-title">Don&#8217;t know where to start</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on April 19, 2007</div><div class="thread-post-content">Does your uVision come with the old Keil or RealView compiler.&nbsp; If the former than you can start with the existing LPC2129 Keil demo and convert this for the MCB2300.&nbsp; I think there is a small change required in the port.c file when setting up the timer between the LPC2129 and LPC23xx, should be straight forward.&nbsp; If you are using the RealView tools then there is not a project in the download &#40;why not?&#41;, but if you email Richard he can send you an ARM7 RealView project which you would then havet to convert to be LPC23xx specific.&nbsp; 90% of the code is the same between all the ARM7 ports, only the timer, startup code and interrupt controller configuration differs.
