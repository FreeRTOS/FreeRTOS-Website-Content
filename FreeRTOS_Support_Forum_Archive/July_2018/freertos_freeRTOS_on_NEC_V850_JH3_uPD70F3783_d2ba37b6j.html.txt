</div></div><div class="thread-post"><h3 class="thread-post-title">freeRTOS on NEC V850 JH3 (uPD70F3783)</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/xcubbi">xcubbi</a> on July 26, 2018</div><div class="thread-post-content">I solved the issue regarding the interrupt handler. I checked the port assembler file and saw that the wrong interrupt vector was set.
First it was
~~~
; Tick ISR Prototype
;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;
        PUBWEAK <code>??MD_INTTM0EQ0??INTVEC 640</code>
        PUBLIC MD_INTTM0EQ0
MD<em>INTTM0EQ0        SYMBOL &#8220;MD</em>INTTM0EQ0&#8243;
<code>??MD_INTTM0EQ0??INTVEC 640</code> SYMBOL &#8220;??INTVEC 640&#8221;, MD_INTTM0EQ0
~~~
But 0x640 is the interrupt vector for INTDMA1.
It needs to be 0x430 for the needed INTTM0EQ0 interrupt.
I&#8217;ve changed it and now it works.
The changes need to be done in  portasm.s85
~~~
; Tick ISR Prototype
;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;
        PUBWEAK <code>??MD_INTTM0EQ0??INTVEC 0x430</code>
        PUBLIC MD_INTTM0EQ0
MD<em>INTTM0EQ0        SYMBOL &#8220;MD</em>INTTM0EQ0&#8243;
<code>??MD_INTTM0EQ0??INTVEC 0x430</code> SYMBOL &#8220;??INTVEC 0x430&#8221;, MD_INTTM0EQ0
~~~
and
~~~
;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;
        COMMON INTVEC:CODE:ROOT(2)
        ORG 0x430
<code>??MD_INTTM0EQ0??INTVEC 0x430</code>:
        JR MD_INTTM0EQ0
~~~
Everything seems to be working right now.
