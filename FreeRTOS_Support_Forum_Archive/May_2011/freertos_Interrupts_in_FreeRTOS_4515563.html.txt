Earlier I have developed the servo code in&nbsp; a separate control loop program and confirmed that it worked. However when I put them into the RTOS it don&#8217;t work, the servo simply don&#8217;t move. Also mounted on the servo is an IR sensor connected to an external interrupt pin. To test code, I connected the PIC32 to the PC via USB the program is working, the MPLAB output display window showed the task switching, the various ISRs being entered and the IR sensor &#40;ext interrupt&#41; is working &#40;I coded it to blink an LED when interrupted&#41;. So I am not sure what went wrong I was hoping those with more experience can point out my mistakes, code below:

</div></div><div class="thread-post"><h3 class="thread-post-title">Interrupts in FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/tacadia">tacadia</a> on May 4, 2011</div><div class="thread-post-content">Hi there,  
Here are a few things that you might want to look into:  
1&#41; Ensure that no interrupts are firing before the scheduler starts.<br />
2&#41; Ensure that any interrupts that are using FreeRTOS APIs are below that of FreeRTOS&#8217; configMAX&#95;SYSCALL&#95;INTERRUPT&#95;PRIORITY.<br />
3&#41; Ensure that you have enough stack space for each of your created Task.  
Just curious, are your Tick Interrupts coming in?  
Cheers,<br />
Ivan
