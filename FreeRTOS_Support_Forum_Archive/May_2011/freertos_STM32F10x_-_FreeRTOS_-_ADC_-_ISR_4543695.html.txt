  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">STM32F10x &#8211; FreeRTOS &#8211; ADC &#8211; ISR</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/valeriogiampa">valeriogiampa</a> on May 24, 2011</div><div class="thread-post-content">Dear Collegue,<br />
I have to use an ADC integrated into the STM32F10x microcontroller.<br />
The firmware application is based of STM32 Peripheral Library and FreeRTOS Porting for STM32 Arm Cortex M3 RTOS.<br />
I have to configure the ADC to operate in single channel continuous conversion mode.<br />
i would select the ouuput data of the ADC with the ADC Interrupt service routine.<br />
I don&#8217;t know How I can configure the ADC Interrupt and How I can generate an OS Signal in the ADC ISR to start the task.<br />
Can yu help me?<br />
In addition I would like to know if I can use in alternative at the ADC ISR, a DMA to transfer the ADC Output data into the memory without CPU load and How I can do it.  
</div></div><div class="thread-post"><h3 class="thread-post-title">STM32F10x &#8211; FreeRTOS &#8211; ADC &#8211; ISR</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on May 24, 2011</div><div class="thread-post-content">If you have questions about setting up STM32 ADC conversions, then read the STM32 manual, look at the examples ST give you, and then if you are stuck ask on an STM32 forum. This is a FreeRTOS forum.  
Hidden in your question is a sub question about how to generate an OS signal to start a task. Every FreeRTOS port has its own demo project, and each demo project includes an interrupt definition that demonstrates what you want to do. Have a look at that first, read the FreeRTOS tutorial books, and inspect the queue and semaphore API function descriptions on the web site &#40;look at the ones that end in the text FromISR&#41;. When you have done all that, if you cannot get it to work, then ask again with information on what you have tried and what the problem is.  
Until that time, I don&#8217;t think anybody here is going to put any time into answering such an open question when all the information you need is already provided.
