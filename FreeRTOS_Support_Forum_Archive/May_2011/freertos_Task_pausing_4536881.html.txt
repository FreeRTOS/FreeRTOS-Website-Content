  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Task pausing </h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/sly76">sly76</a> on May 19, 2011</div><div class="thread-post-content">Hi I have a system that, at the moment dose not use preemption &#40;that may come later&#41; so I want the task to pause &#40;not a timed delay&#41; in order to let the other tasks run. From what I can see I have 2 options, vTaskDelay&#40;0&#41; or taskYIELD&#40;&#41;.  
1, Does vTaskDelay&#40;0&#41;, with delay = 0, give the behaviour as taskYIELD&#40;&#41;?<br />
2, Do either of these let all tasks, of all priorities, to run before resuming the calling task?<br />
3, If not, will ALL tasks of the same priority be given the chance to run before resuming the calling task?  
Thanks for any help  
simon 
</div></div><div class="thread-post"><h3 class="thread-post-title">Task pausing </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on May 19, 2011</div><div class="thread-post-content">vTaskDelay&#40;0&#41; and taskYIELD&#40;&#41; will have the same end behavior, but vTaskDelay&#40;0&#41; will take longer to run. Both will force a switch to another ready task that has an identical priority, neither will allow a task that has a lower priority to run. You can call vTaskDelay&#40;&#41; with a non zero value if you need tasks that have a lower priority to run.
</div></div><div class="thread-post"><h3 class="thread-post-title">Task pausing </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/sly76">sly76</a> on May 19, 2011</div><div class="thread-post-content">Thanks Dave,  
Just to clarify, will ALL tasks of the same priority &#40;and in the ready state&#41; run before the calling task resumes?  
</div></div><div class="thread-post"><h3 class="thread-post-title">Task pausing </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on May 19, 2011</div><div class="thread-post-content">Yes, they should do.
