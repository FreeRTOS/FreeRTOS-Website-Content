What could be happening&#8230;?
Thanks for any help on this.

</div></div><div class="thread-post"><h3 class="thread-post-title">After Running USB OTG Code, FreeRTOS hangs / WDT Reboot</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 8, 2015</div><div class="thread-post-content">If it is hitting a default handler, then an interrupt has occurred, but 
there is no handler installed for the interrupt.
If it is the svc instruction in prvPortStartFirstTask() that is causing 
it to execute the default handler, then it sounds like the FreeRTOS 
interrupts are no longer in the vector table &#8211; perhaps the vector base 
address has been changed.
If it is not the svc instruction then could it possibly be a USB interrupt?
The next thing you are going to have to do is work out which interrupt 
was triggered, and caused the default interrupt handler to be executed.
