  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">SAM7 IAR demo fails at restart</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on August 23, 2005</div><div class="thread-post-content">I have the sam7s-ek evaluation board, and I run the freeRTOS demo for this. I can build it and load it into flash and run: runs OK. I can stop it using the debugger, and run again: OK. But, if I reset it with the debugger it will crash on restart, shortly after line &quot;AT91C&#95;BASE&#95;AIC-&gt;AIC&#95;EOICR = 0;&quot;
Any explanations and solutions?
Thanks in advance
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7 IAR demo fails at restart</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on August 23, 2005</div><div class="thread-post-content">Try removing the line.&nbsp; It might not be needed with later IAR releases.
Also check what your JTAG startup script is doing.&nbsp; Does it disable interrupts before the code starts.&nbsp; It could be that the timer interrupt is still running when you reset the code.
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7 IAR demo fails at restart</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jra01">jra01</a> on August 23, 2005</div><div class="thread-post-content">I tried to remove the line, and nothing worked. I have also made the guess that some interrupt is pending. I will have a special look at timer.
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7 IAR demo fails at restart</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jra01">jra01</a> on September 20, 2005</div><div class="thread-post-content">Now I tried to add things to IAR:s startup code:
Adding
&nbsp;&nbsp;&nbsp; &#42;AT91C&#95;AIC&#95;IDCR = 0xffffffff;&nbsp;&nbsp;&nbsp; // disable all irq
&nbsp;&nbsp;&nbsp; &#42;AT91C&#95;AIC&#95;ICCR = 0xffffffff; // clear all pending irq:s
last in the function &quot;AT91F&#95;LowLevelInit&quot;, in CStartup&#95;SAM7.c.
This disables all interrupts, and resets any pending ones. And it helps&#33;
Regards
Jokke
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7 IAR demo fails at restart</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on September 20, 2005</div><div class="thread-post-content">It appears that the macro file used with the J-Link has a function missing.&nbsp; Add the following lines to the file SAM7.mac &#40;if using the SAM7X demo, or equiv for the S demo &#8211; just search for a .mac file in the FreeRTOS directory to find the right one&#41;.
&#45;- start of code to add
// Reset the AIC upon a software reset.
execUserReset&#40;&#41;
&#123;
&nbsp;&nbsp; AIC&#40;&#41;;
&nbsp;&nbsp; Watchdog&#40;&#41;;
&#125;
&#45;- end of code to add
This will then do what is required automatically when you click the reset button on the IDE.
