Using the non-preemtive scheduler works fine. Task switch in FIFO occures in an infinit loop.  
In preemtive mode triggered on a Timer0 results in an Hard-Fault exception &#8220;undef handler&#8221; respectively at an critical memory location.<br />
Each Task will only run for one Time in creating order at same priority for each task.<br />
The tasks switch correctly at the RTOS-Tick.  
If I add one more task &#8211; it goes through 3 tasks…through 4 tasks…5 tasks… and so on.
