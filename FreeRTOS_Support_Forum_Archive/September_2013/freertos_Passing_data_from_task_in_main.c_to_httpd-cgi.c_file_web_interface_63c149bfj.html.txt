What is it that is declared in main.c that you need access to?  Is it a const structure, or a structure that is dynamically updated at run time?
If it is a const structure then presumably you could move the definition of the structure into httpd-cgi.c?
If it is a structure that is dynamically updated then do you need access to the whole structure in httpd-cgi.c or just certain data values.  If it is just certain data values then you could add in some get() functions, like:
uint32<em>t get</em>value( uint32_t ulValueId );
to return the data associated with ulValueId.

</div></div><div class="thread-post"><h3 class="thread-post-title">Passing data from task in main.c to httpd-cgi.c file / web interface</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 1, 2013</div><div class="thread-post-content">Queue handles are just variables, so have the same scope as any other variable.  If you declare Global<em>Queue</em>Handle in one file, you need to extern it in any other file that wants to use it.
For example, if main.c contains the following code:
<pre>
#include "FreeRTOS.h"
#include "queue.h"
xQueueHandle Global_Queue_Handle = NULL;
void main( void )
{
   /* Some code... */
    Global_Queue_Handle = xQueueCreate( ... );
    vTaskStartScheduler();
}
</pre>
Then you want to access Global<em>Queue</em>Handle in another file:
<pre>
#include "FreeRTOS.h"
#include "queue.h"
extern xQueueHandle Global_Queue_Handle;
void SomeFunctionOrOther()
{
    if( Global_Queue_Handle != NULL )
    {
        xQueuePeek( Global_Queue_Handle, ... );
    }
}
</pre>
Regards.
