  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Can not run FreeRTOS demo using DS-5 RTSM</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kbshibukumar">kbshibukumar</a> on September 10, 2013</div><div class="thread-post-content">Hi,<br />
I am new to FreeRTOS and trying to run the demo <strong>CORTEX&#95;A9&#95;RZ&#95;R7S72100&#95;IAR&#95;DS-5</strong> using** DS-5** compiler and <strong>RTSM</strong> simulator &#40;for Cortext A9&#41;. The code compiles properly and on trying to run, it reaches the initialization of interrupt vector table &#40;in file vector&#95;table.s&#41;. However, on trying to step through the code, it gives the following error.<br />
<em>ERROR&#40;CMD440-TAD10-NAL23&#41;:<br />
&#33; Stepping failed<br />
&#33; Failed to read 4 bytes from address S:0x20031958<br />
&#33; Memory read from model failed.</em>  
A screen shot is given below.  
<img src="https://picasaweb.google.com/108715295993987276483/20130909?noredirect=1#5921869221318048418" alt="" />  
It seems that the loading has not been done to the correct address. The memory address <strong>0x20031958</strong> seems to be acquired from the file <strong>Debug/FreeRTOS&#95;Demo.map</strong>, but it is generated by the compiler.  
Any idea how I can get around this error and run the demo?  
Thanks in advance,  
Shibu kumar K B
</div></div><div class="thread-post"><h3 class="thread-post-title">Can not run FreeRTOS demo using DS-5 RTSM</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on September 10, 2013</div><div class="thread-post-content">It doesn&#8217;t sound like your problem is actually FreeRTOS related, but compile/link related.&nbsp; At the point in the code you get the issue the kernel is not actually running.  
I would be very interested in getting a project running in RTSM because it will allow people to try the RZ port without needing any special hardware.&nbsp; The demo in the FreeRTOS download at the moment is configured to run on hardware that is not available to the general community.  
Can you create a new &#8220;hello world&#8221; style project &#40;without FreeRTOS&#41; that runs in RTSM?&nbsp; Once that is running then the FreeRTOS files can be added in.
