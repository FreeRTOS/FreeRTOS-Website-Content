  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS port to PIC18LF45K22 anyone?</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/robertberger">robertberger</a> on July 12, 2011</div><div class="thread-post-content">Hi,  
I&#8217;m playing with the idea of porting FreeRTOS 7.0.1 to a PIC18LF45K22 with MPLAB and friends as my time permits.  
I know that this architecture is suboptimal for a RTOS, but was wondering if someone has done something similar already or if someone would be interested in a joint porting effort.  
The code will be contributed to the community.  
What I&#8217;ve found so far:  
&#42;&#41;&nbsp; In the &#8220;standard FreeRTOS download&#8221;: PIC18&#95;MPLAB which targets a PIC18F452  
&#42;&#41;&nbsp; in the community contributions: <a href="http://interactive.freertos.org/entries/304854-freertos-ported-to-pic18f4520">http://interactive.freertos.org/entries/304854-freertos-ported-to-pic18f4520</a> which targets the PIC18F4520  
&#42;&#41; in the community contributions: <a href="http://interactive.freertos.org/entries/271252-freertos">http://interactive.freertos.org/entries/271252-freertos</a> which targets the PIC18F4520  
&#40;did not yet investigate what&#8217;s the difference between the two&#41;  
My understanding is, that for the PIC18LF45K22 at least some more tweaking for the memory banks is needed.  
Please advise.  
Regards,  
Robert
