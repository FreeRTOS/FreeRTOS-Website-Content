</div></div><div class="thread-post"><h3 class="thread-post-title">Using FreeRTOS on Win7 using VC++ , managed to create a simple project but getting errors?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on January 28, 2015</div><div class="thread-post-content"><blockquote>
  the project is very complex for me to understand
</blockquote>
I think the documentation page for that demo needs updating because the same project is used to build both a complex example and a simple blinky example.  Although that is described at the top of the project&#8217;s main() file I think:
<pre><code>
/* This project provides two demo applications.  A simple blinky style project,
and a more comprehensive test and demo application.  The
mainCREATE_SIMPLE_BLINKY_DEMO_ONLY setting is used to select between the two.
The simply blinky demo is implemented and described in main_blinky.c.  The more
comprehensive test and demo application is implemented and described in
main_full.c. */
#define mainCREATE_SIMPLE_BLINKY_DEMO_ONLY  0
</code></pre>
If you set mainCREATE<em>SIMPLE</em>BLINKY<em>DEMO</em>ONLY to 1 then main_blinky.c is used.  That creates one queue and two tasks &#8211; and nothing else.
<blockquote>
  vPrintString 
</blockquote>
I think that is a function that is used in the book examples, it is not a FreeRTOS nor a MSVC function.
<blockquote>
  i replaced it with printf
</blockquote>
printf() makes Windows system calls, which can mess up the scheduling, but in your simple case it should not be too much of a problem.
However, you will need to protect it if both tasks are calling it simultaneously &#8211; something like:
vTaskSuspendAll();
printf();
fflush(); /* May not be required in MSVC, is required in MingW. */
xTaskResuleAll();
I think that is what vPrintString() did in the book examples.
or alternatively, protect it with a mutex.
I&#8217;m not sure what you have mainDELAY<em>LOOP</em>COUNT set to, but on a modern PC it will have to be massive to make a noticeable delay.  You are better off calling <a href="http://www.freertos.org/a00127.html">vTaskDelay()</a>.
<blockquote>
  Download Link is as follow, copy and paste it in browser and please help
</blockquote>
I&#8217;m not going to do that (not without charging you a consultancy fee, anyway ;o), but if you post the errors to this thread we may be able to help.
Regards.

</div></div><div class="thread-post"><h3 class="thread-post-title">Using FreeRTOS on Win7 using VC++ , managed to create a simple project but getting errors?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on January 29, 2015</div><div class="thread-post-content"><blockquote>
  error LNK2001: unresolved external symbol _vAssertCalled -> tasks.obj
</blockquote>
Its difficult to add more than the linker is already telling you &#8211; your 
code is calling a function call vAssertCalled() but vAssertCalled() is 
not defined anywhere in your source file.
I guess the first thing you will have done is search the files using 
grep or whatever to see where vAssertCalled is used, found that it was 
in the definition of configASSERT() in FreeRTOSConfig.h, then either 
provided the function or changed configASSERT() so it did something else 
&#8211; so I won&#8217;t suggest you do that now.
<blockquote>
  error LNK2019: unresolved external symbol _vApplicationMallocFailedHook
</blockquote>
I guess here you would have googled vApplicationMallocFailedHook, found 
other people asking the same question, and found the following 
documentation page: http://www.freertos.org/a00016.html which tells you 
how to use and define it &#8211; so I won&#8217;t suggest you do that now.
<blockquote>
  referenced in function <em>pvPortMalloc heap</em>5.obj
  Error 8 error LNK2019: unresolved external symbol
  _ulGetRunTimeCounterValue referenced in function _uxTaskGetSystemState
</blockquote>
Again I guess you will already have done two things to help yourself 
here.  First search the source files to see where this function is, and 
found the preprocessor definitions required to include the function, and 
Googled the function to find the following documentation page: 
http://www.freertos.org/uxTaskGetSystemState.html which will also give 
you information &#8211; so I won&#8217;t suggest you do that now.
<blockquote>
  Error 10 error LNK2019: unresolved external symbol _vApplicationTickHook
  referenced in function _xTaskIncrementTick tasks.obj
</blockquote>
As above.
So I guess, if you have done all these simple things yourself already, 
you won&#8217;t have these build errors any more.
Regards.
