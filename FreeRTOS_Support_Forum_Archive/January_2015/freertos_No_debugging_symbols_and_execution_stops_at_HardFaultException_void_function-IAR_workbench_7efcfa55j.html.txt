  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">No debugging symbols and execution stops at &#8220;HardFaultException(void)&#8221; function-IAR workbench</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/aruns06">aruns06</a> on January 1, 2015</div><div class="thread-post-content">Hi,
I am trying to run a demo freeRTOS project CORTEX<em>STM32F103</em>IAR. I was able to compile and upload it in to STM32F1 discovery board. (<a href="http://www.st.com/web/en/catalog/tools/FM116/SC959/SS1532/PF250863?sc=stm32-discovery">http://www.st.com/web/en/catalog/tools/FM116/SC959/SS1532/PF250863?sc=stm32-discovery</a>). In normal case I have to press the &#8220;>>>&#8221; go button to start the execution. But in this example the soon after the uploading is completed, it is going to the execution mode, not giving the room to press the go button. When I &#8220;Break&#8221; the execution, it stops at a function called void HardFaultException(void). The execution never comes out of this function. Any suggestions???
Regards,
Arun.S
</div></div><div class="thread-post"><h3 class="thread-post-title">No debugging symbols and execution stops at &#8220;HardFaultException(void)&#8221; function-IAR workbench</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on January 1, 2015</div><div class="thread-post-content">I expect it is trying to run to main() then crashing before it ever gets there. Look in the debug options for the project and uncheck &#8216;run to main&#8217; then try again. You should then be able to step through the code to see where it crashes.
