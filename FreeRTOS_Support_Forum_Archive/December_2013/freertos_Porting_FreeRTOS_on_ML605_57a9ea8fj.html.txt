http://www.freertos.org/a00016.html
<blockquote>
  ./src/port.o: In function <code>xPortStartScheduler':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/port.c:277: undefined reference 
  to</code>vApplicationSetupTimerInterrupt&#8217;
</blockquote>
Search for vApplicationSetupTimerInterrupt() on the documentation page for your port:
http://www.freertos.org/Free-RTOS-for-Xilinx-MicroBlaze-on-Spartan-6-FPGA.html
<blockquote>
  C:RworkspaceDaUDPaRTOSlwip<em>echo</em>server_0Debug/../src/port.c:288: undefined reference 
  to `vPortStartFirstTask&#8217;
</blockquote>
vPortStartFirstTask() is defined in port.S, which is in the same directory and port.c, and must also be included in your build.
<blockquote>
  ./src/port.o: In function <code>vPortYield':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/port.c:315: undefined reference 
  to</code>VPortYieldASM&#8217;
</blockquote>
vPortYieldASM is also in Port.S
<blockquote>
  ./src/port.o: In function <code>vPortTickISR':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/port.c:424: undefined reference 
  to</code>vApplicationClearTimerInterrupt&#8217;
</blockquote>
Refer to port documentation page &#8211; link provided already above.
<blockquote>
  ./src/port.o: In function <code>prvInitialiseInterruptController':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/port.c:447: undefined reference 
  to</code>vPortExceptionsInstallHandlers&#8217;
</blockquote>
Refer to port documentation page &#8211; link provided already above.
<blockquote>
  ./src/tasks.o: In function <code>vTaskStartScheduler':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/tasks.c:1239: undefined 
  reference to</code>vMainConfigureTimerForRunTimeStats&#8217;
  ./src/tasks.o: In function <code>uxTaskGetSystemState':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/tasks.c:1510: undefined 
  reference to</code>ulMainGetRunTimeCounterValue&#8217;
  ./src/tasks.o: In function <code>xTaskIncrementTick':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/tasks.c:1683: undefined 
  reference to</code>ulMainGetRunTimeCounterValue&#8217;
</blockquote>
These three are complaining that you have your FreeRTOSConfig.h header file set to use run time stats gathering, but have not provided the kernel with the source of the run time counter.
http://www.freertos.org/rtos-run-time-stats.html
<blockquote>
  ./src/tasks.o: In function <code>vTaskSwitchContext':
  C:RworkspaceDaUDPaRTOSlwip_echo_server_0Debug/../src/tasks.c:1842: undefined 
  reference to</code>vApplicationStackOverflowHook&#8217;
</blockquote>
This is complaining that you have configCHECK<em>FOR</em>STACK_OVERFLOW set to a non-zero value, but you have not provided the vApplicationStackOverflowHook() function.
http://www.freertos.org/Stacks-and-stack-overflow-checking.html
<blockquote>
  C:RworkspaceDaUDPaRTOSlwip<em>echo</em>server_0Debug/../src/tasks.c:2088: undefined 
  reference to `vApplicationIdleHook&#8217;
</blockquote>
This is complaining that you have configUSE<em>IDLE</em>HOOK set to a non-zero value in FreeRTOSConfig.h, but have not provided the vApplicationIdleHook() function &#8211; see the same link already provided somewhere above to the kernel hook functions documentation page.
A lot of these look like you have taken a FreeRTOSConfig.h header file from an application that defined quite a rich set of functionality, but your current application does not currently provide the same hooks into that functionality.
