</div></div><div class="thread-post"><h3 class="thread-post-title">xTaskGetTickCount always returns 0</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/hs2sf">hs2sf</a> on May 28, 2017</div><div class="thread-post-content">Question is if the SysTick interrupt / its ISR is properly installed.
Note that this is port / BSP specific.
For STMF4 ie. Cortex-M4 architecture you have to prepare the exception vector table containing the interrupt handlers used by your application.
It should at least contain the entries required by FreeRTOS to run.
These are defined in your FreeRTOSConfig.h:
~~~
/* Definitions that map the FreeRTOS port interrupt handlers to their CMSIS standard names. */
<h1>define vPortSVCHandler     SVC_Handler</h1>
<h1>define xPortPendSVHandler  PendSV_Handler</h1>
<h1>define xPortSysTickHandler SysTick_Handler</h1>
~~~
