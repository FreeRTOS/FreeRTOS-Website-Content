  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Accessing scheduler list</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dioghenes-0">dioghenes-0</a> on May 14, 2017</div><div class="thread-post-content">Hi all,
I need to write an application that is able to make FreeRTOS to fail under fixed conditions. To do so I need to access the scheduler List_t structure &#8216;pxReadyTasksLists&#8217;, in order to get data about TCBs and stacks of the started tasks, but looking at the code, the list I&#8217;m interested into is defined in tasks.c and so not visible to the programmer. Is there a good and elegant way to access to those data?
Thank you in advance.
</div></div><div class="thread-post"><h3 class="thread-post-title">Accessing scheduler list</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on May 14, 2017</div><div class="thread-post-content">A quick answer: there are more than 25 trace macros&#8217;s that you can fill in, for example:
~~~
 traceTASK<em>INCREMENT</em>TICK( xTickCount );
 traceTASK<em>SWITCHED</em>OUT();
 traceTASK<em>SWITCHED</em>IN();
~~~
You can define them in your <code>FreeRTOSConfig.h</code>.
Another trick you could do is include your own code into task.c, e.g. after the last declaration and macro definition:
~~~
    #include &#8220;my<em>testing</em>module.c&#8221;
~~~
When you mess up the code, no warranty is given, of course. Good luck
</div></div><div class="thread-post"><h3 class="thread-post-title">Accessing scheduler list</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dioghenes-0">dioghenes-0</a> on May 14, 2017</div><div class="thread-post-content">Uhm&#8230;there is no way, for example, to modify some field of some elements of pxReadyTasksLists without modifying the code of FreeRTOS? I ask because trace macros allow me only to &#8216;react&#8217; to events while I need to access data in writing mode. I have tried with a &#8216;dirty&#8217; trick: I have removed the PRIVILEGED_DATA ahead that list, so that it is accessible from anywhere&#8230;could it be a good way to proceed?
Thank you a lot.
</div></div><div class="thread-post"><h3 class="thread-post-title">Accessing scheduler list</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on May 14, 2017</div><div class="thread-post-content">It <strong>is</strong> dirty and risky to write e.g. in <code>pxReadyTasksLists</code>. There are many limitations on what you can do safely. One thing is for sure: things that <strong>might</strong> go wrong, certainly  <strong>will</strong> go wrong.
The structure and objects have been kept local and <code>static</code> to avoid users from getting access to them.
