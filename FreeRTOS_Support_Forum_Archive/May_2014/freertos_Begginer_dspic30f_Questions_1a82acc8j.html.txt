</div></div><div class="thread-post"><h3 class="thread-post-title">Begginer dspic30f Questions</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on May 10, 2014</div><div class="thread-post-content"><blockquote>
   i cant understand how to set port data with a task
</blockquote>
There are lots of examples of flashing LEDs. In its simplest form
void flash<em>task( void *x ) {
  while(1){
    vTaskDelay(100);
    toggle</em>led();
  }
}
toggle_led() is the function you write to write to the port.
<blockquote>
  the second question is
</blockquote>
As I remember you can set bits in the source code or in the MPLAB project, but not both. If the project defines the bits in the source code and you want to set them in the project then I guess you will have to delete something. Read the documentation for MPLAB.
</div></div><div class="thread-post"><h3 class="thread-post-title">Begginer dspic30f Questions</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/leviatan1">leviatan1</a> on May 10, 2014</div><div class="thread-post-content">FreeRTOS does not set anything for the cpu clock? i mean if i don&#8217;t do it, the FreeRTOS source code does not set anything that has to do with config bits?

</div></div><div class="thread-post"><h3 class="thread-post-title">Begginer dspic30f Questions</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on May 10, 2014</div><div class="thread-post-content">FreeRTOS does not do anything to &#8220;setup&#8221; your basic processor, except for those things that it exclusively uses. It will configure the tick timer and related interrupt.
You need to configure the rest of the processor in the manner that you need.
If you are not familiar with the processor, I would suggest that you look at the basic Microchip provided examples to understand how the processor works, and how to write code for it.
