</div></div><div class="thread-post"><h3 class="thread-post-title">How to install Freertos OS on the Renesas RZ/A1 card</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on May 14, 2014</div><div class="thread-post-content">Currently the official FreeRTOS demos for the RZ are executing on an internal development board, which is not publicly available, rather than the official RZA1 RSK.  However the demo makes little use of anything other than the core itself, and should be relatively easy to run on any RZ hardware:
http://www.freertos.org/Renesas<em>RZ</em>Cortex-A9-RTOS.html
http://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html
FreeRTOS is statically linked into the application, so does not require any special boot procedure.  The official demo runs the init code provided by Renesas then calls main() driver from the reset vector.  main() then creates tasks and starts the scheduler as normal for FreeRTOS application.
In the case of the demo (as I recall) the application is just downloaded to RAM via JTAG, then either executed or debugged from there.  Obviously that means the application is not maintained in memory across power cycles.  If you wanted a FreeRTOS application to boot up from cold then you would need some way of either programming it into Flash and running it from there, or have a loader copy it from flash and run it from RAM &#8211; how that is done is specific to your hardware, and is not dependent on FreeRTOS as it would be done in the same way as if you had a completely bare metal application with no OS at all.
Regards.
