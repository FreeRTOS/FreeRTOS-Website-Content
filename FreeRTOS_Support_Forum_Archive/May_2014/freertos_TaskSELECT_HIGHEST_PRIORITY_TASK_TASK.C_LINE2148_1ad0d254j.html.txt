</div></div><div class="thread-post"><h3 class="thread-post-title">TaskSELECT_HIGHEST_PRIORITY_TASK TASK.C LINE2148</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on May 5, 2014</div><div class="thread-post-content">taskSELECT<em>HIGHEST</em>PRIORITY_TASK() is not a function, but a macro, which is defined at the top of tasks.c, which is also the file the macro is called from, so I don&#8217;t know why the compiler would output such a warning.
What taskSELECT<em>HIGHEST</em>PRIORITY<em>TASK() actually does depends on the value of configUSE</em>PORT<em>OPTIMISED</em>TASK<em>SELECTION in FreeRTOSConfig.h.  Do you define configUSE</em>PORT<em>OPTIMISED</em>TASK_SELECTION in FreeRTOSConfig.h?  If so, what is is set to?
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">TaskSELECT_HIGHEST_PRIORITY_TASK TASK.C LINE2148</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/luisdanieldorta">luisdanieldorta</a> on May 6, 2014</div><div class="thread-post-content">Thanks,
configUSE<em>PORT</em>OPTIMISED<em>TASK</em>SELECTION is already define in FreeRTOSConfig.h
With configUSE<em>PORT</em>OPTIMISED<em>TASK</em>SELECTION set to 1 the warning appears, but set to 0 there is not warning.
The compiler version of CCS5 is TI v4.9.5. and the device i am working is a TI RM48l950.

</div></div><div class="thread-post"><h3 class="thread-post-title">TaskSELECT_HIGHEST_PRIORITY_TASK TASK.C LINE2148</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on May 6, 2014</div><div class="thread-post-content">__clz() is a compiler intrinsic &#8211; that is &#8211; it is provided by the compiler not by FreeRTOS.  I&#8217;m not sure why it is not finding the definition, maybe it is just related to a compiler version updated?  It might be that the name of the intrinsic has changed, try looking it up in the compiler&#8217;s documentation.  Alternatives would be to:
1) Ask TI about it, maybe on an TMS570/RM48 forum, or on a CCS forum.
2) Implement the function yourself.  You just need a few lines of assembly code that executes the clz instruction and returns the result.
3) Just set configUSE<em>PORT</em>OPTIMISED<em>TASK</em>SELECTION to 0.
Regards.
