</div></div><div class="thread-post"><h3 class="thread-post-title">Preemptive scheduling  </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/markwrichardson">markwrichardson</a> on July 9, 2014</div><div class="thread-post-content">This was my first mistake too.  I haven&#8217;t used any other small RTOSes, but it was hard to adjust my brain to remember that the delay in task create is the only initial delay.  Afterwards, the task itself must regulate it&#8217;s own loop rate or block while waiting on some flag.  
The task has it&#8217;s own stack and the locals there are persistent.  Returning from a task will crash the system because there is no return value on the stack for the task-function to return to.
Your sample will probably blink all four LEDs evenly 500ms On, 500 ms Off.
