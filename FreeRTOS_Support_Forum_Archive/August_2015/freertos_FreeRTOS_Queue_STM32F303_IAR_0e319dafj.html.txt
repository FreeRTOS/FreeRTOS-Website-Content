</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS Queue + STM32F303 + IAR</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on August 1, 2015</div><div class="thread-post-content">You are declaring an AxedRaw<em>t structure on the stack, filling it with data, then using xQueueSendToBack() to copy the structure into the queue &#8211; that should be fine provided the queue was created so each space in the queue can hold an AxesRaw</em>t structure.  However you are creating the queue using a call to GyroRawDataQueueHandle(), and I have no idea what that is doing as it is not a FreeRTOS function.  Can you try using xQueueCreate(), so I can see how the queue is being created, as then if you still have a problem I will be able to advise if the queue is being created correctly for how it is being used.
Regards.
