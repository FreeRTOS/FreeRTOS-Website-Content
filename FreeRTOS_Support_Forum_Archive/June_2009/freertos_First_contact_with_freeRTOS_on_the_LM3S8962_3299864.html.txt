</div></div><div class="thread-post"><h3 class="thread-post-title">First contact with freeRTOS on the LM3S8962</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on June 11, 2009</div><div class="thread-post-content">If you have removed these lines from the Source= list then you should not get these problems. You don&#8217;t need to keep the high frequency timer in, that generates a 20KHz interrupt for test and demo only.

However, I have a new problem of undefined reference for &#8216;xFirstTimerHandler&#8217; and &#96;xSecondTimerHandler&#8217; in IntQueueTimer.c, caused by the deletion of&nbsp; &quot;$&#40;DEMO&#95;COMMON&#95;DIR&#41;/IntQueue.c&quot; from the Makefile. I thought that IntQueueTimer.c was neither needed as it simply introduces some timer tests but, before removing this file from the project, I need to change the vector table in startup.c. Which values should I place instead of vT2InterruptHandler, vT3InterruptHandler and Timer0IntHandler? I guess the answer is &quot;IntDefaultHandler&quot; but I&#8217;d like to be sure.

Daniel.
</div></div><div class="thread-post"><h3 class="thread-post-title">First contact with freeRTOS on the LM3S8962</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on June 12, 2009</div><div class="thread-post-content">The interrupt queue test is different to the high frequency timer test and is split into two &#8211; the code that is common to all ports and the interrupt setup/handler code that is specific to a port.&nbsp; You can remove both files from the build &#40;I think you have done this already&#41;.
$&#40;DEMO&#95;COMMON&#95;DIR&#41;/IntQueue.c and
./IntQueueTimer.c
are the two lines to remove from the makefile.
However&#8230;as you have found removing these files will remove the implementation of the timer interrupt handlers, so you also need to remove references to these from the vector table which is defined in startup.c, and you are correct you can simply replace them with IntDefaultHandler.
Regards.
