</div></div><div class="thread-post"><h3 class="thread-post-title">New Project with 18F452</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jgmartinez">jgmartinez</a> on June 29, 2009</div><div class="thread-post-content">You have copied some files from a project and you did not take in account some others were some funtions are defined in.
If you do not want to play with serial port you can include next code in your main.c file, for example, to remove the error message:
&#35;if &#40;config&#95;USE&#95;SERIAL&#95;PORT&nbsp;&nbsp;&nbsp; == 0&#41;
&nbsp;&nbsp;&nbsp; void vSerialRxISR&#40;void&#41;&#123;&#125;
&nbsp;&nbsp;&nbsp; void vSerialTxISR&#40;void&#41;&#123;&#125;
&#35;endif
Then in FreeRTOSConfig.h file you have to include next line:
&#35;define config&#95;USE&#95;SERIAL&#95;PORT&nbsp;&nbsp;&nbsp; 0
