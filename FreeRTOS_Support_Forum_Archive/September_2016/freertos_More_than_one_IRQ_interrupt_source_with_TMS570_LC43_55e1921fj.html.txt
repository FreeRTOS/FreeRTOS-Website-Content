  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">More than one IRQ interrupt source with TMS570 (LC43)</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/simointe">simointe</a> on September 12, 2016</div><div class="thread-post-content">(TMS570LC4, C++)
I have a fully functionnal FreeRtos implementation on TMS570.
My high frequency interrupt is on FIQ though, and now I want to change it on IRQ.
FreeRtos is on IRQ, are interrupts could be nested and how ?
I have already some assembler code to handle this in « usual C++ function » but I don&#8217;t know how to merge it within the vPortPreemptiveTick and vPortYeildWithinAPI interrupts.
You could refer to a previous post I&#8217;ve done.
https://sourceforge.net/p/freertos/discussion/382005/thread/0caeaa55/#45db 
For others interrupt than FreeRtos, nesting seems to work (no crash at least) puting this 2 little codes before and after:
BEFORE
///        Copy SPSR<em>irq to LR
///        Save SPSR</em>irq
///        Enable IRQ and set System Mode
///        Save LR
//&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8211;
      {                                           
      asm( &#8221; ADD       SP, SP, #8      &#8221; );       
      asm( &#8221; SUB       LR, LR, #4      &#8221; );       
      asm( &#8221; SRSFD     #0x12 !         &#8221; );       
      asm( &#8221; CPS       #0x13           &#8221; );       
      asm( &#8221; PUSH      {R0-R12}        &#8221; );       
      asm( &#8221; FMRX      R5,FPEXC        &#8221; );       
      asm( &#8221; PUSH      {R5}            &#8221; );       
      asm( &#8221; FMRX      R5,FPSCR        &#8221; );       
      asm( &#8221; PUSH      {R5}            &#8221; );       
      asm( &#8221; FSTMDBD   SP!, {D0-D7}    &#8221; );       
      asm( &#8221; MOV       R1, SP          &#8221; );       
      asm( &#8221; AND       R1, R1, #4      &#8221; );       
      asm( &#8221; SUB       SP, SP, R1      &#8221; );       
      asm( &#8221; PUSH      {R1, R14}       &#8221; );       
AFTER
///        Restore LR
///        Disable IRQ (IRQ Mode)
///        Restore SPSR<em>irq to LR
///        Copy LR to SPSR</em>irq
//&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8211;<br />
      asm( &#8221; POP       {R1, LR}       &#8221; );        
      asm( &#8221; ADD       SP, SP, r1     &#8221; );        
      asm( &#8221; FLDMIAD   SP!, {D0-D7}   &#8221; );        
      asm( &#8221; POP       {R5}           &#8221; );        
      asm( &#8221; FMXR      FPSCR, R5      &#8221; );        
      asm( &#8221; POP       {R5}           &#8221; );        
      asm( &#8221; FMXR      FPEXC, R5      &#8221; );        
      asm( &#8221; POP       {R0-R12}       &#8221; );        
      asm( &#8221; CPS       #0x12          &#8221; );        
      asm( &#8221; RFEFD     SP!            &#8221; );

</div></div><div class="thread-post"><h3 class="thread-post-title">More than one IRQ interrupt source with TMS570 (LC43)</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on September 13, 2016</div><div class="thread-post-content">The link was to a generic Cortex-R port which supports interrupt 
nesting.  For historical reasons the RM48/TMS570 port is different, so 
the files are not compatible.
See the &#8220;interrupt service routines&#8221; section of the following page for 
information on adding additional interrupts 
http://www.freertos.org/Free<em>RTOS</em>for<em>TI</em>RM48<em>and</em>TMS570.html
Search for all occurrences of vSCIInterruptHandler in the following file 
to see how an interrupt is defined and installed.
https://sourceforge.net/p/freertos/code/HEAD/tree/trunk/FreeRTOS/Demo/CORTEX<em>R4</em>RM48<em>TMS570</em>CCS5/serial.c

vPortPreemptiveTick:
<pre><code>    ; Save the context of the current task.
    portSAVE_CONTEXT
    ; Clear interrupt flag
    MOVW    R0, #0xFC88
    MOVT    R0, #0xFFFF
    MOV     R1, #1
    STR     R1, [R0]
    ;HERE ????????
    ;Enable int.
