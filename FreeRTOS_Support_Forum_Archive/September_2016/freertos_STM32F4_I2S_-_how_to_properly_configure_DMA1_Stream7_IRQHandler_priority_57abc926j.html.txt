</div></div><div class="thread-post"><h3 class="thread-post-title">STM32F4 (I2S) &#8211; how to properly configure DMA1_Stream7_IRQHandler priority?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on September 5, 2016</div><div class="thread-post-content">I suspect your problem will be with this line:
NVIC<em>InitStructure.NVIC</em>IRQChannelPreemptionPriority = 
configMAX<em>SYSCALL</em>INTERRUPT_PRIORITY;
which is using an unshifted priority value (the priority bits are 
already set in the most significant bits) &#8211; whereas you probably need to 
use an unshifted value (whereas the priority bits are set in the least 
significant bits).  See the following link for more details:
http://www.freertos.org/RTOS-Cortex-M3-M4.html
<blockquote>
  DMA1<em>Stream7</em>IRQHandler
</blockquote>
In this handler it would be more efficient to use a direct to task 
notification than a semaphore.
