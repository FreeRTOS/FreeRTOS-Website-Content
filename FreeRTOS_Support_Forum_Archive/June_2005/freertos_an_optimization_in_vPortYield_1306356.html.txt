</div></div><div class="thread-post"><h3 class="thread-post-title">an optimization in vPortYield()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on June 22, 2005</div><div class="thread-post-content">this definately will not work.&nbsp; SwitchContext must come between save&#95;context and restore&#95;context otherwise you save the context of one task into the tcb of another.
as
1 task a is running.
2 tick happens
3 SwitchContext decides another task &#40;b&#41; should run and switches the current tcb.
4 as your code SwitchContext returns true and save&#95;context is called.
5 save&#95;context saves task a context into task b stack.
6 restore&#95;context then immediately removes task a context from task b stack.
now task a is running but the current tcb is pointing to task b.
