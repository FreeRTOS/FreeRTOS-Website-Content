</div></div><div class="thread-post"><h3 class="thread-post-title">Strange Assembler Error from AT91 USBSample.c</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on June 28, 2005</div><div class="thread-post-content">Hi,
There is actually no official SAM7 GCC port currently.&nbsp; It is not documented and is not mentioned anywhere on the WEB site.
The files in the source/portable/gcc/ARM7&#95;AT91SAM7S directory were created for use with the Rowley CrossStudio tools&nbsp; a &#40;very nice&#41; IDE for the GCC ARM7 compiler.&nbsp; While this port is compiling it has not yet been downloaded onto the target for any testing.&nbsp; I intend to return to and complete this port in the future&nbsp; hence I left it in the source tree but dont reference it anywhere.&nbsp; I think this was a mistake on my part as you are the second person in two days to use it.&nbsp; Also the Rowley tools use their own linker/project files so there is no GCC compatable versions for this port.
Having said that, I will be happy to assist where I can to get it going, but please understand that I cannot support it fully at the moment.&nbsp; There should not be anything particularly new in the files as they are a combination of other ARM7 GCC ports along with the hardware setup from the IAR SAM7 port.
As to what the problem is&nbsp; very unhelpfully, I dont know&#33;&nbsp; There is nothing obviously wrong.&nbsp; The asm output has the line:
mov r3, &#35;-2147483648
which does not look correct, but this is off the bottom of the portEXIT&#95;SWITCHING&#95;ISR&#40;&#41; macro so I dont know where it comes from.
A couple of suggestions:
1&#41; You start with the AT91 GCC port and adapt this for the SAM7.&nbsp; This would allow you to start with the latest build of code &#40;3.1.1&#41; and a working Atmel SAM7 port.&nbsp; The SAM7 GCC files are not up to the latest standard&nbsp; for example portBASE&#95;TYPE is not defined.
or
2&#41; If you could zip up your entire project &#40;makefiles, linker scripts, etc.&#41; and send them to me &#40;email address form the contacts page of the WEB site&#41;, then I could take a look.
Regards.
