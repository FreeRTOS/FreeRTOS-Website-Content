I followed the instructions provided by Stefano from here: <a href="http://developers.stf12.net/linux-demo">http://developers.stf12.net/linux-demo </a>&#40;if ur a windows user a similar then go here <a href="http://developers.stf12.net/eclipse-demo">http://developers.stf12.net/eclipse-demo</a>&#41;&nbsp; Be sure to download the latest OpenOCD &#40;I&#8217;m using 0.4.0&#41; and use the jlink.cfg and &#8216;target&#8217;.cfg that came with the new version &#40;old version .cfg files wont work…&#41;&nbsp;&nbsp; This will be perfect if you&#8217;re using an STM32 microcontroller.&nbsp; However you are not, then get a demo project that is specific to your core and configure the debugger and openocd Stefano&#8217;s way.&nbsp;   
Hope this helps

</div></div><div class="thread-post"><h3 class="thread-post-title">freeRTOS w/ Eclipse and JLink</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/spotdott">spotdott</a> on March 4, 2010</div><div class="thread-post-content">Of course.&nbsp; Here are my config files<br />
jlink.cfg:  
<pre><code>#
# Segger J-Link
#
# http://www.segger.com/jlink.html
#
interface jlink
</code></pre>
stm32.cfg:  
<pre><code># JTAG speed should be &lt;= F_CPU/6. F_CPU after reset is 8MHz, so use F_JTAG = 1MHz
jtag_khz 565
jtag_nsrst_delay 100
jtag_ntrst_delay 100
#jtag scan chain
if { [info exists CPUTAPID ] } {
   set _CPUTAPID $CPUTAPID
} else {
  # See STM Document RM0008
  # Section 26.6.3
   set _CPUTAPID 0x3ba00477
}
jtag newtap $_CHIPNAME cpu -irlen 4 -ircapture 0x1 -irmask 0xf -expected-id $_CPUTAPID
if { [info exists BSTAPID ] } {
   # FIXME this never gets used to override defaults...
   set _BSTAPID $BSTAPID
} else {
  # See STM Document RM0008
  # Section 29.6.2
  # Low density devices, Rev A
  set _BSTAPID1 0x06412041
  # Medium density devices, Rev A
  set _BSTAPID2 0x06410041
  # Medium density devices, Rev B and Rev Z
  set _BSTAPID3 0x16410041
  # High density devices, Rev A
  set _BSTAPID4 0x06414041
  # Connectivity line devices, Rev A and Rev Z
  set _BSTAPID5 0x06418041
}
jtag newtap $_CHIPNAME bs -irlen 5 -expected-id $_BSTAPID1 
    -expected-id $_BSTAPID2 -expected-id $_BSTAPID3 
    -expected-id $_BSTAPID4 -expected-id $_BSTAPID5
set _TARGETNAME $_CHIPNAME.cpu
target create $_TARGETNAME cortex_m3 -endian $_ENDIAN -chain-position $_TARGETNAME
$_TARGETNAME configure -work-area-phys 0x20000000 -work-area-size $_WORKAREASIZE -work-area-backup 0
set _FLASHNAME $_CHIPNAME.flash
flash bank $_FLASHNAME stm32x 0 0 0 0 $_TARGETNAME
# For more information about the configuration files, take a look at:
# openocd.texi
</code></pre>
stm32&#95;gdb.cfg:  
<pre><code># default ports
telnet_port 4444
gdb_port 3333
tcl_port 6666
init
jtag_khz 565
reset init
verify_ircapture disable
</code></pre>
Also, please make sure that you have libusb installed and running Eclipse as root.&nbsp;   
In the External Tools Configurations you should have OpenODB Programmer and OpenODB Server pass in arguments of &#8220;-f jlink.cfg -f stm32.cfg -f stm32&#95;program&#95;eclipse.cfg&#8221; and &#8220;-f jlink.cfg -f stm32.cfg -f stm32&#95;gdb.cfg&#8221;, respectively.&nbsp; Make sure that Eclipse knows where you installed OpenODB.&nbsp; This is also done in the External Tools Configurations&#8217; Main tab under Location&nbsp; &#40;for me it&#8217;s /usr/local/bin/openocd&#41;.&nbsp;   
In Debug Configurations make sure that under the Debugger tab only GDB Command has a value &#40;for me it&#8217;s /home/lsong/CodeSourcery/Sourcery&#95;G++&#95;Lite/bin/arm-none-eabi-gdb&#41; and under the Startup tab only Initialize Commands is filled as follows:  
<pre><code>target extended-remote localhost:3333
b main
monitor soft_reset_halt
monitor sleep 500
continue
clear main
</code></pre>
Hope this will get rid of your error messages.  
Spotdott
