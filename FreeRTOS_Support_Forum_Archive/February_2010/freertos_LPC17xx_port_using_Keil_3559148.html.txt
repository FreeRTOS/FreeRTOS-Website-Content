</div></div><div class="thread-post"><h3 class="thread-post-title">LPC17xx port using Keil</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 19, 2010</div><div class="thread-post-content">The code that comes with the LPC17xx eBook is configured to compile with GCC, and in particular with the LPCXpresso IDE.&nbsp; Am I right in thinking you are trying to compile it with Keil?&nbsp; I would not expect that to work, however the FreeRTOS download contains a port layer for Keil too so if you want to use Keil you would be better off using the Keil port layer directly rather than trying to convert the GCC port layer.  
The book demos rely on the terminal output too &#8211; I&#8217;m not sure what the Keil IDE will do with the terminal output.  
Can you just try using the LPCXpresso IDE?&nbsp; It is a free download.&nbsp; Once you have gone through the book examples you can set up a project using Keil based on one of the standard demos in the main download.
