</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error with lwIP gcc sam7x demo</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 25, 2010</div><div class="thread-post-content">I just tried the same, and found it compiled with no problem but generated the following error while linking:

I have read stuff about this error before and from memory &#40;so might be wrong&#41; there are two things that can cause this.&nbsp; The first is an error in the linker script &#8211; but the linker script worked fine with previous versions of Yagarto.&nbsp; The second is simply that the section &#8220;.eh&#95;frame&#8221; should be stripped out using some command line option or other that I can&#8217;t remember.&nbsp; I think this will require a bit of Googling.

</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error with lwIP gcc sam7x demo</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/bejkarna">bejkarna</a> on February 25, 2010</div><div class="thread-post-content">Thanks a lot for your answer, it now works, I dont know how :&#40; i will try to explain  
I found on yagarto.de that if the message you mentioned about &#8220;.eh&#95;frame&#8221; appears one should add the following to the linker script:  
. = ALIGN&#40;4&#41;;<br />
.eh&#95;frame :<br />
&#123;<br />
KEEP &#40;&#42;&#40;.eh&#95;frame&#41;&#41;<br />
&#125; &gt; ram  
Now I was actually working with two demos: SAM7X WEB Server &amp; USB Mouse Demo<br />
Using Eclipse where I removed the uIP stack and added lwIP from the lwIP demo<br />
and I also tried lwIP demo as I said earlier.  
with the uIP demo the linker script contained the above part but the lwIP did not, so I added it there, this removed the .eh&#95;frame error but new one appeard:   
c:/program files/yagarto/bin/../lib/gcc/arm-elf/4.4.2/../../../../arm-elf/lib/interworklibg.a&#40;lib&#95;a-sbrkr.o&#41;: In function &#96;&#95;sbrk&#95;r&#8217;:<br />
C:msys1.0homeyagartonewlib-buildarm-elfinterworknewliblibcreent/../../../../../../newlib-1.18.0/newlib/libc/reent/sbrkr.c:60: undefined reference to &#96;&#95;sbrk&#8217;<br />
collect2: ld returned 1 exit status  
but I found that the linker script works with memory I increased it as I have at91sam7x512 which has larger memory. this caused that the uip demo &#40;with lwIP implemented&#41; started working. Sadly the lwIP demo does not work as it throws the error mentioned above.  
I am not really sure what I exactly did as I am just begginer, but now it works. Amazing.   
</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error with lwIP gcc sam7x demo</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/bejkarna">bejkarna</a> on February 25, 2010</div><div class="thread-post-content">I changed the following in atmel-rom.ld

ram : ORIGIN = 0x00200000, LENGTH = 64K<br />
&#125;  
&#95;&#95;stack&#95;end&#95;&#95; = 0x00200000 + 64K &#8211; 4;  
to  
MEMORY<br />
&#123;<br />
flash : ORIGIN = 0x00100000, LENGTH = 512K<br />
ram : ORIGIN = 0x00200000, LENGTH = 128K<br />
&#125;
