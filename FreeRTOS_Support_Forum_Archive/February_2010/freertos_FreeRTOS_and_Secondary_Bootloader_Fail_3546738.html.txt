  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS and Secondary Bootloader Fail</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/slicetex">slicetex</a> on February 8, 2010</div><div class="thread-post-content">Hi,  
I cannot get a FreeRTOS system to work from starting<br />
address 0x8000 with a secondary bootloader.<br />
I&#8217;m using a NXP LPC2148 microcontroller.  
My application program crash when vTaskStartScheduler&#40;&#41;<br />
is called.  
If application program is located on flash address 0x0000,<br />
FreeRTOS works.  
Anyone did something like this ?.  
NOTES:  
1&#41; vTaskStartScheduler&#40;&#41; is called in supervisor mode.<br />
Interrupt disabled.  
2&#41; Interrupt vector table is remaped to RAM with MEMMAP=2.<br />
First 64 bytes, from address 0x8000 are copied to RAM<br />
address 0x40000000.  
3&#41; Linker script memory areas:<br />
MEMORY<br />
&#123;<br />
flash &#40;rx&#41;: ORIGIN = 0x00008000, LENGTH = 468K<br />
ram&#95;ivt&#40;rwx&#41;: ORIGIN = 0x40000000, LENGTH = 64<br />
ram &#40;rwx&#41;: ORIGIN = 0x40000040, LENGTH = 32K-64<br />
&#125;  
4&#41; Secondary bootloader, jumps to user program &#40;0x8000&#41;<br />
in supervisor mode also.  
5&#41; FreeRTOS version: 6.0.2  
6&#41; Toolchain: GCC 4.1.1  
7&#41; MCU: LPC2148.  
Thanks in advance.  
Regards,<br />
Boris Estudiez.-
