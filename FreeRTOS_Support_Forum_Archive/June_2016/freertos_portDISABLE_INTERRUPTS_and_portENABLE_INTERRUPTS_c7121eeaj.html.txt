</div></div><div class="thread-post"><h3 class="thread-post-title">portDISABLE_INTERRUPTS and portENABLE_INTERRUPTS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on June 13, 2016</div><div class="thread-post-content">Dont know about your code but these macros always have to work the same way.
portDISABLE<em>INTERRUPTS() -> leave interrupts disabled
portENABLE</em>INTERRUPTS() -> leave interrupts enabled
portSET<em>INTERRUPT</em>MASK<em>FROM</em>ISR() -> leave interrupts disabled and return prior interrupt state, only needed when interrupt nesting is supported otherwise leave undefined
portCLEAR<em>INTERRUPT</em>MASK<em>FROM</em>ISR(x) -> set interrupt state to x, only needed when interrupt nesting is supported otherwise leave undefined
