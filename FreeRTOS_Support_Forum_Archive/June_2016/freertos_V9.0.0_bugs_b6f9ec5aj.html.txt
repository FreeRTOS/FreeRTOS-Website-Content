<pre>
#if configMAX_PRIORITIES < 1

I have changed the FreeRTOS.h file to have.
<pre><code>#ifndef configMAX_PRIORITIES
 #error Missing definition:  configMAX_PRIORITIES must be defined in FreeRTOSConfig.h.  See the Configuration section of the FreeRTOS API documentation for details.
#elif configMAX_PRIORITIES &lt; 1
#error configMAX_PRIORITIES must be defined to be greater than or equal to 1.
#endif
</code></pre>

<pre><code>#define configGENERATE_RUN_TIME_STATS   0

but I hadn't defined the two functions in code.
