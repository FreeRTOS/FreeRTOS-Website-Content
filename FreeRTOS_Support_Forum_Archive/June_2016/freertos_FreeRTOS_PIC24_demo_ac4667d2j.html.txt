</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS PIC24 demo</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on June 30, 2016</div><div class="thread-post-content"><blockquote>
  build/default/production/<em>ext/1472/main.o(.text+0xe6): In function _vApplicationIdleHook&#8217;: : undefined reference to</em>vCoRoutineSchedule&#8217;
</blockquote>
This error tells you vCoRoutineSchedule() is called in the idle hook. As you set configUSE<em>CO</em>ROUTINES to 0 coroutine code will not be built so vCoRoutineSchedule() is undefined. Just remove the call and the error will be fixed.
<blockquote>
  build/default/production/_ext/1163846883/crflash.o
</blockquote>
Same thing. If configUSE<em>CO</em>ROUTINES is 0 you cant build files that use coroutines, so dont build crflash.c.
