</div></div><div class="thread-post"><h3 class="thread-post-title">ISR </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on July 19, 2016</div><div class="thread-post-content"><blockquote>
  portSET<em>INTERRUPT</em>MASK<em>FROM</em>ISR();
  portCLEAR<em>INTERRUPT</em>MASK<em>FROM</em>ISR();
</blockquote>
These are the equivalent of taskENTER<em>CRITICAL() and taskEXIT</em>CRITICAL() for us in ISRs and are used to avoid race conditions. You can call taskENTER<em>CRITICAL</em>FROM<em>ISR() and taskEXIT</em>CRITICAL<em>FROM</em>ISR() too which makes this more obvious. You will find examples of how the functions are used inside the queue.c file.
<blockquote>
  Can System Tick preempt ISR&#8217;s ?
</blockquote>
System tick is an ISR so I think this has already been answered. Normally the system tick is the lowest priority ISR.
</div></div><div class="thread-post"><h3 class="thread-post-title">ISR </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/michaeln32">michaeln32</a> on July 21, 2016</div><div class="thread-post-content">I never use the function memcpy in ISR.
But i use in in tasks.
Is it good or is it bad to use critical section with memcpy in tasks ?
For example :
<pre><code>    portENTER_CRITICAL();
    memcpy(&amp;I2, &amp;I1, sizeof(I1_FLSMsrEvnt));
   portEXIT_CRITICAL();
</code></pre>
</div></div><div class="thread-post"><h3 class="thread-post-title">ISR </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on July 21, 2016</div><div class="thread-post-content">memcpy() itself does not need a critical section.  The only time you 
would need a critical section is if the buffer being memcpy&#8217;ed to or 
from could be accessed by another task while the memcpy operation was in 
progress.
If there are any occasions that you need to use a critical section in an 
interrupt then use taskENTER<em>CRITICAL</em>FROM<em>ISR() and 
taskEXIT</em>CRITICAL<em>FROM</em>ISR() in place of taskENTER<em>CRITICAL() and 
taskEXIT</em>CRITICAL().  See 
http://www.freertos.org/taskENTER<em>CRITICAL</em>FROM<em>ISR</em>taskEXIT<em>CRITICAL</em>FROM<em>ISR.html 
for information on how to use the _FROM</em>ISR() versions.
