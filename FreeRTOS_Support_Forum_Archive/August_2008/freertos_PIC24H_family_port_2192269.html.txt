  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">PIC24H family port</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/macsac">macsac</a> on August 29, 2008</div><div class="thread-post-content">Will the PIC24/dsPIC port work with PIC24H microcontroller ?
The demo is for PIC24F &#8211; it&#8217;s a different family. Has somebody run freeRTOS on PIC24H family ?
I&#8217;ve changed the freeRTOSconfig.h &#40;changed the microcontroller header&#41; and attached the PIC24HJ256GP206 linker script &#40;from MPLAB distro&#41; and everything is compiling.
As I see there are some differences in linker scripts from freeRTOS projects and those from MPLAB distro.
May I use standard linker script from mplab?
Do I need to modify port.c or portmacro.h or something else ?
Thanks
MaciekS
</div></div><div class="thread-post"><h3 class="thread-post-title">PIC24H family port</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on August 29, 2008</div><div class="thread-post-content">Changing the linker script is normal to move from one device to another in the same family, just as moving any program from one device to another.
If the core is the same between the H and F parts then the port should work. ie the register set and instruction set. You may need to change to a different timer unless the H and F parts have the same timer peripheral.
