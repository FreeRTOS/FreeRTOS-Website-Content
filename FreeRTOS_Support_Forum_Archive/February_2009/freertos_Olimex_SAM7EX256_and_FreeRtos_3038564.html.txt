  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Olimex SAM7EX256 and FreeRtos</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jmaeng">jmaeng</a> on February 24, 2009</div><div class="thread-post-content">Hi,
Olimex has an eval board called SAM7EX256 and they promote freertos. I have the board and have downloaded the freertos version 5.1.2. It turns out that Olimex have a code example that is based on freertos version 4.0.2.As the Olimex changes done to version 4.0.2 appeared to be minimal. I attempted to include the changes in version 5.1.2.
The web server page comes up but the network statistics page shows many dropped packages.
I was curious to see if you have any recommendation for what version I should use?
My compile environment is set up with Eclipse and Yagarto.&nbsp; The evaluation is almost working so it may be a minor detail or it could be related to that I am not using the best version for the compiler setup. Have you heard about a similar problem before and if so what did it relate to?
My changes to 5.1.2 are minimal, namely PHY&#95;ID, powerdown bit inversion and PHY address. In addition&nbsp; I adjusted the clock value to 48.054857Mhz.
I see that some Makefiles are using arm&#95;source only and others thumb&#95;arm mixed. Could this relate to the problem with dropped packages? 
Thanks&#33;
&nbsp; JMA
</div></div><div class="thread-post"><h3 class="thread-post-title">Olimex SAM7EX256 and FreeRtos</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on February 25, 2009</div><div class="thread-post-content">ARM or Thumb mode should not make any difference. 
Its always best to use the latest version, but I don&#8217;t think this will make any difference to the dropped packets you are seeing.
Can you step through the code to see why the packets are being dropped, you can search for the code that increments the drop statistic, place a break point there, then work backwards to find the reason? Is there a heavy traffic load on the network.?
