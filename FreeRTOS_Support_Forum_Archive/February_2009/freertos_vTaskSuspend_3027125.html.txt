  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">vTaskSuspend()</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/fkln">fkln</a> on February 20, 2009</div><div class="thread-post-content">I am working with STM32 and GCC. My program have several tasks which communicate with two Queues, a Counting Semaphore and a Mutex. For debugging, I have implemented some of the Trace Hook Macros.
If I do a xQueueReceive&#40;RxQueue, &amp;value, portMAX&#95;DELAY&#41; to an empty queue, I see that the traceTASK&#95;SUSPEND&#40;&#41; macro is active in the actual running task and&nbsp; that this task is restarted at the beginning again.
Is this possible / correct ? 
</div></div><div class="thread-post"><h3 class="thread-post-title">vTaskSuspend()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 21, 2009</div><div class="thread-post-content">I can understand that this would be unexpected, but it is actually correct.
When a task wants to block indefinitely it is actually placed onto the suspended list rather than a blocked list &#8211; this is because tasks on the blocked list must have a timeout.&nbsp; Even thought the suspended list is used, the task is in the Blocked state not the Suspended state.
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">vTaskSuspend()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/fkln">fkln</a> on February 22, 2009</div><div class="thread-post-content">With your explanation the program is now running.
The problem was, that I have taken a Mutex and later I was receiving characters with xQueueReceive&#40;RxQueue, &amp;value, portMAX&#95;DELAY&#41; in the same task. Because the queue was still waiting of more values, the task was suspended and the mutex was lost forever. Perhaps you can add this hint to your FreeRTOS eBook.
Thanks,
Klaus.
</div></div><div class="thread-post"><h3 class="thread-post-title">vTaskSuspend()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/fkln">fkln</a> on February 22, 2009</div><div class="thread-post-content">With your explanation the program is now running.
