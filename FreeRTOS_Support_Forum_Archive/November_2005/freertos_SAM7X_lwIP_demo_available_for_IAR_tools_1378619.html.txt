</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7X  lwIP demo available for IAR tools ???</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on November 3, 2005</div><div class="thread-post-content">Not aware of any such port, but check out Adam Dunkels site for some comparisons &#8211; one of his papers contains a comparison table I think.
Basically lwIP is more featured and therefore RAM, ROM and processor hungry.&nbsp; It has the more familiar socket interface.
uIP takes tiny RAM and ROM.&nbsp; It&#8217;s main disadvantage is that it can only have one outstanding message at any one time.&nbsp; This will make it slow if you send lots of small packets &#40;so just send large packets and you are fine&#33;&#41;.&nbsp; The interface is less familiar and the application has to handle retransmissions rather than the stack &#8211; but otherwise I really like uIP.&nbsp; It is also easy to understand and follow which is a boon.
