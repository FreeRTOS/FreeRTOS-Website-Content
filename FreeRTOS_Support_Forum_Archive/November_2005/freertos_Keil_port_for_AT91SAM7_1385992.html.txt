</div></div><div class="thread-post"><h3 class="thread-post-title">Keil port for AT91SAM7</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 17, 2005</div><div class="thread-post-content">Open the existing Keil demo then:
1&#41; From the Project menu, select &quot;Select device for target FreeRTOS&quot;, and select the SAM7.
2&#41; Open the file FreeRTOSSourceportableIARAtmelSAM7S64port.c.&nbsp; This is the port.c file for the IAR compiler.&nbsp; It contains the code that will setup the timer for the SAM7 in a function called prvSetupTimerInterrupt&#40;&#41;.&nbsp; Overwrite the prvSetupTimerInterrupt&#40;&#41; function in the Keil demo port.c &#40;which is configured to setup an LPC2000 timer&#41; with the version from the IAR port &#40;which is configured to setup a SAM7 timer&#41;.&nbsp; There may also be a few &#35;defines at the top of the file that are required to compile the function.
3&#41; Open the file FreeRTOSDemoARM7&#95;LPC2129&#95;KeilFreeRTOSConfig.h.&nbsp; You will notice it includes the header lpc21xx.h.&nbsp; Delete this line for obvious reasons.&nbsp; You may have to replace it with a header file that defines the registers for your processor.&nbsp; This will become obvious when you try to compile.
4&#41; Also in FreeRTOSConfig.h you will see the definitions for configCPU&#95;CLOCK&#95;HZ, configMINIMAL&#95;STACK&#95;SIZE and configTOTAL&#95;HEAP&#95;SIZE.&nbsp; Set these to values appropriate for your hardware.&nbsp; You might like to just copy the values from the IAR SAM7 &#40;SAM7S or SAM7X demo as appropriate&#41; FreeRTOSConfig.h file which can be found in the FreeRTOSDemoARM7&#95;AT91SAM7S64&#95;IAR directory.
5&#41; The serial port drivers will be incorrect.&nbsp; You can transfer the SAM7X drivers from IAR demo, but for now just delete the files serial.c and serialISR.c from the Keil project.
6&#41; To start with the smallest application prevent all tasks other than the simple LED flash tasks from being started.&nbsp; To do this open main.c, and find the lines and commend out all the lines between vStartIntegerMathTasks and vStartDynamicPriorityTasks, EXCEPT the line vStartLEDFlashTasks.
7&#41; The code to set or clear an LED is defined in the file FreeRTOSDemoARM7&#95;AT91SAM7S64&#95;IARParTest.&nbsp; The Keil project is configured to access the LED&#8217;s on the Keil LPC2000 demo board.&nbsp; You will have to update this to access the correct ports to access the LED&#8217;s on your hardware.&nbsp; If you are using the Atmel demo board then again you can just copy the files from the IAR SAM7 demo.&nbsp; There are demos for both the SAM7S and SAM7X hardware.&nbsp; Also check the function prvSetupHardware&#40;&#41; in the file main.c.&nbsp; This sets the data direction or ports, etc.&nbsp; You will also have to set this appropriately for your hardware.
I&#8217;m sure when you compile there will be a few includes, definitions, etc. that need some tweaking, but this should get you 95% of the way.
Regards.

</div></div><div class="thread-post"><h3 class="thread-post-title">Keil port for AT91SAM7</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 22, 2005</div><div class="thread-post-content">If you look in Startup.s that comes with the Keil LPC port you will notice &#40;as you mention&#41; that the processor is placed in a certain mode, then the stack is setup, then this is repeated for all necessary modes.
After this you will see the following code:
&#45;&#8212;&#8211;start of code
// Start in supervisor mode
MSR&nbsp;&nbsp;&nbsp;&nbsp; CPSR&#95;c, &#35;Mode&#95;SVC|I&#95;Bit|F&#95;Bit
&#45;&#8212;&#8211;end of code
This just ensure that, once all the stacks have been setup, the processor is placed back into supervisor mode, and remains in supervisor mode until main&#40;&#41; is called.&nbsp; You will see that the very next line following these two has the comment &quot;// Enter the C code&quot;.
You might also like to check the various stack sizes used by your SAM7 port.&nbsp; In the keil demo the stack sizes are set by constants such as &quot;IRQ&#95;Stack&#95;Size&quot; at the top of the .s file.
Regards.
