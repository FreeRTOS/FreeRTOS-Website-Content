  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Related to FreeRTOS license‏</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rafia-inam">rafia-inam</a> on October 4, 2010</div><div class="thread-post-content">Hi,  
I am a student and in a project i have to implement a hierarchical scheduler in using FreeRTOS.<br />
We will be doing some changes to the kernel also to accomplish it.   
I am black about the license knowledge. I read the license policy.&nbsp; I am not very clear about the following matters:  
1&#46; Our implementations will be open source or not?<br />
2&#46; Can we distribute our implementation &#40;source code&#41; at FreeRTOS website ?<br />
&nbsp; if yes then : 2.1. Can we distribute it as a part of FreeRTOS or as a separate plugin?<br />
&nbsp; if no then :&nbsp; 2.2. Can we distribute it at our own website?<br />
3.&nbsp; Is FreeRTOS owned by the company&#40;like google chrome: which is open source but<br />
company will not distribute any kind of patches from others&#41; or is it totally&nbsp; free.  
We really want to contribute to the FreeRTOS. Please answer these questions. I will be obliged.  
best regards &nbsp;&nbsp; &nbsp;
</div></div><div class="thread-post"><h3 class="thread-post-title">Related to FreeRTOS license‏</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 4, 2010</div><div class="thread-post-content"><blockquote>
  1&#46; Our implementations will be open source or not?
</blockquote>
The FreeRTOS license is very liberal, and only effects changes and/or additions to the scheduler itself.&nbsp; In your case it sounds like your modifications are directly related to the scheduler, and therefore will be open source.  
<blockquote>
  2&#46; Can we distribute our implementation &#40;source code&#41; at FreeRTOS website ?<br />
  &nbsp; if yes then : 2.1. Can we distribute it as a part of FreeRTOS or as a separate plugin?<br />
  &nbsp; if no then :&nbsp; 2.2. Can we distribute it at our own website?  
</blockquote>
It is unlikely that this type of change would get its way into the core kernel code, but you can still distribute it on the FreeRTOS web site by using the FreeRTOS Interactive forums.&nbsp; See <a href="http://interactive.freertos.org/">http://interactive.freertos.org</a> .&nbsp; You can also distribute it on your own web site without having to worry about any licensing issue.s  
<blockquote>
  3.&nbsp; Is FreeRTOS owned by the company&#40;like google chrome: which is open source but<br />
  company will not distribute any kind of patches from others&#41; or is it totally&nbsp; free.  
</blockquote>
I&#8217;m not sure I understand the question.&nbsp; The IP is owned by my company &#8211; Real Time Engineers Ltd &#8211; but it is also completely free.&nbsp; I don&#8217;t see these as being conflicting attributes.&nbsp; The code base origin and quality is tightly controlled to ensure people have a good experience, and to ensure that commercial licenses can be sold where appropriate.&nbsp; See:  
<a href="http://www.freertos.org/differences-between-officially-supported-and-contributed-FreeRTOS-code.html">http://www.freertos.org/differences-between-officially-supported-and-contributed-FreeRTOS-code.html</a>  
Regards.
