Checked the OS still runs, which it does..
Then I modified vPreemptiveTick&#40;&#41; as described the linked thread.
Then hooked in UartDbguIsr&#40;&#41;. Hey presto it works. Now its time to test&#8230;
There is another thread in the AT91 forum under the title &quot;debug serial port interrupts&quot; which talks about using a while loop to service interrupts until they are all cleared. May be worth a look.
So&#8230; I give you step by step instructions on how I did it&#8230;
&lt;b&gt;In port.c, replace the following text:&lt;/b&gt;
/&#42; Currently the IAR port requires the preemptive tick function to be
defined in an asm file. &#42;/
&lt;b&gt;With:&lt;/b&gt;
&#95;&#95;arm void vPreemptiveTick&#40; void &#41;;
&#95;&#95;arm void vPreemptiveTick&#40; void &#41;
&#123;
&nbsp;&nbsp; unsigned portLONG ulDummy;
&nbsp;&nbsp; if &#40;AT91C&#95;BASE&#95;PITC-&gt;PITC&#95;PISR &amp; AT91C&#95;PITC&#95;PITS&#41;
&nbsp;&nbsp; &#123;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Increment the tick count &#8211; this may wake a task. &#42;/
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; vTaskIncrementTick&#40;&#41;;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Find the highest priority task that is ready to run. &#42;/
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; vTaskSwitchContext&#40;&#41;;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Clear the AT91C&#95;PITC&#95;PITS flag &#42;/
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ulDummy = AT91C&#95;BASE&#95;PITC-&gt;PITC&#95;PIVR;
&nbsp;&nbsp; &#125;
&nbsp;&nbsp; else
&nbsp;&nbsp; &#123;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Possible interrupt caused by the DBGU. AT91C&#95;US&#95;RXRDY and
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; AT91C&#95;US&#95;TXRDY checked &amp; cleared within UartDbguIsr &#42;/
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; extern &#95;&#95;arm void UartDbguIsr&#40;void&#41;;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; UartDbguIsr&#40;&#41;;
&nbsp;&nbsp; &#125;
&nbsp;&nbsp; /&#42; End the interrupt in the AIC. &#42;/
&nbsp;&nbsp; AT91C&#95;BASE&#95;AIC-&gt;AIC&#95;EOICR = ulDummy;
&#125;
&lt;b&gt;In portasm.s79, add the following to the list of externals:&lt;/b&gt;
&nbsp;&nbsp; EXTERN vPreemptiveTick
&lt;b&gt;In portasm.s79, rewrite vPreemptiveTick as a simple wrapper:&lt;/b&gt;
vPortPreemptiveTick:
&nbsp;&nbsp;&nbsp; portSAVE&#95;CONTEXT&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ; Save the context of the current task.
&nbsp;&nbsp;&nbsp; bl&nbsp;&nbsp;&nbsp; vPreemptiveTick&nbsp;&nbsp; ; Call the ISR routine.
&nbsp;&nbsp;&nbsp; portRESTORE&#95;CONTEXT&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ; Restore the context of the selected task.
&#8230;..Hope this helps&#8230;..Jon&#8230;.
