</div></div><div class="thread-post"><h3 class="thread-post-title">In Application programming with freeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/bones23">bones23</a> on April 11, 2008</div><div class="thread-post-content">I have tried commenting out everything from the freeRTOS main function and popped in my own led flashing program. This worked with the stmicro bootloader. Adding back the freeRTOS stuff I found that the program stops working when I add back prvSetupHardware function. I thought this might be because of the FMI&#95;BankRemapConfig call inside of the prvSetupHardware function but commenting that out did not fix the problem. Does anybody have any ideas about what could be causing this?
</div></div><div class="thread-post"><h3 class="thread-post-title">In Application programming with freeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/acrazylion2">acrazylion2</a> on April 18, 2008</div><div class="thread-post-content">Hello Everybody.
I have had the same problem like you. 
I fixed it with these 4 steps:
&#45; cut the PLL configuration code lines in prvSetupHardware from the main application in BANK 0
&nbsp; and paste it into a start sequence in the bootloader &#40;main&#40;&#41; of IAP&#41; in BANK 1.
&#45; also cut and paste the FMI&#95;Config&#40;xx&#41; command in the same way.
&#45; The FMI configuration &#40;the lines with the 0x540000XX Registers&#41;
&nbsp; of FREERTOS init &#40;asssembler&#41; file must change &#40;or maybe could deleted?&#41; to the right size and address 
&#45; Comment or delete the FMI&#95;BankRemapConfig command in prvSetupHardware.
NOTE: The FREERTOS will not run if bootbank = bank0 &#33;&#33; 
It works, but why? Why is it not possible to config pll after using a bootloader with bank-address-switch.
Have anybody a clue?
