  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">STM3210C-EVAL and GCC</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/grunzasr">grunzasr</a> on December 23, 2009</div><div class="thread-post-content">I&#8217;m trying to build FreeRTOS for the ST Micro evaluation board STM3210C.&nbsp; It has their connectivity line STM32F107 and a bunch of interesting peripherals.&nbsp; I don&#8217;t want to use anyone&#8217;s IDE &#40;for now&#41;.&nbsp; I just want to use GCC and related utilities &#40;make, objcopy, etc&#41;.  
In theory this should be easy since this board &lt;a href-&#8220;<a href="/wp-content/uploads/2019/07/index.html?http://www.freertos.org/FreeRTOS-For-STM32-Connectivity-Line-With-WEB-Server-Example.html">/wp-content/uploads/2019/07/index.html?http://www.freertos.org/FreeRTOS-For-STM32-Connectivity-Line-With-WEB-Server-Example.html</a>&#8220;&gt;board&lt;/a&gt; is already supported using the CrossStudio IDE from Rowley Associates.&nbsp; I should just need a standard Gnu Makefile and the linker script &#40;I built GCC for arm using the information from the RTEMS website&#41;.  
In practice I&#8217;m having no end of difficulty figuring out what files need to be included, what the linker script should contain, and how to resolve the numerous &#8220;undefined reference to …&#8221; messages.&nbsp; I tried using what are probably the RIDE project files and the other board&#8217;s source files as hints but so far nothing but error messages.  
Does anyone have a Gnu makefile and linker script I can use?&nbsp; Is there anyone interested in reviewing what I&#8217;ve created and providing some suggestions as to what I&#8217;ve done wrong?  
</div></div><div class="thread-post"><h3 class="thread-post-title">STM3210C-EVAL and GCC</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on December 23, 2009</div><div class="thread-post-content">First off &#8211; I never understand why people build their own GCC tool chains rather than just using a pre-built binary.&nbsp; Unless its just for their own interest and education that is.  
I have a command line build for that very board that uses arm-none-eabi-gcc.&nbsp; Two caveats, the linker scripts are files that were originally output by Ride and the makefiles are for SafeRTOS, not FreeRTOS.  
Ref the linker scripts.&nbsp; I will have to check the copyright message in them to see if they can be sent, but I don&#8217;t expect there to be a problem.&nbsp; Otherwise you can just look at other linker scripts in the FreeRTOS download and modify them for your memory map.  
Ref the makefile.&nbsp; I cannot send you the SafeRTOS source code, but the files required are very similar to FreeRTOS and I can point out the differences, so you should be able to adapt if for use with FreeRTOS very easily.  
If you want the files then contact me directory using r&nbsp; barry &#40;at &#41; FreeRTOS.org.  
Regards.
