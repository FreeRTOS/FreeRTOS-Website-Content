</div></div><div class="thread-post"><h3 class="thread-post-title">MikroC + STM32F4Discovery + FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/aussa">aussa</a> on March 2, 2013</div><div class="thread-post-content">Mikroc has a ARM compiler also
</div></div><div class="thread-post"><h3 class="thread-post-title">MikroC + STM32F4Discovery + FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on March 2, 2013</div><div class="thread-post-content">The CMSIS library has configurations for IAR, Keil and GCC. Different configurations are required because each compiler uses different syntax. If you want to use MikroC then you will either have to strip out all calls to CMSIS libraries, or update the CMSIS library yourself to provide a mikroC port.
