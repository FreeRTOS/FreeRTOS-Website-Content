  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">hook functions</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/umnurw">umnurw</a> on January 26, 2011</div><div class="thread-post-content">Hi,  
I need to know about the hook functions in FreeRTOS kernel which are called whenever a scheduling decision is made.<br />
I have used traceTASK&#95;SWITCHED&#95;OUT, and traceTASK&#95;SWITCHED&#95;IN macros, but they work with tasks, not at every context switch.<br />
Can someone provide a little information or any example to use them?  
thanks.
</div></div><div class="thread-post"><h3 class="thread-post-title">hook functions</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on January 26, 2011</div><div class="thread-post-content">In FreeRTOSConfig.h:  
For an idle hook set configUSE&#95;IDLE&#95;HOOK to 1, then in your application write a function<br />
void vApplicationIdleHook&#40; void &#41;;  
For a tick hook set configUSE&#95;TICK&#95;HOOK to 1, then in your application write a function<br />
void vApplicationTickHook&#40; void &#41;;  
Those are mentioned on <a href="http://www.freertos.org/a00016.html">http://www.freertos.org/a00016.html</a>  
Also, for a malloc&#40;&#41; failed hook set configUSE&#95;MALLOC&#95;FAILED&#95;HOOK to 1, then in your application write a function<br />
void vApplicationMallocFailedHook&#40; void &#41;; /&#42; used for heap&#95;1.c and heap&#95;2.c and heap&#95;3.c only &#42;/  
Is there a link for the malloc failed thing?  
For stack overflow hook set configCHECK&#95;FOR&#95;STACK&#95;OVERFLOW to 1 or 2, and provide a function<br />
void vApplicationStackOverflowHook&#40; xTaskHandle &#42;pxTask, signed char &#42;pcTaskName &#41;;  
see <a href="http://www.freertos.org/Stacks-and-stack-overflow-checking.html">http://www.freertos.org/Stacks-and-stack-overflow-checking.html</a>
</div></div><div class="thread-post"><h3 class="thread-post-title">hook functions</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/umnurw">umnurw</a> on January 27, 2011</div><div class="thread-post-content">thanks a lot for a detailed answer.  
tick hook is called during each tick interrupt by the kernel.<br />
I need a hook function that is called at every context switch &#40;whenever a scheduling decision is made&#41;.<br />
Is there any hook function to fulfill this requirement?  
best regards.  
</div></div><div class="thread-post"><h3 class="thread-post-title">hook functions</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on January 27, 2011</div><div class="thread-post-content">You can do this using the traceTASK&#95;SWITCHED&#95;OUT and traceTASK&#95;SWITCHED&#95;IN macros.&nbsp; The sections I&#8217;m currently adding to the tutorial books actually contain an example that show you how to do just that.&nbsp;   
These macros run in the context of the tasks.c file, so have access to the pxCurrentTCB variable.&nbsp; Therefore, what you do is something along the lines of:  
xTaskHandle xTaskThatWasRunning;  
&#35;define traceTASK&#95;SWITCHED&#95;OUT xTaskThatWasRunning = pxCurrentTCB  
&#35;define traceTASK&#95;SWITCHED&#95;IN <br />
&#95;&#95;&#95;&#95;if&#40; xTaskThatWasRunning &#33;= pxCurrentTCB &#41; <br />
&#95;&#95;&#95;&#95;&#123; <br />
&#95;&#95;&#95;&#95;&#95;&#95;&#95;&#95;/&#42; A context switch has occurred, do something. &#42;/ <br />
&#95;&#95;&#95;&#95;&#125;  
Regards.
