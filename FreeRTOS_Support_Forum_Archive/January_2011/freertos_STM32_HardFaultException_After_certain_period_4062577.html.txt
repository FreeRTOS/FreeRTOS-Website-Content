  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">STM32 HardFaultException After certain period</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/irvind">irvind</a> on January 20, 2011</div><div class="thread-post-content">Hi,  
Currently I am using STM32 Cortex M3, compiler IAR 4.x &amp; FreeRTOS v6.1.0.  
I have a firmware that send some data through GSM module to PC.  
Before I start implement FreeRTOS, everything worked properly.  
After I implement FreeRTOS to my code, I facing HardFaultException problem after sending certain bytes of string. I try debug and narrow down the posibility so I have only 1 task running.  
I found that if I send a long string which mean more bytes in 1 message, then it crash earlier. If I reduce the string size that I am sending per message, then it take longer time to crash.   
Could anyone please guide me on this? If I need to clear any buffer etc? But this firmware running without RTOS and it work properly. I also tried to put enter critical before I do and strcpy or memcpy, I thought interrupt might causing this problem but still the same problem. I really run out of idea. So please give me a hand on this.  
Thank you so much.
</div></div><div class="thread-post"><h3 class="thread-post-title">STM32 HardFaultException After certain period</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on January 20, 2011</div><div class="thread-post-content">To save Richard the trouble. Have you read number three of this faq?<br />
<a href="http://www.freertos.org/FAQHelp.html">www.freertos.org/FAQHelp.html</a>  
</div></div><div class="thread-post"><h3 class="thread-post-title">STM32 HardFaultException After certain period</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/irvind">irvind</a> on January 21, 2011</div><div class="thread-post-content">yes. I read the FAQ before and also I bought their e-bbok. But I can&#8217;t find my problem related to any of the FAQ.  
By the way, I found that it not caused by create string etc. It caused by the stack size I assigned to the task, before I post the previous thread. I set my task stack as 2048. Then today I tried to increase higher stack size to 3072 just in case overflow check failed to trigger. But it go worst, it crashed&nbsp; faster than before. So I reduced my stack size to 1024, and it could run longer than before. But it still enter hardfaultexception at the end. Anyone have any idea that could solve this?  
Thanks.
</div></div><div class="thread-post"><h3 class="thread-post-title">STM32 HardFaultException After certain period</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/irvind">irvind</a> on January 21, 2011</div><div class="thread-post-content">Problem solved.  
Just in case anyone having this problem, I wrote down my problem and solution here hope it could help other.  
When using FreeRTOS, instead of using malloc, we are using pvPortMalloc&#40;&#41;. But I forgot to use vPortFree to free all memory which I am still using free function. So it crash when memory only alloc but not freed.
