  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">compiler error in queue.c at taskYIELD</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/mkrug">mkrug</a> on January 3, 2010</div><div class="thread-post-content">Hello,  
I get the compiler error:<br />
Error: missing expression &#8211; &#96;swi&#8217; in queue.c at the line&#40;s&#41; taskYIELD. I am using RTOS 6.0.1 for the ARM7 in the GCC version. However I tried a 5.x queue.c file with the same result. Additionally I generated a list file of queue. c that has the following appearence:<br />
485:C:/ARM7Programme/workspace/RTOS/rtos/sourcequeue.c &#42;&#42;&#42;&#42; taskYIELD  
308&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; .loc 1 486 0  
309&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; @ 486 &#8220;C:/ARM7Programme/workspace/RTOS/rtos/source/queue.c&#8221; 1  
310&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; SWI  
311&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; @ 0 &#8220;&#8221; 2  
So in principle the replacement of taskYIELD&#40;&#41; to SWI seems OK. So my guess is more of an assembler syntax problem. I also tried the different portmacro.h versions for the ARM7 that are available without any success.<br />
I am using the gcc version 4.4.2 and assembler 2.2.  
Does anybody has a hint ?  
Best Regards<br />
Markus
</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error in queue.c at taskYIELD</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/aturowski">aturowski</a> on January 3, 2010</div><div class="thread-post-content">Latest GCC &amp; binutils requires that every SWI instruction should be followed by number which is passed to called software exception. Before tools assumed that the lack of this number means 0. So add 0 to SWI and it should compile/work.  
You may fing example how to change that in <a href="http://freeecu.svn.sourceforge.net/trunk/">http://freeecu.svn.sourceforge.net/trunk/</a>  
Regards,<br />
Adam
</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error in queue.c at taskYIELD</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/aturowski">aturowski</a> on January 3, 2010</div><div class="thread-post-content">Exactly in <a href="http://freeecu.svn.sourceforge.net/viewvc/freeecu/trunk/FreeRTOS/Source/portable/GCC/ARM7_AT91SAM7X/portmacro.h?revision=79&amp;view=markup">http://freeecu.svn.sourceforge.net/viewvc/freeecu/trunk/FreeRTOS/Source/portable/GCC/ARM7&#95;AT91SAM7X/portmacro.h?revision=79&amp;view=markup</a> line 231  
Hope that helps,<br />
Adam
</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error in queue.c at taskYIELD</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/bejkarna">bejkarna</a> on January 5, 2010</div><div class="thread-post-content">Hi  
to previous reply its actulay line 213  
as I changed the line to  
&#35;define portYIELD&#40;&#41;                    &#95;&#95;asm volatile &#40; &#8220;SWI 0&#8221; &#41;   
the SWI errors disappeared but others came out:  
../../../Source/queue.c: In function &#8216;xQueueGenericSend&#8217;:  
../../../Source/queue.c:480: error: stray &#8216;240&#8217; in program  
eclipse shows that this error is caused everywhere the portYIELD&#95;WITHIN&#95;API&#40;&#41;; function is called in queue.c  
</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error in queue.c at taskYIELD</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on January 5, 2010</div><div class="thread-post-content">In all but the ports that support memory protection it is defined as  
&#35;define portYIELD&#95;WITHIN&#95;API portYIELD  
I would guess that the problem is in your edit of portYIELD.  
240 is not an ascii character &#40;only an extended ascii character&#41;.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error in queue.c at taskYIELD</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/bejkarna">bejkarna</a> on January 5, 2010</div><div class="thread-post-content">Sorry, you are right I found this somewhere else, now I changed it to  
&lt;pre&gt;&lt;code&gt; &#35;define portYIELD&#40;&#41;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; asm volatile&nbsp; &#40; &#8220;SWI 0&#8221; &#41; &lt;/code&gt;&lt;/pre&gt;  
and everything works fine.  
Thanks all of you.  
</div></div><div class="thread-post"><h3 class="thread-post-title">compiler error in queue.c at taskYIELD</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/mkrug">mkrug</a> on January 5, 2010</div><div class="thread-post-content">Hello,  
thanks everyone for their help. It was simply to change the SWI instruction to SWI 0  
Best Regards<br />
