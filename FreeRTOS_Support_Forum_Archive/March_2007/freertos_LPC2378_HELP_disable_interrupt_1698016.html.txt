</div></div><div class="thread-post"><h3 class="thread-post-title">LPC2378 HELP!  __disable_interrupt()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 21, 2007</div><div class="thread-post-content">Which compiler are you using?&nbsp; If you are using the Keil tools, then are you using the original Keil compiler or the Realview compiler?
If Keil, then look at the existing Keil port for hints.
If Realview then you can use:
&#35;define portDISABLE&#95;INTERRUPTS&#40;&#41;&nbsp;&nbsp;&nbsp; &#95;&#95;disable&#95;irq&#40;&#41;

</div></div><div class="thread-post"><h3 class="thread-post-title">LPC2378 HELP!  __disable_interrupt()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on March 21, 2007</div><div class="thread-post-content">The kernel runs in Supervisor mode.&nbsp; Tasks run in System mode.&nbsp; Therefore you can call the enable/disable functions ok.
