  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS for AVR32</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rbarzic">rbarzic</a> on March 22, 2007</div><div class="thread-post-content">Hello everybody,
After months of inactivity, here are some fresh news about the &#40;unofficial&#41; port of the FreeRTOS.org real-time kernel to AT32AP700x processors.
A new stable version &#40;0.2&#41; is available on SourceForge that fixes lot
of bugs &#40;many thanks to Ben, Laurent &amp; Cyrille &#33;&#41;
This release includes two demonstration programs :
&#45; the &quot;Minimal&quot; demo : several tasks runing in // , with a usart
&nbsp; generating interrupts events
&#45; a Web server demo using the LWIP IP TCP/IP stack
&#40;These demos ran several days without crashing&#41;
Project page on SourceForge :
http://sourceforge.net/projects/avr32freertos/
Download :
http://sourceforge.net/project/showfiles.php?group&#95;id=170020
This AVR32 port is based on FreeRTOS.org v4.0.2 and uses BSP v1.0
BSP v2.0 beta is not fully supported yet as the Webserver doesn&#8217;t seem to work when compiled with the v2.0beta version of the tools &#40;but I didn&#8217;t had time to look further &#8211; the Minimal demo and LCD test program are OK with v2.0beta&#41;
Note : only gcc is supported. I have no plan to support IAR AVR32 compiler &#8211; And I did all my developments on Linux &#40;Ubuntu&#41; &#8211; So&nbsp; Cygwin support is not tested
Next on the to-do list
&#45; full BSP 2.0 support
&#45; LCD support &#40;a standalone demonstration program is already working&#41; 
&#45; use latest version of FreeRTOS.org
&#45; integration a linux/busybox-like menuconfig configuration system
&#40;see http://sourceforge.net/project/screenshots.php?group&#95;id=170020&#41;
&#45; use newlib as the default std lib
&#45; use U-boot as a bootloader
&#45; Nano-X port &#40;may need newlib&#41;
&#45; Network gateway support
Code for some of those features is already available on the Subversion
server in the unstable&#95;BSPv1.0 and unstable&#95;BSPv2.0 branches :
 for BSP 1.0 : 
svn co https://avr32freertos.svn.sourceforge.net/svnroot/avr32freertos/unstable&#95;BSPv1.0
 for BSP 2.0 : 
svn co https://avr32freertos.svn.sourceforge.net/svnroot/avr32freertos/unstable&#95;BSPv2.0beta
&#40;I will make snapshots of these branches available for download from time to time if you can&#8217;t access the SVN server&#41;
I will be happy to give write access to the SVN server to anyone who wants to contribute
Enjoy &#33;
Ronan
