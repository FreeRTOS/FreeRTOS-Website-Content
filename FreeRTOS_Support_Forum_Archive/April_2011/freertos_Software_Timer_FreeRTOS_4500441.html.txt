</div></div><div class="thread-post"><h3 class="thread-post-title">Software Timer FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on April 26, 2011</div><div class="thread-post-content">What is the timer queue length?&nbsp; The code you have posted has two definitions for this, so I&#8217;m surprised it compiles without giving you a warning.  
The two definitions you have are 1 and 255.&nbsp; If it is using the value 1, then I would not expect the above code to work.&nbsp; That is because the timer command queue is not processed until after the scheduler has been started.&nbsp; With a queue length of 1, the first call to xTimerStart&#40;&#41; will fill the timer command queue to it&#8217;s capacity, and all the other calls to xTimerStart&#40;&#41; will fail.  
Regards.
