  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS and PIC32 need PBCLK to be 12mhz.</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/roujesky">roujesky</a> on April 4, 2011</div><div class="thread-post-content">Using FreeRTOS on a custom PIC32 based board.&nbsp;&nbsp; Literally, just been running for a day&#33; :&#41;&nbsp;&nbsp; I am a newb to both PIC32 and FreeRTOS, so please be gentle.&nbsp;&nbsp; I need the UART to communicate with a device that is running a baud rate of 58,252.&nbsp;&nbsp; Yes, weird&#33;&nbsp;&nbsp; Anyway, to get this baud rate, I need a PBCLK of 12mhz.&nbsp;&nbsp; I cannot seem to find where in FreeRTOS it sets PBCLK.&nbsp;&nbsp; Probably me :&#40;&nbsp;&nbsp;&nbsp; Anyway, I set configPERIPHERAL&#95;CLOCK&#95;HZ to 12000000UL thinking this would do it.&nbsp; I dont think it is right, because I have a LED flashing task which flashes the led every second.&nbsp;&nbsp; when I change configPERIPHERAL&#95;CLOCK&#95;HZ from 40mhz to 12mhz, my led blinks a lot faster &#40;too fast&#41;.&nbsp;&nbsp; I am not sure where to look for the correct way to do this.&nbsp;&nbsp; I bought the ebook &#8220;Using the FreeRTOS Real Time Kernel &#8211; A Practical Guide&#8221;, but it does not address this at all.  
thanks&#33;  
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS and PIC32 need PBCLK to be 12mhz.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on April 5, 2011</div><div class="thread-post-content">You need to look at the C32 libraries &#40;that come with the compiler, not with FreeRTOS.&nbsp;   
In main.c you will see a function called prvSetupHardware&#40;&#41; that makes a call to the &#40;Microchip&#41; library functions&nbsp;&nbsp;&nbsp;&nbsp; SYSTEMConfigPerformance&#40; configCPU&#95;CLOCK&#95;HZ &#8211; 1 &#41; and mOSCSetPBDIV&#40; OSC&#95;PB&#95;DIV&#95;2 &#41;;&nbsp; You then need to set the configPERIPHERAL&#95;CLOCK&#95;HZ setting in FreeRTOSConfig.h to match whatever you set the clock to using these library functions.  
Regards.
