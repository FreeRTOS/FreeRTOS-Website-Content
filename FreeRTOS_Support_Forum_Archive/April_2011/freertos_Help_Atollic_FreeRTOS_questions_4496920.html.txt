  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Help! Atollic + FreeRTOS questions</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/antonio-milano">antonio-milano</a> on April 20, 2011</div><div class="thread-post-content">Hello&#33;<br />
I&#8217;m a newbie and I have a couple of &#40;stupid?&#41; questions.<br />
I&#8217;m making some experiments on two Stellaris evaluation kits, the LM3S811 and the LM3S6965, using the IAR based FreeRTOS projects with my familiar IAR compiler, with very good results.<br />
Now I would like to do the same trying a GCC based compiler with a Eclipse IDE.<br />
I downloaded and installed the Atollic TrueStudio Lite, it seems ok, but I have a lot of difficults to build a working code.<br />
I would like to use the FreeRTOS distribution file structure, without modifications to the tree.<br />
Is there anybody willing to give me some advice in using FreeRTOS under Atollic?<br />
Thank You Very Much<br />
Antonio  
</div></div><div class="thread-post"><h3 class="thread-post-title">Help! Atollic + FreeRTOS questions</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on April 20, 2011</div><div class="thread-post-content">Have a look at the &#8220;Preparing the TrueStudio &#40;Eclipse&#41; project directory&#8221; section on the following page:  
<a href="http://www.freertos.org/FreeRTOS-for-Cortex-M3-STM32-STM32F100-Discovery.html">http://www.freertos.org/FreeRTOS-for-Cortex-M3-STM32-STM32F100-Discovery.html</a>  
This is not a Stellaris project, but uses Eclipse.&nbsp; In fact, there are lots of projects using various different Eclipse versions.&nbsp; Some set up variables to reference files outside of the directory structure &#40;which has two issues, one it is hard to do, two the variables are stored in the workspace and not the project, and three only absolute paths can be used &#8211; ok, that was three not two&#41;.&nbsp; Other projects, as per the one I just linked to, set up a batch file to copy the files you want &#8211; but that to has obvious drawbacks.  
The other way of doing it is to set up eclipse to use a standard makefile project, rather than a managed make project.&nbsp; Then you can use an old fashioned makefile to reference files from anywhere you like.  
Regards.
