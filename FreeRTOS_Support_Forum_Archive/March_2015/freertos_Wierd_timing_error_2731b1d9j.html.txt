</div></div><div class="thread-post"><h3 class="thread-post-title">Wierd timing error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on March 11, 2015</div><div class="thread-post-content">When you say &#8220;// ADD ONE LINE OF CODE AFTER THIS. THE CODE RUNS FASTER&#8221; do you mean add a line of code between that comment and the call to SWV_printnum()?  If so, what is the line?
If you are trying to get the switch as fast as possible then:
<ul>
<li>ensure configCHECK<em>FOR</em>STACK_OVERFLOW is 0</li>
<li>ensure no trace macros are enabled</li>
<li>ensure run-time stats are disable</li>
<li>ensure configUSE<em>PORT</em>OPTIMISED<em>TASK</em>SELECTION is set to 1.</li>
</ul>
Regards.
