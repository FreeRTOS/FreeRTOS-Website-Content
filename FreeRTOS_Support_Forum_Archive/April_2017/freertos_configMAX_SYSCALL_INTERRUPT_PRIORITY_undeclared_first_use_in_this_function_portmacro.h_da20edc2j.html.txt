</div></div><div class="thread-post"><h3 class="thread-post-title">&#8216;configMAX_SYSCALL_INTERRUPT_PRIORITY&#8217; undeclared (first use in this function)	portmacro.h</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on April 15, 2017</div><div class="thread-post-content">It is right then, it is not defined in your FreeRTOSConfig.h.
Any macro that is prefixed &#8216;config&#8217; is a user editable macro that can be 
placed in the FreeRTOSConfig.h.  If a macro is missing from 
FreeRTOSConfig.h then in many cases it will be defaulted, but not in the 
case of configMAX<em>SYSCALL</em>INTERRUPT_PRIORITY because it is very much 
dependent on the chip you are using.
Did you try Googling configMAX<em>SYSCALL</em>INTERRUPT<em>PRIORITY?  That is 
normally the first thing to be done.  When I try this the first link I 
get is this: http://www.freertos.org/a00110.html  then searching this 
page for configMAX</em>SYSCALL<em>INTERRUPT</em>PRIORITY I find this information: 
http://www.freertos.org/a00110.html#kernel_priority
