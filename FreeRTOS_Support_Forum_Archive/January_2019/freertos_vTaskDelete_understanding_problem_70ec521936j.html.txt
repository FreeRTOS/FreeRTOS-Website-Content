</div></div><div class="thread-post"><h3 class="thread-post-title">vTaskDelete understanding problem</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on January 7, 2019</div><div class="thread-post-content">As far as I can see &#8211; you delete the task but never set its handle to NULL.
vTaskDelete( buttonTaskHandle );
buttonTaskHandle = NULL; // Add this line.
Watch out for race conditions though.
Creating and deleting tasks in this way would not be an optimal way of 
implementing this, but I assume this is more of an academic exercise 
rather than a real door opener.
