</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS &#8211; STM32-  Data in queue not processed fast enough</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richarddamon">richarddamon</a> on January 15, 2019</div><div class="thread-post-content">If you are using the queue as a simple character fifo, it is quite possible to overload your system, as is well described in the documentation and examples. There is a LOT of over head for each character. A stream buffer or message buffer might be more efficient, or some method where you build up a buffer of data for a message, and just send a buffer address through a queue.
You also may need a much larger queue to be big enough to hold the amount of data you need, and have some form of dealing with overrun.
