I believe I am improperly using the counting sempahore which is the reason for the problem I am facing now,
I implemented a circular queue by myself and have 8 instances of such a queue,  which are 2 queues per each of 4 tasks. 8 = 2 x 4.
I wanted every task to wake up once a new message from other  tasks arives at any of its 2 queues. It checks then each of these 2 queues according to predefined priority , pulls a new message and starts processing it.
I assigned a counting sempahore to each of these 4 tasks (4 semaphores). Every time a new message arrives at any of the 2 queues  I thought to &#8220;give&#8221; the semaphore with xSemaphoreGive, which in fact increments it, and in each of these 4 tasks I intended to block with xSemaphoreTake until the semaphore count increases . 
My problem is when the count of the semaphore is 0, xSemaphoreTake returns with 0 and then I get configASSERT(0). I get it actually immediately after initialization, because the initial semaphore value is 0.
The question is whether my application is wrong or using of semaphore is not  applicable here?
Thanks!
