</div></div><div class="thread-post"><h3 class="thread-post-title">xQueueSendFromISR about V850</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on August 23, 2017</div><div class="thread-post-content">Let me guess, is your code like the following?
~~~
    void UART<em>IRQHandler()
    {
    BaseType</em>t xHigherPriorityTaskWoken = pdFALSE;
    uint8_t ch;
<pre><code>    ch = uart_receive();
    xQueueSendFromISR( xTxBufferQueue, &amp;ch, ( BaseType_t * ) &amp;xHigherPriorityTaskWoken );
    portYIELD_FROM_ISR( xHigherPriorityTaskWoken );
}
void myTask( void *pvParameter )
{
uint8_t ch;
    for( ;; )
    {
        if( xQueueReceive( xTimerQueue, &amp;ch, portMAX_DELAY ) != pdFAIL )
        {
            printf( "Received '%c'n", ch );
        }
    }
}
</code></pre>
~~~
The task will spend most of it&#8217;s time in <code>xQueueReceive()</code>. The test for <code>pdFAIL</code> is not really necessary in case the time-out equals <code>portMAX_DELAY</code>.
Note that <code>portMAX_DELAY</code> is a symbolic value, it is not <code>0xffffffff</code> or <code>0xffff</code> ticks. It means: &#8220;for ever&#8221;, or until success.
If your code is different, would you mind showing some of your code, both the UART interrupt handler as well as the task.

</div></div><div class="thread-post"><h3 class="thread-post-title">xQueueSendFromISR about V850</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on August 25, 2017</div><div class="thread-post-content"><blockquote>
  If the task will be woken up when data is written to the queue successfully?
</blockquote>
That is what I would expect. Your code looks perfectly sane.
<blockquote>
  Why my test result is the &#8220;xQueueReceive&#8221; cannot return a &#8220;pdPASS&#8221;
  even the data is send to the queue successfully?
</blockquote>
Which is strange.
Did you also call <code>vTaskStartScheduler()</code> to start the scheduler?
Is <code>SerTask()</code> the only task in this demo?
Can you confirm that <code>SerTask()</code> really gets started?
Are you sure that <code>uart2_interrupt_receive()</code> gets called?
Note that <code>portBASE_TYPE</code> is a less-used define ( typedef ) for <code>BaseType_t</code>.
Experiment: can your replace <code>portMAX_DELAY</code> with some reasonable value, like:
~~~
    pdMS<em>TO</em>TICKS( 1000u );
~~~
When using that value, the function <code>xQueueReceive()</code> will return every second with <code>pdFAIL</code>. Can you verify if that happens?
