<h2 class="thread-post-title">Low-Power-Management</h2>
<div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on May 8, 2007</div>
<div class="thread-post-content">
<p>Hi,</p>
<p>i have running A IAR-MSP430 Port of V4.2.0 with some small extentions for Low-Power-Modes.<br />
So the System is running in Power-Down with the 32kHz &#8211; Clock as a Realtime Clock toggeling ans showing on LCD every second with 10uA current.</p>
<p>For Power-Down I loaded the value of the tik-counter in a timer with the next task-wakeup-time and coroutine-wakeup-time in a Compare-Register of that Timer.</p>
<p>So the Controller can Sleep up to the nextwakeup or asynchron event.</p>
<p>Then the Tik-Counter is restored and the normal Realtime-Tiks are Handled.</p>
<p>If there ist no task or coroutine to run, the Power-Down-Mechanism is Called in the IDLE-task.</p>
<p>I Implemented this in port.c file but I extended the task.c with some small Routines to get and set the TIKs</p>
<p>portTickType  xTaskGetxTickCount(void)<br />
void xTaskSetxTickCount( portTickType newxTickCount )</p>
<p>and to get the next Timepoint to wake up</p>
<p>portTickType xTaskGetNextDelayedTik( void )<br />
portTickType pxGetNextDelayedCoRoutineTik ( void )</p>
<p>Are there an interest or plans to implement some more low-power-management feature in Free RTOS ?</p>
<p>Jürgen</p>
