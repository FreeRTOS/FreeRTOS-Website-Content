</div></div><div class="thread-post"><h3 class="thread-post-title">DAbt with LPC2368</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on May 7, 2007</div><div class="thread-post-content">The files in the new zip file setup the timer differently for the LPC23xx devices.&nbsp; Are you using the original FreeRTOS.org LPC2000 files, or the ones with the LPC23xx&nbsp; timer setup?&nbsp; It might be that the timer is not running, which would mean that tasks blocked using vTaskDelay&#40;&#41; would never unblock.
When your tasks stop running, what is the processor doing?&nbsp; If it is running the idle task then I think it is likely that the timer is not running.
Dave.

Dave.
