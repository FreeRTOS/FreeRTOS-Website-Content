  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">LWIP Problem : Stops working after some time</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/vipin_bansal">vipin_bansal</a> on May 31, 2007</div><div class="thread-post-content">I am using LWIP stack with FreeRTOS code on STR9. I am using V4.1.2 version of freeRTOS.
While using it I got a problem that the code gets stuck in the loop of function vListInsert&#40;&#41;&#40;present in list.c file&#41; after ethernet working fine for 10 minutes.&nbsp; 
I feel that it’s a problem of freeRTOS code.
After reading the details about this I came to know that :
1&#46; vListInsert&#40;&#41; function was optimized in the new version.
2&#46; Algorithm has to be modified if control gets stuck in the loop of this function &#40; as mentioned in function comments&#41;
Does any one has the idea about the function working and how to modify so as not to get this type of problem?
</div></div><div class="thread-post"><h3 class="thread-post-title">LWIP Problem : Stops working after some time</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 31, 2007</div><div class="thread-post-content">This symptom is nearly always a caused by corruption of the data structures used by FreeRTOS.org, which in turn is nearly always caused by the stack of a task overflowing.
When the problem occurs, look at the free stack available to each task &#40;the stacks are filled with 0xa5 when the task is created&#41; to see if any have overflowed.&nbsp; You can also use the WEB server to show the stack high water mark of each task as per the lwIP demo included in the FreeRTOS.org download.
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">LWIP Problem : Stops working after some time</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/vipin_bansal">vipin_bansal</a> on June 25, 2007</div><div class="thread-post-content">Thanks for the answer. 
I tried but I was not able to check the stack used by tasks. I increase the stack size &#40;almost made it double&#41; for each operating task but the problem persists. My understanding is that if the tasks have not proper stack then we will get DATA&#95;Abort exception which is not coming in my case.
Moreover the program sometimes also stuck at idle task and keep on executing the task. Do you have any idea regrading this.
</div></div><div class="thread-post"><h3 class="thread-post-title">LWIP Problem : Stops working after some time</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/vipin_bansal">vipin_bansal</a> on June 26, 2007</div><div class="thread-post-content">I have webserver running on my board.
