</div></div><div class="thread-post"><h3 class="thread-post-title">ESP32 Demo project and AWS set up.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on June 15, 2019</div><div class="thread-post-content">Sorry you are having these problems.  To get you going I suggest you do
the following:
1) Check configSUPPORT<em>STATIC</em>ALLOCATION is set to 1 in
FreeRTOSConfig.h. &#8211; The nnnCreateStatic() functions won&#8217;t be available
otherwise.
2) Ensure FreeRTOS.h and then queue.h or tasks.h  are included (as
appropriate) at the top of the offending .c file.
You can also turn off the option that treats warnings as errors &#8211; just
so you can build.
Longer term, to ensure this is investigated and fixed, open an issue
here: https://github.com/aws/amazon-freertos/issues
