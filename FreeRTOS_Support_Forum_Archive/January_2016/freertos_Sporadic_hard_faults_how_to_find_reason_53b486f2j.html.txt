</blockquote>
With any Cortex-M4 microcontroller, if the microcontroller has a 
floating point unit (FPU) then use the code from 
FreeRTOS/Source/portable/[compiler]/ARM<em>CM4F, otherwise use the code 
from FreeRTOS/Source/portable/[compiler]/ARM</em>CM3.
