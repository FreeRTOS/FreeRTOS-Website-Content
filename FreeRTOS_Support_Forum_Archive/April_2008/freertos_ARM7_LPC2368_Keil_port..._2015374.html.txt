&nbsp;&nbsp; Thank you for your e-mail. I have used exactly this demo as start point to make my port. It is working now, I have modified just a little the original demo and LPC2368 startup code from Keil. I am sending you the port files as attach. If you need, I can send you a working project.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; This port have just one &quot;problem&quot;, the macros &quot;portSAVE&#95;CONTEXT&quot; and &quot;portRESTORE&#95;CONTEXT&quot; are implemented in assembly and can be used just in assembly files, so to call an interruption that can cause a context switch, it is necessary to create a assembly wrapper. As a example, I am sending you the file serialISRE.s, from the original demo.
&nbsp;&nbsp; I am not using these macros in my project now, and it works the way it was implemented, but I think that I will try to modify it when I need to use them. I don&#8217;t now yet if it can be done, the author of the demo made it this way because the RealView compiler have some restrictions in the assembly code that can be used inline in the C code.
&nbsp;&nbsp; One last commentary about the port, I didn´t test it in THUMB mode.
&nbsp;&nbsp; I hope that this files help you save some time, and if you find some bug or have some idea of how to implement &quot;portSAVE&#95;CONTEXT&quot; and &quot;portRESTORE&#95;CONTEXT&quot; as inline assembly, please send me a e-mail.
