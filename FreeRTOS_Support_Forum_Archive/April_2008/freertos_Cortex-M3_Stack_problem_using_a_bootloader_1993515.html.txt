In the port.c file the MSP &#40;main stack pointer&#41; is initialized assuiming that the vector table is strored at the adress 0x00000000, using a bootloader this is not hte case. For that reason I modified the code as follow:
Line 160:&nbsp;&nbsp; prvSetMSP&#40; &#42;&#40;&#40;unsigned portLONG &#42;&#41; portNVIC&#95;VTABLE &#41; &#41;;
The portNVIC&#95;VTABLE must be defined using:
&#35;define portNVIC&#95;VTABLE&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 0xE000ED08
Hope can help&#8230;.
