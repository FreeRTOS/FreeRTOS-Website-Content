In fact, I have to ensure that 64KB of Ram is enough to include lwIP, USB CDC, IRDA stack and enough space to include my own application.
regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">IRDA stack vs FreeRtos </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 18, 2006</div><div class="thread-post-content">I would have thought 64 was enough, but to be sure you can look at the ROM/RAM usage in the CrossStudio IDE.&nbsp; If you build your code then look in the project window you will see the rom and ram usage of each component.&nbsp; You can lower the stack size used by the kernel if you remove the demo tasks.
</div></div><div class="thread-post"><h3 class="thread-post-title">IRDA stack vs FreeRtos </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 19, 2006</div><div class="thread-post-content">I agreee, but to do that I have to merge the IRDA stack in FreeRtos and this will take a while. I only want to make a prediction. 
Does it exist a way to calculate the Heap memory needed when we add a task. For example, IRDA stack takes 10K of Flash and less than 1K of RAM, but how many heap memory must I reserve to include it in the kernel. May be its impossible to evaluate like that ? 
regards
</div></div><div class="thread-post"><h3 class="thread-post-title">IRDA stack vs FreeRtos </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 19, 2006</div><div class="thread-post-content">Assuming ARM7,
Tasks take:
sizeof&#40; tskTCB &#41; + &#40; requested stack &#42; 4 &#41; bytes of heap.
Queues task:
sizeof&#40; xQUEUE &#41; + &#40; sizeof&#40; Item&#95;being&#95;stored &#41; &#42; queue&#95;length &#41; bytes of heap.
</div></div><div class="thread-post"><h3 class="thread-post-title">IRDA stack vs FreeRtos </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 19, 2006</div><div class="thread-post-content">The heap is only used when the kernel calls pvPortMalloc.&nbsp; You can choose to use pvPortMalloc for your irda stack also if you wish, but would suggest that you just allocate the necessary RAM statically.
