</div></div><div class="thread-post"><h3 class="thread-post-title">Windoze Simulator</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 11, 2006</div><div class="thread-post-content">How are you using jlink with gcc?&nbsp; I would like to have an alternative to the wiggler.

</div></div><div class="thread-post"><h3 class="thread-post-title">Windoze Simulator</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 11, 2006</div><div class="thread-post-content">keil only support c. It does not have c++.
using Visual c++ for simulation is better than anything else.Because it is ANSI C&nbsp; compliant,more near to embedded system.
What is you idea about proteus?
VC++ have very nice IDE editor and debugger and it is possible to simulate peripherals like as UART,SPI,I2C,GPIO,Timers,&#8230;. in it.
</div></div><div class="thread-post"><h3 class="thread-post-title">Windoze Simulator</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 12, 2006</div><div class="thread-post-content">I am using the Segger Jlink cable instead of the wiggler.

A damn sight more reliable than the wiggler, and you can download and debug flash apps. &#40;i use the download ability of JlinkServer, but haven&#8217;t the time to muck around with the gdb&#41;.&#40;old school flashing lights..&#41;
