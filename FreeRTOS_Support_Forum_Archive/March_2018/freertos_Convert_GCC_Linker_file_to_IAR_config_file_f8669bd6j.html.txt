</div></div><div class="thread-post"><h3 class="thread-post-title">Convert GCC Linker file to IAR config file</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on March 27, 2018</div><div class="thread-post-content">https://sourceforge.net/p/freertos/discussion/382005/thread/7399998f/?limit=25#0dee/1e98
</div></div><div class="thread-post"><h3 class="thread-post-title">Convert GCC Linker file to IAR config file</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on March 27, 2018</div><div class="thread-post-content">These are linker variables, you would have to check the IAR manual to 
see if IAR provides an equivalent &#8211; but probably the simplest method 
would be to #define them to constants within the C code, rather than in 
the linker script.  The important thing is to ensure that the memory 
areas used by the heap are not used to store any variables &#8211; so you 
would have to check the linker script, and update the memory it defines 
if needed, to make sure the memory allocated to the heap and the memory 
allocated by the linker do not overlap.
</div></div><div class="thread-post"><h3 class="thread-post-title">Convert GCC Linker file to IAR config file</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kat123">kat123</a> on March 27, 2018</div><div class="thread-post-content">Thank you very much!
I can definitely see how to do that for <code>_estack</code> as that is defined as an address. 
However, <code>_bss_end__</code> is less clear, what I can see in the linker file
~~~
  /* This is used by the startup in order to initialize the .bss secion <em>/
    _sbss = .;         /</em> define a global symbol at bss start <em>/
    <strong>bss_start</strong> = _sbss;
    *(.bss)
    *(.bss</em>)
    *(COMMON)
<pre><code>. = ALIGN(4);
_ebss = .;         /* define a global symbol at bss end */
__bss_end__ = _ebss;
</code></pre>
~~~
How would I find the address to set this to? 
</div></div><div class="thread-post"><h3 class="thread-post-title">Convert GCC Linker file to IAR config file</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kat123">kat123</a> on March 28, 2018</div><div class="thread-post-content">I&#8217;ve added these lines at the strat of my main file and now the code compiles 
~~~
<h1>pragma section=&#8221;.bss&#8221;</h1>
uint32<em>t *bss</em>section_end = __section_end(&#8220;.bss&#8221;);
<h1>pragma section=&#8221;CSTACK&#8221;</h1>
uint32<em>t *stack</em>block_end = __section_end(&#8220;CSTACK&#8221;);
~~~
