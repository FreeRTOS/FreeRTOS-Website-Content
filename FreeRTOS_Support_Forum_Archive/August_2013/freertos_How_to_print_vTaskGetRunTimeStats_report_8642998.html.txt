</div></div><div class="thread-post"><h3 class="thread-post-title">How to print vTaskGetRunTimeStats report?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on August 22, 2013</div><div class="thread-post-content">You need to allocate a buffer into which the stats information can be written, and pass a pointer to that buffer into the vTaskGetRunTimeStats&#40;&#41; function.&nbsp;   
At the moment you are declaring a pointer, but the pointer is not initialised, so you don&#8217;t know where it is pointing.&nbsp; The vTaskGetRunTimeStats&#40;&#41; function is therefore going to write the table of stats information into a random place in your RAM.  
This can be easily fixed by changing the line   
<pre><code>char *stats;
</code></pre>
To   
<pre><code>char stats[ 2048];
</code></pre>
Assuming 2048 bytes is adequate to hold the generated table of information.&nbsp; Then when you pass stats into the function you are passing a pointer to a 2K buffer.&nbsp;   
Regards.
