</div></div><div class="thread-post"><h3 class="thread-post-title">LPC3250 porting</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on October 5, 2017</div><div class="thread-post-content">A couple of notes:
1) Is you vPortYieldProcessor() also a naked function?  If not, it needs 
to be.
2) The call to timer<em>ioctl() needs to be in assembly too. 
portTickTimerId in register r0, TMR</em>CLEAR<em>INTS in r1 and 1 in r2.  It 
might just be simpler to write the code inline using assembly, or have a 
function that takes no parameters that calls 
timer</em>ioctl(portTickTimerId, TMR<em>CLEAR</em>INTS, 1) so you can simply bl to 
that function rather than load the registers and bl to timer_ioctl.
