I am working on a project using the Rowley compiler, and i saw that the 
declaration of the stack size in the lwip demo for sam7x in the file flash&#95;placement.xml is set to 0.
My question is, is this the correct setting ?
Does this not pose a problem at start up &#40;creating tasks and starting the scheduler&#41;?
What do other users of the rowley compiler set there stack sizes to ?
regards,
Martin

whitin the Rowley IDE.
regards,
Martin
</div></div><div class="thread-post"><h3 class="thread-post-title">Rowley project stack size = 0 ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/embeddedc">embeddedc</a> on February 19, 2007</div><div class="thread-post-content">I would expect the users/system mode stack to be set to 0 as the stacks used by the tasks are allocated when the task is created.
The IRQ stack should be configured.
The FIQ stack may or may not be configured.
The System mode stack should be configured, but may just be set to the bottom of the other stacks so it can use any space left.
It might be that the stacks are configured in the start up assembler file, and that the settings in the project are ignored.&nbsp; Can you check the map file and see if this is the case?
</div></div><div class="thread-post"><h3 class="thread-post-title">Rowley project stack size = 0 ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on February 19, 2007</div><div class="thread-post-content">Just checked the demo and it seems that the svc stack starts at 0x20f7ac and uses 400 bytes before it hits the irq stack at 0x20f16c.&nbsp; I dont know where it gets the 400 from.
</div></div><div class="thread-post"><h3 class="thread-post-title">Rowley project stack size = 0 ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on February 19, 2007</div><div class="thread-post-content">In the project there is flash&#95;placement.xml.&nbsp; Open this, double click on External SRAM, then look at the section properties.&nbsp; This is where the 400 &#40;0x190&#41; size is setup.&nbsp; I don&#8217;t know how this relates to the settings for stack sizes in the project.&nbsp; Can somebody from Rowley comment?
</div></div><div class="thread-post"><h3 class="thread-post-title">Rowley project stack size = 0 ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/martinpb">martinpb</a> on February 20, 2007</div><div class="thread-post-content">The values in flash&#95;placement.xml corresponds to the value set from within Rowley.
But is it necessary to setup stacks there, to make sure the application runs with
a correctly setup stack ?
</div></div><div class="thread-post"><h3 class="thread-post-title">Rowley project stack size = 0 ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 20, 2007</div><div class="thread-post-content">I just looked at one of the sample applications that comes with CrossWorks and it does not used the xml file directly, it just uses the IDE settings.&nbsp; To be honest I&#8217;m not sure why I set up the stacks this way.&nbsp; It might be a legacy thing from CrossWorks V1.5, or it might be that this was the first project I did in CrossWorks and did not make full use of the IDE as it is intended to be used.
