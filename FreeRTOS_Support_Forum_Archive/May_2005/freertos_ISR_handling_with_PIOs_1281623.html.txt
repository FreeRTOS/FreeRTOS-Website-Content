</div></div><div class="thread-post"><h3 class="thread-post-title">ISR handling with PIOs</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 11, 2005</div><div class="thread-post-content">I cannot see anything obviously wrong by looking at the code.&nbsp; Unfortunately I will not be able to try it until Sunday but here are a couple of pointers:
&#43; Could it be a stack problem?&nbsp; Try increasing the stack size a bit &#8211; or inspecting the stack in the debugger.
&#43; Currently the code is always set to pass false to portEND&#95;SWITCHING&#95;ISR.&nbsp; If you are not wanting to cause a context switch from within the ISR then you do not require any special syntax, and the standard IAR syntax can be used.&nbsp; You also then dont then require the wrapper either &#40;see the &quot;interrupt service routines&quot; section of http://www.freertos.org/portsam7iar.html for detail&#41;.&nbsp; 
Even if you are intending on adding a context switch within the ISR at a later time it might be worth trying it without the wrapper to start with to check that there is nothing else wrong.
Let me know how you get on.&nbsp; If you are still having problems on Sunday I should&nbsp; be able to setup a test.
Regards.
