</div></div><div class="thread-post"><h3 class="thread-post-title">Queue Handling</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on July 8, 2009</div><div class="thread-post-content">Note that taskYield&#40;&#41; will only switch to a task with same or higher priority &#40;and higher only if preemption is turned off or some ISR didn&#8217;t run the scheduler when it needed, as otherwise they would have been running already&#41; as the task is still marked &quot;Ready&quot; so if it is still the highest priority task that is ready it will still run. taskDelay makes the current task &quot;Not Ready&quot; so lower priority tasks can execute.
