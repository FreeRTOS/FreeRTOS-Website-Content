</div></div><div class="thread-post"><h3 class="thread-post-title">DSM and Low power mode</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on July 1, 2009</div><div class="thread-post-content">The way it is often done is by defining an idle task &#40;executed when nothing else is ready to execute&#41; which puts the processor in whatever sleep mode you want.
</div></div><div class="thread-post"><h3 class="thread-post-title">DSM and Low power mode</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/aturowski">aturowski</a> on July 1, 2009</div><div class="thread-post-content">The easy way to hook into idle task without having to modify FreeRTOS code is to use
void vApplicationIdleHook&#40; void &#41; function to do the job putting processor in sleep mode. To use it you have to include
&#35;define configUSE&#95;IDLE&#95;HOOK&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 1
in your FreeRTOSConfig.h file.
</div></div><div class="thread-post"><h3 class="thread-post-title">DSM and Low power mode</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/yariv008">yariv008</a> on July 1, 2009</div><div class="thread-post-content">Thanks for quick answer.
In that case when I call vApplicationIdleHook&#40; void &#41; what makes the processors to wake up again?
I guess that in case of idle task, interrupt will wakeup the system.
Also is there any watchdog timer for each task&nbsp; ?
Thanks
</div></div><div class="thread-post"><h3 class="thread-post-title">DSM and Low power mode</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/aturowski">aturowski</a> on July 2, 2009</div><div class="thread-post-content">Almost all CPUs are woken up from sleep mode by interrupt. So the same applies to FreeRTOS.
When CPU will be woken up by interrupt, interrupt service routine will wake up any task&nbsp; waiting for data provided by this ISR. CPU will be active until all pending tasks will be executed and then idle task will be executed. This in turn will call vApplicationIdleHook&#40; void &#41; putting CPU back into sleep mode.
Please note that FreeRTOS uses tick timer interrupt to run preemptive scheduler. This interrupt occurs &#40;usually&#41; every 1ms. So CPU will be woken up every 1ms,&nbsp; any pending task will be executed and then idle task will be called to put CPU back to sleep.
Regarding watchdog timer question there is no such timer for each task. You have to implement it yourself if you really need it.
Hope that helps,
Adam
