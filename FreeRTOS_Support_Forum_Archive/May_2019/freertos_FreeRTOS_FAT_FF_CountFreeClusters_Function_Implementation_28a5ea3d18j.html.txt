  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS + FAT FF_CountFreeClusters()  Function Implementation</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kydong2019">kydong2019</a> on May 8, 2019</div><div class="thread-post-content">Hello Hein Tibosch
Recently, I am studying the FreeRTOS + FAT source code using FreeRTOS-Plus-FAT-160919a-MIT.zip.
I have some questions about the  implementation of <code>uint32_t FF_CountFreeClusters( FF_IOManager_t *pxIOManager, FF_Error_t *pxError )</code> need your advice.
Question 1:
I Think 
<code>for( ulIndex = 0; ulIndex &lt; pxIOManager-&gt;xPartition.ulSectorsPerFAT; ulIndex++ )</code> should be changed to
<code>for( ulIndex = 0; ulIndex &lt; pxIOManager-&gt;xPartition.ulSectorsPerFAT * pxIOManager-&gt;xPartition.ucBlkFactor; ulIndex++ )</code> 
for the case that <code>pxIOManager-&gt;xPartition.usBlkSize &gt; pxIOManager-&gt;usSectorSize</code>
Question 2:
<code>pxIOManager-&gt;xPartition.ulNumClusters</code> don&#8217;t include  the first reserved 2 fat entries, so I think
<code>if( ClusterNum &gt; pxIOManager-&gt;xPartition.ulNumClusters )</code>
should be changed to
<code>if( ClusterNum &gt; pxIOManager-&gt;xPartition.ulNumClusters  + 2)</code>
because the code also check the first reserved 2 fat entries in the FAT Area. and count these 2 fat entries into <code>ClusterNum</code>.
Question 3:
~~~
/* ulFreeClusters is -2 because the first 2 fat entries in the table are reserved. */
if( ulFreeClusters > pxIOManager->xPartition.ulNumClusters )
{
   ulFreeClusters = pxIOManager->xPartition.ulNumClusters;
}
~~~
The values of the first 2 fat entries aren&#8217;t zero, So I don&#8217;t think this if condition could be TRUE in some cases.
