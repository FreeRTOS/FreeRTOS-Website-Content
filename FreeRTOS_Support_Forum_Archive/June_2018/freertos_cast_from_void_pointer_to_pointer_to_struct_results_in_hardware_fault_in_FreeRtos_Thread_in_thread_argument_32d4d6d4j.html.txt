</div></div><div class="thread-post"><h3 class="thread-post-title"> cast from void pointer to pointer to struct results in hardware fault in FreeRtos Thread in thread argument</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on June 14, 2018</div><div class="thread-post-content">If your question is &#8220;the pointer to Board<em>A</em>blinky is corrupt inside the 
task air<em>blinky&#8221; then that is because Board</em>A<em>blinky is defined on the 
stack of main() &#8211; which no longer exists when the scheduler has been 
started.  Either make Board</em>A_blinky static so it is not on the stack, 
or move the definition to be file scope.
