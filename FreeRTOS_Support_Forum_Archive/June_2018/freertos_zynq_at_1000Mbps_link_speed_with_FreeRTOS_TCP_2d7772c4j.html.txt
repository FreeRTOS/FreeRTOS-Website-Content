I downloaded the labs 160919 package and have the demo working at 100Mbps. Is there another setting that has to change as well?  I notice that the zynq support files in 160919 are behind FreeRTOS10.0.1 &#8211; should I update them?  I&#8217;m using v2018.1 of the Xilinx SDK.

</div></div><div class="thread-post"><h3 class="thread-post-title">zynq at 1000Mbps link speed with FreeRTOS+TCP</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/wzengerle">wzengerle</a> on June 18, 2018</div><div class="thread-post-content">ipconfigNIC<em>LINKSPEED</em>AUTODETECT did the trick, thanks for your help.
I also merged in the code you attached and it seems to work (well, connects at 1000Mbps and logs; I haven&#8217;t tried the other functions at this point).  I had to make a couple of changes to get it to compile &amp; link:
&#8211; def&#8217;d out lines 213 to 219 of NetworkInterface.c (the function xCheckLoopback() isn&#8217;t included in my project)
&#8211; in x<em>emacpsif</em>dma.c, I commented out the line #include &#8220;eventLogging.h&#8221; and the 2 calls to eventLogAdd() on lines 382 &amp; 647 &#8211; looks like some debug code; I don&#8217;t have an eventLogging.h in my FreeRTOSlabs based project.
&#8211; also in x<em>emacpsif</em>dma.c, on line 480 I changed passEthMessages(); to passEthMessages(ethMsg);  the code wasn&#8217;t consistent and wouldn&#8217;t compile (older versions using file scope variable instead of passing the ptr).
I&#8217;m also curious why the allocation for the uncached memory is done the way it is.  Putting something after the linker&#8217;s &#8216;end&#8217; marker seems like asking for trouble.  Why not just use a static buffer and mark it  with the align directive?
Like so:
  static uint8<em>t uncached</em>mem[UNCACHED<em>MEMORY</em>SIZE] <strong>attribute</strong> ((aligned (UNCACHED<em>MEMORY</em>SIZE)));
    pucStartOfMemory = &amp;uncached_mem[0];  
Instead of:
    /* At the end of program&#8217;s space&#8230; <em>/
    pucStartOfMemory = (uint8_t *) &#038;_end;
    /</em>
     * Align the start address to 1 MB boundary.
     */
    pucStartOfMemory = (uint8_t *)( ( ( uint32_t )pucStartOfMemory + UNCACHED_MEMORY_SIZE ) &amp; ( ~( UNCACHED_MEMORY_SIZE &#8211; 1 ) ) );
Lastly, something that will cause issues with anyone trying to use C++: 
    There is one place left that I can see where a function declaration is in the .c files rather than including Networkinterface.h.  x<em>emacpsif</em>hw.c line 143 (xNetworkInterfaceInitialise).
