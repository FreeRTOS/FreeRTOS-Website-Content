</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS : Cache Invalidation when Task Switching on ARM Corterx CM7</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on April 2, 2018</div><div class="thread-post-content">Is the Ethernet using DMA?  We have generally found that, if that is the 
case, the easiest thing to do is to ensure the memory used by the DMA is 
marked as non-cacheable &#8211; otherwise you will have two memory bus masters.
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS : Cache Invalidation when Task Switching on ARM Corterx CM7</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/balajisubrcyp">balajisubrcyp</a> on April 2, 2018</div><div class="thread-post-content">Hi Richard,
This is STM32H7 MCU intefacing with ARM cortex CM4 via SDIO bus. ARM CM4 is a Wifi Chip receiving Data from the Host STM32H7MCU. 
The buffer used a for the transfer is a global buffer aligned (on receive ) side..
ALIGNED<em>PRE(4) static uint8</em>t temp<em>dma</em>buffer[ MAX( 2 * 1024, MTU_SIZE+ 64 ) ] ALIGNED(4);
Do you know how to mark this data non-cacheable in FreeRTOS..
Also while writing data we use allocated buffer from heap..(TX) is there any way to mark some section of memory from heap as Non-Cacheable.. using FreeRTOS-lwip stack..
Thanks
Balaji.
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS : Cache Invalidation when Task Switching on ARM Corterx CM7</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on April 3, 2018</div><div class="thread-post-content"><blockquote>
  Do you know how to mark this data non-cacheable in FreeRTOS..
</blockquote>
It is not a FreeRTOS configuration, but an MCU configuration.  The easiest way to do it is to place the network buffers in a known memory location, then mark that memory as non cachable in the C start up code.  I think the Zynq demo does this already so you could use that as a reference.
