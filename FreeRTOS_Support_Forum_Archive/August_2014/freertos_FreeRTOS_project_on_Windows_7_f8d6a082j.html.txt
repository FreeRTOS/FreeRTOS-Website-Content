</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS project on Windows 7</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on August 13, 2014</div><div class="thread-post-content">&#8230;and you are sure the files are <b><i>unmodified</i></b> from those in a fresh FreeRTOS installation, because I I don&#8217;t think the Eclipse project settings are set to use -O2 in the command line, but that is what is shown in your build log.
