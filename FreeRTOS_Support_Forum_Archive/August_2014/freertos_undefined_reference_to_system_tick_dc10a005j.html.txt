</div></div><div class="thread-post"><h3 class="thread-post-title">undefined reference to &#8216;system_tick&#8217;</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on August 13, 2014</div><div class="thread-post-content">The first thing to note is that the official FreeRTOS download contains a GCC port for the ATMega, but not the XMega &#8211; which I think that part is.  That said there are plenty of people using FreeRTOS on XMega parts and you will find ports in the Atmel section of the <a href="http://interactive.freertos.org/forums/103473-Atmel">FreeRTOS Interactive</a> site.
The first thing to do would be to get a program that does not use FreeRTOS running on your hardware with Atmel Studio &#8211; then once you are sure your environment is working as expected &#8211; <a href="http://www.freertos.org/Creating-a-new-FreeRTOS-project.html">add in the FreeRTOS source files</a>.  In your case the port layer files you require are in the FreeRTOS/Source/portable/GCC/[whatever] directory &#8211; where [whatever] is whatever the directory is called in the contributed XMega port.
Regards.
