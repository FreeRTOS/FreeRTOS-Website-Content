</div></div><div class="thread-post"><h3 class="thread-post-title">Passing Data from custom peripheral to socket using FreeRTOS_Send</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on March 22, 2016</div><div class="thread-post-content">When the function <code>FreeRTOS_recv()</code> returns a negative number, it says:
<pre><code>else
{
    /* Socket closed? */
    break;
}
</code></pre>
It would be more correct to write:
<pre><code>else if( lBytes != -pdFREERTOS_ERRNO_EWOULDBLOCK )
{
    /* Socket closed? */
    break;
}
</code></pre>
When sending, you might get a non-fatal return value <code>-pdFREERTOS_ERRNO_ENOSPC</code>
What does your function <code>get_ifm_test_reg()</code> return? 
<pre><code>rd_data = get_ifm_test_reg(AXI_TO_REG_BASEADDR , TESTFREQ_REGISTER1_OFFSET);
</code></pre>
You assign the result to an integer <code>int rd_data</code>
Later on, you&#8217;re calling <code>FreeRTOS_send()</code> with <code>rd_data</code> as a parameter where <code>void *</code> is expected.
I&#8217;m afraid I do not understand the logic of your application 🙁
