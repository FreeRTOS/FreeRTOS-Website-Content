  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Crash on vPortFree</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/athos1984">athos1984</a> on March 20, 2016</div><div class="thread-post-content">Hi all,
I&#8217;m facing a crash (HardFault) into my project within pvPortMalloc/vPortFree functions.
heap_4 management, queues 16 in length, latest stable FreeRTOS Release.
Task#1 (Priority 2):
&#8211; addr = pvPortMalloc()
&#8211; q1_xQueueSend(addr)
&#8211; Force ISR#1
&#8211; &#8230;
&#8211; addr2 = pvPortMalloc()
&#8211; &#8230;
&#8211; vPortFree(addr2)
ISR#1:
&#8211; q1_xQueueReceiveFromISR(addr)
&#8211; Force ISR#2
ISR#2:
&#8211; q2_xQueueSendFromISR(addr)
Task#2  (Priority 4):
&#8211; top:
&#8211; q2_xQueueReceive(addr)
&#8211; vPortFree(addr)
&#8211; goto top
Some debug infos:
&#8211; No crash if code runs @ lower MCU speed (64MHz vs 180MHz, STM32F1 vs STM32F4)
&#8211; No crash removing vPortFree from Task#2
&#8211; No crash if vPortFree inside Task#2 is delayed after xQueueReceive (by printf, or by vTaskDelay, or other)
&#8211; configASSERT inside pvPortMalloc tells me that &#8220;blocks are NOT aligned to the required number of bytes&#8221;
&#8211; configASSERT inside vPortFree tells me that &#8220;block is NOT actually allocated&#8221;
I tried:
&#8211; different priorities
&#8211; different ISR preemption priorities
What can I do? Any idea?
Thanks
j
</div></div><div class="thread-post"><h3 class="thread-post-title">Crash on vPortFree</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on March 20, 2016</div><div class="thread-post-content">It is difficult to say what could be wrong without seeing how the queue is created and how the addr is passed into the queue.  Is the queue created to hold pointers?  Are you reading the value out of the queue into a pointer?
</div></div><div class="thread-post"><h3 class="thread-post-title">Crash on vPortFree</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/athos1984">athos1984</a> on March 20, 2016</div><div class="thread-post-content">Both queues are used to send/receive addresses of dynamically allocated objects (structures): xQueueCreate(16, sizeof(struct object *))
T1
struct object *o = pvPortMalloc(sizeof(struct object))
xQueueSend(q1, &amp;o, portMAXDELAY)
struct object *i (global var)
ISR1
xQueueReceiveFromISR(q1, &amp;i, &amp;higherWoken)
ISR2
xQueueSendFromISR(q2, &amp;i, &amp;higherWoken)
T2
struct object *f
xQueueReceive(q2, &amp;f, portMAXDELAY)
vPortFree(f)
</div></div><div class="thread-post"><h3 class="thread-post-title">Crash on vPortFree</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on March 20, 2016</div><div class="thread-post-content">Maybe just a typing error in your post or sourceforge formatting, but shouldnt that be
