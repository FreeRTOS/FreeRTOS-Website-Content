It must be below <a href="http://www.freertos.org/RTOS-Cortex-M3-M4.html">configMAX<em>SYSCALL</em>INTERRUPT_PRIORITY</a>. </div></div><div class="thread-post"><h3 class="thread-post-title">xTaskNotifyWait never gets notification in TIVA TM4C1294</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on March 17, 2016</div><div class="thread-post-content">The kernel interrupt priority (PendSV and SysTick) is set in the 
FreeRTOS port layer &#8211; and <em>must</em> be the lowest possible interrupt priority.
Any interrupt that makes use of the FreeRTOS API cannot be left at its 
default priority, and must be set to a priority at or below 
configMAX<em>SYSCALL</em>INTERRUPT_PRIORITY.
As there are priorities 0 to 7 on your device then there must it must 
implement three priority bits (or the possible 8, although in practice 3 
or 4 bits seems to be the norm).
