</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS and Microchip Harmony</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on September 2, 2015</div><div class="thread-post-content">I would recommend asking questions related to running FreeRTOS on a PIC32 (configuration, interrupt handlers, etc.) on this forum, and questions relating to the Harmony integration on the Microchip forum. </div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS and Microchip Harmony</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/blavo1">blavo1</a> on September 2, 2015</div><div class="thread-post-content">I&#8217;ve been successful in getting a project started.  I&#8217;d recomend using 1.06 from what the microchip support team told me, the even number releases are based off the main trunk.
One thing you could try if you haven&#8217;t already, as you mentioned you&#8217;re using 795 device which I&#8217;m guessing you already own an ethernet starter kit.
I would look at sample applications that ship with Harmony.  In the ~/apps/rtos/freertos directory you&#8217;ll see a tcpip<em>client</em>server which is using freertos and was created using harmony configurator.  You can look at that example and see what was done there.  
For you&#8217;re custom hardware you may be able to start with project and use you&#8217;re own board support package or you can use the harmony configurator tool to create from scratch using the settings from the tcpip<em>client</em>server settings as an reference.
If you decide to post to the microchip forum, I&#8217;ll look for your posting there if you need more help.
