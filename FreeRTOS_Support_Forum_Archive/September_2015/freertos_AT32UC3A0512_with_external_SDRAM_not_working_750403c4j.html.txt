</div></div><div class="thread-post"><h3 class="thread-post-title">AT32UC3A0512 with external SDRAM not working</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on September 9, 2015</div><div class="thread-post-content">Hi Adis,
Using Atmel&#8217;s UC3A0512 :
<blockquote>
  { ( uint8_t * ) 0xD0000000UL, 0x7A12000 },
</blockquote>
My calculator says that &#8216;0x7A12000&#8217; equals 128000000, which is about 122 MB. Accessing non-existent memory might lead to a crash (hardware exception). You write that you have 16MB of SDRAM, which corresponds to 0x1000000.
The heap regions are described in an array of:
~~~~~
/* Used by heap<em>5.c. */
typedef struct HeapRegion
{
    uint8</em>t *pucStartAddress;
    size_t xSizeInBytes;
} HeapRegion_t;
~~~~~
You could write it like this:
~~~~~
<h1>incluide &lt;avr32/io.h></h1>
/*
which includes &#8220;uc3a0512.h&#8221; with this declaration:
<h1>define AVR32<em>EBI</em>CS1_ADDRESS              0xD0000000</h1>
*/
<h1>define SDRAM<em>ADDRESS     ( AVR32</em>EBI<em>CS1</em>ADDRESS )</h1>
<h1>define SDRAM_SIZE        ( 16ul * 1024 * 1024 )</h1>
/*
 * What is the clock speed of your CPU: 48, 60 or 66 MHz ?
 * The HSB (High-Speed-Bus) is equal to the CPU speed,
 * they&#8217;re coupled.
 */
<h1>define CLOCK<em>HSB</em>HZ    48000000</h1>
const HeapRegion<em>t xHeapRegions[] =
{
    { ( uint8</em>t * ) SDRAM<em>ADDRESS, ( size</em>t ) SDRAM<em>SIZE },
    { ( uint8</em>t * ) NULL, ( size_t ) 0 }
};
/* or if you like, a less-used C syntax: */
const HeapRegion<em>t xHeapRegions[] =
{
    [0] = {
        .pucStartAddress = ( uint8</em>t * ) SDRAM<em>ADDRESS,
        .xSizeInBytes = ( size</em>t ) SDRAM<em>SIZE
    },
    [1] = {
        .pucStartAddress = ( uint8</em>t * ) NULL,
        .xSizeInBytes = ( size_t ) 0
    }
};
void main()
{
    /* Initialise the SDRAM. <em>/
    /</em> See &#8220;EBI/SDRAMC/sdramc.c&#8221; */
    sdramc_init( CLOCK_HSB_HZ );
<pre><code>/* Tell heap_5 which heap area(s) can be used. */
vPortDefineHeapRegions( xHeapRegions );
/* Your code: */
trvInitHercules();
/* The string "Blink MCU" doesn't need a cast to
because now xTaskCreate() takes a const char* */
xTaskCreate( trvBlinkMCULED, "Blink MCU", configMINIMAL_STACK_SIZE,
    NULL, mainLED_TASK_PRIORITY1, NULL );
xTaskCreate( trvBlinkAlarmLED, "Blink Alarm", configMINIMAL_STACK_SIZE,
    NULL, mainLED_TASK_PRIORITY2, NULL );
vTaskStartScheduler();
</code></pre>
}
~~~~~
Will that work?
Regards.
