</div></div><div class="thread-post"><h3 class="thread-post-title">Resuming task from interrupt delay problem</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on September 21, 2015</div><div class="thread-post-content">Please read the documentation for the <a href="http://www.freertos.org/taskresumefromisr.html">xTaskResumeFromISR()</a> as it tells you two things:
1) <strong>Don&#8217;t</strong> use the function to synchornise a task with an interrupt &#8211; it is dangerous and can lead to missed interrupts as it does not latch interrupts (like a semphore or task notification would).  That might be what your problem is.
2) Use the function&#8217;s return value to know if a context switch is required:
<pre>
xYieldRequired = xTaskResumeFromISR( handle );
portYIELD_FROM_ISR( xYieldRequired );
</pre>
