My end goal is to implement the FreeRTOS FAT SL file system on a PSoC5LP Dev Kit (CY8CKIT-050). 
<em>Do I actually need to integrate there real time kernel with the FAT SL file system files in my project or can the FAT SL file system code stand alone?</em>
To do this, I took the advice presented on FreeRTOS.org and tried to get a demo project up and running. I chose to test out the CORTEX<em>CY8C5588</em>PSoC<em>Creator</em>GCC project for FreeRTOSv8.2.2. I opened up the project in PSoC Creator 3.2 in the original project directory. I updated the device from the original device to the CY8C5868AXI-LP035 TQFP100, which is the processor on the PSoC5LP development kit.  The PSoC Creator prompted me to update the components wihtin the project as the originals were out of date. I performed that updated and then built the project.  The project errored out before it could be completely built and displayed the following error:
<em>prj.M0120:Build error: FreeRTOS.h: no such file or directory, BlockQ.c, Line 97</em>
I did not want to start modifying the code and hoped there was a simple fix for this. What do I need to do to fix this issue?
Once I get the demo project working, how do I integrate the FAT SL functionality into the project and remove the functions that are not necessary? How do I identify what parts of the project aren&#8217;t needed for the FAT SL functionality?
All help and advice is greatly appreciated!
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS FAT SL, Demo project, PSoC 5 Dev Kit</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on September 24, 2015</div><div class="thread-post-content">I think you can use the file system without any OS if you set F<em>FS</em>THREAD<em>AWARE to 0.
http://www.freertos.org/FreeRTOS-Plus/FreeRTOS</em>Plus<em>FAT</em>SL/embedded-file-system-configuration.shtml
That demo was created some time ago and presumably the tools have changed a lot since.
<blockquote>
  prj.M0120:Build error: FreeRTOS.h: no such file or directory, BlockQ.c, Line 97
  I did not want to start modifying the code
</blockquote>
This is simply telling you it can&#8217;t find a header file.  No need to modify the code, just ensure FreeRTOS/source/include is in the compiler&#8217;s include path.
