  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS for Renesas R-Car</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/toby-flenderson">toby-flenderson</a> on February 20, 2019</div><div class="thread-post-content">I tried searching for ROTS for the Renesas R-Car H3 and V3H but couldnt find any. They both have quad core  ARM Cortex A53. Is there any varient of the FreeRTOS that I can use to run on these SOCs?
For reference, here are the block diagrams for the two-
H3    &#8211; https://www.renesas.com/us/en/solutions/automotive/soc/r-car-h3.html
V3H &#8211; https://www.renesas.com/us/en/solutions/automotive/soc/r-car-v3h.html
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS for Renesas R-Car</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 20, 2019</div><div class="thread-post-content">Demonstrated on a different part, but this may get you started.  Note it 
is just a flat memory model, as per the model used when running FreeRTOS 
on MCUs: https://www.freertos.org/RTOS-Xilinx-UltraScale<em>MPSoC</em>64-bit.html
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS for Renesas R-Car</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/toby-flenderson">toby-flenderson</a> on February 20, 2019</div><div class="thread-post-content">Thank you Richard. I actually have the zcu102 board at my desk and have the Xilinx SDK installed. Do you mean to say I can build the FreeRTOS using it and use it on the Renesas too? Wont the Device Tree, BSP and others vary?
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS for Renesas R-Car</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 20, 2019</div><div class="thread-post-content">This is just the kernel ported to the core &#8211; that part interacts with 
the hardware directly with no library support.  The application, on the 
other hand, uses the drivers provided by Xilinx on that page, so 
likewise would use the Renesas drivers when the kernel is on Renesas 
hardware.
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS for Renesas R-Car</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/toby-flenderson">toby-flenderson</a> on February 22, 2019</div><div class="thread-post-content">I got the source files and the demo project for the ARM53 for Xilinx. I could test it out on the zcu102 and debug.  I see in the link you provided that FreeRTOS can either be built part of the BSP or as an application. How do I go about if I plan on porting this onto the ARM53 on Renesas R-Car?
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS for Renesas R-Car</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 22, 2019</div><div class="thread-post-content">Building as part of the BSP is specific to the Xilinx way of doing 
things, just look at the other project, which builds the source files 
directly as part of the application.  That is what you need to do to &#8211; 
add the correct source files into the application.  The following links 
might help:
https://www.freertos.org/a00017.html
https://www.freertos.org/Creating-a-new-FreeRTOS-project.html
https://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html
