  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">How to restart the task</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kuoping">kuoping</a> on May 10, 2008</div><div class="thread-post-content">I want to restart a task, but I do not find any of direct way to do it. Currently, I delete the task and re-create it again to restart the task. It will release the memory of stack, and allocate another memory space as stack. If I restart the task several times, it has a risky to cause memory fragmentation. How should I do to restart a task?
</div></div><div class="thread-post"><h3 class="thread-post-title">How to restart the task</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on May 10, 2008</div><div class="thread-post-content">If &#40;you are using heap&#95;2&#41; &amp;&amp; &#40;the stack size allocated to the task is always the same&#41; &amp;&amp; &#40;you are not dynamically creating and deleting any other objects &#40;queues for example&#41;&#41; then you should not suffer from fragmentation as the same memory block will just get reused. This is easy enough to test.
</div></div><div class="thread-post"><h3 class="thread-post-title">How to restart the task</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kuoping">kuoping</a> on May 11, 2008</div><div class="thread-post-content">Unfortunately, I use malloc function call &#40;Newlib C library&#41; to allocate memory instead of heap&#95;2, and the other task may dynamically allocate memory when the task is restarted. I am not sure the impact of memory fragmentation on the more complicate application, so I need more safe mechanism to restart the task. Actually, I want to implement the plug-ins function in my system. It will stop the task of plug-ins, load the other code to the memory, and restart the task again to run the code of plug-ins. Maybe I can suspend the task and modify the content of TCB or whatever, and resume the task. But, dose exist any simple &amp; portable way to do that?
</div></div><div class="thread-post"><h3 class="thread-post-title">How to restart the task</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/zaphodbe">zaphodbe</a> on May 11, 2008</div><div class="thread-post-content">Why not just modify the code in the task so you can set a flag or send a message to it to cause it to restart.&nbsp; e.g.
boolean fMyTask&#95;Restart;
void MyTask &#40;void &#42;pvParameters&#41;
&#123;
&nbsp; for &#40;;;&#41; &#123;
&nbsp;&nbsp;&nbsp; fMyTask&#95;Restart = FALSE;
&nbsp;&nbsp;&nbsp; /&#42; Any other task initialization here &#42;/
&nbsp;&nbsp;&nbsp; while &#40;&#33;fMyTask&#95;Restart&#41; &#123;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; You main task code here &#42;/
&nbsp;&nbsp;&nbsp; &#125;
&nbsp; &#125;
&#125;
Now any time you want to restart the task just set fMyTask&#95;Restart to TRUE.&nbsp; You can also check the flag to make sure the restart occurred.
