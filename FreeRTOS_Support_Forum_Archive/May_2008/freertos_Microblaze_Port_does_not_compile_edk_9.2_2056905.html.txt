</div></div><div class="thread-post"><h3 class="thread-post-title">Microblaze Port does not compile [edk 9.2]</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 29, 2008</div><div class="thread-post-content">There has been a long discussion over the last few days about the Microblaze port, which was created &#40;and still functions under&#41; EDK V7.1 but not under later versions.&nbsp; There are two issues:
1&#41; This is the easy one to fix.&nbsp; The later versions of GCC generate warnings for code the old version was perfectly happy to let pass.&nbsp; The code currently in the FreeRTOS.org Subversion repository have fixed all these.&nbsp; The warning you highlight above is simply that the original declaration of the variable has a volatile qualifier, whereas the extern declaration in the macro does not.&nbsp; You can add the volatile qualifier to the extern declaration and the error will go away.
2&#41; More difficult is the change in the way interrupts are installed executed in the later versions of the EDK.&nbsp; This is going to require a code change to fix.&nbsp; It might be that the contributor to the other thread has this fixed already.&nbsp; If you look a couple of threads down the list you will see the one I&#8217;m referring to &#40;it has 20 or so replies&#41;.&nbsp;&nbsp; I hope to get this updated in the release soon but its not going to be in the next few days.
Regards.
