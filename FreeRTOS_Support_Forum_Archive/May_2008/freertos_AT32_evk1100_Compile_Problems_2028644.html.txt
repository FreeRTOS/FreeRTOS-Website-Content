  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">AT32 evk1100 Compile Problems</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/schmidtw">schmidtw</a> on May 4, 2008</div><div class="thread-post-content">I just downloaded FreeRTOS 5.0.0 and tried to build with the latest avr32-&#42; GNU toolchain from Atmel &amp; got several compile errors.&nbsp; It looks like the Atmel header files possibly changed.
First try:
$ make clean
$ make
Compiling &#96;../../BOARDS/EVK1100/led.c&#8217; to &#96;../../BOARDS/EVK1100/led.o&#8217;.
../../BOARDS/EVK1100/led.c:77: error: &#8216;AVR32&#95;PWM&#95;PWM&#95;0&#95;FUNCTION&#8217; undeclared here &#40;not in a function&#41;
../../BOARDS/EVK1100/led.c:77: error: &#8216;AVR32&#95;PWM&#95;PWM&#95;1&#95;FUNCTION&#8217; undeclared here &#40;not in a function&#41;
../../BOARDS/EVK1100/led.c:77: error: &#8216;AVR32&#95;PWM&#95;PWM&#95;2&#95;FUNCTION&#8217; undeclared here &#40;not in a function&#41;
../../BOARDS/EVK1100/led.c:77: error: &#8216;AVR32&#95;PWM&#95;PWM&#95;3&#95;FUNCTION&#8217; undeclared here &#40;not in a function&#41;
make: &#42;&#42;&#42; &#91;../../BOARDS/EVK1100/led.o&#93; Error 1
So in evk1100.h I changed AVR32&#95;PWM&#95;PWM&#95;x&#95;FUNCTION to AVR32&#95;PWM&#95;x&#95;FUNCTION &#8211; problem solved.
Second try:
$ make clean
$ make
Compiling &#96;../../BOARDS/EVK1100/led.c&#8217; to &#96;../../BOARDS/EVK1100/led.o&#8217;.
Compiling &#96;../../DRIVERS/INTC/intc.c&#8217; to &#96;../../DRIVERS/INTC/intc.o&#8217;.
../../DRIVERS/INTC/intc.c:52: error: &#8216;AVR32&#95;INTC&#95;IPR0&#95;INTLEV&#95;SIZE&#8217; undeclared here &#40;not in a function&#41;
../../DRIVERS/INTC/intc.c: In function &#8216;&#95;get&#95;interrupt&#95;handler&#8217;:
../../DRIVERS/INTC/intc.c:111: error: &#8216;avr32&#95;intc&#95;t&#8217; has no member named &#8216;icr3&#8217;
../../DRIVERS/INTC/intc.c: In function &#8216;INTC&#95;register&#95;interrupt&#8217;:
../../DRIVERS/INTC/intc.c:199: error: &#8216;AVR32&#95;INTC&#95;IPR0&#95;INTLEV&#95;MASK&#8217; undeclared &#40;first use in this function&#41;
../../DRIVERS/INTC/intc.c:199: error: &#40;Each undeclared identifier is reported only once
../../DRIVERS/INTC/intc.c:199: error: for each function it appears in.&#41;
../../DRIVERS/INTC/intc.c:199: error: &#8216;AVR32&#95;INTC&#95;IPR0&#95;INTLEV&#95;OFFSET&#8217; undeclared &#40;first use in this function&#41;
make: &#42;&#42;&#42; &#91;../../DRIVERS/INTC/intc.o&#93; Error 1
This time I&#8217;m not sure what AVR32&#95;INTC&#95;IPR0&#95;INTLEV&#95;SIZE should be mapped to.
Any ideas?
Here are the avr32 versions I&#8217;m using:

avr32parts-1.9.9-1.fc8
avr32-gdb-6.7.1.atmel.1.0.3-1.fc8
avr32headers-1.9.11-1.fc8
avr32program-3.0.4-1.fc8
avr32-binutils-2.17.atmel.1.2.6-1.fc8
libavr32ocd-3.0.8-1.fc8

libavr32sim-0.2.1-1.fc8
avr32-gcc-newlib-4.2.2-atmel.1.0.8&#95;1.fc8

Thanks,
Wes
</div></div><div class="thread-post"><h3 class="thread-post-title">AT32 evk1100 Compile Problems</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 5, 2008</div><div class="thread-post-content">Thanks for pointing this out.&nbsp; I have searched through the header files and come up with this:
&#35;define AVR32&#95;INTC&#95;IPR0&#95;INTLEV&#95;SIZE&nbsp; 2
This was in intc.h, which was marked as revision 36724, Fri 16th March 2007.
There has been some confusion over the AVR32 headers for a while, but this was historically more to do with the IAR builds than the GCC builds.
Atmel provide their own FreeRTOS.org projects that can be downloaded from the Atmel WEB site.&nbsp; It might be worth looking at these to see what they have changed these constants to.&nbsp; I will have to download the latest tools to make updated.
Regards.
