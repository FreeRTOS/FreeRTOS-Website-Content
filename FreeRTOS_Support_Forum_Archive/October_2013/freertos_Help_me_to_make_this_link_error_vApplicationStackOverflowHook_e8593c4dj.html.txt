</div></div><div class="thread-post"><h3 class="thread-post-title">Help me to make this link error &#8220;vApplicationStackOverflowHook</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/xz8987f">xz8987f</a> on October 16, 2013</div><div class="thread-post-content">Hello,
it is because you have asked to check for stack overflow in your FreeRTOSConfig.h:
configCHECK<em>FOR</em>STACK_OVERFLOW
Set it to 0 if you want Stack overflow disabled.
Altough I recommend to have it enabled. Simply add something like this to your application:
void FRTOS1<em>vApplicationStackOverflowHook(xTaskHandle pxTask, signed portCHAR *pcTaskName)
{
  /* This will get called if a stack overflow is detected during the context
     switch.  Set configCHECK</em>FOR<em>STACK</em>OVERFLOWS to 2 to also check for stack
     problems within nested interrupts, but only do this for debug purposes as
     it will increase the context switch time. <em>/
  (void)pxTask;
  (void)pcTaskName;
  taskDISABLE_INTERRUPTS();
  /</em> Write your code here &#8230; */
  for(;;) {}
}
If you are using ColdFire V2 (MCF52259) with CodeWarrior, then you might have a look at my Processor Expert component for FreeRTOS: it supports many cores, including ColdFire:
<a href="http://mcuoneclipse.com/2012/06/28/tutorial-freertos-on-demojm/">Tutorial: FreeRTOS on&nbsp;DEMOJM</a>
http://mcuoneclipse.com/tag/freertos/
I hope this helps.
