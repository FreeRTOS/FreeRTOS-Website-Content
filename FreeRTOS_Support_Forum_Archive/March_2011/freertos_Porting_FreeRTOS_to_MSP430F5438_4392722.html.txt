  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Porting FreeRTOS to MSP430F5438</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtostony">rtostony</a> on March 2, 2011</div><div class="thread-post-content">I&#8217;ve started porting FreeRTOS to MSP430F5438 using CCS. The development platform is MSP-EXP430F5438. Note that I am not porting to the MSP430X. I&#8217;ve gathered what I thought were all the soruce files, and what I thought would be the required changes to the port.c file, but I still have problems during the compile phase.  
Can someone supply the list of source files needed to build a new project? If anyone knows of the changes required to port to the MSP430F5438, I would very much appreciate it.
</div></div><div class="thread-post"><h3 class="thread-post-title">Porting FreeRTOS to MSP430F5438</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on March 2, 2011</div><div class="thread-post-content">There is already an MSP430F5438 demo that uses IAR so you can get the required files from that.&nbsp; A CCS version will also be released very soon.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">Porting FreeRTOS to MSP430F5438</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtostony">rtostony</a> on March 3, 2011</div><div class="thread-post-content">Yes, this is true, but it is the MSP430<strong>X</strong> version, not the standard MSP430F5438. I&#8217;ve looked at the IAR and CCS versions from Westmoreland Engineering, but those versions do not compile correctly, at least for me. I was using the latest version of the tools as well.  
I will try to use the IAR version as a guide to create a baseline for a new project, but so far, I haven&#8217;t had any luck.
</div></div><div class="thread-post"><h3 class="thread-post-title">Porting FreeRTOS to MSP430F5438</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on March 4, 2011</div><div class="thread-post-content">As far as I can tell the MSP430F5438 has an MSP430X core. I doubt TI have two versions with the same part number that have two different cores. It looks like you can compile for a small memory model that will keep to using MSP430 instructions.
</div></div><div class="thread-post"><h3 class="thread-post-title">Porting FreeRTOS to MSP430F5438</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtostony">rtostony</a> on March 5, 2011</div><div class="thread-post-content">The MSP430X is not the same as a MSP430. It is a 20-bit extension of the MSP430. They are two separate parts. Similar, but different.  
MSP430 = 16-bit address<br />
MSP430X = 20-bit address  
What I am trying to determine is how to port the MSP430X demo to MSP430. The MSP-EXP430F5438 board I have contains a MSP430F5438 &#40;non-&#8220;A&#8221; version&#41;. So, the current demo, as-is, will not work on my demo board.  
Any ideas?
