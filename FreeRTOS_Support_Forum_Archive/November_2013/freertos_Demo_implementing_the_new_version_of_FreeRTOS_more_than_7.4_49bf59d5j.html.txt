  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Demo implementing the new version of FreeRTOS (more than 7.4)</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/ltu-pierre">ltu-pierre</a> on November 6, 2013</div><div class="thread-post-content">Hi,
I am a student and I am working on a project using FreeRTOS v6.1.1 on a NXP LPC1769 Cortex M3 with LPCExpresso IDE but I am quite new in the RTOS world. =)
My problem is that I want to pend on multiple semaphore at the same time. I know that in the new version of FreeRTOS, there are queue sets that would allow me to do that.
I&#8217;m currently using FreeRTOS v6.1.1 Library given with the examples from the document &#8220;Using the FreeRTOS Real Time Kernel &#8211; A Practical Guide&#8221;.
My question is:
&#8211; Is there some demo(s) implementing these queue sets or at least the new version of FreeRTOS (more than 7.4 I think) ? I didn&#8217;t manage to find any of them on the web site.
&#8211; Or is there other solutions to pend on multiple semaphore at the same time ?
Best regards,
Pierre
</div></div><div class="thread-post"><h3 class="thread-post-title">Demo implementing the new version of FreeRTOS (more than 7.4)</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on November 6, 2013</div><div class="thread-post-content">From http://www.freertos.org/History.txt it looks like you are going to need to update to at least V7.4.0. You could copy the functionality into your v6 code, but I would not recommend that. Just update the code in FreeRTOS/source to the latest version.
</div></div><div class="thread-post"><h3 class="thread-post-title">Demo implementing the new version of FreeRTOS (more than 7.4)</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/ltu-pierre">ltu-pierre</a> on November 6, 2013</div><div class="thread-post-content">Thank you for your answer.
As you said, I update the code in FreeRTOS/source to the latest version. I kept the FreeRTOSConfig.h file and I add the line:
<h1>define configUSE<em>QUEUE</em>SETS        1</h1>
to be able to use the queue sets related fonctions. 
It seems to work know, so thank you !
Best regards
