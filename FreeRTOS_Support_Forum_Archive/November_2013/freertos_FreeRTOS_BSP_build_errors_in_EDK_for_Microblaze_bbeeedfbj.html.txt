  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS BSP build errors in EDK for Microblaze</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dagustaf">dagustaf</a> on November 19, 2013</div><div class="thread-post-content">Hi
I am trying to build a FreeRTOS BSP in EDK for Microblaze. It seems to be a path that is incorrect somewhere that tries to find &#8220;standalone<em>v3</em>01<em>a&#8221; but this directory is not present in the ISE 14.6 installation. Target is a Spartan6 on a custom board. I have already changed the &#8220;OPTION DEPENDS = (standalone</em>v3<em>07</em>a);&#8221;in &#8220;freertos<em>v2</em>1<em>0.mld&#8221; and the &#8220;set standalone</em>version standalone<em>v3</em>07<em>a&#8221; in &#8220;freertos</em>v2<em>1</em>0.tcl&#8221;. These were both originally st to &#8220;standalone<em>v3</em>01_a&#8221;.
The error I keep getting is:
make -k all 
libgen -hw ../microblaze<em>1</em>hw<em>platform/system.xml
           -lp C:/SDK</em>repository
           -pe microblaze<em>0 
           -log libgen.log 
           system.mss

</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS BSP build errors in EDK for Microblaze</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 19, 2013</div><div class="thread-post-content">We are aware of some EDK version issues.  The demo was created with version 13.  It is intended to get this updated to the latest EDK version in the relatively near future.  In the mean time have a look in http://interactive.freertos.org &#8211; I think there may be a patch provided by a third party there (?).
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS BSP build errors in EDK for Microblaze</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dagustaf">dagustaf</a> on November 20, 2013</div><div class="thread-post-content">Thank you for the reply Richard, not sure if I can wait for that though
I found the problem, it was a no-brainer. It is not enough with &#8220;set standalone<em>version standalone</em>v3<em>07</em>a&#8221; 
There were still 2 more lines in the &#8220;freertos<em>v2</em>1<em>0.tcl&#8221; file that refered to standalone</em>v3<em>01</em>a:
set makeconfig [open &#8220;../standalone<em>v3</em>01<em>a/src/config.make&#8221; w] 
set filename [file join &#8220;../standalone</em>v3<em>01</em>a/src&#8221; &#8220;microblaze<em>interrupts</em>g.c&#8221;] 
After correcting this it compiles fine!
/David
