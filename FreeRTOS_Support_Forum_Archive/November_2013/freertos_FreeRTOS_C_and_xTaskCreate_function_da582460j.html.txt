  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS, C++ and xTaskCreate() function</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on November 3, 2013</div><div class="thread-post-content">Hi!
I try to create a C++ application (and C++ tasks) based on FreeRTOS but I can not call the xTaskCreate() function from my C++ code.
Default FreeRTOS main() function:
<pre><code>/* default FreeRTOS main() */
int main( void )
{
    prvSetupHardware();
    /* Exported C++ function */
    runTask();
    ...
}
</code></pre>
Below the header and source files based on the following both examples:
http://sourceforge.net/p/freertos/discussion/382005/thread/5d5201c0
http://interactive.freertos.org/entries/223648-using-freertos-with-c
I think I have included all relevant C-header files in my C++ header:
<pre><code>#ifdef __cplusplus
extern "C" {
#endif
#include &lt;FreeRTOS.h&gt;
#include &lt;task.h&gt;
#ifdef __cplusplus    
}
#endif
</code></pre>
&#8230; and my C/C++ wrapper functions:
<pre><code>#ifdef __cplusplus
extern "C" {
#endif
void tskWrp(void* p);
void runTask();
#ifdef __cplusplus
}
#endif
</code></pre>
C++ source file: prl_task.cc
<pre><code>/* C++ source file: prl_task.cc /*   
/*-----------------------------*/
/* 2 simple tasks */
void vTask1( void ) {
    doSomething();
}
void vTask2( void ) {
    doSomething();
}
/*------------------------------*/
/* base class CTask */
CTask::CTask(char const* name,
    unsigned portBASE_TYPE priority,
    unsigned portSHORT stackDepth=1000) {
    /* Code works up to here! */    
    //vTask1();
    xTaskCreate(&amp;tskWrp, (signed char*)name, 1000, this, 1, NULL);
}
void CTask::Task() {
 vTask1();
}
/*-------------------------------*/
/* derived class CTask1 */
CTask1::CTask1(char const* name,
            unsigned portBASE_TYPE priority,
    unsigned portSHORT stackDepth=1000) : CTask(name, priority,stackDepth) {
}
void CTask1::Task() {
 vTask2();
}
/*--------------------------------*/ 
/* interface functions C C++ */
void runTask(){
    CTask1 task("tsk",1,1000);
}
/*--------------------------------*/
/* wrapper function */
void tskWrp(void* p) {
(static_cast&lt;CTask*&gt;(p))-&gt;Task();
}
</code></pre>
I can compile the code without errors but the xTaskCreate() function will be &#8220;ignored&#8221; and the program is not running on my MPU. If I call directly another functions e.g. vTask1() instead of xTaskCreate() the program works fine on the MPU.
By the way my IDE throws a warning &#8220;Function &#8216;xTaskGenericCreate&#8217; could not be resolved&#8221;. I&#8217;m not sure whether the IDE warning or any other reason is the cause of my problem.
Maybe someone can help me?
Florian
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS, C++ and xTaskCreate() function</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on November 3, 2013</div><div class="thread-post-content">First, you shouldn&#8217;t need the #ifdef __cplusplus lines to add the extern &#8220;C&#8221; stuff, as that should be in the headers already.
The other thing to note it that the FreeRTOS files MUST be compelled a C files, not C++ files, or they won&#8217;t work right, The extern &#8220;C&#8221; stuff in the headers sets up the linkage properly for the cross language link. That might explain the could not be resolved problem.
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS, C++ and xTaskCreate() function</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on November 3, 2013</div><div class="thread-post-content">If I will create a C-compiled freeRTOS.o object file and a C++ compiled application.o object file, is it possible to link both together by using g++?
The following link recommends to use g++ for the linking process in case ob mixing C and C++:
http://www.parashift.com/c++-faq/overview-mixing-langs.html
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS, C++ and xTaskCreate() function</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on November 3, 2013</div><div class="thread-post-content">Yes, you should be able to link files compiled as C and files compiled as C++, that is the main purpose of the extern &#8220;C&#8221; syntax. As the link suggests, main should be C++, the libraries used should be C++, so the linker should generally be the C++ linker. The C compiler needs to be ABI complient with the C++ compiler.
