</div></div><div class="thread-post"><h3 class="thread-post-title">PIC32MZ</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 18, 2013</div><div class="thread-post-content">The definitions in that file are obsolete, and only kept for backward compatibility with really old projects that still use them.  I think the PIC24 project is one such project, although there it is used to select between the PIC24 and dsPIC headers.  PIC32 projects should not use them at all, but instead add the path to the correct portmacro.h as an include path in the project settings.
I had actually changed the PIC32 one to forward slashes in FreeRTOS V7.6.0, and have now done the same for the other PIC projects.
Regards.
