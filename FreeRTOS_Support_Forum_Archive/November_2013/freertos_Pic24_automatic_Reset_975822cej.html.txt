  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Pic24 automatic Reset</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/amarjith">amarjith</a> on November 8, 2013</div><div class="thread-post-content">Automatic resetting occurs when i add/ create some tasks for example if i add xTaskCreate( vHandlerTask, &#8220;Handler&#8221;, 500, NULL, 1, NULL);  
in my program microcontroller will reset automatically 
void vHandlerTask( void <em>pvParameters )
{
     int i;
    /</em> As per most tasks, this task is implemented within an infinite loop. <em>/
    for( ;; )
    {
        U1_puts( &#8220;Handler task .rn&#8221; );
        /</em> Use the semaphore to wait for an event. The semaphore was created
        before the scheduler was started so before this task ran for the first
        time. The task blocks indefinitely so the function call will only
        return once the semaphore has been successfully taken (obtained). There
        is therefore no need to check the function return value. <em>/
        xSemaphoreTake( xBinarySemaphore, portMAX_DELAY );
        /</em> To get here the event must have occurred. Process the event.
        case processing is simply a matter of printing out a message. */
       U1_puts( &#8220;Handler task &#8211; Processing event.rn&#8221; );
    }
}
Why this happening when adding some tasks?, if i delete or comment this task program  will work. Please help
These are my Tasks if i put tasks as shown below &#8220;vMT_InitRepman&#8221; will execute first , it never enter in to  vHandlerTask even its priority is 10.
<pre><code>    xTaskCreate( vMT_InitRepman, "vMT_InitRepman", 500, NULL, 3, &amp;xInitHandle );
    xTaskCreate( vMT_Loging, "vMT_Loging", 500, 5, 1, &amp;xLogingHandle);
    xTaskCreate( vMT_Upload, "vMT_Upload", 500, 20, 1, &amp;xUploadHandle );
    xTaskCreate( vMT_ErrorHandler, "vMT_ErrorHandler", 500, NULL, 2, &amp;xErrorHandle );
    xTaskCreate( vHandlerTask, "Handler", 500, NULL, 10, NULL);
</code></pre>
And if put as shown below, microcontroller will reset continuously
<pre><code>     xTaskCreate( vHandlerTask, "Handler", 500, NULL, 10, NULL);
     xTaskCreate( vMT_InitRepman, "vMT_InitRepman", 500, NULL, 3, &amp;xInitHandle );
    xTaskCreate( vMT_Loging, "vMT_Loging", 500, 5, 1, &amp;xLogingHandle);
    xTaskCreate( vMT_Upload, "vMT_Upload", 500, 20, 1, &amp;xUploadHandle );
    xTaskCreate( vMT_ErrorHandler, "vMT_ErrorHandler", 500, NULL, 2, &amp;xErrorHandle );
</code></pre>
</div></div><div class="thread-post"><h3 class="thread-post-title">Pic24 automatic Reset</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 8, 2013</div><div class="thread-post-content">Try all the usual things first &#8211; define configASSERT(), have the malloc failed and stack overflow hooks defined, etc.  Then, if still no luck in trapping the error, step through the task in the debugger until the point at which the reset occurs to see what is causing it.
