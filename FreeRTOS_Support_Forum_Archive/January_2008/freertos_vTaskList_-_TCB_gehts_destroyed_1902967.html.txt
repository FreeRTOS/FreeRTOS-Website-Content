</div></div><div class="thread-post"><h3 class="thread-post-title">vTaskList &#8211; TCB gehts destroyed</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on January 3, 2008</div><div class="thread-post-content">My mistake you are right.
From your first post you start with three tasks being listed then get four tasks with the fourth being corrupt and the original three still showing correctly. This must be some memory corruption going on which could cause any kind of unwanted behavior so this could be the cause of the strange semaphore behavior.
I would start by checking that you are not getting stack overflows. This is the most likely cause so should be checked first, especially if you are using string handling library functions which can use a lot of stack.
Is your interrupt handler just called when the last character has been sent or after every character. From your code I would assume just when the last character was sent.
