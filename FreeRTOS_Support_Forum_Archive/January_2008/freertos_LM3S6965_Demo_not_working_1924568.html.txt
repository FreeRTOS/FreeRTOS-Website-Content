</div></div><div class="thread-post"><h3 class="thread-post-title">LM3S6965 Demo not working</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on January 29, 2008</div><div class="thread-post-content">I remember getting warnings when flashing but I don&#8217;t remember that warning about working area. If you can ping the board then the flashing must have worked though, right? This makes it odd you don&#8217;t see anything on the display then.
Can you set a break point at the entry to vOLEDTask&#40;&#41; in main.c, then step through the code to check that the display initialization is working. There is a switch statement that checks to see what type of board it is and initialize the display accordingly. Check it is going through the correct case in the switch statement.
I think you need to get the display working first then move on to the Ethernet.
