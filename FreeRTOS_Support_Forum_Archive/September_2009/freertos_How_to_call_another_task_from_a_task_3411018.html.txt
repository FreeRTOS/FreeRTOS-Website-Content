</div></div><div class="thread-post"><h3 class="thread-post-title">How to call another task from a task?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/el_es">el_es</a> on September 29, 2009</div><div class="thread-post-content">Do you have to have the infinite loop in task2 ?   
Can you not make it a part of task &#40;which is an infinite loop itself&#41;?   
I.E. the way the task system works, it guarantees that a&#41; every function within the for &#40;,,&#41; &#123;&#125; block is called, and b&#41; that it is called in the coded order once per cycle;   
If you just want the operations in task2 to run &#8216;constantly&#8217;, take the vTaskDelayUntil out of it and set it to lower priority than Task1, so that Task1 is woken up when needed; or configure them to have the same priority, then they will be run in round-robin manner &#40;Task1-Task2-Task1-Task2 and so on&#41;. The scheduler will freeze them as appropriate and then restart where they left off, every &#8216;tick&#8217;.  
Then if you want task1 to tell task2 something, you need to create a queue, to which task1 will be writing &#40;e.g. 1 character long queue&#41;, and task 2 will be emptying it &#40;reading&#41; and acting accordingly.
