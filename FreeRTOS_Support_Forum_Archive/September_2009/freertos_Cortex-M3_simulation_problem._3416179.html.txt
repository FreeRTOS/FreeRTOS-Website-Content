</div></div><div class="thread-post"><h3 class="thread-post-title">Cortex-M3 simulation problem.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on September 30, 2009</div><div class="thread-post-content">functions that implement tasks should not return, and normally have built int them an infinite loop like a while&#40;1&#41;&#123;&#125; or for&#40;;;&#41;&#123;&#125; loop. your tasks execute the code once and then return which will cause a crash.
