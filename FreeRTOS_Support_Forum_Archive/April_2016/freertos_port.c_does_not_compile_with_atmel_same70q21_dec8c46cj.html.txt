  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">port.c does not compile with atmel same70q21</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/cjedic">cjedic</a> on April 21, 2016</div><div class="thread-post-content">The arguments for my build are as follows:
-mthumb -D<strong>SAME70Q21</strong> -DSAME70 -DDEBUG -DTHUMB_INTERWORK -O1 -ffunction-sections -mlong-calls -g3 -Wall -mcpu=cortex-m7 -std=gnu99
All other files compile fine but when it compiles the port.c file in the portable/GCC/ARM<em>CM4F or the portable/GCC/ARM</em>C7/rp01 directories I get the follwoing errors
/tmp/ccVxLxH7.s: Assembler messages:
/tmp/ccVxLxH7.s:409: Error: selected processor does not support Thumb mode <code>vstmdbeq r0!,{s16-s31}'
/tmp/ccVxLxH7.s:411: Error: instruction not allowed in IT block --</code>stmdb r0!,{r4-r11,r14}&#8217;
/tmp/ccVxLxH7.s:432: Error: selected processor does not support Thumb mode <code>vldmiaeq r0!,{s16-s31}'
/tmp/ccVxLxH7.s:434: Error: instruction not allowed in IT block --</code>msr psp,r0&#8242;
I am developing on eclipse and using the tools from a makefile but I tried it on a windows box with atmel studio 7 and it failed the same way.
Please help.
</div></div><div class="thread-post"><h3 class="thread-post-title">port.c does not compile with atmel same70q21</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on April 21, 2016</div><div class="thread-post-content">Those are floating point instructions, and your command line does not tell GCC that the processor has a floating point unit.
The FreeRTOS download has an Atmel Studio (GCC) project for these parts, which builds without problems, and from which you can obtain the command line used:
http://www.freertos.org/Creating-a-new-FreeRTOS-project.html (note: &#8220;It is always recommended that a new FreeRTOS project is created by starting with, and then adapting, one of the provided pre-configured demos. Doing this ensures the new project includes all the necessary source and header files, and installs the necessary interrupt service routines, with no effort on the part of the project&#8217;s creator.&#8221;)
