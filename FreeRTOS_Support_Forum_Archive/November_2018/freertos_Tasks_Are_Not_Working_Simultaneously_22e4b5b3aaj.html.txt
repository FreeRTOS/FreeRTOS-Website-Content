what the tasks are doing, and what the task priorities are relative to 
each other.

</div></div><div class="thread-post"><h3 class="thread-post-title">Tasks Are Not Working Simultaneously</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 2, 2018</div><div class="thread-post-content">If the tasks are the same priority then they should both run unless:
1) configUSE<em>TIME</em>SLICING is defined and set to 0.  That would prevent 
context switch to an equal priority task until the running task blocked.
2) The running task has locked the scheduler or entered a critical 
section.  Could that be the case?
Also, what is your configUSE<em>TICKLESS</em>IDLE setting?  If you have it 
defined try setting it to 0 to ensure normal operation in case there is 
anything untoward in the tickless idle implementation.
