  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">I have a problem in using FreeRTOSv10.1.1. The MCU is iteratively rebooting and not executing task function.</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/pnk004">pnk004</a> on November 27, 2018</div><div class="thread-post-content">I have a problem in using FreeRTOSv10.1.1.
The MCU is iteratively rebooting and not executing task function.
I am using dsPIC33CK256mp508 MCU. The development tool is MPLAB X IDE v5.10.
The freeRTOS supports dsPIC33FJ256GP710 MCU and not supports dsPIC33CK256mp508 MCU.
So, I changed the FreeRTOS as follows for the dsPIC33CK256mp508 MCU.
<ol>
<li>In port.c and portasm_dsPIC.S, I added &#8221; || defined( <strong>dsPIC33C</strong> )&#8221; in the source code.</li>
<li>The PIC33CK has not PSVPAG register. So I replaced the PSVPAG with DSRPAG register.</li>
</ol>
The MCU is rebooing after executing  main() -> vTaskStartScheduler(() -> xPortStartScheduler() -> portRESTORE_CONTEXT().
If I add extra code after portRESTORE_CONTEXT(), the MCU does not rebooting but does not execute task functions.
I used the stack size of LED task function as 512 (which is sufficient).
I used the STACK GROWTH definition as follows. Would you check it is right?
<pre><code>   #define portSTACK_GROWTH         1
</code></pre>
I will really appreciate if I can be given any advice and solutions.
Thank you very much.
Sincerely Yours,
Ick-Sung Choi.
</div></div><div class="thread-post"><h3 class="thread-post-title">I have a problem in using FreeRTOSv10.1.1. The MCU is iteratively rebooting and not executing task function.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 27, 2018</div><div class="thread-post-content"><blockquote>
<pre><code>The PIC33CK has not PSVPAG register. So I replaced the PSVPAG with
DSRPAG register.
</code></pre>
</blockquote>
So is this an ESD part?  The FreeRTOS port uses the <strong>HAS_EDS</strong> 
definition to switch between pushing and popping the PSVPAG register, or 
alternatively pushing and popping both the DSRPAG and DSWPAG registers. 
It is quite a while since I&#8217;ve looked at these details.
</div></div><div class="thread-post"><h3 class="thread-post-title">I have a problem in using FreeRTOSv10.1.1. The MCU is iteratively rebooting and not executing task function.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/pnk004">pnk004</a> on November 27, 2018</div><div class="thread-post-content">I did not define <strong>HAS_EDS</strong>, but it is defined by system (compliler).
In the source code, there is a comment that &#8220;dsPIC parts(dsPIC33CK256mp) with EDS are not supported&#8221;.
I tried to undeclare the <em>HAS</em>EDS definition in the source code.
The rebooting does not happen. But the task does not executed.
Can I disable EDS in the dsPIC33CK256mp and MPLAB X IDE compiler?
How can I solve the problem?
Thank you very much.
