</div></div><div class="thread-post"><h3 class="thread-post-title">Queue Task Crashing &#8211; Please Help</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on October 22, 2015</div><div class="thread-post-content">Hi Roger,
A bit more about your code fragment.
Here below the queue handle is passed as a task parameter to the <code>vTxQueueFunction</code>.
You can pass any data of the size of a pointer. In fact <code>TaskHandle_t</code> is also a pointer.
It also declares <code>TaskHandle_t xTaskHandle</code>. The address of this handle is passed to <code>xTaskCreate</code> which fills in the handle of the newly created task.
~~~~~
//message task will wait forever for queue to clear
<h1>define rxQueueRATE      portMAX_DELAY</h1>
static void vTxQueueFunction( void *pvParameters );
TaskHandle_t xTaskHandle;
int main()
{
QueueHandle_t xQueueHandle;
<pre><code>//create transmit queue
xQueueHandle = xQueueCreate( 1, sizeof(uint8_t) );
xTaskCreate( vTxQueueFunction, "rxDataQueue", 80,
    ( void * ) xQueueHandle, 2, &amp;xTaskHandle );
vTaskStartScheduler();
while(1)
{
    i++;
}
</code></pre>
}
