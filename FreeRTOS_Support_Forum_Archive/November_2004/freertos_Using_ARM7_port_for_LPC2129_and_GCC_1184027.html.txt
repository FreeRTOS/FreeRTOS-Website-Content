</div></div><div class="thread-post"><h3 class="thread-post-title">Using ARM7 port for LPC2129 and GCC</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on November 24, 2004</div><div class="thread-post-content">It might be easier to do it the other way around.&nbsp; Take the GCC port and convert it to run on the keil platform by using the keil port as a guide.
Assuming the register locations are the same for both ports if you take the GCC port then cut it down to its minimum it should work.
Change the linker script file as per previous post.&nbsp;&nbsp; Change the portTOTAL&#95;HEAP&#95;SIZE macro for different RAM size.
The portMINIMAL&#95;STACK&#95;SIZE macro may also need changing.
Change the partest.c file so you access the IO pins for the LED&#8217;s as per the keil platform.
Try starting with the minimum functionality &#8211; take out all the functions in main that start tasks other than the flash tasks, also remove these all the demo task files from the makefile other than the flash task file.&nbsp; This way you will get the smallest exe file and the simplest application.

</div></div><div class="thread-post"><h3 class="thread-post-title">Using ARM7 port for LPC2129 and GCC</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on November 24, 2004</div><div class="thread-post-content">portTOTAL&#95;HEAP&#95;SIZE sets the amout of RAM the scheduler can use when allocating TCB&#8217;s, stacks, queue&#8217;s, etc.&nbsp; See:
http://www.freertos.org/a00111.html
portMINIMAL&#95;STACK&#95;SIZE seems to be set differently for the two ARM ports.&nbsp; The GCC port uses 128.&nbsp; The best setting for this parameter is dependent on your own application.
Do you have a debugger?&nbsp; If so then step through the main&#40;&#41; function and you will see how the memory is allocated as tasks are created.&nbsp; You will probably find where the old problem was occurring.
The setuphardware function in main does more in the GCC port than the keil.&nbsp; I presume you have copied the setup routines from the GCC port.&nbsp; &#91;the Keil port does the setup automatically in the startup routine&#93;.
