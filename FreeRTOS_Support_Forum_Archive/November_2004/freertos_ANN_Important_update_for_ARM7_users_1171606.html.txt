</div></div><div class="thread-post"><h3 class="thread-post-title">ANN:Important update for ARM7 users</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on November 5, 2004</div><div class="thread-post-content">I have tried building the demo application with V2.5.1, then upgrading the source directory and building again and did not find any problems.
However, the constant portTICK&#95;RATE&#95;MS / portTICKS&#95;PER&#95;MS was changed between V2.5.0 and V2.5.1, so it is unlikely that you were previously using V2.5.1 &#91;otherwise you would not have had to change anything&#93;.
Is it possible that you were using V2.4.1?&nbsp; If so then there are some differences as follows:
V2.4.1 did not support THUMB mode so the source code was all set to build into ARM mode.&nbsp; When THUMB mode was introduced the source code was split into two &#8211; the code that can be built into both ARM and THUMB mode, and the code that must be built into ARM mode.&nbsp; This basically involved two changes:
port.c was split into port.c and portISR.c.
serial.c was plit into serial.c and serialISR.c
the xxxxISR.c versions having the code that must be built into ARM mode.
The makefile was then updated to have two source lists, one for THUMB and one for ARM.&nbsp; If you are building everything for ARM then both source lists get built to ARM.
I have tried building the V2.4.1 demo application, then upgrading the source directory to V2.5.3.&nbsp; It would not compile as some functions were undefined.&nbsp; Adding both serialISR.c and portISR.c to the makefile and doing a complete rebuild I found the code built without error.&nbsp; Have you got these two files in your makefile &#40;you will only need serialISR.c if you are using the supplied serial.c in your application&#41;.
The rom.bat and ram.bat files supplied with V2.4.1 have been replaced with rom&#95;arm.bat, rom&#95;thumb.bat, ram&#95;arm.bat and ram&#95;thumb.bat.
Have a look at the V2.5.3 demo application makefile and .bat files to see how to switch between ARM and THUMB should you wish to do so.
Hope this helps.
