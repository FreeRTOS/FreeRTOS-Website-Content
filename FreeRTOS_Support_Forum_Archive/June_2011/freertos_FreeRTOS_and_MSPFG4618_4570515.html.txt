</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS and MSPFG4618</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on June 13, 2011</div><div class="thread-post-content">The MSP430F449 uses an MSP430 core.&nbsp; The MSP430FG4618 uses an MSP430X core.&nbsp; The FreeRTOS download contains 2 demos for the MSP430X in the FreeRTOS/Demo/MSP430X&#95;MSP430F5438&#95;CCS4 and FreeRTOS/Demo/MSP430X&#95;MSP430F5438&#95;IAR directories respectively.&nbsp; Each demo uses 3 different memory models.&nbsp; There is a lot of code behind it.&nbsp;   
The ports for these demos are found in the FreeRTOS/Source/portable/CCS4/MSP430X and FreeRTOS/Source/portable/IAR/MSP430X directories respectively.  
I suggest you look at one of these demos as a starting point.  
Regards.
