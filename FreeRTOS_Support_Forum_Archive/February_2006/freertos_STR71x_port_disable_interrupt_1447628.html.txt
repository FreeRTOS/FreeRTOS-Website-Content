if I instead call EIC&#95;IRQConfig&#40; DISABLE &#41;; then the interrupts are disabled. So maybe the &#95;&#95;disable&#95;interrupt&#40;&#41; in the function portENTER&#95;CRITICAL&#40;&#41; has to be changed?
Best regards, Frank Andersen
