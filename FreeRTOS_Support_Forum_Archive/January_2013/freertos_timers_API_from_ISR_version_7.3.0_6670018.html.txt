</div></div><div class="thread-post"><h3 class="thread-post-title">timers API from ISR version 7.3.0</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on January 23, 2013</div><div class="thread-post-content">Sorry &#8211; you say there is a bug, but I can&#8217;t understand from your post what the bug is.  
Currently the timer API that can be used from an ISR <strong>cannot</strong> have its last parameter set to NULL, and I don&#8217;t think anything in the documentation says it can.&nbsp; The queue/semaphore implementation can set the parameter to NULL, but this is also not documented so I don&#8217;t think people using the API documentation will be trying to do that yet.  
Are you reporting a bug in the timer implementation, or are you saying you can&#8217;t use the interrupt safe timer API with pxHigherPriorityTaskWoken parameter set to NULL and you wish to do so &#40;in which case it would be a feature request rather than bug report&#41;.  
Regards.
