</div></div><div class="thread-post"><h3 class="thread-post-title">HardFault in Tasks.c when using IAR 6.50</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on April 23, 2015</div><div class="thread-post-content">We find it extremely difficult to provide free support for lwIP, especially when the integration has been performed by somebody else.  That is why we introduced <a href="http://www.freertos.org/FreeRTOS-Plus/FreeRTOS_Plus_TCP/index.html">our own TCP/IP stack</a>.
In this case the first thing I suggest you do is a complete rebuild &#8211; make sure there are absolutely no object or dependency files created by IAR 7.4 left anywhere before clean building with IAR V6.x.
If that does not help, look through IAR&#8217;s change history to see if that provides any clues.
Next try without lwIP being used/called.
If you still have a problem, use IAR V7.4.
Regards.
