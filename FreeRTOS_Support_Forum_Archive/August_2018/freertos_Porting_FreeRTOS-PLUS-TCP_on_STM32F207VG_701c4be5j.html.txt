</div></div><div class="thread-post"><h3 class="thread-post-title">Porting FreeRTOS-PLUS-TCP on STM32F207VG</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on August 16, 2018</div><div class="thread-post-content">You are setting the send time-out on <code>xConnectedSocket</code>, but you do not show the actual value of <code>xSendTimeout</code>.
Despite that, I can not see an apparent reason why <code>FreeRTOS_send()</code> would not send-out the data contained in the variable <code>page</code>.
Have you defined <code>ipconfigDRIVER_INCLUDED_TX_IP_CHECKSUM</code> as <code>0</code>?
If it is non-zero, either your network driver must calculate and set the checksums ( IP and protocol ), or the EMAC must set it.
Your application is likely to run until all resources are exhausted: after sending the data, the variable <code>xConnectedSocket</code> will be overwritten and the handle to the old socket becomes unreachable.
If you want to keep it simpler ( for testing ), allow only a single client:
~~~
    FreeRTOS_listen( xListeningSocket, 1 );
~~~
And keep on reading from <code>xConnectedSocket</code> until you get a negative value, not equal to <code>-EWOULDBLOCK</code>:
~~~
    if( xConnectedSocket != FREERTOS<em>INVALID</em>SOCKET )
    {
        for( ;; )
        {
<pre><code>        lByteReceived = FreeRTOS_recv( xConnectedSocket, socketRecvBuf, sizeof(socketRecvBuf), 0 );
        if( ( lByteReceived &lt; 0 ) &amp;&amp; ( lByteReceived != -pdFREERTOS_ERRNO_EWOULDBLOCK ) )
        {
            /* Break out of the loop in order to receive a new client. */
            /* The most probable return code is -pdFREERTOS_ERRNO_ENOTCONN */
            break;
        }
        if( lByteReceived &gt; 0 )
        {
            /* Send a reply back. */
            lBytesSent = FreeRTOS_send(xConnectedSocket, page, sizeof(page), 0);
            printf( "Bytes sended: %dn", lBytesSent );
            if( ( lBytesSent &lt; 0 ) &amp;&amp; ( lBytesSent != -pdFREERTOS_ERRNO_EWOULDBLOCK ) )
            {
                /* Send returns a fatal error, break from the loop. */
                break;
            }
        }
    }
    FreeRTOS_closesocket( xConnectedSocket );
    xConnectedSocket = FREERTOS_INVALID_SOCKET;
}
</code></pre>
~~~
You set <code>FREERTOS_SO_RCVTIMEO</code> of the listening socket. That value will be inherited by the child socket.
Give it a reasonable value unequal to zero.
If you want to see a simple HTTP server that works well, please download :
https://freertos.org/FreeRTOS-Labs/downloads/160919<em>FreeRTOS</em>Labs.zip?dl=0
and have a look at <code>FreeRTOS-PlusSourceFreeRTOS-Plus-TCPprotocols</code>
