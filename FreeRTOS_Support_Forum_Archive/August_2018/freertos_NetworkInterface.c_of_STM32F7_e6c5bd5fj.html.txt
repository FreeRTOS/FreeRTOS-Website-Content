</div></div><div class="thread-post"><h3 class="thread-post-title">NetworkInterface.c of STM32F7</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on August 8, 2018</div><div class="thread-post-content">I think there are some essential differences. Please use the unified <code>stm32fxx_hal_eth.c</code> from the 7-zip and the corresponding header files.  That should work for both F4 and F7.  Please define the correct part as:
~~~
    #define STM32F7xx    1
~~~
Make sure that the header file <code>stm32f7xx_hal_eth.h</code> from STM32Cube does not appear in the include path (<code>-I</code>).

/* Put the DMA descriptors in &#8216;.first_data&#8217;.

<strong>attribute</strong> ((aligned (32)))
<strong>attribute</strong> ((section(&#8220;.first_data&#8221;)))
    ETH_DMADescTypeDef  DMARxDscrTab[ ETH_RXBUFNB ];

When using D-Cache, the table <code>DMARxDscrTab</code> is expected to be placed in a non-cacheable memory range.
