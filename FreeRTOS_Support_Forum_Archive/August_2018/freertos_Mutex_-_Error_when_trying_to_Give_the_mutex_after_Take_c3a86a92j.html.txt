  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Mutex &#8211; Error when trying to Give the mutex after Take</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/alho">alho</a> on August 3, 2018</div><div class="thread-post-content">Hi,
I was looking around the forum but didn&#8217;t find the same problem. Maybe I&#8217;m overseeing something, in fact I could use some help!
I want to protect a shared resource (SPI) using a mutex. The main project is based on STM Cube MX (STM32L4 MCU).
I always control the return values of the xSemaphore&#8230; functions. So init works also fine. When I use the Mutex in a  test case (one and only Task &#8220;defaultTask&#8221;) it works without errors:
~~~
/* StartDefaultTask function <em>/
void StartDefaultTask(void const * argument)
{
    osDelay(500);
  /</em> USER CODE BEGIN 5 <em>/
    /</em> Infinite loop */
    for(;;)
    {
        if(xSemaphoreTake(MutexHandle) != pdTRUE)
        {
            Error_Handler();
        }
        osDelay(1000);
        if(xSemaphoreGive(MutexHandle) != pdTRUE)
        {
            Error_Handler();
        }
        osDelay(1000);
<pre><code>}
</code></pre>
  /* USER CODE END 5 */ 
}
~~~
In my user code, different tasks need the SPI resource during their initialisation, so before the infinite loop in the tasks. The calls are similar as in the example above, instead of a delay I use the SPI to read/write stuff. When I run the code, I&#8217;m running into errors when trying to give the Mutex. So the task was able to take it, but is unable to give after that.
What could be the reason for that? I don&#8217;t get it&#8230;
What could i do to investigate deeper into that? I tried to use xSemaphoreGetMutexHolder between the Take and Give but it throws me a  Compile Error &#8221; undefined reference to &#8216;xQueueGetMutexHolder&#8217; &#8221; (although configUSE_MUTEXES is set to 1 in FreeRTOSConfig.h)
Could I try the whole implementation with a binary semaphore instead?
Best regards,
Alex
</div></div><div class="thread-post"><h3 class="thread-post-title">Mutex &#8211; Error when trying to Give the mutex after Take</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richarddamon">richarddamon</a> on August 3, 2018</div><div class="thread-post-content">One issue I see is that you are missing a parameter to xSemaphoreTake, it needs a second parameter to specify how long it is allowed to wait. If the unprovided parameter happens to be 0, then the take will return immediately.
Second, you code looks like it could go on and assume it has the mutex if the take fails (assuming Error_Handler just logs an error and returns). You should condition the actions and the give on the Take succeeding.
