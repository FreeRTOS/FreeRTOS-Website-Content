  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Renesas V850 port not supporting preserving FPU registers. Ideas please.</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/acollins22">acollins22</a> on May 2, 2018</div><div class="thread-post-content">Hello,
I am working on an existing project based on the Renesas V850E2.
Occasionally I see a problem where a task&#8217;s floating point maths goes awry. Looking at the assembler code produced by the IAR C compiler I can see a point where, if a context switch occurred, it could cause this problem.
Looking into the <strong>portSAVE_CONTEXT</strong> and <strong>portRESTORE_CONTEXT</strong> macros in <strong>portasm.s85</strong> for my port, I can&#8217;t see any attempt to save the FPU registers and I think this is the root cause of my problem.
The top of <strong>portSAVE_CONTEXT</strong> looks like this&#8230;
~~~
    prepare {r20,r21,r22,r23,r24,r25,r26,r27,r28,r29,r30}, 76 ,sp ; save general purpose registers
    sst.w   r19,72[ep]
    sst.w   r18,68[ep]
    sst.w   r17,64[ep]
    sst.w   r16,60[ep]
~~~
I need to modify it to save the FPU registers. I have tried increasing the amount of memory reserved by the <strong>prepare</strong> instruction to make space for my additions but the system won&#8217;t run afterwards so I am clearly doing something wrong and my V850 assembler knowledge isn&#8217;t strong enough yet to know what it is.
Has anyone used freeRTOS on a V850E3 or any other V850 with the FPU and has some code they could share please?
Thanks,
Andy.
</div></div><div class="thread-post"><h3 class="thread-post-title">Renesas V850 port not supporting preserving FPU registers. Ideas please.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on May 2, 2018</div><div class="thread-post-content">Unfortunately I don&#8217;t think the device that port was written for even 
had an FPU unit.
Did you also update pxPortInitialiseStack() in the V850 version of port.c?
</div></div><div class="thread-post"><h3 class="thread-post-title">Renesas V850 port not supporting preserving FPU registers. I wasn&#8217;t aware of <strong>pxPortInitialiseStack</strong>. 
I&#8217;ll give that a try.
Thanks again,
Andy.
