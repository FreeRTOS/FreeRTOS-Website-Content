</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS &#8211; TCP/IP: UDP socket buffer size?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on May 28, 2018</div><div class="thread-post-content">Interesting question!
The number of UDP messages that you can receive without reading them, is indeed
limited by <code>ipconfigNUM_NETWORK_BUFFER_DESCRIPTORS</code>.
For TCP  a circular &#8220;stream buffer&#8221; is created for each direction. TCP data must be
buffered, and kept in a buffer until the transmission has been acknowledged by the
peer.
This TCP housekeeping of data is complicated. I tried to make clear how it works in 2
pictures ( attached to this post ).
The implementation of UDP sockets is a lot simpler. It has a list ( <code>List_t</code> ) of Network Buffers that were received.  Note that <code>FreeRTOS_recvfrom()</code> has a zero-copy possibility, so that you can peek directly into a Network Buffer.
There is an important setting for UDP sockets, limiting the maximum number of received packets:
~~~
<h1>ifndef ipconfigUDP<em>MAX</em>RX_PACKETS</h1>
<pre><code>/* Make positive to define the maximum number of packets
 * which will be buffered for each UDP socket. Can be
 * overridden with the socket option FREERTOS_SO_UDP_MAX_RX_PACKETS
 */
#define ipconfigUDP_MAX_RX_PACKETS        0u
</code></pre>
<h1>endif</h1>
~~~
Suppose that you get a UDP attack: thousands of packets are fired to your UDP
port, the attack will not disturb the device because at most <code>ipconfigUDP_MAX_RX_PACKETS</code>
network buffers will be stored.

The driver <code>x_emacpsif_dma.c</code> worked fine as long as it handled a single NIC.  You found that when it serves two EMAC&#8217;s, corruption may occur.  So the problem was only present in the <strong>/multi</strong> version.
My stupid: two tasks were storing temporary data in common variables.
These simple changes were made to avoid mentioned problem:
Around line 320:
~~~
-static NetworkBufferDescriptor_t *ethMsg = NULL;
<h2>-static NetworkBufferDescriptor_t *ethLast = NULL;</h2>
-static void passEthMessages( )
+static void passEthMessages( NetworkBufferDescriptor_t *ethMsg )
~~~
Around line 346:
~~~
