</div></div><div class="thread-post"><h3 class="thread-post-title">TCP open socket and remain open</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on May 11, 2016</div><div class="thread-post-content"><blockquote>
  &#8230; Are there any examples that do something similar?
</blockquote>
This is more a general question about how to program TCP.
A TCP server is maybe the simplest:
Task-1 waits for a new client connection while calling FreeRTOS_accept() in a blocking way.
For every client, a new task will be created, which will call FreeRTOS_recv() in a blocking way.
Checking the result codes is very important:
~~~~
    xResult = FreeRTOS<em>recv( socket, buf, len, flags );
    if( ( xResult &lt; 0 ) &amp;&amp; ( xResult != -pdFREERTOS</em>ERRNO<em>EWOULDBLOCK ) )
    {
        FreeRTOS</em>closesocket( socket );
        /* break from the main loop and terminate this task. */
        break;
    }
<pre><code>/* The result of FreeRTOS_send() must be checked in the same way: */
xResult = FreeRTOS_send( socket, buf, len, flags );
if( ( xResult &lt; 0 ) &amp;&amp; ( xResult != -pdFREERTOS_ERRNO_EWOULDBLOCK ) )
{
    FreeRTOS_closesocket( socket );
    /* break from the main loop and terminate this task. */
}
</code></pre>
~~~~
Normally a TCP server will not actively close a connection. But if it does want to actively close a connection, you can do it like this:
~~~~
    for( ;; )
    {
        /* Read and write from socket as shown above. <em>/
        if( xDoSendShutdown != pdFALSE )
        {
            xDoSendShutdown = pdFALSE;
            FreeRTOS_shutdown( socket, FREERTOS_SHUT_RDWR );
        }
        /</em> Continue normal processing and wait for the closure. */
    }
~~~~
and continue the normal loop that calls <code>FreeRTOS_recv()</code> for this socket. After some time <code>FreeRTOS_recv()</code> will return an error like <code>-pdFREERTOS_ERRNO_ENOTCONN</code>.
The above scheme is maybe the easiest to start with.
Have a look at these files:
<pre><code>FreeRTOS-Plus-TCPprotocolsCommonFreeRTOS_TCP_server.c
FreeRTOS-Plus-TCPprotocolsFTPFreeRTOS_FTP_server.c
FreeRTOS-Plus-TCPprotocolsHTTPFreeRTOS_HTTP_server.c
</code></pre>
This is an advanced example of a TCP server that only uses one single task. At one point it calls select() in a blocking way:
~~~~
    xRc = FreeRTOS_select( pxServer->xSocketSet, xBlockingTime );
~~~~
All other network calls in these source files are non-blocking.
Another +TCP specific method of handling many socket within a single task is with the use of <a href="http://www.freertos.org/FreeRTOS-Plus/FreeRTOS_Plus_TCP/TCP_IP_Configuration.html#ipconfigSOCKET_HAS_USER_SEMAPHORE">socket semaphores</a>
That allow you to block on a semaphore. The IP-task will give to that semaphore as soon as anything of interest has happened (data arrival, new connection, connection lost etc).
<blockquote>
  Where are these examples?
</blockquote>
When you look at the <a href="http://www.freertos.org/FreeRTOS-Labs/RTOS_labs_download.html">labs download</a>, you will find the source code of the examples in the directory <code>FreeRTOS-Plus/Demo/Common</code>.
