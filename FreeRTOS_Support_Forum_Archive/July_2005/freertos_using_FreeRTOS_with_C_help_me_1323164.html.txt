Im using the snytax &quot;msp430-gcc -x c++ -Os -mmcu=msp430x169&#8230;&#8230;..&quot;. i do this adaptation on makefile but i cant compile the files .c. the answer of the compiler is &quot;invalid conversion from &#8216;const char&#42; &#8216; to const signed char&#42;&quot;. this error apper in file tasks.c e main.c.
my question is:
is possible to have some incompatibility of FreeRTOS with C++? or can I be making something wrong?
thanks :&#41; 
</div></div><div class="thread-post"><h3 class="thread-post-title">using FreeRTOS with C++ help me</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on July 22, 2005</div><div class="thread-post-content">The source code is compiled with a lot of different compilers &#8211; each of which generate warnings for slightly different conditions.&nbsp; The code contains a lot of casting to attempt to enable it to be compiled with all compilers without generating any warnings.&nbsp; &#91;sometimes a cast required to compile with one compiler, causes another to complain&#93;
One area where embedded compilers differ is in their representation of vanilla char types.&nbsp; Some have them signed, some unsigned.&nbsp; For this reason in the code char types should always be qualified with either signed or unsigned to force one or other to be used in all cases, no matter which compiler is utalized.&nbsp; It is possible that in some cases the qualifier has been missed &#8211; which is fine for C but may cause C++ to complain.&nbsp; 
It should be a simple case of matching up the casting to enable the code to be compiled.&nbsp; Can you tell me which line the error comes on &#8211; then I should be able to tell you had to solve it.
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">using FreeRTOS with C++ help me</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on July 22, 2005</div><div class="thread-post-content">in the file main.c the error comes on call to xTaskCreate, 
in the file tasks.c the error comes on line 863 
&quot;xReturn = xTaskCreate&#40; prvIdleTask, &#40; const tipoCHAR &#42; const &#41; &quot;IDLE&quot;, tskIDLE&#95;STACK&#95;SIZE, &#40; void &#42; &#41; NULL, tskIDLE&#95;PRIORITY, &#40; xTaskHandle &#42; &#41; NULL &#41;;&quot;
</div></div><div class="thread-post"><h3 class="thread-post-title">using FreeRTOS with C++ help me</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on July 22, 2005</div><div class="thread-post-content">Change
&#40; const tipoCHAR &#42; const &#41; &quot;IDLE&quot;
