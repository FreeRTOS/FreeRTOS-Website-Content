  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS Interrupt with Arduino Due Cortex-M3</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/arduino2012">arduino2012</a> on March 18, 2013</div><div class="thread-post-content">Hi,<br />
I want to learn about how to implement interrupt in freeRTOS. I am using the Arduino Due SAM3X8E Cortex-M3 microcontroller. Have somebody used an interrupt in freeRTOS which you could share with me. Is there any guide of how to implement interrupt in freeRTOS. I have read alot in the freeRTOS website but I have not found any guide.
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS Interrupt with Arduino Due Cortex-M3</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on March 18, 2013</div><div class="thread-post-content">Writing FreeRTOS aware interrupts on a Cortex-M chip is actually very simple as, unlike when doing the same on their ARM7 predecessors, there are not special requirements <strong>other than</strong> ensuring you have the priorities set correctly.&nbsp; Basically, just write a standard C function and install it in the vector table.  
See the &#8220;Interrupt Service Routines&#8221; section of the following page.&nbsp; Most &#40;if not all&#41; official demos have examples included too.  
<a href="http://www.freertos.org/Atmel_SAM3_SAM3X-EK_SAM3S-EK2_RTOS_Demo.html">http://www.freertos.org/Atmel_SAM3_SAM3X-EK_SAM3S-EK2_RTOS_Demo.html</a>  
The important bits:&nbsp;   
1&#41; If an interrupt is going to use a FreeRTOS API function then, as with all the FreeRTOS ports, only the API functions that end in FromISR can be used &#40;see the last bullet point at the top of the following page for the rationale: <a href="http://www.freertos.org/Embedded-RTOS-Queues.html%29.">http://www.freertos.org/Embedded-RTOS-Queues.html&#41;.</a>  
2&#41; FreeRTOS Cortex-M ports implement a full interrupt nesting model, the behaviour of which is configured using two FreeRTOSConfig.h constants:&nbsp; configMAX&#95;SYSCALL&#95;INTERRUPT&#95;PRIORITY and configKERNEL&#95;INTERRUPT&#95;PRIORITY.&nbsp; Interrupt safe FreeRTOS functions can only be called from interrupts that have a priority at or below that set by configMAX&#95;SYSCALL&#95;INTERRUPT&#95;PRIORITY &#40;if CMSIS priority functions are being used then configLIBRARY&#95;MAX&#95;SYSCALL&#95;INTERRUPT&#95;PRIORITY&#41;.&nbsp;   
See <a href="http://www.freertos.org/RTOS-Cortex-M3-M4.html">http://www.freertos.org/RTOS-Cortex-M3-M4.html</a> for the full explanation.  
Regards.
