Error: argument of type &#8220;void &#40;&#42;&#41;&#40;void &#42;, void &#42;&#41;&#8221; is incompatible with parameter of type &#8220;pdTASK&#95;CODE&#8221; C:UsersjddDocumentsIAR Embedded WorkbenchCode&#95;BaseRTOSSystem&#95;Control.c 36   
Can someone please tell me what might cause this? It&#8217;s in a separate file &#40;System&#95;Control.c&#41; , in a function that&#8217;s called from main&#40;&#41;, which that function is declared in a header file. Here is the call from main:<br />
ReadCOMmBufferTaskFunction&#40; pvParameters &#41;;  
The function in main is itself a task created by &#8220;xTaskCreate&#8221;  
Thanks for any help&#33;  
</div></div><div class="thread-post"><h3 class="thread-post-title">xTaskCreate Parameter Error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on March 27, 2013</div><div class="thread-post-content">The error say that the task function being passed at this point is taking two parameters, both of which are pointer to void. This is the wrong signature. A task function needs to have exactly 1 parameter, of type pointer to void.  
Check carefully the function, and its signature, on the line being flaged as an error.
</div></div><div class="thread-post"><h3 class="thread-post-title">xTaskCreate Parameter Error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/groufosse">groufosse</a> on March 27, 2013</div><div class="thread-post-content">Hi,<br />

I need to get that handle over to the C file that has functions that use it. it&#8217;s also used in the C file where it&#8217;s created. No other way to get it over other than using an &#8220;extern&#8221; ?  
</div></div><div class="thread-post"><h3 class="thread-post-title">xTaskCreate Parameter Error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on March 27, 2013</div><div class="thread-post-content">The void &#42; parameter allows you to send whatever you want &#8211; but it has to be a single parameter.&nbsp; If you want to send multiple parameters then place the parameters in a structure and send a pointer to the structure.&nbsp; Here is an example from one of the standard demo tasks:  
<pre><code>/* Structure used to pass parameters to each task. */
typedef struct SEMAPHORE_PARAMETERS
{
  xSemaphoreHandle xSemaphore;
  volatile unsigned long *pulSharedVariable;
  portTickType xBlockTime;
} xSemaphoreParameters;
/* Create the structure used to pass parameters to the first two tasks. */
pxFirstSemaphoreParameters = pvPortMalloc( sizeof( xSemaphoreParameters ) );
if( pxFirstSemaphoreParameters != NULL )
{
  /* Create the semaphore used by the first two tasks. */
  vSemaphoreCreateBinary( pxFirstSemaphoreParameters-&gt;xSemaphore );
  if( pxFirstSemaphoreParameters-&gt;xSemaphore != NULL )
  {
    /* Create the variable which is to be shared by the first two tasks. */
    pxFirstSemaphoreParameters-&gt;pulSharedVariable = 
                ( unsigned long * ) pvPortMalloc( sizeof( unsigned long ) );
    /* Initialise the share variable to the value the tasks expect. */
    *( pxFirstSemaphoreParameters-&gt;pulSharedVariable ) = 
                semtstNON_BLOCKING_EXPECTED_VALUE;
    /* The first two tasks do not block on semaphore calls. */
    pxFirstSemaphoreParameters-&gt;xBlockTime = ( portTickType ) 0;
    /* Spawn the first two tasks.  As they poll they operate at the idle 
    priority. */
    xTaskCreate( prvSemaphoreTest, 
                 ( signed char * ) "PolSEM1", 
           semtstSTACK_SIZE, ( void * ) 
           pxFirstSemaphoreParameters, 
           tskIDLE_PRIORITY, 
           ( xTaskHandle * ) NULL );
  }
}
</code></pre>
Regards.
