</div></div><div class="thread-post"><h3 class="thread-post-title">STM32 and FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on March 10, 2013</div><div class="thread-post-content">Originally library files were stored in a &#8216;common&#8217; area so demo projects referenced a core set of files that could be easily updated &#8211; however as the number of demos grew that soon proved unworkable.&nbsp; Now a fix baseline of drivers is included directly in the demo directory so a demo is guaranteed to work as provided.  
The FreeRTOS files can be used with any STM32 project though &#8211; the core files do not make use of any library functions &#40;and in fact work on all Cortex-M devices, be they STM32 or not&#41;.&nbsp; Only the demos use the driver libraries.  
<a href="http://www.freertos.org/Creating-a-new-FreeRTOS-project.html">http://www.freertos.org/Creating-a-new-FreeRTOS-project.html</a><br />
<a href="http://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html">http://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html</a>  
Regards.

</div></div><div class="thread-post"><h3 class="thread-post-title">STM32 and FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jdurand">jdurand</a> on March 10, 2013</div><div class="thread-post-content">I do that all the time.&nbsp; You have to be careful to update EVERYTHING having to do with FreeRTOS.&nbsp;   
I&#8217;m using Code Red tools &#40;gcc based&#41; and in my case that&#8217;s everything in my FreeRTOS folder under SRC as well as the FreeRTOSConfig.h and cr&#95;startup&#95;lpc… that are in with the main files.  
I copy the new FreeRTOSConfig.h file over and then change the settings to match the old one.  
I leave the old cr&#95;startup file there but compare it to the new one to see if there&#8217;s anything I need to change.&nbsp; I do this because the demo files are normally for an older version of the tools than I use and they may also have things defined like interrupt vectors that are for a specific demo but I need them at the default handler or something else.
