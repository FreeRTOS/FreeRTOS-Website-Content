</div></div><div class="thread-post"><h3 class="thread-post-title">freertos and pic 24 error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on March 28, 2013</div><div class="thread-post-content">objtasks.o(.text+0x53a):C:Demo webserver v1.0 AdhocFreertosFreeRTOSSourcetasks.c: undefined reference to `vApplicationTickHook&#8217;
If configUSE&#95;APPLICATION&#95;TICK&#95;HOOK is set to 1 you must provide a function called vApplicationTickHook&#40;&#41;.  
<pre><code>objtasks.o(.text+0x56e):C: - Demo webserver v1.0 AdhocFreertosFreeRTOSSourcetasks.c: undefined reference to `vApplicationStackOverflowHook'
</code></pre>
If configCHECK&#95;FOR&#95;STACK&#95;OVERFLOW is not set to 0 then you must provide a function called vApplicationStackOverflowHook&#40;&#41;.  
<pre><code>objport.o(.text+0x90):C: - Demo webserver v1.0 AdhocFreertosFreeRTOSSourceportableMPLABPIC24_dsPICport.c: undefined reference to `portRESTORE_CONTEXT'
</code></pre>
portRESTORE&#95;CONTEXT&#40;&#41; is defined in port.c itself.&nbsp; If you look at the source code you will see that there are some &#35;defines that must be defined to get the correct version included.&nbsp; If none are defined then none will be included and you will get this error.
