</div></div><div class="thread-post"><h3 class="thread-post-title">hw emulation</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on September 27, 2012</div><div class="thread-post-content">FreeRTOS runs in various simulators &#40;QEMU, Keil, a PCB CAD package the name of which escapes me temporarily, etc.&#41;, and it runs in both windows and Linux simulators.  
The real simulators simulate the hardware itself, so you run a real port of FreeRTOS on them.&nbsp; The Windows/Linux simulators run the FreeRTOS scheduler to schedule tasks, where the tasks are Windows/linux threads.&nbsp; That means the kernel selects which task to run, but the context switching is done by WindowsLinux so it is not a real hardware port.  
<a href="http://www.freertos.org/FreeRTOS-Windows-Simulator-Emulator-for-Visual-Studio-and-Eclipse-MingW.html">http://www.freertos.org/FreeRTOS-Windows-Simulator-Emulator-for-Visual-Studio-and-Eclipse-MingW.html</a> &#40;the MSVC is the demo/port that I maintain actively myself&#41;.  
<a href="http://www.freertos.org/simple-freertos-demos.html">http://www.freertos.org/simple-freertos-demos.html</a> &#40;see the Keil simulator&#41;  
<a href="http://www.freertos.org/FreeRTOS-simulator-for-Linux.html">http://www.freertos.org/FreeRTOS-simulator-for-Linux.html</a> &#40;supported/maintained by a third party&#41;
