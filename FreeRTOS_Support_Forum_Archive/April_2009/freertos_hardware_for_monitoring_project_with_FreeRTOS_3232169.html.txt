</div></div><div class="thread-post"><h3 class="thread-post-title">hardware for monitoring project with FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/spacewrench">spacewrench</a> on April 21, 2009</div><div class="thread-post-content">Take a look at SparkFun: www.sparkfun.com.&nbsp; They&#8217;re a hobbyist support site where people seem to build lots of projects like yours.&nbsp; They have a wide range of microcontroller boards available.&nbsp; The tricky / expensive part of your project is the web-server bit.&nbsp; You&#8217;ll need a board with an Ethernet interface, or a USB interface and a LOT of programming skill.

http://www.sparkfun.com/commerce/advanced&#95;search&#95;result.php?keywords=ethernet

</div></div><div class="thread-post"><h3 class="thread-post-title">hardware for monitoring project with FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/djg">djg</a> on April 24, 2009</div><div class="thread-post-content">Those board have a wide range of capabilities. If the LPC-E2124 is sufficient for your needs you may want to look at the&nbsp; http://www.luminarymicro.com/products/lm3s6965&#95;ethernet&#95;evaluation&#95;kit.html
It has more ram and is supported by FreeRTOS with a web server demo. 
http://www.freertos.org/portlm3sx965.html
I have used it and it seems to work well using FreeRTOS and the Luminary driver library. With the existing port you can&#8217;t use the micro SD and the display at the same time &#40;unless recent versions have fixed that&#41;. I have modified my version to allow it to work but its against 4.7.2 but&nbsp; haven&#8217;t finished porting to the current version. 
With this class of boards the Ethernet and web server have very basic capabilities to fit in the available resources.
