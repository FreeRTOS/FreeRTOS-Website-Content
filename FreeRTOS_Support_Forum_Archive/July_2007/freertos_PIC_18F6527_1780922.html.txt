452
High Performance RISC CPU:
• C compiler optimized architecture/instruction set
&#45; Source code compatible with the PIC16 and PIC17 instruction sets
• Linear program memory addressing to 32 Kbytes
• Linear data memory addressing to 1.5 Kbytes
• Up to 10 MIPs operation:
&#45; DC &#8211; 40 MHz osc./clock input
&#45; 4 MHz &#8211; 10 MHz osc./clock input with PLL active
• 16-bit wide instructions, 8-bit wide data path
• Priority levels for interrupts
• 8 x 8 Single Cycle Hardware Multiplier
Peripheral Features:
• High current sink/source 25 mA/25 mA
• Three external interrupt pins
• Timer0 module: 8-bit/16-bit timer/counter with 8-bit programmable prescaler
• Timer1 module: 16-bit timer/counter
• Timer2 module: 8-bit timer/counter with 8-bit period register &#40;time-base for PWM&#41;
• Timer3 module: 16-bit timer/counter
• Secondary oscillator clock option &#8211; Timer1/Timer3
• Two Capture/Compare/PWM &#40;CCP&#41; modules.
CCP pins that can be configured as:
&#45; Capture input: capture is 16-bit,max. resolution 6.25 ns &#40;TCY/16&#41;
&#45; Compare is 16-bit, max. resolution 100 ns &#40;TCY&#41;
&#45; PWM output: PWM resolution is 1- to 10-bit,
max. PWM freq. @: 8-bit resolution = 156 kHz 10-bit resolution = 39 kHz
• Master Synchronous Serial Port &#40;MSSP&#41; module,
Two modes of operation:
&#45; 3-wire SPI&#x2122; &#40;supports all 4 SPI modes&#41;
&#45; I2C&#x2122; Master and Slave mode
Peripheral Features &#40;Continued&#41;:
• Addressable USART module:
&#45; Supports RS-485 and RS-232
• Parallel Slave Port &#40;PSP&#41; module
Analog Features:
• Compatible 10-bit Analog-to-Digital Converter module &#40;A/D&#41; with:
&#45; Fast sampling rate
&#45; Conversion available during SLEEP
&#45; Linearity ≤ 1 LSb
• Programmable Low Voltage Detection &#40;PLVD&#41;
&#45; Supports interrupt on-Low Voltage Detection
• Programmable Brown-out Reset &#40;BOR&#41;
Special Microcontroller Features:
• 100,000 erase/write cycle Enhanced FLASH program memory typical
• 1,000,000 erase/write cycle Data EEPROM memory
• FLASH/Data EEPROM Retention: &gt; 40 years
• Self-reprogrammable under software control
• Power-on Reset &#40;POR&#41;, Power-up Timer &#40;PWRT&#41; and Oscillator Start-up Timer &#40;OST&#41;
• Watchdog Timer &#40;WDT&#41; with its own On-Chip RC Oscillator for reliable operation
• Programmable code protection
• Power saving SLEEP mode
• Selectable oscillator options including:
&#45; 4X Phase Lock Loop &#40;of primary oscillator&#41;
&#45; Secondary Oscillator &#40;32 kHz&#41; clock input
• Single supply 5V In-Circuit Serial Programming&#x2122; &#40;ICSP&#x2122;&#41; via two pins
• In-Circuit Debug &#40;ICD&#41; via two pins
CMOS Technology:
• Low power, high speed FLASH/EEPROM technology
• Fully static design
• Wide operating voltage range &#40;2.0V to 5.5V&#41;
• Industrial and Extended temperature ranges
• Low power consumption:
&#45; &lt; 1.6 mA typical @ 5V, 4 MHz
&#45; 25 μA typical @ 3V, 32 kHz
&#45; &lt; 0.2 μA typical standby current
6527
Peripheral Highlights: 
• Two Master Synchronous Serial Port &#40;MSSP&#41; modules supporting 2/3/4-wire SPI&#x2122; &#40;all 4 modes&#41; and I2C&#x2122; Master and Slave modes
• Two Capture/Compare/PWM &#40;CCP&#41; modules
• Three Enhanced Capture/Compare/PWM &#40;ECCP&#41; modules:
&#45; One, two or four PWM outputs
&#45; Selectable polarity
&#45; Programmable dead time
&#45; Auto-Shutdown and Auto-Restart
• Two Enhanced Addressable USART modules:
&#45; Supports RS-485, RS-232 and LIN 1.2
&#45; Auto-Wake-up on Start bit
&#45; Auto-Baud Detect
• 10-bit, up to 16-channel Analog-to-Digital Converter module &#40;A/D&#41;
&#45; Auto-acquisition capability
&#45; Conversion available during Sleep
• Dual analog comparators with input multiplexing
• High-current sink/source 25 mA/25 mA
• Four programmable external interrupts
• Four input change interrupts External Memory Interface &#40;PIC18F8527/8622/8627/8722 only&#41;:
• Address capability of up to 2 Mbytes
• 8-bit or 16-bit interface
• 8, 12, 16 and 20-bit Address modes
Power-Managed Modes:
• Run: CPU on, peripherals on
• Idle: CPU off, peripherals on
• Sleep: CPU off, peripherals off
• Idle mode currents down to 15 μA typical
• Sleep current down to 0.2 μA typical
• Timer1 Oscillator: 1.8 μA, 32 kHz, 2V
• Watchdog Timer: 2.1 μA
Special Microcontroller Features:
• C compiler optimized architecture:
&#45; Optional extended instruction set designed to optimize re-entrant code
• 100,000 erase/write cycle Enhanced Flash program memory typical
• 1,000,000 erase/write cycle Data EEPROM memory typical
• Flash/Data EEPROM Retention: 100 years typical
• Self-programmable under software control
• Priority levels for interrupts

• Extended Watchdog Timer &#40;WDT&#41;:
&#45; Programmable period from 4 ms to 131s

</div></div><div class="thread-post"><h3 class="thread-post-title">PIC 18F6527</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on July 19, 2007</div><div class="thread-post-content">C compiler optimized architecture?&nbsp; That&#8217;s funny.
FreeRTOS only cares about the register set and timers.&nbsp; I was meaning are there any differences to the cores?&nbsp; Do they share the same register set?&nbsp; If so then the two are &#8216;compatible&#8217;.&nbsp; Maybe if the timers are different then a different timer would have to be chosen to generate the tick?
</div></div><div class="thread-post"><h3 class="thread-post-title">PIC 18F6527</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/paul_piak">paul_piak</a> on July 31, 2007</div><div class="thread-post-content">Hi
Don&#8217;t worry about the peripherals, the instruction set of the processors are the same, so you can use it. I have been using freertos on the 8525 and the 8627 without problems.
Just be sure to disable &#8216;extended&#8217; mode in the compiler options, as this &#40;when checked&#41; activates the &#8216;c-optimized instructions&#8217;. These allow more efficient translation from C to machine instructions &#40;indirect access with offset, etc.&#41; but the context save/restore routines should be changed for this to work because the mathdata and tempdata are on different locations then. Save this for later.
Be sure to follow the PIC18 instructions on the freertos website to modify the mathdata and tempdata save/restore sections in port.c 
Good luck,
Paul van der Hulst
