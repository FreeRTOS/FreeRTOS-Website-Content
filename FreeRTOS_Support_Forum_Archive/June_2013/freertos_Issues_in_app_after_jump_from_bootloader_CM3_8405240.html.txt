</div></div><div class="thread-post"><h3 class="thread-post-title">Issues in app after jump from bootloader CM3 </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on June 4, 2013</div><div class="thread-post-content">Calling vTaskEndScheduler&#40;&#41; will not do anything on a Cortex.  
Are you remapping the vector table from the table used by your bootloader to the one used by your application?  
Are you stopping the timer that generates the tick interrupts and clearing any pending interrupts before jumping to your application? Just disabling interrupts is probably not good enough because as soon as interrupts become enabled in your C start up code pending interrupts will execute but no longer have anything to execute because the bootloader is not running any more.  
It might also be an idea to search the support archive as this topic has come up a few times before. <a href="http://www.freertos.org/FreeRTOS_Support_Forum_Archive/freertos_support_forum_archive_index.html/">http://www.freertos.org/FreeRTOS_Support_Forum_Archive/freertos_support_forum_archive_index.html</a>
</div></div><div class="thread-post"><h3 class="thread-post-title">Issues in app after jump from bootloader CM3 </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/hackrid">hackrid</a> on June 4, 2013</div><div class="thread-post-content">hi,  
thanks for your answer.  
sure I&#8217;m remapping the vector table.<br />
the main application and the jump to it does work, as long as i do not create tasks in the bootloader.  
here is the code of the jump routine. is there something missing?  
<pre><code>void vBootApplication(void)
{
   uint32_t u32JumpAddress;
   mg_DeInit();
   /* Disable all interrupts */
   RCC-&gt;CIR = 0x00000000;
   uint8_t tmp;
   /* Disable all interrupts */
   NVIC-&gt;ICER[0] = 0xFFFFFFFF;
   NVIC-&gt;ICER[1] = 0x00000001;
   /* Clear all pending interrupts */
   NVIC-&gt;ICPR[0] = 0xFFFFFFFF;
   NVIC-&gt;ICPR[1] = 0x00000001;
   /* Clear all interrupt priority */
   for (tmp = 0; tmp &lt; 32; tmp++) {
       NVIC-&gt;IP[tmp] = 0x00;
   }
   NVIC_SetVectorTable(NVIC_VectTab_FLASH, 0x20000);
   /* Get jump address to application */
   u32JumpAddress = START_ADDR_OF_APPLICATION;
   u32JumpAddress = *(__IO uint32_t*) (START_ADDR_OF_APPLICATION + 4);
   Jump_To_Application = (mg_pFunction) u32JumpAddress;
   /* Initialize user application's Stack Pointer */
   __set_MSP(*(__IO uint32_t*) START_ADDR_OF_APPLICATION);
   /* Jump to application */
   Jump_To_Application();
}
</code></pre>
