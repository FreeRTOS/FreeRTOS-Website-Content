/&#42; THIS FUNCTION MUST BE CALLED WITH INTERRUPTS DISABLED OR THE<br />

/&#42; The event list is sorted in priority order, so we can remove the<br />

get called &#8211; the lock count on the queue will get modified instead.&nbsp; This<br />
means we can always expect exclusive access to the event list here.  
This function assumes that a check has already been made to ensure that<br />
pxEventList is not empty. &#42;/<br />
pxUnblockedTCB = &#40; tskTCB &#42; &#41; listGET&#95;OWNER&#95;OF&#95;HEAD&#95;ENTRY&#40; pxEventList &#41;;<br />

if&#40; uxSchedulerSuspended == &#40; unsigned portBASE&#95;TYPE &#41; pdFALSE &#41;<br />
&#123;<br />
uxListRemove&#40; &amp;&#40; pxUnblockedTCB-&gt;xGenericListItem &#41; &#41;;<br />
prvAddTaskToReadyQueue&#40; pxUnblockedTCB &#41;;<br />
