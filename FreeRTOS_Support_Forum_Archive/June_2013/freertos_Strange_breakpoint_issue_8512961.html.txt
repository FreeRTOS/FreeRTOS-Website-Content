Anyone knows anything about this?

</div></div><div class="thread-post"><h3 class="thread-post-title">Strange breakpoint issue</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on June 28, 2013</div><div class="thread-post-content">That is strange. Can you establish exactly where the failure happens. Maybe add a link&#95;down&#95;processing++ after each previousLinkState = 0 statement and link&#95;up&#95;processing++ after each previousLinkState = 1 statement to see if you go through the if statement at all. If the counters values show that the netif&#95;set&#95;link&#95;x functions are being called, but the network is still not coming up, then it is more likely to be in the implementation of those functions rather than the timer not being called.  
Are the netif&#95;set&#95;link&#95;x&#40;&#41; functions thread safe?
