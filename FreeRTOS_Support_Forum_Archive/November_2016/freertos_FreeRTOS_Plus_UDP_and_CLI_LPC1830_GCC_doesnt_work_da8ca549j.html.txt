</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS_Plus_UDP_and_CLI_LPC1830_GCC doesn&#8217;t work</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 16, 2016</div><div class="thread-post-content">__set_PRIMASK is a cmsis library function, so it looks like there is a 
problem with including the cmsis core header file.  Sometimes this 
header file is included explicitly using a
<pre>
#include
</pre>
and locating the header file in the application directory.  Sometimes it 
is included implicitly by the tools and located in one of the tools 
library directories.  I expect the way or method it is included has 
changed since the demo was created (it is quite old).
If you cannot work out how to get the cmsis header file into the code 
then simply add an implementation of __set<em>PRIMASK into your application 
code.  Googing __set</em>PRIMASK will show you how it is implemented, just a 
few lines.
