</div></div><div class="thread-post"><h3 class="thread-post-title">Intel Galileo Gen2 and FreeRTOS TCP</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on July 6, 2016</div><div class="thread-post-content">I&#8217;m not aware of a driver that is specific for the FreeRTOS+TCP stack, 
but there are other drivers around for the Galileo Ethernet port.  You 
will have to create a FreeRTOS+TCP driver (and if so, please post it to 
the FreeRTOS Interactive site), and probably the easiest thing to do 
would be to base it on whatever drivers Intel are providing themselves.

Do you have any basic structure or starting point so I can do some research and try? If I get it to work I will happily share it.
</div></div><div class="thread-post"><h3 class="thread-post-title">Intel Galileo Gen2 and FreeRTOS TCP</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on July 6, 2016</div><div class="thread-post-content">Very broadly speaking, and oversimplifying, there are two phases to 
creating a driver:
1) Set up the hardware so that packets can be sent onto the network and 
received from the network.
In this step, you could read the user manual, and then create lots of 
very low level code to enable, clock and initialise the MAC&#8230;.or as per 
my previous email you could take a working driver provided for you by 
Intel (or whoever).  I think their driver is open source.
2) Once you have the hardware inputting and outputting, stitch it into 
the FreeRTOS+TCP stack.
If the hardware is happily reading and writing, then this step should be 
straight forward as there are only a couple of functions that are needed.
There are examples in the FreeRTOS+TCP download already, in the 
FreeRTOS<em>Plus</em>TCPMulti<em>IPv6</em>BranchFreeRTOS-PlusSourceFreeRTOS-Plus-TCPportableNetworkInterface 
directory.  There is also some information on the web site: 
http://www.freertos.org/FreeRTOS-Plus/FreeRTOS<em>Plus</em>TCP/Embedded<em>Ethernet</em>Porting.html
</div></div><div class="thread-post"><h3 class="thread-post-title">Intel Galileo Gen2 and FreeRTOS TCP</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on July 6, 2016</div><div class="thread-post-content">Sure, there are several examples. Have a look at any of these drivers:
~~~~
    FreeRTOS-Plus-TCP/portable/NetworkInterface/STM32Fxx
    FreeRTOS-Plus-TCP/portable/NetworkInterface/Zynq
    FreeRTOS-Plus-TCP/portable/NetworkInterface/ATSAM4E
~~~~
For simplicity, I would start with a driver that is not zero-copy.
If you encounter problems, there is a forum to ask question 🙂
