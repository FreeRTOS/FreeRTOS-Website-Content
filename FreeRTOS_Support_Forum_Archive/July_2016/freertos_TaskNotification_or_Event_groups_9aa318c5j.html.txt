  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">TaskNotification or Event groups</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rrrum">rrrum</a> on July 13, 2016</div><div class="thread-post-content">Hello,
I would like to ask for a opinion, it is a design issue and I am not able to find among many different mechanisms the right one for my task:
<ol>
<li>Let’s focus on 3 tasks, A, B1, B2</li>
<li>Task A is implemented as follows: waits on its “command queue” and there is also timeout set to allow it to run periodically to do some work if no commands are present.</li>
<li>Task A is controlling also B1 and B2, at some point task A writes to receive queues of B1 and B2 which unblock and B1 or B2  or both run</li>
<li>Each task B1 and B2 should set some flag, showing task is running</li>
<li>It can take undefined amount of time to complete B1 or B2, when completed, each task resets its “running flag”</li>
<li>Now task A, at some point in the “periodic” run section, should check if tasks B1 and B2 completed their job (running flag not set), if both are finished it should perform some action, otherwise is should just continue executing periodic stuff.</li>
</ol>
So I wonder if task notification mechanism or event groups can be used for this purpose or what is the most suitable/efficient mechanism for this design problem.  
Thank you
rum
</div></div><div class="thread-post"><h3 class="thread-post-title">TaskNotification or Event groups</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/hs2sf">hs2sf</a> on July 14, 2016</div><div class="thread-post-content">IMO notifications should be sufficient for this design. I&#8217;ve developed a pretty similar system purely using notifications b/c they are by far the fastest and smallest IPC mechanism available in FreeRTOS (you can disable almost all other OS features).
I think event_groups are an overkill.
But if you&#8217;re a lucky boy having no constraints regarding performance and code size you can choose the most convenient IPC 🙂
Good luck !
