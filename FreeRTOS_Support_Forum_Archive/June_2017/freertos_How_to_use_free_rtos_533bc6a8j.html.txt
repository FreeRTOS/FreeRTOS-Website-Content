  FreeRTOS is an Open Source library, you are free to use and change it, 
  as long as your code remains Open Source as well.
</blockquote>
That only applies to the RTOS source code, not application code that is 
using FreeRTOS.
<blockquote>
  In case you want to use FreeRTOS in a commercial non-Open-Source 
  project, that is OK, but you&#8217;ll need to purchase a license to use it 
  that way.
</blockquote>
Actually not so.  FreeRTOS can be used for free in closed source 
application.  The linkage exception says you can distribute products 
that use FreeRTOS &#8216;under the terms of your choice&#8217;, so the FreeRTOS 
license does not affect the license of any other software in your 
system, and does not impose any restrictions or requirements on how 
products that use FreeRTOS are sold or distributed.
