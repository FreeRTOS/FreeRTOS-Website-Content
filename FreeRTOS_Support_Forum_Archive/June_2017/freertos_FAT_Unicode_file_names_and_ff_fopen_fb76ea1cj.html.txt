That would let me to use filenames in unicode, i supposed. 
But how can I pass a unicode string to ff_fopen() function, if its pcFile parameter have the type of const char *?
How could one open a file which filename is a unicode string?

Vladimir
</div></div><div class="thread-post"><h3 class="thread-post-title">+FAT Unicode file names and ff_fopen()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on June 6, 2017</div><div class="thread-post-content">Vladimir, I am guessing that you want to see file names in Cyrillic?
The Unicode variant of the library ( <code>ffconfigUNICODE_UTF16_SUPPORT</code> ) has been tested, but it was never included into the top layer: ff_stdio.c
When you use the low-level functions like <code>FF_Open()</code>, you do have Unicode, but you will miss the &#8220;file system layer&#8221;. Which is no problem if you just have a single volume, an SD-card.
I think I would define a type that holds a character ( of file name ) :
~~~
    #if( ffconfigUNICODE<em>UTF16</em>SUPPORT != 0 )
        typedef FF<em>T</em>WCHAR FileName<em>t;
    #else
        typedef const char FileName</em>t;
    #endif
<pre><code>FF_FILE *ff_fopen( FileName_t *pcFile, const char *pcMode );
int ff_mkdir( FileName_t *pcPath );
int ff_rmdir( FileName_t *pcDirectory );
int ff_remove( FileName_t *pcPath );
</code></pre>
~~~
</div></div><div class="thread-post"><h3 class="thread-post-title">+FAT Unicode file names and ff_fopen()</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on June 6, 2017</div><div class="thread-post-content">Just checked the above change with <code>ff_stdio.c</code>
I&#8217;m afraid it is a lot more work because there are lots of manipulations with the file- and directory-names. Also <code>ff_sys.c</code> will need to be adapted to use Unicode. No quick fix available, I&#8217;m afraid
