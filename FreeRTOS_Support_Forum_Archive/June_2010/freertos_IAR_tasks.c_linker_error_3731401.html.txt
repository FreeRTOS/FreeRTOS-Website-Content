  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">IAR tasks.c linker error</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/peisenhower">peisenhower</a> on June 4, 2010</div><div class="thread-post-content">I am using IAR cortex M3 Kick Start to work with the energyMicro EFM32 G290F128.  
I am using all the files from the freeRTOS website to start my project. I used the configuration files and source code from that demo and moved it into a project I have been working on.   
When I go to build my project I get the following error:  
Error: no definition for &#8220;vApplicationStackOverflowHook&#8221;&nbsp;   
I put a &#35;error in the StackMacro.h file to make sure the function was being declared and it is.<br />
What doesnt make sense to me is that a macro is defined in StackMacro.h taskFIRST&#95;CHECK&#95;FOR&#95;STACK&#95;OVERFLOW&#40;&#41;&nbsp; and that macro has a function definition and declartion in it &#40;extern void vApplicationStackOverflowHook…&#41;. But that macro is then called within another function. I did not think that was even possible.   
I can fix this error by pulling out the macro and making it a function in the task.c file but i dont thing that is the correct fix.   
If someone undestands this error I would greatly appreciate the help.   
Thanks,<br />
Peter  
</div></div><div class="thread-post"><h3 class="thread-post-title">IAR tasks.c linker error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on June 4, 2010</div><div class="thread-post-content">the extern void vApplicationStackOverflowHook in the macro is a function DECLARATION not a DEFINITION. It tells the compiler how to call the function, but not what is in it. FreeRTOS does not include a definition of this function, because it doesn&#8217;t know what you want to be done once the error occurs. You program needs to provide the definition of this function, which could be as simple as just an infinite loop.
</div></div><div class="thread-post"><h3 class="thread-post-title">IAR tasks.c linker error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/peisenhower">peisenhower</a> on June 4, 2010</div><div class="thread-post-content">Fantastic thanks a bunch. 
</div></div><div class="thread-post"><h3 class="thread-post-title">IAR tasks.c linker error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/peisenhower">peisenhower</a> on June 4, 2010</div><div class="thread-post-content">That fixed it. The only file I did not copy from the demo was main and thats where vApplicationStackOverflowHook was defined.   
thanks again,<br />
Peter
</div></div><div class="thread-post"><h3 class="thread-post-title">IAR tasks.c linker error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on June 4, 2010</div><div class="thread-post-content">Thanks to Richard&#95;Damon for his excellent support &#8211; as always.  
Anything that starts vApplication is intended for definition by the application code.&nbsp; These are always optional, with settings in FreeRTOSConfig.h being used to either enable or disable the option.
