Actually, only the top four bits of the interrupt priority bytes are implemented &#40;on the STM32, in any case, that is not true for all CM3 implementations&#41;.&nbsp; Therefore the priorities are 0 &#40;highest&#41; and 1&lt;&lt;4 to 15&lt;&lt;4.&nbsp; Or in binary, 0 and 00010000 to 11110000.&nbsp; The inconsistency comes from the fact that some API functions &#40;CMSIS for example&#41; want the priority stated <strong>without</strong> the shift, while others <strong>require</strong> the shift.&nbsp; If you use a shifted priority with a function that does not want the value shifted your actual interrupt priority will end up as being zero, and visa versa.
