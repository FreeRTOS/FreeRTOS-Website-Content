  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS on MSP430 using IAR interrupts probl</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/mariohuizar">mariohuizar</a> on June 2, 2010</div><div class="thread-post-content">Hello all,  
I am using the FreeRTOS on a MSP430FG439 and I want to use the Uart0 but because the Free RTOS on the file portext.s43 redefine the INTVEC I am having problems…<br />
The FreeRTOS needs the timer0 to define the &#8220;tick&#8221; of the OS. And it defines it in assembler like this:  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ASEG<br />
ORG 0xFFE0 + TIMERA0&#95;VECTOR  
&#95;vTickISR&#95;: DC16 vTickISR  
I was having the following error:  
Error: Segment INTVEC &#40;size: 0x14 align: 0x1&#41; is too long for segment definition. At least 0x2 more bytes needed. The problem occurred while processing the&nbsp;<br />
segment placement command &#8220;-Z&#40;CODE&#41;INTVEC=FFE0-FFFF&#8221;, where at the moment of placement the available memory ranges were &#8220;CODE:ffe0-ffeb,CODE:ffee-ffff&#8221;<br />
&nbsp;&nbsp; Reserved ranges relevant to this placement:<br />
&nbsp;&nbsp; ffe0-ffeb&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; INTVEC<br />
&nbsp;&nbsp; ffec-ffed&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Absolute code from TICK&#95;ISR<br />
&nbsp;&nbsp; ffee-ffff&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; INTVEC   
Now what I did was to redefine the INTVEC as a Common segment like this:  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; COMMON INTVEC&#40;1&#41; ; Interrupt vectors<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ORG TIMERA0&#95;VECTOR&nbsp;&nbsp;&nbsp;<br />
&#95;vTickISR&#95;: DC16 vTickISR  
But now the linker complains with:  
Linking<br />
Error: Undefined external &#8220;?cstart&#95;init&#95;copy&#8221; referred in port &#40; C:UsersMarioDocumentsMasterArbeitLifebridgeSupervisorDemomsp430&#95;IARDebugObj<br />
port.r43 &#41;<br />
Error: Undefined external &#8220;?cstart&#95;init&#95;zero&#8221; referred in tasks &#40; C:UsersMarioDocumentsMasterArbeitLifebridgeSupervisorDemomsp430&#95;IARDebugObj<br />
tasks.r43 &#41;<br />
Error while running Linker   
Any ideas?  
Thanks&#33;<br />
Mario Huizar
