Hi FreeRTOS experts,
I am running Win7 (64-bit) with CCS 7.3, compiler TI 16.9.6.LTS. For my TI Launchpad MSP430FR5969 I downloaded the CCS/IAR version of the FreeRTOS (v.9.0.0) demo and imported it as described on the project page:
http://www.freertos.org/MSP430FR5969<em>Free</em>RTOS_Demo.html.
However, when building the project I encounter 5 error messages for task.c related to conversions and modifiers, namely:
<ul>
<li>2631 Conversion u not allowed in printf<em>support=minimal mode  tasks.c /RTOSDemo/FreeRTOS</em>Source   line 4018, 4114, 4130   C/C++ Problem</li>
<li>2632 Modifiers are not allowed in printf<em>support=minimal mode tasks.c /RTOSDemo/FreeRTOS</em>Source   line 4114, 4130 C/C++ Problem.</li>
</ul>
Affected lines in task.c are 4018, 4114, 4130. 
I tried to run it with different TI compiler versions: problem still persists. The GCC compiler results in over 100 errors.
I tried also full printf() support with no change.
Any help would be appreciated. Thank you!
P.S.: Changing #define mainCREATE<em>SIMPLE</em>BLINKY<em>DEMO</em>ONLY   1 (or 0) did not affect the issue since it relates to task.c.
Ideas-moose
</div></div><div class="thread-post"><h3 class="thread-post-title">Build Error for FreeRTOS demo in CCS 7.3, compiler TI 16.9.6.LTS &#8211; sprintf() &#8211; task.c &#8211; MSP430X &#8211; Launchpad MSP430FR5969</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 15, 2017</div><div class="thread-post-content">Looks like an incompatibility with the compiler&#8217;s standard C library. 
You could change the definition of portLU<em>PRINTF</em>SPECIFIER<em>REQUIRED to 
see if that helps (it switches the format specifiers as they are non 
standard), or include the small printf-stdarg.c file in your build 
(there are lots of copies in the FreeRTOS download), or edit the source 
code so it works with your printf version, or, if you are not using the 
vTaskGetRunTimeStats() function &#8211; simply set 
configUSE</em>STATS<em>FORMATTING</em>FUNCTIONS to 0 in FreeRTOSConfig.h.  The 
function in question is just a &#8216;helper&#8217; function, not part of the 
FreeRTOS kernel.

Nevertheless, I tried to follow your other two routes. I was unable to make them work.

When placed as #define portLU</em>PRINTF<em>SPECIFIER</em>REQUIRED 1 (or 0) in main.c it does not compile when vTaskGetRunTimeStats() is called.</li>
</ul>
I appreciate your help! Thanks!
