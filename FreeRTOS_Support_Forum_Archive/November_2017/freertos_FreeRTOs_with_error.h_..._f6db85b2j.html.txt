</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOs with &#8220;error.h&#8221; &#8230;</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on November 30, 2017</div><div class="thread-post-content">That&#8217;s indeed the way to go.
When defining <code>configNUM_THREAD_LOCAL_STORAGE_POINTERS</code>, a number of objects can be stored in the task&#8217;s context.
This object has the size of a pointer, but it does not have to be a pointer. An integer may be casted and stored as a pointer.
The FreeRTOS+FAT library already uses 3 of these storage pointers, one of the to stored the last <code>errno</code> seen. Another pointer stores the CWD (current working directory).
Here are the two access functions:
~~~
/* The errno is stored in a thread local buffer. */
static portINLINE void stdioSET_ERRNO( int iErrno )
{
    vTaskSetThreadLocalStoragePointer( NULL, ffconfigCWD_THREAD_LOCAL_INDEX, ( void * ) ( iErrno ) );
}
static portINLINE int stdioGET_ERRNO( void )
{
void *pvResult;
<pre><code>pvResult = pvTaskGetThreadLocalStoragePointer( ( TaskHandle_t )NULL, ffconfigCWD_THREAD_LOCAL_INDEX );
return ( int ) pvResult;
</code></pre>
}
~~~
I know that in some environments <code>errno</code> has an instance per thread in some magic way, but I don&#8217;t think that it will work together with FreeRTOS.
Regards,

</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOs with &#8220;error.h&#8221; &#8230;</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on November 30, 2017</div><div class="thread-post-content">Not everyone appreciates C++, but you could make a nice little class for <code>errno</code>.
~~~
class CErrno {
public:
    operator int()
    {
    void *pvResult;
<pre><code>    pvResult = pvTaskGetThreadLocalStoragePointer( ( TaskHandle_t )NULL, ffconfigCWD_THREAD_LOCAL_INDEX );
    return ( int ) pvResult;
}
int operator =(int aValue)
{
    vTaskSetThreadLocalStoragePointer( NULL, ffconfigCWD_THREAD_LOCAL_INDEX, ( void * ) ( aValue ) );
    return aValue;
}
</code></pre>
};
CErrno myErrno;
~~~
Now the same instance of <code>myErrno</code> can be used by any task:
~~~~
    myErrno = 0;
    /* call function */
    if( myErrno == 2 )
    {
    }
~~~~

If you are using newlib, you only have to set
  configUSE<em>NEWLIB</em>REENTRANT  to 1
in your FreeRTOSConfig.h
In newlib,&#8221;errno&#8221; and other global variables like &#8220;stdout&#8221; are defined as macros and will actually point to a task local reent structure. On single core systems, there&#8217;s just a pointer called &#8220;<em>impure</em>ptr&#8221; that is updated by FreeRTOS on task switch (see task.c).
