</div></div><div class="thread-post"><h3 class="thread-post-title">Problem with FFT Functions in FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on December 1, 2017</div><div class="thread-post-content">I don&#8217;t think configUSE<em>TASK</em>FPU_SUPPORT  has any effect for the STM32.
Do you have stack overflow checking turned on? 
https://www.freertos.org/Stacks-and-stack-overflow-checking.html
How are you passing the data via a queue?  Do you just queue a pointer 
to the data?  That might not work if the array is on the stack but the 
tack frame no longer exists.  I presume you are talking about the task 
stack, not the stack of main(), as the main() stack will also no longer 
exist.
