</div></div><div class="thread-post"><h3 class="thread-post-title">xSTATIC_QUEUE had a different meaninf during compilation</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 28, 2018</div><div class="thread-post-content">xSTATIC<em>QUEUE is defined in a header file, so it might be something to

</div></div><div class="thread-post"><h3 class="thread-post-title">xSTATIC_QUEUE had a different meaninf during compilation</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on February 28, 2018</div><div class="thread-post-content">The definition of <code>xSTATIC_QUEUE</code> depends on four defines from <code>FreeRTOSConfig.h</code>.
You can test how the preprocessor sees them by issuing temporary warnings from <code>FreeRTOS.h</code>:
~~~
<h1>if( configSUPPORT<em>STATIC</em>ALLOCATION != 0 )</h1>
<pre><code>#warning STATIC_ALLOCATION yes
</code></pre>
<h1>else</h1>
<pre><code>#warning STATIC_ALLOCATION no
</code></pre>
<h1>endif</h1>
<h1>if( configSUPPORT<em>DYNAMIC</em>ALLOCATION != 0 )</h1>
<pre><code>#warning DYNAMIC_ALLOCATION yes
</code></pre>
<h1>else</h1>
<pre><code>#warning DYNAMIC_ALLOCATION no
</code></pre>
<h1>endif</h1>
<h1>if( configUSE<em>QUEUE</em>SETS != 0 )</h1>
<pre><code>#warning QUEUE_SETS yes
</code></pre>
<h1>else</h1>
<pre><code>#warning QUEUE_SETS no
</code></pre>
<h1>endif</h1>
<h1>if( configUSE<em>TRACE</em>FACILITY != 0 )</h1>
<pre><code>#warning TRACE_FACILITY yes
</code></pre>
<h1>else</h1>
<pre><code>#warning TRACE_FACILITY no
</code></pre>
<h1>endif</h1>
~~~
You should see the same pattern of yes/no for every module compiled, especially <code>main.c</code> and <code>BufferAllocation_2.c</code>.
Make also sure that there is only a single copy of <code>FreeRTOSConfig.h</code> within the entire project.

</div></div><div class="thread-post"><h3 class="thread-post-title">xSTATIC_QUEUE had a different meaninf during compilation</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on February 28, 2018</div><div class="thread-post-content"><blockquote>
  Trace_facility comes up as no for everything except .. main.c
</blockquote>
So when main.c is seeing include/FreeRTOS.h the structure <code>xSTATIC_QUEUE</code> is smaller than it is for other source files.
~~~
typedef struct xSTATIC<em>QUEUE
{
    &#8230;
    #if ( configUSE</em>TRACE<em>FACILITY == 1 )
        UBaseType</em>t uxDummy8;
        uint8_t ucDummy9;
    #endif
};
~~~
And it looks like the compiler is warning about this.
Now you should check why main.c and stm32f4xx_it.c do not see that <code>configUSE_TRACE_FACILITY</code> is not defined.
