  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Looking for a similar function to getpeername() for win32 simulator</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kat123">kat123</a> on February 1, 2018</div><div class="thread-post-content">I&#8217;ve got some C++ code and I&#8217;m trying to replicate the functionality with FreeRTOS + TCP on the Windows simulator before porting it to an STM32F4. 
My original code broadcasts a UDP message and then  uses getpeername() to find the IP address  of devices on a local network that respond fore creating a TCP socket and connecting to the devices. 
I can&#8217;t find anything that performs the same function or a combination of things that perfom the same function in the FreeRTOS API.
FreeRTOS_getremoteaddress() seems to do something similar but is only for TCP connections. 
Is there a way to do this with FreeRTOS + TCP? 
</div></div><div class="thread-post"><h3 class="thread-post-title">Looking for a similar function to getpeername() for win32 simulator</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on February 1, 2018</div><div class="thread-post-content">Hi Kathryn, when this is the BSD function:
~~~
int getpeername(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
~~~
&#8230;this is the +TCP variant:
~~~
/* Return the remote address and IP port. */
BaseType_t FreeRTOS_GetRemoteAddress( Socket_t xSocket, struct freertos_sockaddr *pxAddress );
~~~
And yes, we should have named it <code>FreeRTOS_getpeername()</code>
<blockquote>
  <code>FreeRTOS_getremoteaddress()</code> seems to do something similar
  but is only for TCP connections. 
</blockquote>
That is true, because a UDP socket in FreeRTOS+TCP can not <code>connect()</code> to a remote socket.  A UDP socket can send data to any address at any time, using <code>sendto()</code>.
</div></div><div class="thread-post"><h3 class="thread-post-title">Looking for a similar function to getpeername() for win32 simulator</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kat123">kat123</a> on February 1, 2018</div><div class="thread-post-content">Is there anyway to get an IP address from a UDP packet? 
So if I receive a UDP packet from a device, can I get the IP of the device that sent it? 
Currently I receive a UDP packet 
<code>ByteReceived[i] = recvfrom(s, recvBuffer[i], 1024, 0, (SOCKADDR *)&amp;SenderAddr[i], &amp;SenderAddrSize);</code>
And then 
<code>getpeername(s, (SOCKADDR *)&amp;SenderAddr[i], &amp;SenderAddrSize);</code>
Then I can use the IP from the sender address and create a TCP socket
</div></div><div class="thread-post"><h3 class="thread-post-title">Looking for a similar function to getpeername() for win32 simulator</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on February 1, 2018</div><div class="thread-post-content">The BSD function is :
~~~
ssize<em>t recvfrom(int sockfd, void *buf, size</em>t len, int flags, struct sockaddr *src_addr, socklen_t *addrlen);
~~~
FreeRTOS+TCP has a similar definition:
~~~
int32<em>t FreeRTOS</em>recvfrom( Socket<em>t xSocket, void *pvBuffer, size</em>t xBufferLength, BaseType<em>t xFlags, struct freertos</em>sockaddr *pxSourceAddress, socklen_t *pxSourceAddressLength )
~~~
In this case, you don&#8217;t need to call <code>getpeername()</code>, because you already have that address in <code>src_addr</code> or <code>pxSourceAddress</code>.
When replying to the sender, you can safely use that address. No need to call <code>getpeername()</code>.
UDP is a connectionless protocol, there is no fixed peer. There has been some attempt to do as if a UDP socket can be connected. Here some comments on that attempt:
https://stackoverflow.com/questions/9741392/can-you-bind-and-connect-both-ends-of-a-udp-connection
</div></div><div class="thread-post"><h3 class="thread-post-title">Looking for a similar function to getpeername() for win32 simulator</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kenchang1">kenchang1</a> on February 1, 2018</div><div class="thread-post-content">I think Kathryn is looking for a macro or function to extract the IP-address from the struct member freertos<em>sockaddr.sin</em>addr in pxSourceAddress.
You can modify FreeRTOS<em>GetRemoteAddress() for UDP, right?
Edit: never mind, it makes no sense to extract the IP address, you can just reuse struct freertos</em>sockaddr *pxSourceAddress
