</div></div><div class="thread-post"><h3 class="thread-post-title">pack_struct_end.h errors when compiling with IAR</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jeronimo479">jeronimo479</a> on February 26, 2018</div><div class="thread-post-content">Eclipse did the same thing to me. It would flag all the places where the &#8220;;&#8221; was supposed to be, but was located in the pack<em>struct</em>end.h file so it wasn&#8217;t recognized. I added an extra &#8220;;&#8221; before &#8216;typedef&#8217;. It doesn&#8217;t cause bad code, and get&#8217;s rid of the error.
<h1>include &#8220;pack<em>struct</em>start.h&#8221;</h1>
struct xARP<em>HEADER
{
    uint16</em>t usHardwareType;                /*  0 +  2 =  2 <em>/
    uint16_t usProtocolType;                /</em>  2 +  2 =  4 <em>/
    uint8_t ucHardwareAddressLength;        /</em>  4 +  1 =  5 <em>/
    uint8_t ucProtocolAddressLength;        /</em>  5 +  1 =  6 <em>/
    uint16_t usOperation;                   /</em>  6 +  2 =  8 <em>/
    MACAddress_t xSenderHardwareAddress;    /</em>  8 +  6 = 14 <em>/
    uint8_t ucSenderProtocolAddress[ 4 ];   /</em> 14 +  4 = 18  <em>/
    MACAddress_t xTargetHardwareAddress;    /</em> 18 +  6 = 24  <em>/
    uint32_t ulTargetProtocolAddress;       /</em> 24 +  4 = 28  */
}
<h1>include &#8220;pack<em>struct</em>end.h&#8221;</h1>
;typedef struct xARP<em>HEADER ARPHeader</em>t;

</div></div><div class="thread-post"><h3 class="thread-post-title">pack_struct_end.h errors when compiling with IAR</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 26, 2018</div><div class="thread-post-content">Are these actual compiler errors?  If so, please paste a few into the 
forum.  Somebody mentioned Eclipse previously, are you using Eclipse of 
Embedded Workbench?  Eclipse will try and parse C code itself and 
display lots of errors in the IDE because it&#8217;s not very good at it &#8211; but 
those are not compiler errors, or indeed anything to do with the 
compiler and can be ignored (or you can tell Eclipse not to do it in the 
project or workspace options).
</div></div><div class="thread-post"><h3 class="thread-post-title">pack_struct_end.h errors when compiling with IAR</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/kat123">kat123</a> on February 26, 2018</div><div class="thread-post-content">How do I check if they are compiler errors or IDE errors?
</div></div><div class="thread-post"><h3 class="thread-post-title">pack_struct_end.h errors when compiling with IAR</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on February 26, 2018</div><div class="thread-post-content">Compiler errors will appear in the console out window.  You will see the 
compiler&#8217;s command line being called to build a file, then the errors 
and warnings output when building that file, before moving onto the next 
file.  The compiler&#8217;s hap hazard attempt at parsing C code generates 
warnings and errors visible in the left margin of the editor window &#8211; 
nothing to do with the running of the compiler or the output of the 
compiler.
