</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS+TCP on SAME70 with ASF4 (Atmel Start) MAC drivers</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/skjafar">skjafar</a> on November 7, 2018</div><div class="thread-post-content">Hi,
After a lot of help from Hein I was able to get it all running on both ASF3 and ASF4 for the SAME70-Xplained board with SAME70Q21A not B.
Below are links for example projects, one using ASF3, it&#8217;s a very simple example. The second is using ASF4, aka Atmel Start.
They both start looking for a DHCP server upon wake up for a valid connection, if not found they will switch to the defined static IP.
Details on the ASF4 project:
<ul>
<li>UART using the debug board at 115200 baud, this should give you periodic statistics.</li>
<li>After TCP connection you will see the IP address, connect to it using telnet at port 2008, it has FreeRTOS+CLI implemented there, type &#8220;help&#8221; for the command list.</li>
<li>You can use Atmel Start to add drivers but make sure to do the following afterwards:
<ul>
<li>Never allow modifications on the FreeRTOS files even if it asks.</li>
<li>Never allow modifications on FreeRtosConfig.h</li>
<li>Modify the linker scripts as shown in directory: Device_Startup. Read &#8220;AddMeToldFiles.txt&#8221;</li>
<li>Add &#8220;#include &#8220;application<em>include.h&#8221;&#8221; to &#8220;driver</em>init.h&#8221;</li>
<li>add &#8220;init<em>application();&#8221; into &#8220;void system</em>init(void)&#8221; in file &#8220;driver_init.c&#8221;</li>
<li>if you see file name &#8220;main.c&#8221; in root directory remove it.</li>
</ul></li>
</ul>
If you decide to get the FreeRTOS+TCP part into your project make sure to change the linkerscript to accomedate the change, mainly defining the following right after the .text part of memory. :
.first<em>data (NOLOAD) :
    {
        . = ALIGN(4);
        _first</em>data = . ;
        <em>(._first_data ._first_data.</em>)
        . = ALIGN(4);
        <em>e</em>first_data = . ;
    } > ram
Please note that the gmac driver included with FreeRTOS+TCP for SAME70 cannot run with CACHE enabled, at least not yet, maybe Hein can comment on this, and if you do get it running please let us know.
I hope this benifets you.
The links:
ASF3: https://drive.google.com/open?id=1WBOGMzwHGw5X35h51ABLxd6CNs6<em>WYmW
ASF4: https://drive.google.com/open?id=1gfFz7jkVkEAZap2RYFdMlC34c</em>Nfp5f9
I will try to keep the links as long as possible. I have also attached the files.
Thanks Hein.
