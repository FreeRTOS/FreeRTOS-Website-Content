  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Semaphore pending ?</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/delphes">delphes</a> on October 31, 2018</div><div class="thread-post-content">Dear All,
I have a task1 like this :
<pre><code>for (;;) {
     xSemaphoreTake(XSemSend, portMAX_DELAY);
   // doing some consuming process
   }
</code></pre>
in few other tasks during the consuming process of task1 I can have xSemaphoreGive (XsemSend); let&#8217;s say 6 times. I discovered that when the consuming process is done and it goes to SemaphoreTake waiting it immediately going again to consuming process, but only no more than 3 times, is this normal or not?
<pre><code>   Thanks and Rgds
   David
</code></pre>
</div></div><div class="thread-post"><h3 class="thread-post-title">Semaphore pending ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on October 31, 2018</div><div class="thread-post-content">Sorry &#8211; I don&#8217;t understand your question.  Are you saying that if you 
give a semaphore 6 times you would expect to be able to take it 6 times 
too?  That would only be the case if the semaphore was created as a 
counting semaphore with the max count parameter set to 6 or greater.
https://www.freertos.org/CreateCounting.html
</div></div><div class="thread-post"><h3 class="thread-post-title">Semaphore pending ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/delphes">delphes</a> on November 1, 2018</div><div class="thread-post-content">Dear Richard,
The Semaphore was created with xSemaphoreCreateBinary() so maxcount is 1 I believe, so if I have :
task1 
for (;;) {
     xSemaphoreTake(XSemSend, portMAX_DELAY);
   // doing some consuming process consuming 1 sec
   }
task2<br />
   for (;;) {
     xSemaphoregive((XSemSend);
     vTaskDelay(100); 
     count++;
     if( count == 10) vTaskDelete(NULL);
   }
task1 should wakeup only one time ?
</div></div><div class="thread-post"><h3 class="thread-post-title">Semaphore pending ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/fizzyaid">fizzyaid</a> on November 1, 2018</div><div class="thread-post-content">Task 2 is giving the semaphore back after 100ms which means Task1 can take it again.
</div></div><div class="thread-post"><h3 class="thread-post-title">Semaphore pending ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/delphes">delphes</a> on November 1, 2018</div><div class="thread-post-content">yes of course but task 1 is busy during 1 sec  so IMO it should not take again
</div></div><div class="thread-post"><h3 class="thread-post-title">Semaphore pending ?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/fizzyaid">fizzyaid</a> on November 1, 2018</div><div class="thread-post-content">You have a logic (pattern) problem.
This will execute at least twice according to what you&#8217;ve posted, possibly more times depending on how quickly task 1 processes its data.
