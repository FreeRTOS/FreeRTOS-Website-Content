  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Connecting  STR9 with lwIP demo to internet</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/anisba">anisba</a> on June 11, 2008</div><div class="thread-post-content">Hello,
Please I&#8217;m trying to connect an STR9 board runing the lwIP FreeRtos Demo to internet.
For this I&#8217;m using a Linksys Gateway which I have configured to forward incoming packet from internet to the board. 
I used a dynamic DNS &#40;dyndns.org&#41; in order to have a hostname &#40;mypagename.homeip.net&#41;
Finally I have configured the gateway address on LwIP to be my Gateway lan address.
Locally I&#8217;m able to download the page when typing the page URL on my explorer but from outside this doesn&#8217;t seem to work.
Do you know if there is any limitation in the http server provided with the demo? or is it performance issue with the STR9?
Or do I need to change anything in the LwiP options.
Thanks,
Anis
</div></div><div class="thread-post"><h3 class="thread-post-title">Connecting  STR9 with lwIP demo to internet</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on June 11, 2008</div><div class="thread-post-content">There are a number of things it could be. 
Which port number are you using? If using the standard port 80 then check your ISP allows you to run servers. It might block port 80 access. If you are using a non standard port then check your firewall and router don&#8217;t block access to non standard ports.
Whatever the problem is it is a networking issue, maybe in the configuration. If you can connect locally then its just a matter of hitting the right setup to be able to connect from externally.
</div></div><div class="thread-post"><h3 class="thread-post-title">Connecting  STR9 with lwIP demo to internet</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/anisba">anisba</a> on June 11, 2008</div><div class="thread-post-content">Hi Dave,
Thanks for your answer.
As you mentionned it my ISP is blocking port 80, so I&#8217;ve used port 7777. In fact I&#8217;ve configured my gateway to forward any traffic with port 7777 to my STR9 board and with changing port to 80.
I&#8217;ve already tested that it works fine using an Apache webserver runing on ubuntu PC &#40;it can be accessed from outside&#41;.
Anis
