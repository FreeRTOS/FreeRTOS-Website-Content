</div></div><div class="thread-post"><h3 class="thread-post-title">newbie needs help for mips port</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on February 15, 2008</div><div class="thread-post-content">On the assumption you are using the PIC32 MIPS port, have you defined MPLAB&#95;PIC32MX&#95;PORT in your compiler options? This will ensure the correct portmacro.h file is included in your build. Look at the file sourceincludeportable.h for more info. If you are creating your own port then you will have to provide a portmacro.h file.

</div></div><div class="thread-post"><h3 class="thread-post-title">newbie needs help for mips port</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 20, 2008</div><div class="thread-post-content">You appear to be making calls to the Microblaze libraries &#8211; which as you might expect are part of the Microblaze port not the MIPS port.&nbsp; Which portmacro.h file did you base yours on?
Look in the portmacro.h file, at the macros definitions for portENABLE&#95;INTERRUPTS&#40;&#41; and portDISABLE&#95;INTERRUPTS&#40;&#41;, also check the implementation of portENTER&#95;CRITICAL&#40;&#41; and portEXIT&#95;CRITICAL&#40;&#41;.&nbsp; You need these macros to be as per those defined in the PIC32 port.&nbsp; It looks like you are using them as per defined in the Microblaze port.
Regards.
