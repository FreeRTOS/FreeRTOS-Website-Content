</div></div><div class="thread-post"><h3 class="thread-post-title">PWM CONFIGURATION</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on January 22, 2007</div><div class="thread-post-content">You can generate the tick interrupt from any peripheral that can generated a fix period interrupt.&nbsp; I&#8217;m not familiar with the PIC, but other processors I have used have been able to generate the tick from the watchdog timer.&nbsp; Look at the function prvSetupTimerInterrupt&#40;&#41; in port.c for the PIC18 port.&nbsp; This is where the timer interrupt is configured.&nbsp; You can change it as required.
