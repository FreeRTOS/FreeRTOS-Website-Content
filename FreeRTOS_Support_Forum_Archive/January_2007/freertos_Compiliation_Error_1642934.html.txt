</div></div><div class="thread-post"><h3 class="thread-post-title">Compiliation Error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/embeddedc">embeddedc</a> on January 4, 2007</div><div class="thread-post-content">You cannot include queue.h in queue.c.&nbsp; This is because the queue handle is defined as a pointer to a structure in queue.c and a pointer to a void in queue.h.&nbsp; Hides the implementation of the queue structures from application programs.
