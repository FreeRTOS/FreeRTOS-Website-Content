  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">openRTOS plugin &#8211; will it work w/ freeRTOS?</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/oahmad2">oahmad2</a> on May 10, 2010</div><div class="thread-post-content">Hi,  
I am using <strong>freeRTOS.org version v6.0.0</strong> under <strong>Code-Red Suite 3 NXP Edition</strong> on an <strong>LPC1768</strong>.&nbsp;   
As part of the download, I also got the <strong>rtos.openrtos.viewer&#95;1.0.10.jar</strong> and followed the document <strong>&#8220;OpenRTOS APPLICATION NOTE: &#35;34-185-AN-001 &#8211; Installing and Using the OpenRTOS Eclipse Plug-In&#8221;</strong> to install the plug-in.&nbsp; I then tried to view the Queue Table and Tasks Table.&nbsp; I had success with the Tasks Table but not with the Queue Table; I then noticed that I needed to use the function <strong>vQueueAddToRegistry&#40;&#41;</strong> after the** xQueueCreate&#40;&#41;** function, which I did, but the Queue Table still does not show anything.&nbsp; Does anyone know what might be wrong?&nbsp;   
In particular, does this plugin work with freeRTOS or is it only for openRTOS?&nbsp;&nbsp;   
Further, the application note mentions that a similar method may be followed for semaphores:…&#8221;<em>The following description refers only to queue, but is equally applicable to binary semaphores, counting semaphores, mutex type semaphores and recursive semaphores&#8221;</em>…. but I see no register function for each of these types of semaphores similar to xQueueAddToRegistry&#40;&#41;, so how does one go about registering these semaphores and does the results appear under the Queue Table window as well?
</div></div><div class="thread-post"><h3 class="thread-post-title">openRTOS plugin &#8211; will it work w/ freeRTOS?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 11, 2010</div><div class="thread-post-content">Sorry for very quick responses:  
&#45; yes it works with FreeRTOS as well.<br />
&#45; have you set configUSE&#95;QUEUE&#95;REGISTRY to 1?&nbsp; This is needed in FreeRTOSConfig.h for the queue table to do anything.&nbsp; I think it is explained in the application note.<br />
&#45; You can use the same function to register semaphores as queues.  
Regards.
