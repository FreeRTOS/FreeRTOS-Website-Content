</div></div><div class="thread-post"><h3 class="thread-post-title">ISR/semaphore help on PIC18F</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 7, 2010</div><div class="thread-post-content">The code you have posted is not particularly easy to read &#40;formatting has been lost&#41; but I cannot see anything that looks wrong.  
The PIC18 is not an ideal target for running a real time kernel, and it might just be that it is running too slowly, resulting in overrun errors in the UART.&nbsp; You could try adding the following to the ISR:  
/&#42; Clear any overrun errors. &#42;/  
<pre><code>    if( RCSTAbits.OERR )
    {
        RCSTAbits.CREN = serCLEAR_OVERRUN;
        RCSTAbits.CREN = serCONTINUOUS_RX;  
    }
</code></pre>
Also you could try looking at the usual suspects of stack overflow, etc.
