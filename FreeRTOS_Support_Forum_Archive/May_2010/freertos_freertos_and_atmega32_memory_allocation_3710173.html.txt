</div></div><div class="thread-post"><h3 class="thread-post-title">freertos (and atmega32) memory allocation</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on May 15, 2010</div><div class="thread-post-content">It somewhat depends on the machine/compiler, but in general &#8220;static&#8221; and &#8220;global&#8221; variables, are allocated in one part of memory together, and &#8220;automatic&#8221; variables &#40;those declared inside a function, including main or tasks&#41;, are allocated on the &#8220;stack:, For automatic variables in a task, or functions called by a task, these are stored in the task&#8217;s stack, which depending on which version of &#8220;heap&#8221; you are using, will either be from an array in the static memory allocated in heap1.c or heap2.c, or if you are using heap3.c, will be within the program heap. Automatic variable from main, will be in the main stack &#40;which will be what the compiler/linker will think is &#8220;stack&#8221;.  
I&#8217;m afraid that if you need more details, you are going to need to read the manuals. That is where the details will be described. Normally you don&#8217;t really need to know about this sort of details though.
