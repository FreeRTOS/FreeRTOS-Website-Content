</div></div><div class="thread-post"><h3 class="thread-post-title">ATMega644 and FreeRTOS &#8211; not working</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on December 5, 2007</div><div class="thread-post-content">pxPortInitialiseStack sets up the stack that is used by the task when it first starts running.&nbsp; It fills the RAM used by the task as its stack with values that will get popped into the task registers when the task starts.&nbsp; It does not at that point write to any registers.
The AVR port is quite mature so I&#8217;m surprised you are having issues with it.&nbsp; Are you using WinAVR?&nbsp; If so, which version?
Also, I know some AVRs have three program counter bytes now, whereas the port assumes two program counter bytes.&nbsp; Does the device you are using have two or three?
