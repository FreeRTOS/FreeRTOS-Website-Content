</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS-CLI</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on April 26, 2014</div><div class="thread-post-content">taskCLI.c is not a FreeRTOS file, so I guess it is your file, and I also guess that you are casting strings to &#8220;signed char *&#8221; where as V1.03 does not require the &#8216;signed&#8217; any more.
I can&#8217;t quite remember, but in FreeRTOS itself rather than +CLI the coding standard rule stating char types must be qualified as either signed or unsigned was relaxed when the char was used to point to a character string.  This makes the code simpler and neater, and also is inline with &#8216;MISRA thinking&#8217;.
I think if you just edit your code to take the &#8216;signed&#8217; away it will be fine.
