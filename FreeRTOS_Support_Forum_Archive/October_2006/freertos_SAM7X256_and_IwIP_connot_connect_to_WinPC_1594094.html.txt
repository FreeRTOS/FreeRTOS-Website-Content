  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">SAM7X256 and IwIP connot connect to WinPC</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 17, 2006</div><div class="thread-post-content">I tried to build FreeRTOS v4.1.0 and IwIP 1.1.0 on an ARM7X256 using Crossworks 1.6. Everything went fine till I downloaded the code on the ARM. The WinPC I used as a client for the demo refuses to connect properly. It just kept switching from connected to unplunged. I think that there&#8217;s something wrong with the EMAC routines since I&#8217;ve placed some initial messagges at the begging of the FreeRTOS initialisations and they only appear once&#40;while the Ethernet keeps switching&#41;. Has anyone any suggestions on this?
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7X256 and IwIP connot connect to WinPC</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 17, 2006</div><div class="thread-post-content">With the cable unplugged the ethernet on the sam7 will attempt to connect every few seconds until it successfully connects.&nbsp; You will see the link LED go on an off every few seconds during this period.
Once the cable is plugged in the next time it attempts to connect should be successful and the LED will stay on.
If it is repeatedly connecting then disconnecting it sounds like the software is running, but not detecting the connection so disconnecting again.
Is the rest of the software running OK?&nbsp; Leds flashing, etc?
Have you got the MII/RMII setup correct for your board.
Are you using the correct cable type?
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7X256 and IwIP connot connect to WinPC</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 17, 2006</div><div class="thread-post-content">The leds are flashing allright, meaning that the physical layer is trying to connect to the other end&#40;I suppose&#8230;&#41;. The cable I&#8217;m using is a crossover but I&#8217;m not sure about the MII/RMII. What do you mean by saying &quot;correctly&quot;? I thought that every MII chip whould be O.K with the SAM7X&#8217;s MII. Isn&#8217;t that right? Anyway I&#8217;m using Olimex&#8217;s SAM7X board with a KS8721BL. Do you think this might be the problem? The thing is that there&#8217;re no other leds on it so I suppose I have to play a bit with the USART just to be sure that the other tasks are running.
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7X256 and IwIP connot connect to WinPC</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 17, 2006</div><div class="thread-post-content">In the EMAC code there is a constant something like
&#35;define USE&#95;RMII
which must be set to 1 for RMII mode and 0 for MII mode.&nbsp; I don&#8217;t think RMII is reliable on sam7x.
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7X256 and IwIP connot connect to WinPC</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 17, 2006</div><div class="thread-post-content">I think the SAM7X&#8217;s MII interface as it&#8217;s implemented in FreeRTOS, is based on the existance of DP83840 on the board. So you have &#40;probably&#41; to adjust the way ESAC is communicating over MII with your PHY ethernet chip.
