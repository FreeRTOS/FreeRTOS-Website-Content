</div></div><div class="thread-post"><h3 class="thread-post-title">init(netif) doesn&#8217;t exist in IwIP 1.1.0?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 18, 2006</div><div class="thread-post-content">init&#40;&#41; is a callback function supplied as a parameter to netif&#95;add&#40;&#41;.&nbsp; In the lwIP demo, init calls ethernetif&#95;init&#40;&#41; which is a standard lwIP function.&nbsp; ethernetif&#95;init&#40;&#41; in turn calls low&#95;level&#95;init&#40;&#41; which is where the MAC/PHY initialisation specific to the hardware is performed.&nbsp; This will be where you code is not returning from, it contains the following loop:
&nbsp;&nbsp;&nbsp; while&#40; xEMACInit&#40;&#41; == NULL &#41;
&nbsp;&nbsp;&nbsp; &#123;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#95;&#95;asm&#40; &quot;NOP&quot; &#41;;
&nbsp;&nbsp;&nbsp; &#125;
which it runs at a low priority &#40;so the other tasks continue to run while it is waiting for the MAC/PHY initialisation to complete&#41;.
