</div></div><div class="thread-post"><h3 class="thread-post-title">porting from IAR to GCC STR91x</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on October 17, 2006</div><div class="thread-post-content">First, you may find it easier to take an existing CrossWorks ARM7 demo, and retarget it at the STR9.&nbsp; Although internally there are many differences between the ARM7 and ARM9 from the programmer view point they are very similar, so probably only the timer set and memory map will be very different to the existing ARM7 demo.&nbsp; The ARM7 demos use a different interrupt entering mechanism than the ARM9 demo, but this is only a matter of taste.
Now to your question.
I think you can simply replace the &#95;&#95;disable&#95;interrupt&#40;&#41; with libarm&#95;disable&#95;irq&#40;&#41;.&nbsp; Lookup libarm&#95;disable&#95;irq&#40;&#41; in the CrossWorks docs.
The FreeRTOS project uses the same port files as the vanilla GCC project, hence the CrossWorks extensions such as libarm&#95;disable&#95;irq&#40;&#41; are not used as they would not compile with vanilla GCC.
