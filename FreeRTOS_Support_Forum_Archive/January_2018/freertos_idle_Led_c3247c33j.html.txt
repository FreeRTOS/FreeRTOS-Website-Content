  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">idle Led</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/ojoj42">ojoj42</a> on January 23, 2018</div><div class="thread-post-content">Hi all,
Does anyone know how to achieve an idle LED?
By &#8220;idle LED&#8221; I mean a led that is lit while the RTOS is idle.
Thanks in advance.
</div></div><div class="thread-post"><h3 class="thread-post-title">idle Led</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/tlafleur">tlafleur</a> on January 23, 2018</div><div class="thread-post-content">One way is to turn it on when you enter the idle loop, turn it off when you enter the scheduler and maybe tick_hook and again at the entry to each ISR if you using them.
</div></div><div class="thread-post"><h3 class="thread-post-title">idle Led</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/tlafleur">tlafleur</a> on January 23, 2018</div><div class="thread-post-content">Correction, you would want to turn off led when a task other that the idle task is running, so again this would be done in the scheduled&#8230;.
May not be perfect, but it might give you what your looking for&#8230;
</div></div><div class="thread-post"><h3 class="thread-post-title">idle Led</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on January 23, 2018</div><div class="thread-post-content">You could use traceTASK<em>SWITCHED</em>IN() or traceTASK<em>SWITCHED</em>OUT() hooks, 
or potentially https://www.freertos.org/rtos-trace-macros.html &#8211; or 
potentially but more clumsily an application task tag that points to a 
function that turns the LED on and off.
</div></div><div class="thread-post"><h3 class="thread-post-title">idle Led</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on January 23, 2018</div><div class="thread-post-content">Lafleur&#8217;s suggestion is better.  
Turn it on in the idle hook and off in the tick hook.
</div></div><div class="thread-post"><h3 class="thread-post-title">idle Led</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on January 24, 2018</div><div class="thread-post-content">Turning off in the tick hook doesn&#8217;t work, as tasks started by some other interrupt won&#8217;t clear the LED.  I personally think the best solution is traceTASK<em>SWITCHED</em>IN() hook and set the LED to the state of pxCurrentTCB == the Idle Task TCB, so it accurately indicates if the current task is the Idle task.
Personally, I think rather than an Idle LED, and Active LED would be more useful, as I find I tend to have periods where I spend a lot of time in the Idle task, but their some activity going on, and it is easier to see that the LED is dimly glowing rather than just slightly dimmer. The one use for an Idle LED that I see is that if it ever goes out (or very dim) that is a good sign that the machine is heavily loaded.
</div></div><div class="thread-post"><h3 class="thread-post-title">idle Led</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/tlafleur">tlafleur</a> on January 24, 2018</div><div class="thread-post-content">But you also need to turn off led when entering an ISR&#8230;

</div></div><div class="thread-post"><h3 class="thread-post-title">idle Led</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on January 24, 2018</div><div class="thread-post-content">Turning off the LED depends a lot on if you consider being in an ISR to be &#8216;non-Idle&#8217;. ISRs should be very short, so the time in them should be negligable, and not really noticable, so for a person observed LED, not observable. Also, it would be very invasive to do this.
Note, if the ISR does wake up a task, having the hook in TASK<em>SWITCHED</em>IN() will still get triggered, so the LED will get updated on the exit of the ISR.
