</div></div><div class="thread-post"><h3 class="thread-post-title">Hardfault in Task Scheduling [STM32f107]</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 19, 2012</div><div class="thread-post-content">So it looks like you are creating just one task.&nbsp; Your application will also create the idle task, so provided configUSE&#95;TIMERS is set to 0, there will be two tasks running in your system.  
Start by:  
&#43; Having your application task the highest priority task, which in this case just means settings its priority above tskIDLE&#95;PRIORITY.  
&#43; Having a large task stack, say &#40; configMINIMAL&#95;STACK&#95;SIZE &#42; 4 &#41;  
&#43; Using the co-operative scheduler.&nbsp; Set configUSE&#95;PREEMPTION to 0.&nbsp; That means only your application task will ever run because it never blocks or yields.  
&#43; Removing all code other than a NULL loop, so your task is just doing for&#40; ;; &#41; &#95;&#95;asm volatile &#40; &#8220;NOP&#8221; &#41;;&nbsp; The NOP is useful for break points.  
Does the code run then?&nbsp; If not, how many times does the tick interrupt occur before it crashes &#40;you can tell by inspecting the xTickCount variable in tasks.c&#41;?  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">Hardfault in Task Scheduling [STM32f107]</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 19, 2012</div><div class="thread-post-content">Additionally, ensure configUSE&#95;TICK&#95;HOOK is 0, and ideally configCHECK&#95;FOR&#95;STACK&#95;OVERFLOW is 2 &#40;which will require an overflow hook function to be defined, example below&#41;:  
<pre><code>void vApplicationStackOverflowHook( xTaskHandle pxTask, signed char *pcTaskName )
{
    ( void ) pcTaskName;
    ( void ) pxTask;
    /* Run time stack overflow checking is performed if
    configCHECK_FOR_STACK_OVERFLOW is defined to 1 or 2.  This hook
    function is called if a stack overflow is detected. */
    taskDISABLE_INTERRUPTS();
    for( ;; );
}
</code></pre>
Regards.
