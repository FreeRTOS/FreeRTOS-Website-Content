</div></div><div class="thread-post"><h3 class="thread-post-title">Sam3x new SD driver</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on December 7, 2012</div><div class="thread-post-content">I have done some testing with getting creating a sd card program from scratch similar to the demo.&nbsp; I figured out all of the various sd/fatfs compiler flags then I moved on to importing FreeRTOS.&nbsp; Once the FreeRTOS&#95;used flag is enabled,&nbsp; f&#95;open fails and throws a 3&#40;FR&#95;NOT&#95;READY&#41; error.&nbsp; If the SD card debug flag is turned on then you can see that CMD 55 is failing.&nbsp; I think this has to do with the Freertos timers that get enabled in the sd card driver once the flag is used but that is the extent of my knowledge/troubleshooting.  
Hope that helps.<br />
Seth
</div></div><div class="thread-post"><h3 class="thread-post-title">Sam3x new SD driver</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on December 8, 2012</div><div class="thread-post-content">On the SAM4X-EK I have been able to use the ASF wizard inside Atmel Studio 6 to create the FreeRTOS peripheral control demo, then use the ASF Wizard to bring in the MMC driver and file system server.&nbsp; I had to uncomment a couple of items in the generated conf&#95;example.h header file &#40;generated by the ASF wizard&#41; to enable the MMC if I recall correctly.&nbsp; After that I was able to successfully read and write to an SD card from a task.  
The project will get released eventually, but I am adding a few other things to it first.&nbsp; I think all you need is in the ASF already though.&nbsp; If you are using Atmel Studio 6 then you can use the wizards in the IDE if you have the latest ASF version &#40;the latest version can be downloaded from <a href="http://gallery.atmel.com%29./">http://gallery.atmel.com&#41;.</a>  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">Sam3x new SD driver</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on December 8, 2012</div><div class="thread-post-content">I think I figured out the issue at least academically.&nbsp; I haven&#8217;t verified it yet.&nbsp; In the FreeRTOS PC demo, the FREERTOS&#95;USED flag is not defined.&nbsp; So my guess is that is why it works.&nbsp; I am trying to integrate the sd card functionality into the lwip demo and it does have the flag defined.&nbsp; I am going to try to create a demo and modifiy the flag in the sdcard files and see if it works.&nbsp; That might be a temporary solution but at least it will allow me to move on to the next step.  
Thanks for the help.<br />
Seth
</div></div><div class="thread-post"><h3 class="thread-post-title">Sam3x new SD driver</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on December 11, 2012</div><div class="thread-post-content">So I have made positive progress over the weekend.&nbsp; I was able to create a project from scratch with the asf wizard.&nbsp; I added FreeRTOS 7.3 and ported a simplified version of the basic example.&nbsp; I added the sd card/fatfs drivers with the wizard and set the correct flags in the configuration files.  
I created a task that detects the sd card, writes a string to the card then reads it back out.&nbsp; I think this is solid progress&nbsp;&nbsp; The next big task I think will be adding ethernet functionality.&nbsp; Is there a plan to add this to the asf wizard in the future?  
Thanks,<br />
Seth
