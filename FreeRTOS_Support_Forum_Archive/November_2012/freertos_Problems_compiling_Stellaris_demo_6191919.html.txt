cc1: error: unrecognized command line option &#8216;-mthumb&#8217;<br />

main.c:115:19: fatal error: stdio.h: No such file or directory  
The &#8221; ../../../Source/include&#8221; option should point to the correct directory. I even tried adding a -I option with an absolute path to this, it didn&#8217;t change anything.  
Would you have any idea what&#8217;s causing this error?  
Thanks in advance&#33;
</div></div><div class="thread-post"><h3 class="thread-post-title">Problems compiling Stellaris demo</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on November 16, 2012</div><div class="thread-post-content">The Eclipse page you reference is very very old. Eclipse has moved on a long way from then, but I think it just uses a makefile build not a managed make build.  
I&#8217;m pretty sure you need to be using arm-stellaris-eabi compiler, not arm-non-eabi compiler. arm-non-eabi will work but is newer and will need the compiler options adjusting, as you have found out.

For the compiler, I am getting it from the &#8220;CodeBench/Sourcery Lite for ARM EABI&#8221;. I think the arm-stellaris-eabi is the one included in the paid version?
</div></div><div class="thread-post"><h3 class="thread-post-title">Problems compiling Stellaris demo</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 17, 2012</div><div class="thread-post-content">They used to have both available as free lite version downloads, but I don&#8217;t know how things have changed since they were acquired by Mentor.
