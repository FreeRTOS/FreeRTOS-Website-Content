  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Library files for SAM7X512</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/skpgebo">skpgebo</a> on November 13, 2012</div><div class="thread-post-content">Hi  
I have made a project based on the demo uIP&#95;Demo&#95;IAR&#95;ARM7 and it&#8217;s working fine. I am using a SAM7X512, but with the AT91SAM7X256.h and lib&#95;AT91SAM7X256.h files. However, my code is now above 256 Kbytes and and I have tried to find library files for the SAM7X512, but can&#8217;t find any. I have modified the AT91C&#95;IFLASH&#95;SIZE and AT91C&#95;ISRAM&#95;SIZE to 512Kbytes and 128 Kbytes and the code above 256 Kbytes runs ok in IAR debug mode, but won&#8217;t start after power up. Do anybody know where I can find library files for SAM7X512 &#40;AT91SAM7X512.h and lib&#95;AT91SAM7X512.h&#41; or suggestion why the code won&#8217;t start up if code size is larger than 256 Kbytes.  
Regards<br />
Georg  
</div></div><div class="thread-post"><h3 class="thread-post-title">Library files for SAM7X512</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on November 13, 2012</div><div class="thread-post-content">I just tried opening an example that ships with the IAR tools from the Embedded Workbench 6.0armexamplesAtmelat91sam7x-ekbasic-serialflash-project directory, and it appears to have configurations for the 128, 256 and 512K parts.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">Library files for SAM7X512</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/skpgebo">skpgebo</a> on November 13, 2012</div><div class="thread-post-content">Thank you Richard.<br />
I replaced the AT91SAM7X256.h file with the AT91SAM7X512.h from this demo, but I got a bunch of warnings and errors. The file lib&#95;AT91SAM7X256.h seems to have a lot of definition which has been changed. I mangage to clean up this file by renaming definitions and just keeping the definition which is in use in my project &#40;the lib&#95;AT91SAM7X256.h file was not used here&#41;. Finally, I got a running code, but unfortunately with same behaviour. The code runs ok in IAR debug mode, but won&#8217;t start after power up.  
Regards<br />
Georg
</div></div><div class="thread-post"><h3 class="thread-post-title">Library files for SAM7X512</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on November 13, 2012</div><div class="thread-post-content">When the IAR debugger connects to a target it can run a script that peeks and pokes a some registers to do any set up that is needed. Look at the debug options in the IDE to see if it is running a script, and if it is look at the script in a text editor to see what it is doing. It might be that the script is configuring a register that your start up code needs to configure, but isn&#8217;t, causing it to only run when connected to IAR.
</div></div><div class="thread-post"><h3 class="thread-post-title">Library files for SAM7X512</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/skpgebo">skpgebo</a> on November 14, 2012</div><div class="thread-post-content">I found my missing initialising of the flash for SAM7X in AT91F&#95;LowLevelInit&#40;&#41;:  
original:<br />
AT91C&#95;BASE&#95;MC-&gt;MC&#95;FMR = AT91C&#95;MC&#95;FWS&#95;1FWS  
Changed to:<br />
AT91C&#95;BASE&#95;MC-&gt;MC0&#95;FMR = AT91C&#95;MC&#95;FWS&#95;1FWS ;<br />
AT91C&#95;BASE&#95;MC-&gt;MC1&#95;FMR = AT91C&#95;MC&#95;FWS&#95;1FWS ;  
Now, it works just fine.<br />
Thank you for support.
