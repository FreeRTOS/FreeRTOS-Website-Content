</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS KC705 Vivado Source Project</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on March 13, 2017</div><div class="thread-post-content">I think creating Vivado projects is outside the scope of FreeRTOS support.  The Xilinx SDK has built in support for FreeRTOS.  Create the hardware project, then create an SDK project using the SDK wizard.  During creation of the project, select your hardware, and select the &#8216;FreeRTOS<em>bsp&#8217; instead of the &#8216;standalone</em>bsp&#8217; and the SDK will generate a project with the correct drivers for your hardware, include the FreeRTOS source files, and create a working hello world project for you.  Alternatively use a standalone bsp and add the source files to the project yourself as on the following link: http://www.freertos.org/Creating-a-new-FreeRTOS-project.html.
