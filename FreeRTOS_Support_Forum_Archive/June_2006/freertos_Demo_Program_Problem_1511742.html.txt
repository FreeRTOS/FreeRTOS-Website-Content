  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Demo Program Problem?</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on June 5, 2006</div><div class="thread-post-content">I&#8217;m trying to make the demo program work, with:
&#45; IAR compiler for ARM7 &#40;Philips LPC2103&#41;
&#45; all tasks commented out except vErrorChecks and the idle task
I&#8217;m downloading to flash, and it runs fine up to the vTaskDelay call in vErrorChecks in main.c, but never returns from the vTaskDelay call.&nbsp; It looks like it&#8217;s just sitting in the idle task.&nbsp; I&#8217;ve checked the timer, VIC, and SCB settings, and they appear to be OK but I don&#8217;t think I&#8217;m getting an IRQ interrupt from timer 0 &#8211; I never seem to break at the interrupt vector.
Any suggestions?&nbsp; Thanks&#33;
Mark
</div></div><div class="thread-post"><h3 class="thread-post-title">Demo Program Problem?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jwestmoreland">jwestmoreland</a> on June 6, 2006</div><div class="thread-post-content">If all tasks are commented out then it doesn&#8217;t make sense to have vErrorChecks&#40;&#41; running.
You should comment that out and see if your Idle Task is OK &#8211; also check that your timer interrupt is going off.&nbsp; Maybe there&#8217;s a problem with your xtal or clock &#8211; maybe your timer IRQ is in the wrong place, etc. 
Look in your debugger to see if xTickCount&#40;&#41; ever increments &#8211; if it&#8217;s always zero &#8211; then you know your timer IRQ isn&#8217;t getting called.
I have a small target board that had a flaky clock on my RTC &#8211; in the IAR debugger I noticed that xTickCount never incremented which lead me to looking at my clock.&nbsp; Maybe you&#8217;re having a similar problem.
Good Luck,
John W.
</div></div><div class="thread-post"><h3 class="thread-post-title">Demo Program Problem?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jwestmoreland">jwestmoreland</a> on June 6, 2006</div><div class="thread-post-content">xTickCount is defined in tasks.c and is a variable &#8211; not a function as I have in my message above.&nbsp; If the timer IRQ is being serviced &#8211; it will increment.
Regards,
John W.
</div></div><div class="thread-post"><h3 class="thread-post-title">Demo Program Problem?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on June 6, 2006</div><div class="thread-post-content">It sounds like your timer is the problem, once you get the interrupt running it should be ok.
In addition to Johns suggestions:
+Check that interrupts are enabled in the status register.&nbsp; Interrupts should automatically get enabled when the context of the first task is restored &#40;when the first task starts to execute&#41;.
+Check you have configUSE&#95;PREEMPTION set to 1, or that configIDLE&#95;SHOULD&#95;YIELD is set to 1 if configUSE&#95;PREEMPTION is zero.
Regards.
