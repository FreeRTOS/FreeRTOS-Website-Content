</div></div><div class="thread-post"><h3 class="thread-post-title">GCC .s .ld files vs INTERRUPTS???</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on June 9, 2006</div><div class="thread-post-content">You will not be able to disable interrupts unless you are in Supervisor mode.&nbsp; The modes the processor operates in are part of the ARM7 code, which the LPC2129 uses.&nbsp; Its documentation can be found in the ARM manual, rather than the LPC2129 manual which really only tells you about the LPC2129 peripherals.
If you look in the startup.s file that comes with the Keil LPC2129 demo &#40;in the FreeRTOS.org distribution&#41; then you will see the lines:
// Start in supervisor mode
MSR&nbsp;&nbsp;&nbsp;&nbsp; CPSR&#95;c, &#35;Mode&#95;SVC|I&#95;Bit|F&#95;Bit
this sets the processor mode prior to main being called.
Regards.

</div></div><div class="thread-post"><h3 class="thread-post-title">GCC .s .ld files vs INTERRUPTS???</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/nobody">nobody</a> on June 12, 2006</div><div class="thread-post-content">User mode is not a privileged mode, so you cannot access the CPSR.&nbsp; As you cannot access the CPSR you cannot switch back to Supervisor mode.
The only way out of user mode once entered is within an exception handler.&nbsp; When an exception occurs you switch to a privileged mode so can access the CPSR again.
Read part A of http://www.cs.helsinki.fi/u/jikorhon/condev/gp32/dl/DDI0100E&#95;ARM&#95;ARM.pdf.zip.
