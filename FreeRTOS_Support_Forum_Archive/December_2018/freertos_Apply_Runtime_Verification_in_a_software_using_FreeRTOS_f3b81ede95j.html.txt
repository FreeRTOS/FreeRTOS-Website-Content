  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Apply Runtime Verification in a software using FreeRTOS</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/hamaral">hamaral</a> on December 1, 2018</div><div class="thread-post-content">Hello,
I&#8217;m working in a project that has developed (a long time ago) a control flight software using FreeRTOS (V7.5.2). We are using STM32F4discovery to embed the code and make analysis.
Now I want to apply runtime verification to check the execution and I found a toolchain that synthesize monitors and it uses a runtime library called RTMLib to take events from the main code. 
However this RTMLib was developed for an RTOS that uses POSIX and is not the case of FreeRTOS. So, what I should to do is to modify any files to adapt it to FreeRTOS. In the case this is the header: https://anmaped.github.io/rtmlib/doc/task__compat<em>8h</em>source.html
I read FreeRTOS APIs and others documents, but as I&#8217;m new in RTOS and I don&#8217;t know what function can replace &#8220;pthread_attr  &#8221; in this file .
Could anyone help me, please?
</div></div><div class="thread-post"><h3 class="thread-post-title">Apply Runtime Verification in a software using FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on December 1, 2018</div><div class="thread-post-content">This page 
https://www.freertos.org/FreeRTOS-Plus/FreeRTOS<em>Plus</em>POSIX/demo/posix_demo.html 
includes a download link that contains a pre-release version of 
FreeRTOS+POSIX &#8211; a new POSIX threading wrapper for the FreeRTOS kernel 
provided by AWS &#8211; does that help you?
</div></div><div class="thread-post"><h3 class="thread-post-title">Apply Runtime Verification in a software using FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/hamaral">hamaral</a> on December 1, 2018</div><div class="thread-post-content">Thanks to the answer Richard.
As I understood, I will need to modify and adapt the original code that uses the FreeRTOS API to this one, or I can add this wrapper into my FreeRTOS folder (which it has all headers and auxiliary structures), maintain my original code and uses this POSIX API to link with the RTMLib library.
In this case, I will need to modify also my port.c file (I&#8217;m using the GCC/ARM_CM4F)?
</div></div><div class="thread-post"><h3 class="thread-post-title">Apply Runtime Verification in a software using FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on December 2, 2018</div><div class="thread-post-content">If you include the FreeRTOS+POSIX library in your project then your 
existing code can continue to use the native FreeRTOS kernel API and the 
library code can use the pthread API.
