  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Notify request for API to check if task is waiting for Notify</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/lantczak">lantczak</a> on December 14, 2018</div><div class="thread-post-content">Hi,
I need API to check if task is blocked due to waiting for notification. 
I wrote below API. 
~~~
<h1>if( configUSE<em>TASK</em>NOTIFICATIONS == 1 )</h1>
<pre><code>BaseType_t xTaskNotifyIsTaskWaiting( TaskHandle_t xTask )
{
TCB_t *pxTCB;
BaseType_t xReturn = pdFALSE;
    /* If null is passed in here then it is the calling task that is having
    its notification state cleared. */
    pxTCB = prvGetTCBFromHandle( xTask );
    taskENTER_CRITICAL();
    {
        if( pxTCB-&gt;ucNotifyState == taskWAITING_NOTIFICATION )
        {
            xReturn = pdTRUE;
        }
    }
    taskEXIT_CRITICAL();
    return xReturn;
}
</code></pre>
<h1>endif /* configUSE<em>TASK</em>NOTIFICATIONS */</h1>
~~~
Please check if you see any issues with this code and would be nice if you will add it to official release.  Official version could be changed to get notify status of task so API will return:
~~~
/* Values that can be assigned to the ucNotifyState member of the TCB. */
<h1>define taskNOT<em>WAITING</em>NOTIFICATION    ( ( uint8_t ) 0 )</h1>
<h1>define taskWAITING<em>NOTIFICATION        ( ( uint8</em>t ) 1 )</h1>
<h1>define taskNOTIFICATION<em>RECEIVED       ( ( uint8</em>t ) 2 )</h1>
~~~
It is more general and therefroe more useful for other users
