  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">vCoRoutineSchedule to xCoRoutineSchedule</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/sashiono">sashiono</a> on September 12, 2007</div><div class="thread-post-content">proposed change/addition to vCoRoutineSchedule to xCoRoutineSchedule
instead of returning void I would like to return the true if a co-routine is ready to be scheduled, otherwise false if all the co-routines are blocked. 
something like this
signed portBASE&#95;TYPE xCoRoutineSchedule&#40; void &#41;
&#123;
&nbsp;&nbsp;&nbsp; /&#42; See if any co-routines readied by events need moving to the ready lists. &#42;/
&nbsp;&nbsp;&nbsp; prvCheckPendingReadyList&#40;&#41;;
&nbsp;&nbsp;&nbsp; /&#42; See if any delayed co-routines have timed out. &#42;/
&nbsp;&nbsp;&nbsp; prvCheckDelayedList&#40;&#41;;
&nbsp;&nbsp;&nbsp; /&#42; Find the highest priority queue that contains ready co-routines. &#42;/
&nbsp;&nbsp;&nbsp; while&#40; listLIST&#95;IS&#95;EMPTY&#40; &amp;&#40; pxReadyCoRoutineLists&#91; uxTopCoRoutineReadyPriority &#93; &#41; &#41; &#41;
&nbsp;&nbsp;&nbsp; &#123;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; if&#40; uxTopCoRoutineReadyPriority == 0 &#41;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#123;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; No more co-routines to check. &#42;/
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; return pdFALSE;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#125;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#8211;uxTopCoRoutineReadyPriority;
&nbsp;&nbsp;&nbsp; &#125;
&nbsp;&nbsp;&nbsp; /&#42; listGET&#95;OWNER&#95;OF&#95;NEXT&#95;ENTRY walks through the list, so the co-routines
&nbsp;&nbsp;&nbsp;&nbsp; of the&nbsp;&nbsp;&nbsp; same priority get an equal share of the processor time. &#42;/
&nbsp;&nbsp;&nbsp; listGET&#95;OWNER&#95;OF&#95;NEXT&#95;ENTRY&#40; pxCurrentCoRoutine, &amp;&#40; pxReadyCoRoutineLists&#91; uxTopCoRoutineReadyPriority &#93; &#41; &#41;;
&nbsp;&nbsp;&nbsp; /&#42; Call the co-routine. &#42;/
&nbsp;&nbsp;&nbsp; &#40; pxCurrentCoRoutine-&gt;pxCoRoutineFunction &#41;&#40; pxCurrentCoRoutine, pxCurrentCoRoutine-&gt;uxIndex &#41;;
&nbsp;&nbsp;&nbsp; return pdTRUE;
&#125;
The reason this would be useful is for power reduction for example, the IdleHook can look something like this now. 
void vApplicationIdleHook&#40; void &#41;
&#123;
&nbsp;&nbsp;&nbsp; if&#40;xCoRoutineSchedule&#40;&#41; == pdFALSE&#41;
&nbsp;&nbsp;&nbsp; &#123;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; //Idle the CPU
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; PCON&nbsp; = 0x1;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; //IDle Mode
&nbsp;&nbsp;&nbsp; &#125;
&#125;
I haven&#8217;t tested this yet, but I think it should work fine.
