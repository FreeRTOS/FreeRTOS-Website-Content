</div></div><div class="thread-post"><h3 class="thread-post-title">using vTaskStartTrace with terminal</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on September 26, 2007</div><div class="thread-post-content">The timing used by default is the tick count, so any context switches that occur with a higher frequency than that do not have accurate timing information &#8211; although the order of execution shown is correct.&nbsp; When I use the utility I change the behaviour to use a high resolution free running timer, but the timer used depends on the processor on which it is running so this is not portable and cannot therefore be the default behaviour.
