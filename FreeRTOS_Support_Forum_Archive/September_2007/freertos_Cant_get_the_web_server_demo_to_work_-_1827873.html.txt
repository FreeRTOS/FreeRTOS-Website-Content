In main.c, change the definition &#8211;
&#35;define mainCREATOR&#95;TASK&#95;PRIORITY&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#40; tskIDLE&#95;PRIORITY + 3 &#41;
to
&#35;define mainCREATOR&#95;TASK&#95;PRIORITY&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#40; tskIDLE&#95;PRIORITY + 2 &#41;
This means you only have one task running &#40; taskIDLE&#95;PRIORITY + 3 &#41;, the check task.&nbsp; This is the highest priority task in the system so should be the task that starts to execute first.
Now find the function that defines the check task, it is in the same file:
static void vCheckTask&#40; void &#42;pvParameters &#41;
and place a break point on the function entry.
Does the break point ever get hit when you run your code?
