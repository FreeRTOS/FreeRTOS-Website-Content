  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">memory per task</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/pietro77">pietro77</a> on September 20, 2007</div><div class="thread-post-content">Hi all,
how much memory do I need to create and execute a new task averagely?
If I use a PIC18F452 with a 32k flash and 1536 bytes of data memory, if I set in FreeRTOSconfig.h&nbsp; 
&#35;define configTOTAL&#95;HEAP&#95;SIZE&nbsp;&nbsp;&nbsp; &#40; &#40; size&#95;t &#41; 1536 &#41;
I can create up to 3 tasks and they work well. But no one more.
Instead, using a PIC18F6527 with a flash of 48k and data memory of 3936 bytes, and setting
&#35;define configTOTAL&#95;HEAP&#95;SIZE&nbsp;&nbsp;&nbsp; &#40; &#40; size&#95;t &#41; 2048 &#41;
I am, at the moment, using 6 tasks without problems.
Are there any relationships between tasks and their memory usage?
Thank you in advance,
Pietro
</div></div><div class="thread-post"><h3 class="thread-post-title">memory per task</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on September 20, 2007</div><div class="thread-post-content">Each time you create a task the scheduler allocates two blocks of memory.&nbsp; The first to hold the TCB &#8211; this size is fixed.&nbsp; The second to hold the stack of the task, this is variable and set by the parameter you pass to the xTaskCreate&#40;&#41; function.&nbsp; The stack actually used by a task is dependent on how the task is implemented &#40;number of local variables, function call depth, etc.&#41;.
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">memory per task</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/pietro77">pietro77</a> on September 21, 2007</div><div class="thread-post-content">but what is the size of memory I need to held the TCB?
</div></div><div class="thread-post"><h3 class="thread-post-title">memory per task</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on September 21, 2007</div><div class="thread-post-content">sizeof&#40; tskTCB &#41; or sizeof&#40; &#42;pxCurrentTCB &#41; would tell you that.&nbsp; You don&#8217;t have to allocate this memory yourself.&nbsp; It is done by FreeRTOS.
