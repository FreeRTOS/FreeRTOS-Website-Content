</div></div><div class="thread-post"><h3 class="thread-post-title">cannot compile the FreeRTOS example for AVR32</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jaydmdigital">jaydmdigital</a> on December 4, 2007</div><div class="thread-post-content">Those should be defined in your compiler. If IAR uses different names then you should add something to the top of the pm.c file that redefines the names as whatever IAR uses. 
For example:
&#35;define AVR32&#95;PM&#95;OSCCTRL32&#95;MODE&#95;CRYSTAL IAR&#95;AVR32&#95;PM&#95;OSCCTRL32&#95;MODE&#95;CRYSTAL
That&#8217;s a simple answer but maybe not the best. Maybe there is a header file with IAR that does this and all you need to do is included it in main.c. I don&#8217;t know as I don&#8217;t use this processor nor this compiler.
FWIW,
Jay
