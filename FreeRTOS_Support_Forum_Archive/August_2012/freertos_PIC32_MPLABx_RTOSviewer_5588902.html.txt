I&#8217;m preparing to start a new project using a &#40;to me&#41; new mcu &#40;pic32&#41;. I will probably need some new debug gear. I noticed the&nbsp; availability of a RTOSviewer for MPLABx. After googling a while, I could not find which debug tools I can use this viewer with. Microchip has the PicKit3, ICD3 and RealICE. Which of these allow the use of the rtosviewer?
</div></div><div class="thread-post"><h3 class="thread-post-title">PIC32/MPLABx/RTOSviewer</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on August 28, 2012</div><div class="thread-post-content">As I recall, the MPLAB 8 viewer could be used with Real ICE, ICD2 and ICD3 &#8211; these are the only interfaces I have so I don&#8217;t know about anything else.  
I&#8217;m not sure that the viewer in MPLAB X is completely solid yet, I was given some information on it but I&#8217;m afraid I can&#8217;t quite remember what.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">PIC32/MPLABx/RTOSviewer</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/hermarcel">hermarcel</a> on August 28, 2012</div><div class="thread-post-content">Thank you for your reply.  
Is Real ICE really worth the extra cost above an ICD3? And what about the additional Real ICE accesoires for speed/trace in relation to FreeRTOS?  
Marcel
</div></div><div class="thread-post"><h3 class="thread-post-title">PIC32/MPLABx/RTOSviewer</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on August 28, 2012</div><div class="thread-post-content">I&#8217;m not really an expert on these things, so take my advice lightly, but for standard debugging I have found the ICD 3 more than capable.&nbsp; I think the Real ICE is necessary for the more sophisticated tracing on the PIC32 though.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">PIC32/MPLABx/RTOSviewer</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/boscodog">boscodog</a> on August 29, 2012</div><div class="thread-post-content">The ICD3 and REAL ICE share the same basic guts.&nbsp; High Speed USB and the FPGA, so they debug/read/write/program at the same speed.<br />
The ICE adds some features such as the trace and some input/output pins.<br />
But to do really high speed trace you need to shell out more loot for the high speed interface.  
ICD3 should be fine for most uses.&nbsp; The ICD2 is discontinued and it is a bit slow being USB full speed.
