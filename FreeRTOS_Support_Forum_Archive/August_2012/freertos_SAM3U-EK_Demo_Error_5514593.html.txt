  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">SAM3U-EK Demo Error</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/engmmostafa80">engmmostafa80</a> on August 10, 2012</div><div class="thread-post-content">There is an error in the demo project of sam3u-ek in IAR.<br />
In file portasm.s Compilation error &#8220;Failed to open &#35;include file &#8216;FreeRTOSConfig.h&#8221;<br />
Can any new know how to solve this error?  
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM3U-EK Demo Error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on August 11, 2012</div><div class="thread-post-content">Are you referring to the project file in FreeRTOS/Demo/CORTEX&#95;AT91SAM3U256&#95;IAR?&nbsp; If so, I just tried building it and did not experience any problems.&nbsp; Which version of EWARM are you using?  
It sounds like you don&#8217;t have the path to portmacro.h set in the assembler include path settings.&nbsp; Below are instructions for adding it, but it should be there already.  
In IAR, select Options from the Project menu.&nbsp; Select the Assembler category in the pop up window.&nbsp; Select the Preprocessor tab.&nbsp; In the &#8220;Additional Include Directories&#8221; box, enter $PROJ&#95;DIR$/. to include the directory that contains the project in the search path.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM3U-EK Demo Error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/engmmostafa80">engmmostafa80</a> on August 11, 2012</div><div class="thread-post-content">Thank You. It works now, But I found that most of project configuration are not set in the project options. For example the in general menu, the target was not selected. It seems that I am using a different version than the version needed to run the project with no errors. I am using version 5.4 . What is the needed version to run the project?
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM3U-EK Demo Error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on August 11, 2012</div><div class="thread-post-content">It is a persistent feature of IAR that opening a project with a version of Embedded Workbench that is older than the version used to create the project will silently destroy the project &#8211; and it seems that this is what has happened to you.  
I think you will need at least version 6, and probably version 6.3.  
Regards.
