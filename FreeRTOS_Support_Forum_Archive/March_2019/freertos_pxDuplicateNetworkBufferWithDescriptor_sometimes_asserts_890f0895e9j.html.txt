</div></div><div class="thread-post"><h3 class="thread-post-title">pxDuplicateNetworkBufferWithDescriptor sometimes asserts</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on March 6, 2019</div><div class="thread-post-content">Hi,
The problem is this line:
~~~
    /* The EMAC now owns the buffer. */
    pxNetworkBuffer->pucEthernetBuffer = NULL;
~~~
There is a small difference between BufferAllocation 1 and 2:
When using <code>BufferAllocation_1.c</code>, the pointer <code>pucEthernetBuffer</code> will never get set again, so that is why it becomes and remains NULL.
<code>BufferAllocation_2.c</code> is different: <code>pucEthernetBuffer</code> will get set when calling <code>pxGetNetworkBufferWithDescriptor()</code>.
Still you can use BufferAllocation_1 in combination with zero-copy transmissions as here above:
~~~
     /* Will the data fit in the Tx buffer? <em>/
     if( pxNetworkBuffer->xDataLength &lt; EMAC_ETH_MAX_FLEN )
     {
         /</em> copy the buffer to the Tx DMA descriptor. */
         EMAC_PACKETBUF_Type TXBuffer;
         TXBuffer.ulDataLen = pxNetworkBuffer->xDataLength;
         TXBuffer.pbDataBuf = (uint32_t *)pxNetworkBuffer->pucEthernetBuffer;
         EMAC_WritePacketBuffer( &amp;TXBuffer );
         EMAC_UpdateTxProduceIndex();
<pre><code>     /* The EMAC now owns the buffer. */
</code></pre>
&#8211;        pxNetworkBuffer->pucEthernetBuffer = NULL;
+         /* Do not release it until it has been sent. */
+        xReleaseAfterSend = pdFALSE;
<pre><code>     iptraceNETWORK_INTERFACE_TRANSMIT();
     /* The Tx has been initiated. */
     xReturn = pdPASS;
 }
 break;
</code></pre>
~~~
In the above code, the pxNetworkBuffer will not be released.
It has to be released later: as soon as the DMA reports that the packet has been sent.
At that moment you need to know the address of the buffer, and call the following function to get the original <code>NetworkBufferDescriptor_t</code>:
~~~
    NetworkBufferDescriptor<em>t *pxBuffer = pxPacketBuffer</em>to_NetworkBuffer( pvDMABuffer );
    configASSERT( pxBuffer != NULL );
    vReleaseNetworkBufferAndDescriptor( pxBuffer );
~~~
Also, make sure that this is defined in your FreeRTOSIPConfig.h :
~~~
<h1>define ipconfigZERO<em>COPY</em>TX_DRIVER    1</h1>
~~~
In <a href="https://sourceforge.net/p/freertos/discussion/382005/thread/11f944864b/2731/attachment/STM32Fxx_tcp_driver_7_Oct_2018.7z">this STM32Fx driver</a> you see an example of this technique.
