  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Tasks synchronization for TCP/IP sending and receiving data</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/e2738729">e2738729</a> on March 15, 2019</div><div class="thread-post-content">Hi everyone,
I am currently working on a project that involves a PC as a TCP/IP client and 12 ESP32&#8217;s as TCP/IP Server. My goal is to have the ESP32&#8217;s collect data from an ADC via SPI, then send those data to the PC. The PC will use multiprocessing to collect and process these data and send a command back to the ESP32&#8217;s. Based on the command received by the PC, the ESP32&#8217;s will perform certain control algorithms.
I created a tcp/ip server tasks to setup the esp32 as server. This task then created another task to send data from ESP32 (TCP/IP server) to PC (TCP/IP Client) whenever the data buffer was full.
I would like to create another task to receive commands (binaries) from PC after the PC has received and processed the data mentioned above
<ol>
<li>Should I xEventGroupCreate() for the sending and receiving tasks then xEventGroupSync() to make sure the receiving task is done after the sending task with a xTicksToWait? Also, do I need to have xTaskCreate() even if I already have xEventGroupCreate()?</li>
<li>If yes to the above, can you provide a code snippet to do this? Is there an example somewhere?</li>
<li>If no, what would be the best way to ensure that  the receiving task is done after the sending task? </li>
</ol>
I also see this in the freeRTOS documentation:
~~~
/* Bits used by the three tasks. */
<h1>define TASK<em>0</em>BIT        ( 1 &lt;&lt; 0 )</h1>
<h1>define TASK<em>1</em>BIT        ( 1 &lt;&lt; 1 )</h1>
<h1>define TASK<em>2</em>BIT        ( 1 &lt;&lt; 2 )</h1>
<h1>define ALL<em>SYNC</em>BITS ( TASK<em>0</em>BIT | TASK<em>1</em>BIT | TASK<em>2</em>BIT )</h1>
/* Use an event group to synchronise three tasks.  It is assumed this event
group has already been created elsewhere. */
EventGroupHandle_t xEventBits;
void vTask0( void *pvParameters )
{
EventBits_t uxReturn;
TickType_t xTicksToWait = 100 / portTICK_PERIOD_MS;
<pre><code>for( ;; )
{
    /* Perform task functionality here. */
    . . .
    /* Set bit 0 in the event group to note this task has reached the
    sync point.  The other two tasks will set the other two bits defined
    by ALL_SYNC_BITS.  All three tasks have reached the synchronisation
    point when all the ALL_SYNC_BITS are set.  Wait a maximum of 100ms
    for this to happen. */
    uxReturn = xEventGroupSync( xEventBits,
                                TASK_0_BIT,
                                ALL_SYNC_BITS,
                                xTicksToWait );
    if( ( uxReturn &amp; ALL_SYNC_BITS ) == ALL_SYNC_BITS )
    {
        /* All three tasks reached the synchronisation point before the call
        to xEventGroupSync() timed out. */
    }
}
</code></pre>
}
void vTask1( void <em>pvParameters )
{
    for( ;; )
    {
        /</em> Perform task functionality here. */
        . . .
<pre><code>    /* Set bit 1 in the event group to note this task has reached the
    synchronisation point.  The other two tasks will set the other two
    bits defined by ALL_SYNC_BITS.  All three tasks have reached the
    synchronisation point when all the ALL_SYNC_BITS are set.  Wait
    indefinitely for this to happen. */
    xEventGroupSync( xEventBits, TASK_1_BIT, ALL_SYNC_BITS, portMAX_DELAY );
    /* xEventGroupSync() was called with an indefinite block time, so
    this task will only reach here if the syncrhonisation was made by all
    three tasks, so there is no need to test the return value. */
}
</code></pre>
}
void vTask2( void <em>pvParameters )
{
    for( ;; )
    {
        /</em> Perform task functionality here. */
        . . .
<pre><code>    /* Set bit 2 in the event group to note this task has reached the
    synchronisation point.  The other two tasks will set the other two
    bits defined by ALL_SYNC_BITS.  All three tasks have reached the
    synchronisation point when all the ALL_SYNC_BITS are set.  Wait
    indefinitely for this to happen. */
    xEventGroupSync( xEventBits, TASK_2_BIT, ALL_SYNC_BITS, portMAX_DELAY );
