</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7XDemo Build for Latest Yagarto!</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 23, 2012</div><div class="thread-post-content">The Yagarto site used to have an FAQ on this, as I recall, and even supply a syscalls file for download.&nbsp; The file is only required to provide stubs of the functions that the linker is looking for &#40;unless you actually make use of them of course&#41;.&nbsp; You may even find a syscalls.c containing these stubs in the FreeRTOS distribution.  
Please post any updated/working files to the FreeRTOS interactive site.  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">SAM7XDemo Build for Latest Yagarto!</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rbekkers">rbekkers</a> on February 23, 2012</div><div class="thread-post-content">Hi Warren,  
Good to hear the fix at least solved part of the problems. And yes, I added a syscalls.c file to my project. I found a basic version on the internet and modified it until it works with the stdio library in combination with the debug unit of the microcontroller. You can find my modified version here: <a href="http://couchtiger.nl/files/syscalls.zip">http://couchtiger.nl/files/syscalls.zip</a>. Not all functions are tested but the read and write function work for standard input and standard output, which is the debug unit. The sbrk functionality also appears to work because FreeRTOS is able to allocate memory. The only thing you need to do is include this code to initialise the uart of the debug unit:  
<pre><code>    // Disable PIO control for debug unit RX/TX pins
    AT91C_BASE_PIOA-&gt;PIO_PDR = AT91C_PIO_PA28 | AT91C_PIO_PA27;
    /* Initialise the debug unit USART. */
    DBGU_Configure(0x00000800, 9600, 48000000);
</code></pre>
You can always change the baud rate and other communication parameters of course.  
Success&#33;  
Regards,<br />
Rob
