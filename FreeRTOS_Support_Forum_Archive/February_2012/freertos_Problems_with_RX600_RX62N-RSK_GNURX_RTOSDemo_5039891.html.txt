&#45; Used RTOSDemos RX600&#95;RX62N-RDK&#95;GNURX, worked fine, added own code and made some changes<br />
&#45; diff between RTOSDemos&nbsp; RX600&#95;RX62N-RDK&#95;GNURX and RTOSDemos RX600&#95;RX62N-RSK&#95;GNURX, incooperated them in my code to make it run on RSK and RDK<br />
&#45; Result: Ethernet on RSK did not work in my code, anything else runs fine<br />
&#45; Took original&nbsp; RTOSDemos RX600&#95;RX62N-RSK&#95;GNURX, compiled it, found Ethernet not working<br />
&#45; Looked into he code, but found nothing<br />
&#45; Wrote to this Forum<br />
&#45; took Renesas RSK sample code because I thought that maybe my RSK is broken, but Ethernet runs fine with it<br />
&#45; Looked into my code, found that some port setup lines added by me in hwcondig.c were wrong for RSK, Ethernet now runs fine on RSK in my code<br />
&#45; Found the reason for the &#8220;non-working&#8221; RTOSDemos RX600&#95;RX62N-RSK&#95;GNURX: I had changed the network address in my code and still &#8220;ping&#8221;-ed on this address…
