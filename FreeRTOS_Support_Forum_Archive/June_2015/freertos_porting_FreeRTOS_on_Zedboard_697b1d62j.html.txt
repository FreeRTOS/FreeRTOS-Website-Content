  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">porting FreeRTOS on Zedboard</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rohin363">rohin363</a> on June 12, 2015</div><div class="thread-post-content">i am trying to port freeRTOS on zedboard . i downloaded the FreeRTOSV8.2.1 from the website but from there on i don&#8217;t know what to do next. i tried searching a lot but i couldn&#8217;t find a source that tells me how to do it from scratch.
</div></div><div class="thread-post"><h3 class="thread-post-title">porting FreeRTOS on Zedboard</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on June 12, 2015</div><div class="thread-post-content">The demo is somewhat separate from the hardware on which it is running.  If you stick to the blinky demo you will probably find the only thing you need to change is the port number used to toggle an LED.
The Xilinx tools keep the hardware definition and BSP separate from the application. So you will need to create a hardware definition project for your hardware (I&#8217;m sure you will be able to download one, if indeed, there is not one already built into the SDK), then create a BSP for your project (using the File->new->bsp menu in the SDK), then import the FreeRTOS project and set it to use the BSP you just created.
Alternatively, I think in the SDK you can simply use the File->New->Application project menu option, then you will be presented with some pre-configured hardware platforms, and you may find yours is listed.
These are Xilinx tools questions though, not FreeRTOS questions.
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">porting FreeRTOS on Zedboard</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/heinbali01">heinbali01</a> on June 12, 2015</div><div class="thread-post-content">Hello Rohin,
I attached a screen-dump called &#8220;xilinx_project.png&#8221;, hope it&#8217;s helpful.
The Xilinx projects in Eclipse are a bit different from what you might be used to. To run a program, you need 3 sub-projects:
<ul>
<li>BSP : these are source files created by and maintained by Xilinx
Right-click to find a button call &#8220;Re-generate BSP sources&#8221;</li>
<li>MicroZed<em>hw</em>platform, containing files like ps7_init.* and system.xml.
(You can download this sub-project)</li>
<li>RTOSDemo or your own source tree.</li>
</ul>
To run the project you will have to add a debug configuration.
I showed mine in the attachment.
It took me a lot of time to find out that you must use an initialisation file (ps7<em>init.tcl), and use the options shown (&#8220;Reset Entire System&#8221;, and &#8220;Run ps7</em>init&#8221;).
Under Application you will choose something like &#8220;Debug/RTOSDemo.elf&#8221;.
Also check the project references, RTOSDemo refers to the 2 other projects that you use: &#8220;MicroZed<em>hw</em>platform&#8221; and the BSP project.
Regards.
