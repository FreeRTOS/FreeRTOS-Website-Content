  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">How to control you hardware from a webpage</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jon_newcomb">jon_newcomb</a> on December 10, 2010</div><div class="thread-post-content">….using FreeRTOS, Ajax, prototype.js, HTTP POST and a static filesystem  
Hello folks,<br />
A while back I searched for AJAX under FreeRTOS and didn’t find anything, so I thought I’d start a thread to share with the community what I have so far..<br />
I have started a project that uses AJAX calls to send and receive JSON data to update a web page / control hardware. Uses HTTP Post<br />
I make use of the FreeRTOS / prototype.js / Protosockets / uIP 1.0 / AT91SAM7X<br />
PHP is emulated on the target.  
If you are interested in this sort of thing.. Consider joining me to work on the device it is going into..<br />
www.jnewcomb.com/cv  
There is no external filesystem used. All the JavaScript libraries are compressed – and using content encoding in the response header, the web browser decompresses them on the fly. It saves lots space&#33;<br />
You can see all the types of HTTP Headers I have used.. cache connection and so on..  
So far.. this a hosted version of what I have done – and got working in FreeRTOS / uIP<br />
<a href="http://www.jnewcomb.byethost33.com/perm/10_12_10_Pfe5kSnapshot">http://www.jnewcomb.byethost33.com/perm/10_12_10_Pfe5kSnapshot</a>  
The zip file is the uIP webserver and associated html files<br />
<a href="http://www.jnewcomb.byethost33.com/perm/10_12_10_Pfe5kSnapshot/share.zip">http://www.jnewcomb.byethost33.com/perm/10_12_10_Pfe5kSnapshot/share.zip</a>  
I use XAMPP to develop the HTML, then when I’m happy I use of makefsdata.pl and then hardcode the PHP support into the target – so the supplied PHP files are for your test server, not your target.  
I can’t support the project, but if you are trying something similar, consider it as a push in the right direction. Check back from time to time as depending on feedback, I wish to update the files in the links.<br />
It’s not a whole project as such, just the directories where I have made modifications.  
As uIP works within its own thread, you must be careful when linking events generated within uIP to your application. Critical sections can be used for reading and writing to variables shared across tasks..<br />
The uip&#95;post.c&nbsp; is used as the link between uIP and your FreeRTOS application code  
uIP also has relevant discussions, search for AJAX.<br />
<a href="https://list.sics.se/sympa/arc/uip-users/">https://list.sics.se/sympa/arc/uip-users/</a>  
Enjoy..<br />
Jon.
