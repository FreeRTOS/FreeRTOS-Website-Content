</div></div><div class="thread-post"><h3 class="thread-post-title">Idle task stack overflow</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on January 5, 2011</div><div class="thread-post-content">getTickHook is called from within an ISR &#40;the timer interrupt&#41;, so it can only call FreeRTOS functions with FromISR in their name. xTaskGetTickCount uses an ISR to access the count, and those don&#8217;t work inside of ISR routines, it can allow improper interrupt nesting.
</div></div><div class="thread-post"><h3 class="thread-post-title">Idle task stack overflow</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on January 5, 2011</div><div class="thread-post-content">ISRs must not call any FreeRTOS API functions that do not end in &#8220;FromISR&#8221;.&nbsp; Latest versions of FreeRTOS include an xTaskGetTickCountFromISR&#40;&#41; function &#40;although this is mentioned in the change history, it has not made it into the documentation yet&#41;.
