  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS+UDP to create server application</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/anandjose">anandjose</a> on May 3, 2013</div><div class="thread-post-content">We are porting FreeRTOS on Pxa303 board, we want to establish ethernet communication between 2 pxa303 boards. We are using FreeRTOS+UDP&#40;FreeRTOSV7.4.1FreeRTOS-PlusSourceFreeRTOS-Plus-UDP&#41; for this purpose, twoechoclients.c&#40;FreeRTOSV7.4.1FreeRTOS-PlusDemoCommonFreeRTOS&#95;Plus&#95;UDP&#95;DemosEchoClients&#92;&#41; as a client applicaion, as mentioned at <a href="http://www.freertos.org/FreeRTOS-Plus/FreeRTOS_Plus_UDP/Embedded_Ethernet_Examples/Common_Echo_Clients.shtml%2C">http://www.freertos.org/FreeRTOS-Plus/FreeRTOS&#95;Plus&#95;UDP/Embedded&#95;Ethernet&#95;Examples/Common&#95;Echo&#95;Clients.shtml,</a> website suggests desktop computer to use as a server, but we want another pxa303 board to be used as a server. Can any one guide us with how to program a server application for Pxa303 board?
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS+UDP to create server application</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 3, 2013</div><div class="thread-post-content">FreeRTOS+UDP uses a standard &#40;ish&#41; sockets interface, so the procedure is as per using any other Berkeley sockets IP stack:  
1&#41; Call FreeRTOS&#95;socket&#40;&#41; to create a socket &#8211; it will be created with a receive block time of portMAX&#95;DELAY.<br />
2&#41; Call FreeRTOS&#95;bind&#40;&#41; to bind the socket to the echo port &#40;port 7 by default&#41;.<br />
3&#41; Call FreeRTOS&#95;recvfrom&#40;&#41; on the socket.&nbsp; If configINCLUDE&#95;vTaskSuspend is set to 1 the call will only return once data has been received.<br />
4&#41; Call FreeRTOS&#95;sendto&#40;&#41; to send the received data back from whence it came.<br />
5&#41; Go back to step 3 to wait for more data.  
It would look something like this &#40;I have not tried running this code&#33;&nbsp; It is for example only&#41;  
<pre><code>static void prvEchoServer( void *pvParameters )
{
xSocket_t xSocket;
struct freertos_sockaddr xAddress;
/* Make sure array is large enough and that it does not overflow the
task stack.  Make it static if necessary. */
int8_t cBuffer[ 25 ];
uint32_t xAddressLength = sizeof( xAddress );
long lBytes;
  /* Remove compiler warning about unused parameters. */
  ( void ) pvParameters;
  for( ;; )
  {
    /* Create a socket. */
    xSocket = FreeRTOS_socket(  FREERTOS_AF_INET,
                                FREERTOS_SOCK_DGRAM,
                                FREERTOS_IPPROTO_UDP );
    /* Bind the the standard echo server port number. */
    xAddress.sin_port = FreeRTOS_htons( echoECHO_PORT );
    FreeRTOS_bind( xSocket, &amp;xAddress, sizeof( xAddress ) );
    /* Send a number of echo requests. */
    for( ;; )
    {
      /* Wait for data to arrive on the echo port. */
      lBytes = FreeRTOS_recvfrom( xSocket, cBuffer, sizeof( cBuffer ),
                                    0, &amp;xAddress, &amp;xAddressLength );
      /* Send the received data back from the originating address. */
      FreeRTOS_sendto( xSocket, cBuffer, lBytes, 0,
                          &amp;xAddress, xAddressLength );
    }
  }
}
</code></pre>
