</div></div><div class="thread-post"><h3 class="thread-post-title">coding problem &#8211; AT91SAM3U4E + IAR </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on May 31, 2013</div><div class="thread-post-content">Before answering your question &#8211; the use of the portTASK&#95;FUNCTION&#40;&#41; macro is not necessary.&nbsp; Just write<br />
static vComTxTask&#40; void &#42;pvParameters &#41; directly &#40;that is what the macro expands to&#41;.  
Am I right in thinking you have the example as distributed &#40;without your modifications&#41; working as expected, and that this problem only happens when you add code?&nbsp; If so then the most likely reason is that you have run out of heap space and the scheduler is just not starting.&nbsp; Try adding a forever &#40;for&#40;;;&#41;&#41; loop after the call to vTaskStartScheduler&#40;&#41;.&nbsp; If you have insufficient FreeRTOS heap then vTaskStartScheduler&#40;&#41; will return and you will end up in the loop.&nbsp; Alternatively you can add a malloc&#40;&#41; failed hook function and see if the hook function is ever called.  
Assuming this is your problem then either <a href="http://www.freertos.org/a00111.html">increase the size of the FreeRTOS heap</a>, or reduce the amount of heap that is used by stopping some of the standard demo tasks from being created.  
Regards.

I commented out the vAltStartComTestTasks, and the system hanged.  
I tried what you suggested me, inserted a for&#40;;;&#41; after the vTaskStartScheduler&#40;&#41;, with&nbsp; vAltStartComTestTasks still commented, and the system started ok.<br />
So, i commented out vStartLEDFlashTasks&#40;&#41; too. And the system hanged again.  
Thank you for the help.<br />
Vito  
</div></div><div class="thread-post"><h3 class="thread-post-title">coding problem &#8211; AT91SAM3U4E + IAR </h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/disketto">disketto</a> on June 8, 2013</div><div class="thread-post-content">I found the problem.

But still, when i add/remove some code it hangs, so i have to add/remove another line or function to call, like vTaskDelay&#40;&#41;.
