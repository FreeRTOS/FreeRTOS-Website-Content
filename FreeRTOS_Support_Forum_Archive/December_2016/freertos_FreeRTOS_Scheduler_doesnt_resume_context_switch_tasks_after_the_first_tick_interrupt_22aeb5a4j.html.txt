</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS Scheduler doesn&#8217;t resume/context switch tasks after the first tick interrupt</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on December 19, 2016</div><div class="thread-post-content">This start up file is importing the FreeRTOS interrupt handlers:
<pre><code>     EXTERN  vPortSVCHandler
     EXTERN  xPortPendSVHandler
     EXTERN  xPortSysTickHandler
</code></pre>
but not installing them, as the relevant snippet of the vector table shows:
<pre><code>     DCD     SVC_Handler              ; SVCall Handler
     DCD     DebugMon_Handler          ; Debug Monitor Handler
     DCD     0                         ; Reserved
     DCD     PendSV_Handler            ; PendSV Handler
     DCD     SysTick_Handler           ; SysTick Handler
</code></pre>
With this setting you would need to call the FreeRTOS handlers the same 
names as the handlers you have actually installed (each of which ends 
with &#8220;_Handler&#8221; in the code snippet above).  Have you done that?  The 
code needing to be added to FreeRTOSConfig.h to map the FreeRTOS names 
to the names you have actually installed is provided on the link from 
the first reply above in this thread.
