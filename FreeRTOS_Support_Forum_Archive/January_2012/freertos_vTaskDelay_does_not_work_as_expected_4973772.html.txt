</div></div><div class="thread-post"><h3 class="thread-post-title">vTaskDelay() does not work as expected</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/muratursavas">muratursavas</a> on January 27, 2012</div><div class="thread-post-content">Hi,  
I&#8217;ve successfuly managed to run the code on C-SPY Simulator and writing down here to help others.  
As you said Richard, Interrupts can be enabled by macros, but with IAR 6.3 you can directly create and edit an interrupt via dialog boxes.   
Here is the sequence:  
Enable Simulator from Target Options/Debugger Section.<br />
Simulator menu will appear in the main menu bar.<br />
Choose Simulator / Interrupt Setup<br />
In a default situation there won&#8217;t be an interrupt source. Click &#8220;New&#8221;<br />
&#8220;Edit Interrupt&#8221; dialog will appear.<br />
Choose SysTick Interrupt from the list.<br />
Leave the description as it is<br />
Write 2 x configTICK&#95;RATE&#95;HZ to the &#8220;First Activation&#8221; section &#40;To simulate SystemInit&#40;&#41; time&#41;<br />
Write configTICK&#95;RATE&#95;HZ to the &#8220;Repeat Interval&#8221;<br />
And then OK everything and RUN your simulation.  
P.S: I saw that just SysTick interrupt is not enough to run and as you know FreeRTOS also needs PendSV. If you do the setup above, PendSV appears automatically. But if it wouldn&#8217;t, just add PendSV interrupt to the sources with Repeat interval as &#8220;configTICK&#95;RATE&#95;HZ + 5&#8221; &#40;that&#8217;s what I saw with the automatic source creation&#41;
