</div></div><div class="thread-post"><h3 class="thread-post-title">2 Task by non-preemptive mode</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on January 16, 2012</div><div class="thread-post-content">If you have set the code to non-premtive mode then with those task definitions only one task will ever run. You have told the scheduler not to preempt a task, so the task will carry on running until it takes itself out of the Running state, for example by calling vTaskDelay&#40;&#41;, or it explicitly yields, for example by calling taskYIELD&#40;&#41;.  
If you want both tasks to run then they must yeild.
