  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Low power mode when scheduler idle</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on January 26, 2012</div><div class="thread-post-content">I would like to be able to switch my dsPIC33F into a low power mode when there are no tasks running &#40;or all are suspended or blocking&#41;. The idea is to use the core doze mode to reduce power to 1/4 normal operation when idle by underclocking the CPU &#40;but peripherals and timers run on the main clock, so it still keeps time.&#41;   
The simplest way of implementing this, I thought, would be to look for a vGetNumRunningTasks function; but there doesn&#8217;t seem to be one. I&#8217;d need to access the internal RTOS data structures to get the task list, which is probably a bad idea.  
Any ideas?  
Thanks for a great RTOS&#33; 
</div></div><div class="thread-post"><h3 class="thread-post-title">Low power mode when scheduler idle</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on January 26, 2012</div><div class="thread-post-content">The normal way of doing this is to use the idle hook.&nbsp; Assuming your application tasks run at a priority above the idle priority, the idle task will only run when no application tasks can run.&nbsp; Set configUSE&#95;IDLE&#95;HOOK to 1 in FreeRTOSConfig.h, then define a function called vApplicationIdleHook&#40;&#41;, and put your sleep code in that.  
<a href="http://www.freertos.org/a00016.html">http://www.freertos.org/a00016.html</a>  
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">Low power mode when scheduler idle</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/*anonymous">*anonymous</a> on January 26, 2012</div><div class="thread-post-content">Hi Richard  
That looks useful &#8211; thanks. I would need to enter and exit low power mode several times a second though &#40;at least&#41;; is there some function &#40;aside from any of my tasks&#41; that would run a callback when tasks are started so I can exit the low power mode I entered in the idle hook?
</div></div><div class="thread-post"><h3 class="thread-post-title">Low power mode when scheduler idle</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on January 26, 2012</div><div class="thread-post-content">I tend to just execute an Idle instruction in the idle hook to stop the processor when there is nothing to be done.   
If you want to actually a clock change for lower power, you could add that code before the idle, then define a handler for<br />
traceTASK&#95;SWITCH&#95;IN&#40;&#41; that checks if you are in that low power mode, and are switching to a task besides the idle task, switches back into full speed mode.
