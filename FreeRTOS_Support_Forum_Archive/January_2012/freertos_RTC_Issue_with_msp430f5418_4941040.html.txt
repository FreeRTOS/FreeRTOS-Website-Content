  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">RTC Issue with msp430f5418</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/harikk09">harikk09</a> on January 11, 2012</div><div class="thread-post-content">Hello Everybody,  
I am using MSP430F5418 wit IAR EW 5.10.  
In my project I am using FreeRTOS 7.0 as operating system.  
Consider the scenerio:  
0&#46; Setup RTC in alarm mode with one minute interrupt.<br />
1&#46; Create two tasks.<br />
2&#46; When one minute interrupt arrives, send a request to task 2 by task 1.<br />
3&#46; Task 2 response to to task 1 with 4 messages.<br />
4&#46; While receiving messages task 1 calls a simple function which loops for 0x7FFF times.  
Here, after the 4th request, an RTC interrupt is generated immediatly even if one minute is not passed.  
I am using the Work-around code provided by TI for RTC manipulation.  
Can anybody please tell me why this unexpected behaviour happens???  
Thank you,  
Hari
