We have SUPERVISOR mode defined in the .s file, BTW
</div></div><div class="thread-post"><h3 class="thread-post-title">More Secondary USB Bootloader with Rowley</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 9, 2009</div><div class="thread-post-content">The start up assembly file will switch into each mode, set up a stack for that mode, before switching into the next mode &#40;modes being IRQ, FIQ, Supervisor, User, etc&#41;.&nbsp; You have to ensure that before calling main&#40;&#41; you leave the processor in Supervisor mode.&nbsp; Also never go into User mode but instead go into System mode, otherwise you will not be able to get out of User mode without making a system call.  
The same will be true before you call the FreeRTOS application from your boot loader &#8211; make sure you are in Supervisor mode.  
Regards.
