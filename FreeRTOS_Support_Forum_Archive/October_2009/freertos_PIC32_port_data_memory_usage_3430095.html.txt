</div></div><div class="thread-post"><h3 class="thread-post-title">PIC32 port data memory usage</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richard_damon">richard_damon</a> on October 14, 2009</div><div class="thread-post-content">You biggest memory usage is the &amp;quot;malloc heap&amp;quot; which is set at 24k. This can probably be reduced. It&#8217;s size is set up in the option pages under the linker I believe. If your program is using the C heap, then it might make sense to use it for freeRTOS too by using heap3.c If you don&#8217;t need the heap &#40;you don&#8217;t use malloc, even indirectly through other library calls&#41; then you can get rid of the heap entirely. If you do use the heap, you will need to make sure that all allocations and deallocations are protected with a critical section or mutex, as I suspect the library is not set up to be naturally thread safe. &#40;That or all allocations must be from a single thread&#41;.
