</div></div><div class="thread-post"><h3 class="thread-post-title">V6.0.0 &#8211; what changes</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 7, 2009</div><div class="thread-post-content">Change log is below.&nbsp; Note the changes to the portLONG, SHORT and CHAR make diff&#8217;ing the files a little tricky so I have a check in labelled without those changes to make diff&#8217;ing easy:  
hanges between V5.4.2 and V6.0.0  
FreeRTOS V6 is backward compatible with FreeRTOS V5.x.  
Main changes:  
&#43; FreeRTOS V6 is the first version to include memory protection unit &#40;MPU&#41;<br />
&nbsp; support.&nbsp; Two ports now exist for the Cortex M3, the standard FreeRTOS<br />
&nbsp; which does not include MPU support, and FreeRTOS-MPU which does. &nbsp;<br />
&#43; xTaskCreateRestricted&#40;&#41; and vTaskAllocateMPURegions&#40;&#41; API functions added<br />
&nbsp; in support of FreeRTOS-MPU.<br />
&#43; Wording for the GPL exception has been &#40;hopefully&#41; clarified.&nbsp; Also the<br />
&nbsp; license.txt file included in the download has been fixed &#40;the previous<br />
&nbsp; version contained some corruption&#41;.<br />
&nbsp;<br />
Other changes:  
&#43; New API function xPortGetFreeHeapSize&#40;&#41; added to heap&#95;1.c and heap&#95;2.c.<br />
&#43; ARM7 GCC demo interrupt service routines wrappers have been modified to<br />
&nbsp; call the C portion using an &#95;&#95;asm statement.&nbsp; This prevents the function<br />
&nbsp; call being inlined at higher optimisation levels.<br />
&#43; ARM7 ports now automatically set the THUMB bit if necessary when<br />
&nbsp; setting up the initial stack of a task &#8211; removing the need for<br />
&nbsp; THUMB&#95;INTERWORK to be defined.&nbsp; This also allows THUMB mode and ARM mode<br />
&nbsp; tasks to be mixed more easily.<br />
&#43; All ARM7/9 ports now have portBYTE&#95;ALIGNMENT set to 8 by default.<br />
&#43; Various demo application project files have been updated to be up to date<br />
&nbsp; with the latest IDE versions.<br />
&#43; The linker scripts used with command line GCC demos have been updated to<br />
&nbsp; include an eh&#95;frame section to allow their use with the latest Yagarto<br />
&nbsp; release.&nbsp; Likewise the demo makefiles have been updated to include<br />
&nbsp; command line options to reduce or eliminate the eh&#95;frame section all<br />
&nbsp; together.<br />
&#43; The definition of portBYTE&#95;ALIGNMENT&#95;MASK has been moved out of the<br />
&nbsp; various memory allocation files and into the common portable.h header<br />
&nbsp; file.<br />
&#43; Removed unnecessary use of portLONG, portSHORT and portCHAR.  
Regards.
