</div></div><div class="thread-post"><h3 class="thread-post-title">How early can I use a mutex?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/destremps">destremps</a> on February 22, 2010</div><div class="thread-post-content">So just to be clear &#8211; it is safe to call &#8216;xSemaphoreTake&#8217; and &#8216;xSemaphoreGive&#8217; -after- the Mutex has been created but -before- the scheduler has been started? I find myself in the same position as the original poster.  
Suggestion: perhaps a list of which OS API functions are safe to use before the scheduler has been started would be handy/interesting. Probably not many of them are&#33; I have seen in writing that taskENTER&#95;CRITICAL&#40;&#41; and EXIT are safe to use. I wonder which others?  
</div></div><div class="thread-post"><h3 class="thread-post-title">How early can I use a mutex?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on February 22, 2010</div><div class="thread-post-content">I think the semaphore give and take functions will be ok to use before the scheduler is started provided you do not try and block while giving or taking. Keep the block time at zero.
</div></div><div class="thread-post"><h3 class="thread-post-title">How early can I use a mutex?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/destremps">destremps</a> on February 24, 2010</div><div class="thread-post-content">Sorry I&#8217;ve been sidetracked for a few days.  
Thanks edwards for your input.  
Richard,&nbsp; May I ask that you please definitively state if it is okay to call the xSemaphore Take and Give functions after creating the semaphore but prior to starting the scheduler? I&#8217;ve looked in my copy of both your books hoping to see my answer but couldn&#8217;t find it.  
Thank so much.<br />
-rmd
</div></div><div class="thread-post"><h3 class="thread-post-title">How early can I use a mutex?</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on February 24, 2010</div><div class="thread-post-content">vSemaphoreCreateBinary&#40;&#41; is implemented as:  
<pre><code>{                                                                    
    xSemaphore = xQueueCreate( ( unsigned portBASE_TYPE ) 1, 0 );    
    if( xSemaphore != NULL )                                         
    {                                                                
        xSemaphoreGive( xSemaphore );                                
    }                                                                
}
</code></pre>
so that would seem to provide the answer as far as xSemaphoreGive&#40;&#41; is concerned &#40;yes it is ok to call it&#41;.&nbsp; I think the same will be true for taking a semaphore too, provided a block time is never specified &#40;as was previously mentioned&#41;.  
Regards.
