</div></div><div class="thread-post"><h3 class="thread-post-title">How to manage memory on PIC24.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/petermeier">petermeier</a> on October 7, 2009</div><div class="thread-post-content">Hej,<br />
as the linker said -&amp;gt; Could not allocate data in section -&amp;gt; NDATA.<br />
You are running out of RAM. This ram is being static declared in your source code. e.g.<br />
unsigned char buffer;<br />
This statement will allocate 512 bytes of memory.<br />
So you need to reduce the memory usage of freeRTOS. See in FreeRTOSconfig.h for the parameters.<br />
Also have a look in MPLAB at View -&amp;gt; Memory Usage Gauge to have an overview of you consumed ram.  
Kind regards,<br />
Peter  
</div></div><div class="thread-post"><h3 class="thread-post-title">How to manage memory on PIC24.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 7, 2009</div><div class="thread-post-content">Look at the configTOTAL&#95;HEAP&#95;SIZE parameter in FreeRTOSConfig.h.&nbsp; It allocates a huge array that is used as the heap.&nbsp; Lowing it will reduce the RAM consumption.  
Regards.
