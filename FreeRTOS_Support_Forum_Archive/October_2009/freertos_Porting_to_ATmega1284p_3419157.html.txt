Here is what I&#8217;ve changed so far to run on my 1284p:  
&#45; Switched to port A instead of B in ParTest.c &#40;PORTA and DDRA&#41;<br />
&#45; In port.c, changed lines like this:<br />
&#45; void SIG&#95;OUTPUT&#95;COMPARE1A&#40; void &#41; &#95;&#95;attribute&#95;&#95; &#40; &#40; signal, naked &#41; &#41;;<br />
&#45; to lines like this:<br />

&#45; and lines like this:<br />
&#45; TIMSK = ucLowByte;<br />
&#45; to:<br />
&#45; TIMSK1 = ucLowByte;<br />
&#45; Also updated interrupt handling in serial.c so lines like this:<br />
&#45; SIGNAL&#40; SIG&#95;UART&#95;DATA&#41;<br />
&#45; look like:<br />
&#45; ISR&#40; USART0&#95;UDRE&#95;vect &#41;

Sorry, I found your direct emails in my spam folder.&nbsp; I&#8217;ve now replied to you directly.  
To anyone following along here, it was the Timer1 setup that needs attention, not Timer2 like I said before.  
Here are the pertinent sections of port.c &#8211; this is what worked for my 1284p:  
&nbsp;&nbsp;&nbsp; /&#42;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;<br />
&nbsp;&nbsp;&nbsp;&nbsp; &#42; Implementation of functions defined in portable.h for the AVR port.<br />
&nbsp;&nbsp;&nbsp;&nbsp; &#42;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#42;/<br />
&nbsp;&nbsp;&nbsp; /&#42; Start tasks with interrupts enables. &#42;/<br />
&nbsp;&nbsp;&nbsp; &#35;define portFLAGS&#95;INT&#95;ENABLED&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#40; &#40; portSTACK&#95;TYPE &#41; 0x80 &#41;<br />
&nbsp;&nbsp;&nbsp; /&#42; Hardware constants for timer 1. &#42;/<br />
&nbsp;&nbsp;&nbsp; &#35;define portCLEAR&#95;COUNTER&#95;ON&#95;MATCH&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#40; &#40; unsigned portCHAR &#41; 0x08 &#41;<br />
&nbsp;&nbsp;&nbsp; &#35;define portPRESCALE&#95;64&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#40; &#40; unsigned portCHAR &#41; 0x03 &#41;<br />
&nbsp;&nbsp;&nbsp; &#35;define portCLOCK&#95;PRESCALER&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#40; &#40; unsigned portLONG &#41; 64 &#41;<br />
&nbsp;&nbsp;&nbsp; &#35;define portCOMPARE&#95;MATCH&#95;A&#95;INTERRUPT&#95;ENABLE&nbsp;&nbsp;&nbsp; &#40; &#40; unsigned portCHAR &#41; 0x02 &#41;&nbsp;&nbsp;   
And then further down, in the function called &amp;quot; prvSetupTimerInterrupt&amp;quot;:  
&nbsp;&nbsp;&nbsp; static void prvSetupTimerInterrupt&#40; void &#41;<br />
&nbsp;&nbsp;&nbsp; &#123;<br />
&nbsp;&nbsp;&nbsp; unsigned portLONG ulCompareMatch;<br />
&nbsp;&nbsp;&nbsp; unsigned portCHAR ucHighByte, ucLowByte;  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Using 16bit timer 1 to generate the tick.&nbsp; Correct fuses must be<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; selected for the configCPU&#95;CLOCK&#95;HZ clock. &#42;/  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ulCompareMatch = configCPU&#95;CLOCK&#95;HZ / configTICK&#95;RATE&#95;HZ;  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; We only have 16 bits so have to scale to get our required tick rate. &#42;/<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ulCompareMatch /= portCLOCK&#95;PRESCALER;  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Adjust for correct value. &#42;/<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ulCompareMatch -= &#40; unsigned portLONG &#41; 1;  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Setup compare match value for compare match A.&nbsp; Interrupts are disabled<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; before this is called so we need not worry here. &#42;/<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ucLowByte = &#40; unsigned portCHAR &#41; &#40; ulCompareMatch &amp;amp; &#40; unsigned portLONG &#41; 0xff &#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ulCompareMatch &amp;gt;&amp;gt;= 8;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ucHighByte = &#40; unsigned portCHAR &#41; &#40; ulCompareMatch &amp;amp; &#40; unsigned portLONG &#41; 0xff &#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; OCR1AH = ucHighByte;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; OCR1AL = ucLowByte;  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Setup clock source and compare match behaviour. &#42;/<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ucLowByte = portCLEAR&#95;COUNTER&#95;ON&#95;MATCH | portPRESCALE&#95;64;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; TCCR1B = ucLowByte;  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42; Enable the interrupt &#8211; this is okay as interrupt are currently globally<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; disabled. &#42;/<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ucLowByte = TIMSK1;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; ucLowByte |= portCOMPARE&#95;MATCH&#95;A&#95;INTERRUPT&#95;ENABLE;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; TIMSK1 = ucLowByte;<br />
&nbsp;&nbsp;&nbsp; &#125;<br />
&nbsp;&nbsp;&nbsp; /&#42;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#8212;&#42;/<br />
&nbsp;&nbsp;&nbsp; &#35;if configUSE&#95;PREEMPTION == 1  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42; Tick ISR for preemptive scheduler.&nbsp; We can use a naked attribute as<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42; the context is saved at the start of vPortYieldFromTick&#40;&#41;.&nbsp; The tick<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42; count is incremented after the context is saved.<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42;/<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; //void SIG&#95;OUTPUT&#95;COMPARE1A&#40; void &#41; &#95;&#95;attribute&#95;&#95; &#40; &#40; signal, naked &#41; &#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; void TIMER1&#95;COMPA&#95;vect&#40; void &#41; &#95;&#95;attribute&#95;&#95; &#40; &#40; signal, naked &#41; &#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; //void SIG&#95;OUTPUT&#95;COMPARE1A&#40; void &#41;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; void TIMER1&#95;COMPA&#95;vect&#40; void &#41;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#123;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; vPortYieldFromTick&#40;&#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; asm volatile &#40; &amp;quot;reti&amp;quot; &#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#125;<br />
&nbsp;&nbsp;&nbsp; &#35;else  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; /&#42;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42; Tick ISR for the cooperative scheduler.&nbsp; All this does is increment the<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42; tick count.&nbsp; We don&#8217;t need to switch context, this can only be done by<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42; manual calls to taskYIELD&#40;&#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#42;/<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; //void SIG&#95;OUTPUT&#95;COMPARE1A&#40; void &#41; &#95;&#95;attribute&#95;&#95; &#40; &#40; signal &#41; &#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; void TIMER1&#95;COMPA&#95;vect&#40; void &#41; &#95;&#95;attribute&#95;&#95; &#40; &#40; signal &#41; &#41;;<br />
&nbsp;&nbsp;&nbsp; //&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; void SIG&#95;OUTPUT&#95;COMPARE1A&#40; void &#41;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; void TIMER1&#95;COMPA&#95;vect&#40; void &#41;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#123;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; vTaskIncrementTick&#40;&#41;;<br />
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#125;<br />
&nbsp;&nbsp;&nbsp; &#35;endif  
Note also in the above that I commented out signals like this:  
&nbsp;&nbsp;&nbsp; //&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; void SIG&#95;OUTPUT&#95;COMPARE1A&#40; void &#41;<br />
and replaced with singals like this:  
&nbsp;&nbsp;&nbsp; void TIMER1&#95;COMPA&#95;vect&#40; void &#41;  
I don&#8217;t know if this is &amp;quot;right&amp;quot;, but it&#8217;s working for me.&nbsp; :&#41;
