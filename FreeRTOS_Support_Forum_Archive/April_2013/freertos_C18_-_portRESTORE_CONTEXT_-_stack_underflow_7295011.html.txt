&#45; Have you set portCOMPILER&#95;MANAGED&#95;MEMORY&#95;SIZE as described in the &#8220;memory areas used by the compiler&#8221; section of the following page: <a href="http://www.freertos.org/a00097.html">http://www.freertos.org/a00097.html</a> ?  
&#45; Have you set up the linker script as described in the &#8220;linker scripts&#8221; section of the same page?
