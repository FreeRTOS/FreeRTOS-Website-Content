</div></div><div class="thread-post"><h3 class="thread-post-title">uIP on STM32F207</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on April 2, 2013</div><div class="thread-post-content">I would suggest:  
&#45; Getting a hello world style application running on the hardware first.&nbsp; That will ensure your build environment, including the linker script, is correct before tackling the application.  
&#45; Then get FreeRTOS running with a simple blinky style application.&nbsp; That will ensure you have the correct code building and the vector table set up correctly.  
<a href="http://www.freertos.org/Creating-a-new-FreeRTOS-project.html">http://www.freertos.org/Creating-a-new-FreeRTOS-project.html</a><br />
<a href="http://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html">http://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html</a>  
&#45; Finally open up the project in the Rowley IDE &#40;I think you can get an eval copy&#41; to see which uIP files are included and which include paths are necessary &#8211; then just replicate that in your makefile.  
Regards.

</div></div><div class="thread-post"><h3 class="thread-post-title">uIP on STM32F207</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on April 3, 2013</div><div class="thread-post-content"><blockquote>
  My confusions are that this specific demo has no README
</blockquote>
I didn&#8217;t realise there were undocumented demos in the official release other than a Coldfire demo that never got formally released &#8211; but you are right there doesn&#8217;t seem to be a web page for this demo.&nbsp; I&#8217;m therefore not sure of its status, and it doesn&#8217;t seem to build due to the &#35;include &lt;targets/STM32F103RB.h&gt; header file not being found.&nbsp; The error seems to be in an ST library file though, which the demo is probably not even using.&nbsp; I think you could still use the project file to see which FreeRTOS files it is using though.  
…however, you say you have FreeRTOS running already, so maybe we should ignore the Rowley project.&nbsp; It doesn&#8217;t include Ethernet anyway, which is what you are trying to do now, so I&#8217;m not sure how that relates to the Rowley project.&nbsp; I would recommend looking at the Demonstration Builder software from ST &#8211; this has FreeRTOS and lwIP running together on SM32F207 evaluation boards.&nbsp; Take a look at the following:  
<a href="http://www.st.com/st-web-ui/static/active/en/resource/technical/document/user_manual/DM00056722.pdf">http://www.st.com/st-web-ui/static/active/en/resource/technical/document/user_manual/DM00056722.pdf</a>
