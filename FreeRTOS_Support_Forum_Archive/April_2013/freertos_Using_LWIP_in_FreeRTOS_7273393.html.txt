</div></div><div class="thread-post"><h3 class="thread-post-title">Using LWIP in FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on April 2, 2013</div><div class="thread-post-content">The FreeRTOS code you are using is &#42;very&#42; old, and the lwIP code is moderately old.  
You can find a FreeRTOS/lwIP 1.4.0 integration that runs in the FreeRTOS windows simulator here :<br />
<a href="http://interactive.freertos.org/entries/20290712-FreeRTOS-Win32-project-with-lwIP-web-server">http://interactive.freertos.org/entries/20290712-FreeRTOS-Win32-project-with-lwIP-web-server</a>  
lwIP has three APIs, each of which has greater abstraction.&nbsp; The Raw API is the lowest, and the Sockets is the highest.&nbsp; The sockets file are therefore not part of the core lwIP functionality, but use the core functionality to provide a familiar sockets like API.  
Regards.

</div></div><div class="thread-post"><h3 class="thread-post-title">Using LWIP in FreeRTOS</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on April 2, 2013</div><div class="thread-post-content">The page you <a href="http://www.freertos.org/FreeRTOS-Plus/FreeRTOS_Plus_UDP/FreeRTOS_UDP_IP_Embedded_Ethernet_Tutorial.shtml">link to</a> is <strong>not</strong> lwIP but a propriatory UDP stack developed by Real Time Engineers Ltd directly.&nbsp; To use that code you would need to <a href="http://www.freertos.org/FreeRTOS-Plus/FreeRTOS_Plus_UDP/Embedded_Ethernet_Porting.shtml">create a functions to interface the UDP stack to the ST MAC drivers</a>.
