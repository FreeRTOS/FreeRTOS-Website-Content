</div></div><div class="thread-post"><h3 class="thread-post-title">USB Driver and USB Stack Support</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/xz8987f">xz8987f</a> on October 9, 2012</div><div class="thread-post-content">Hi Lisa,<br />
1&#41; FreeRTOS is a RTOS. There is nothing in my view which would prevent it to use it with an USB stack &#40;or any other software or stack&#41; as long they well-behave.<br />
2&#41; If your microcontroller has USB, and you have a FreeRTOS port for it, and you have an USB stack for it, and if this USB stack does not something dramatically different from what I used to see as USB stacks, then it should be possible to have them combined.<br />
3&#41; All of the above heavily depend on which microcontroller, RTOS port and USB stack. You need to verify it with what you plan to use.<br />
4&#41; Some vendors might bundle their USB stack with FreeRTOS. And this might not be free of charge.  
What I can say for myself:<br />
a&#41; I have the Freescale CMX USB HID stack running with Freescale ColdFire and FreeRTOS &#40;e.g. in <a href="http://mcuoneclipse.wordpress.com/2012/08/14/timing-system-in-a-lunch-box/%29">http://mcuoneclipse.wordpress.com/2012/08/14/timing-system-in-a-lunch-box/&#41;</a><br />
b&#41; I have the Freescale USB CDC stack running on multiple devices, from 8bit S08 to 32bit ColdFire and Kinetis ARM &#40;both Cortex-M4 and Cortex-M0+&#41;<br />
Both USB stacks can be downloaded free of charge from the Freescale website &#40;licensing terms apply, as they are not open source, but they are provided free of charge for Freescale devices&#41;. Other silicon vendors have similar offerings.  
I hope this helps,<br />
Erich
