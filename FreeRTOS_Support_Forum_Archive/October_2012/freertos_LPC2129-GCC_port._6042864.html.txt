</div></div><div class="thread-post"><h3 class="thread-post-title">LPC2129-GCC port.</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 21, 2012</div><div class="thread-post-content">The microcontroller should be in Supervisor mode when the first task is started.&nbsp; The code pops the registers from the initial stack frame into the System mode registers.&nbsp; So, while the CPU is using the Supervisor mode registers, it restores the System mode registers, then switches into System mode when the task starts.  
If you are seeing R14 being altered during the start first task execution then my best guest &#40;actually, almost certainly&#41; you are starting the scheduler from the wrong CPU mode.  
The easiest way to ensure the CPU is in the right mode is to have your start up code set the mode to Supervisor before main&#40;&#41; is called.&nbsp; Then it will be in Supervisor when it starts the first task, and System mode when the task actually executes.
