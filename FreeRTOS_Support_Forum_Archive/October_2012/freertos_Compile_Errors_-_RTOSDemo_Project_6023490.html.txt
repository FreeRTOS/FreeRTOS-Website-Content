FreeRTOSV7.2.0FreeRTOSSourceinclude<br />
FreeRTOSV7.2.0FreeRTOSDemoCORTEX&#95;LPC1768&#95;IAR  
Yet, I am still getting errors. The latest:<br />
Fatal Error: could not open source file &#8220;core&#95;cm3.h&#8221; New&#95;DevelopmentFreeRTOSV7.2.0FreeRTOSDemoCORTEX&#95;LPC1768&#95;IARLPC17xx.h 238

Can someone please point me in the right direction?  
Thanks,<br />

</div></div><div class="thread-post"><h3 class="thread-post-title">Compile Errors &#8211; RTOSDemo Project</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/groufosse">groufosse</a> on October 16, 2012</div><div class="thread-post-content">OK, I almost give up. Something doesn&#8217;t add up here. I read through the Ports info for the LPC1768 on the FreeRTOS site. It says if it doesn&#8217;t build as-is, that the version is likely &#8220;too old&#8221;. What does that mean? What version was the project file tested on, or can this information be made available…? I&#8217;m having a lot of difficulty, but no matter what I try, the compiler breaks without me patching .h files, now the linker is breaking.  
Thanks for any help.<br />
Gary  
</div></div><div class="thread-post"><h3 class="thread-post-title">Compile Errors &#8211; RTOSDemo Project</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on October 16, 2012</div><div class="thread-post-content">Different versions of IAR are not compatible with each other.&nbsp; The IAR version you are using is definitely too old.&nbsp; You need at least version 6, and probably version 6.2.&nbsp; I can think of two changes minimum between the version you are using and version 6.2 that will prevent you from being able to compile the project.  
Once you have updated your compiler version you will need to get a clean installation of FreeRTOS and start again.&nbsp; Don&#8217;t try using the project you have opened with IAR version 5.5 as it will have been corrupted.  
Regards.
