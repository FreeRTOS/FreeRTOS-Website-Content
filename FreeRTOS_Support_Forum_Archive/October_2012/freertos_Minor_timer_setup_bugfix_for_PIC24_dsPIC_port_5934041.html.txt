  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">Minor timer setup bugfix for PIC24/dsPIC port</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dnadler">dnadler</a> on October 6, 2012</div><div class="thread-post-content">Hi &#8211; My blinking light was running at half speed, and I assumed I&#8217;d set up the microprocessor clock wrong. After a couple hours checking all the clock configuration options, I found a small 2x error in the port.c timer setup… Here&#8217;s the fix:  
<pre><code>    // DRN: Timer clock input is system clock &gt;&gt;&gt; DIVIDED BY 2 &lt;&lt;&lt;
    // DRN: See DS39704A-page 14-6: bit 1 TCS:
    // DRN: Timerx Clock Source Select bit: 0 = Internal clock (FOSC/2)
    // DRN: line below fixed to reflect this...
    const unsigned long ulCompareMatch = ( ( (configCPU_CLOCK_HZ/2) / portTIMER_PRESCALE ) / configTICK_RATE_HZ ) - 1; // DRN
    // DRN: Was:    const unsigned long ulCompareMatch = ( ( configCPU_CLOCK_HZ / portTIMER_PRESCALE ) / configTICK_RATE_HZ ) - 1;
</code></pre>
Note 1: the CPU clock on PIC24F is typically 32MHz, but the instruction clock is always 1/2 this value. The timer input takes the CPU clock/2.<br />
Note 2: The CPU clock can be reduced in &#8220;Doze Mode&#8221; power-saving &#8211; this is not provided for in FreeRTOS.  
Hope this is helpful &#33;<br />
Best Regards, Dave

</div></div><div class="thread-post"><h3 class="thread-post-title">Minor timer setup bugfix for PIC24/dsPIC port</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dnadler">dnadler</a> on October 10, 2012</div><div class="thread-post-content">I&#8217;m using the PIC24FJ32GB004.<br />
The documentation for the timer module for PIC24 family is here:<a href="http://ww1.microchip.com/downloads/en/DeviceDoc/39704a.pdf"> http://ww1.microchip.com/downloads/en/DeviceDoc/39704a.pdf</a><br />
See section 14.3 Register 14-1: TxCON: Type A Time Base Control bit 1<br />
The clock definitions for these parts are a bit confusing:<br />
CPU clock is 32MHz, also feeds peripherals &#40;excepting USB&#41;.<br />
Instruction clock is always half this at 16MHz &#40;unless further divided in DOZE low-power mode&#41;.<br />
Hope that helps,<br />
Thanks,<br />
Best Regards, Dave
