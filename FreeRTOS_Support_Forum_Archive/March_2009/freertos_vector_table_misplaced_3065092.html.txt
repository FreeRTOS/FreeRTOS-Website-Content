  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">vector table misplaced</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/johst">johst</a> on March 4, 2009</div><div class="thread-post-content">I&#8217;ve modified the sources of FreeRTOS to create a port for the AT91SAM7A3.
The vector table is not being placed at 0x00100000, instead it ends up at 0x00101040.&nbsp; 
In the .icf file there is a definition: 
define symbol &#95;&#95;ICFEDIT&#95;intvec&#95;start&#95;&#95; = 0x00000000;&nbsp; 
but somehow this definition does not seem to produce any result.&nbsp; 
In this way when the instruction SWI is executed by taskYIELD&#40;&#41; the processor starts running the wrong code. 
&#40;Nevertheless, IAR is able to start the program properly&#33;&#33;&#33;&#33;&#41; 
How do I place the vector table at 0x00100000, please?&nbsp; 
/Johan on behalf of eavg 
</div></div><div class="thread-post"><h3 class="thread-post-title">vector table misplaced</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on March 4, 2009</div><div class="thread-post-content">0x100000 is not the normal place for the vector table so I would guess you are trying to do the remapping so part of the RAM code is mapped to 0. Is this correct? If so then are you copying the vector table from 0x00 to 0x100000 before you do the remap? Sometimes this will be done by the debugger macro file that gets called before the debug session commences.
</div></div><div class="thread-post"><h3 class="thread-post-title">vector table misplaced</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/johst">johst</a> on March 5, 2009</div><div class="thread-post-content">there is no remap being made.
the program is being run from Flash so the vector table is at 0x100000 and at 0x0 since after reset Flash is at 0.
I was able to post the same question with an image at AT91 forum.
this is the link:
http://www.at91.com/samphpbb/viewtopic.php?f=14&#038;t=5483&#038;p=16222&#038;hilit=freertos&#35;p16222

any more ideas, please?
