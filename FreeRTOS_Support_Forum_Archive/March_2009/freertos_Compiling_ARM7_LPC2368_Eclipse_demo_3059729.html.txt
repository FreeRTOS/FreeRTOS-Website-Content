<div class="thread-post-content">
<p>Check that the GCC compiler is in your path.</p>
<p>Open a command prompt and type &#8220;arm-elf-gcc&#8221;, you should get a message saying something like &#8220;no input file specified&#8221;.  If you get a message saying arm-elf-gcc is not a known program then you need to add the YAGARTO/bin directory to your PATH environment variable.</p>
<p>Next in the command prompt try typing &#8220;make&#8221;.  Does it recognise that command?</p>
