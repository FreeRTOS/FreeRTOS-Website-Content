</div></div><div class="thread-post"><h3 class="thread-post-title">MSP430X Support</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on March 6, 2009</div><div class="thread-post-content">Google for &quot;Westmoorland Engineering FreeRTOS&quot;. You will find an X port there.
</div></div><div class="thread-post"><h3 class="thread-post-title">MSP430X Support</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/jakbird">jakbird</a> on March 10, 2009</div><div class="thread-post-content">The Westmoreland Engineering website appears to be inactive, no recent updates.&nbsp; I sent an email, no response.
In looking at a port for MSP430X, the big differences are 20 bit address and registers.&nbsp; The task stack size will have to be doubled over an MSP430 to push the larger register set, but context switches should be about the same since the 430X has a push/pop multiple instruction.&nbsp; The other difference is in handling interrupt return address &#40;hi 4 bits of PC stored with status register&#41;.&nbsp; Has anyone else looked at what it would take to do a port from MSP430 to MSP430X?
And does anyone know if there are plans to fully support the 430X in GCC?&nbsp; Doesn&#8217;t seem to be much effort in that direction from what I can find on a web search.
</div></div><div class="thread-post"><h3 class="thread-post-title">MSP430X Support</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/s082579">s082579</a> on March 10, 2009</div><div class="thread-post-content">I&#8217;m also looking for a MSP430X port at the moment, and I&#8217;ve also tried to contact Westmoreland Engineering at the website, without response&#8230; So, does anyone else have this particular port? 
It should be possible to make a port for MSP430X, but it would ofcourse be nice to get inspired from someone who has already made it&#33; &#40;Or thought about it at least &#8230;&#41;
I found this old thread, which covers some of the aspects of the X-port:
https://sourceforge.net/forum/message.php?msg&#95;id=4456703
BTW, I&#8217;m using CCE and want to try out FreeRTOS on a MSP430F5418.
