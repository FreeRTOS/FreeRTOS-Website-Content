  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">CSTACK</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/deboeck">deboeck</a> on March 22, 2009</div><div class="thread-post-content">Dear,
&nbsp; I&#8217;m running FreeRTOS with IAR v5 on an Olimex LPC 2378 STK board. 
&nbsp; The debug log shows &quot;The stack pointer for stack &#8216;CSTACK&#8217; &#40;currently 0x40008E90&#41; is outside the stack range &#40;0x40000040 to 0x40008040&#41;&quot;. Increasing the stack results in &quot;exactly&quot; the same error message. For instance &quot;The stack pointer for stack &#8216;CSTACK&#8217; &#40;currently 0x40009E80&#41; is outside the stack range &#40;0x40000040 to 0x40009040&#41;&quot;. 
&nbsp; The difference between the top of the stack and the offending stack pointer equals in both cases.
&nbsp; Does anyone have any idea what might be causing this?
&nbsp; Your comments are appreciated&#33;
Regards,
Bart
</div></div><div class="thread-post"><h3 class="thread-post-title">CSTACK</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on March 23, 2009</div><div class="thread-post-content">The linker script defines the CSTACK segment, which is used as the stack when main&#40;&#41; is called.&nbsp; The stack of each task is allocated from the RTOS heap, which is not in the CSTACK segment, so when you start running tasks the IDE thinks the stack pointer is in invalid memory &#8211; but it isn&#8217;t it&#8217;s exactly where it should be.
You can safely ignore the warning.
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">CSTACK</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/frankandersen">frankandersen</a> on March 23, 2009</div><div class="thread-post-content">You could decrease the CSTACK size, in the &#42;.icf file, as Richard says it is only used when main&#40;&#41; is called. So I would think that you do not need many bytes for that. 
Richard do you have any idea of how much C stack is needed?
Regards, Frank
</div></div><div class="thread-post"><h3 class="thread-post-title">CSTACK</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/richardbarry">richardbarry</a> on March 23, 2009</div><div class="thread-post-content">How much is required is completely dependent on what your code does prior to starting the scheduler &#8211; sorry for not giving a better answer but I cannot say more than that.
Best to check on your own application.
Regards.
