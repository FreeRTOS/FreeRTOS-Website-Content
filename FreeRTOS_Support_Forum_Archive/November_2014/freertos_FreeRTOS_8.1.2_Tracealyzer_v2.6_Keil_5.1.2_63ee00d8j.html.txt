  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS 8.1.2 + Tracealyzer v2.6 + Keil 5.1.2</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/pablocotan">pablocotan</a> on November 20, 2014</div><div class="thread-post-content">Hello to all.
I&#8217;d like to know if anyone could help me with a problem I have trying to test these software on the STM32F4discovery.
I have already a running project of FreeRTOS 8.1.2 on the board, and would like to try Tracealyzer.
I copied Tracealyzer files and added the path and the header files to my project and when I compile I got an error with the following functions because the compiler doesn&#8217;t recognize asm.
The functions are:(trcHardwarePort.c)
void prvTraceSetIRQMask(uint32_t priMask)
{
    asm volatile (&#8220;MSR primask, %0&#8221; : : &#8220;r&#8221; (priMask) );
}
uint32<em>t prvTraceGetIRQMask(void)
{
    uint32</em>t result;
    asm volatile (&#8220;MRS %0, primask&#8221; : &#8220;=r&#8221; (result) );
    return result;
}
I tried to use __asm{} but I don&#8217;t understand how to change the rest of the sentences.
I don&#8217;t know how to make it work on Keil compiler and would appreciate if anyone could help me to write it properly for the compiler or use a C code instead.
Thank you in advance for your help.
Pablo
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS 8.1.2 + Tracealyzer v2.6 + Keil 5.1.2</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on November 21, 2014</div><div class="thread-post-content">That looks like GCC code. I don&#8217;t think Keil can use inline assembler, but does have extensions to get and set the PRIMASK value, which is what these functions are doing. Look at the intrinsics section of the Keil manual to find the names. Or just search the manual for primask.
