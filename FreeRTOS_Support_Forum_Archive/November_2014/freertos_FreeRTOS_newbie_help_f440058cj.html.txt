  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS newbie help</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/karl80">karl80</a> on November 3, 2014</div><div class="thread-post-content">Hi All, I&#8217;m New to SourceForge and Embedded programming. I have only used µC/OSII in school Projects but never tried to link an embedded system for my self so i thought that starting with FreeRTOS would be a good start.
I have a LPC2119 ET-Arm stamp card that i would like to get a FreeRTOS working on. Im working with Keil µVision 3 and GCC compiler on a Windows 7 computer. 
My question is, have any of you guys any experience working with these Tools and how do I get a FreeRTOS working on LPC2119 with GCC andKeil µVisoin 3??? Any tutorials that i can get help from etc..
Thanks
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS newbie help</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 3, 2014</div><div class="thread-post-content">See:
http://www.freertos.org/Creating-a-new-FreeRTOS-project.html
http://www.freertos.org/porting-a-freertos-demo-to-different-hardware.html
for starters.
I think the port layer files in FreeRTOSSourceportableGCCARM7<em>LPC2000 should work for your part, but these are quite old parts and the port layer likewise very old.  There is an [equally old] Keil project in FreeRTOSDemoARM7</em>LPC2129<em>Keil</em>RVDS which can probably be targeted for your hardware, but it is using the ARM compiler not GCC.  Other than that you will find makefiles for LPC2106 in FreeRTOSDemoARM7<em>LPC2106</em>GCC.
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS newbie help</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/karl80">karl80</a> on November 4, 2014</div><div class="thread-post-content">Hi And thanks for the reply.
I will look in to this material today and hopefully have a working RTOS soon.

Best regards
Karl
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS newbie help</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 4, 2014</div><div class="thread-post-content">The port layer is the small portion of the source code that is specific 
to one particular architecture &#8211; it &#8216;ports&#8217; the core kernel code to run 
on the hardware.
