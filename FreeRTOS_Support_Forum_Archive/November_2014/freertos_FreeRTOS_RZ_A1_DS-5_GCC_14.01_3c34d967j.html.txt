-Opened DS-5 and created a new workspace in &#8216;C:FreeRTOSV7.5.3<em>GNU</em>RSK+RZA1HFreeRTOSV7.5.3’

c:/devtools/KPIT.

is invoked it just crashes, reporting &#8220;Error -1073741819&#8221;.  It seems to 
be building a project specific library, which it is using &#8216;FreeRTOS&#8217; in 
the name of because the project is called FreeRTOS_Demo &#8211; but I suspect 
the library just contains the C run-time that will be used in the final 
link step as the FreeRTOS code is built as part of the application &#8211; as 
far as I can see anyway.
If you look in the libgen options (in the project options dialog) you 
will see there is an option to use a pre-built library rather than 
building the project specific one.  My attempt to use that alternative 
option would indicate that the library needs to be built at least once 
first though.
I am however using the older compiler still and am out of the office

</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS RZ/A1 DS-5 GCC 14.01</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/qwedvit">qwedvit</a> on November 13, 2014</div><div class="thread-post-content">[SOLVED]
I&#8217;ve created a new workspace as the readme.txt tells me from ealier posted URL. Modified GNU compiler path program files to program files (x86). After this step it compiles the code succesfully, which means I&#8217;ve got a working copy!
But when opening the syscalls.c file a ton of errors and warnings appear.
[SOLUTION]
In DS-5: go to window > preferences > C/C++ > Code Analysis. Turn off all potential programming problems and turn off all Syntax ans Semantic errors.
