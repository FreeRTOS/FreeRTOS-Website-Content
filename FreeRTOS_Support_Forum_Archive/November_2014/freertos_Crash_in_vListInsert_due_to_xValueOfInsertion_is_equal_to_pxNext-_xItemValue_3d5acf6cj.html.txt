Therefore the loop will always terminate at some point (assuming no corruption) on the &lt;= test because there should be something with an item value of 0xffffffff, and that code can only execute if the item value being inserted is less than 0xffffffff.
This type of corruption can often happen because of invalid interrupt priorities.  Are you using <b>any</b> interrupts in your application (other than the RTOS interrupts)?  For example, is you CAN peripheral interrupt driven?
What version of FreeRTOS are you using?  Do you have configASSERT() defined?

Just to make sure that you&#8217;re looking at what you think you&#8217;re looking at, a small patch:
~~~~~
-#define configASSERT(x)     if(x == 0) vAssertCalled( <strong>FILE</strong>, <strong>LINE</strong> )
+#define configASSERT(x)     if((x) == 0) vAssertCalled( <strong>FILE</strong>, <strong>LINE</strong> )
+volatile int error<em>caught;
+
 void vAssertCalled( void *pfile, uint32</em>t line)
 {
+   portDISABLE<em>INTERRUPTS( );
    while(1)
+   {
+       // A debugger will stop here on a break
+       error</em>caught++;
+   }
 }
~~~~~
<ol>
<li>Before the while(1), try to disable further interrupts.</li>
<li>A macro parameter shall be put between parentheses</li>
</ol>
ad 1) It has happened to me that one task was caught in vAssertCalled() while other tasks were still running.
ad 2) The parentheses will change the outcome:
~~~~~
    configASSERT( A &amp;&amp; B );
    if( A &amp;&amp; B == 0 ) // wrong
    if( ( A &amp;&amp; B ) == 0 ) // ok
~~~~~
I assume you didn&#8217;t make mistakes in the choice of the FromISR() versions:
~~~~~

BaseType_t xTimerIsTimerActiveFromISR( TimerHandle_t xTimer )

  /* Is the timer in the list of active timers? */
  uxSavedInterruptStatus = portSET_INTERRUPT_MASK_FROM_ISR();
  {
    /* Checking to see if it is in the NULL list in effect checks to see if
    it is referenced from either the current or the overflow timer lists in
    one go, but the logic has to be reversed, hence the '!'. */
    xTimerIsInActiveList = ( BaseType_t ) !( listIS_CONTAINED_WITHIN( NULL, &( pxTimer->xTimerListItem ) ) );

  portCLEAR_INTERRUPT_MASK_FROM_ISR( uxSavedInterruptStatus );
  return xTimerIsInActiveList;
