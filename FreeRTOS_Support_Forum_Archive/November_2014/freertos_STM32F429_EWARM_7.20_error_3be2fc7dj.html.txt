  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">STM32F429 + EWARM 7.20 error</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/alexanderbaev">alexanderbaev</a> on November 8, 2014</div><div class="thread-post-content">Dear friends.
I try to run FreeRTOS on my STM32F429-DISCO board using EWARM 7.20.
When I compile the project 3 errors appear:
Error[Pe020]: identifier &#8220;uint32<em>t&#8221; is undefined C:Program FilesIAR SystemsEmbedded Workbench 7.0armincccmsis</em>iar.h 111 
Error[Pe020]: identifier &#8220;__INLINE&#8221; is undefined C:Program FilesIAR SystemsEmbedded Workbench 7.0armincccmsis_iar.h 258 
Error[Pe065]: expected a &#8220;;&#8221; C:Program FilesIAR SystemsEmbedded Workbench 7.0armincccmsis_iar.h 258 
What did I do wrong?
</div></div><div class="thread-post"><h3 class="thread-post-title">STM32F429 + EWARM 7.20 error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on November 8, 2014</div><div class="thread-post-content">Presumably there is a problem with the order in which the header files are included, but it does not look like it is in a FreeRTOS file.  uint32<em>t is defined in stdint.h, and from the error message it looks like it needs to be included before cmsis</em>iar.h is included (in whichever file cmsis_iar.h is being included).
Regards.
</div></div><div class="thread-post"><h3 class="thread-post-title">STM32F429 + EWARM 7.20 error</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/alexanderbaev">alexanderbaev</a> on November 9, 2014</div><div class="thread-post-content">I included the stdint.h on the first place (however it already have been in the project). What is interesting is that when I point to uint32_t and __INLINE with the command &#8220;find the definition&#8221; the header file with the definition opens&#8230; So it seems like there are some problems with the compiler options (I have not found yet the exact problem/s). Maybe I should try another IDE for which you have an elaborate example?
