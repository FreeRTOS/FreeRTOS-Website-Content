</div></div><div class="thread-post"><h3 class="thread-post-title">LPC2368 + Rowley + FreeRTOS V6 ISR problem</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/edwards3">edwards3</a> on November 29, 2009</div><div class="thread-post-content">&gt;Hints plz  
First hint &#8211; try doing it the way the documentation says to do it, and the examples show it being done.&nbsp; Don&#8217;t use ctl anything.  
Look at the Interrupt Service Routines section of this page <a href="http://www.freertos.org/portlpc2106.html">http://www.freertos.org/portlpc2106.html</a> but note with the compiler that Rowley have been using &#40;I think it changed recently&#41; the call to vASwitchCompatibleISR&#95;Handler&#40;&#41; should be made from assembler as &#95;&#95;asm volatile&#40;&#8221;bl vASwitchCompatibleISR&#95;Handler&#8221;&#41;; to stop it ever getting inlines. Also vASwitchCompatibleISR&#95;Handler&#40;&#41; should be written in ARM mode as ARM to THUMB interworking from naked functions is broken in &lt;i&gt;some&lt;/i&gt; GCC versions.
