  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">LPC1768 demo in a 1766 board</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/fdvalenzuela">fdvalenzuela</a> on November 2, 2009</div><div class="thread-post-content">I am considering purchasing a LPC1766 based development board from Olimex, and I was wondering if any of the Web Server examples &#40;e.g. <a href="http://www.freertos.org/LPC1768_RedSuite.html%29">http://www.freertos.org/LPC1768&#95;RedSuite.html&#41;</a> for the LPC1768 will work there. I know it will demand some effort to make it work, but my main concern is the flash size &#40;1768 comes with 512kb, and 1766 only 256kb&#41;. Since I don&#8217;t have the compiler, I can&#8217;t figure out the final size of the executable file. So, has anyone tried this? Do you know if the web server application will fit and work properly?<br />
Another minor inconvenience is the compiler. I am used to working with Keil&#8217;s Realview compiler. I&#8217;m guessing I could use gcc from Keil IDE, but does anyone know if it is possible to modify the source code to make it compilable with RealView?<br />
Thank you very much&#33;
</div></div><div class="thread-post"><h3 class="thread-post-title">LPC1768 demo in a 1766 board</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on November 3, 2009</div><div class="thread-post-content">You will have to modify the linker script for the smaller flash, but the code will fit in 256 very easily.  
The GCC that comes with Keil is very old and probably won&#8217;t work.  
There is already a FreeRTOS Keil port for Cortex M3, you would just have to create the project.
</div></div><div class="thread-post"><h3 class="thread-post-title">LPC1768 demo in a 1766 board</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/fdvalenzuela">fdvalenzuela</a> on November 3, 2009</div><div class="thread-post-content">Thanks for your reply Dave, I will try the demo on the LPC 1766 board then.<br />
The only port I&#8217;ve seen for Cortex M3 and Keil is for the LM3Sxxxx boards, do you beleive this port can be used with the NXP sample code? Anyway, I could learn how to use Eclispe :p<br />
Once again, thanks.
