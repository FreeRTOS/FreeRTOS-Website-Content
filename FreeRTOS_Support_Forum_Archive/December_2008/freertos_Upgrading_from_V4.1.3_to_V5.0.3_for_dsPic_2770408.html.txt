&#35;define portINTERRUPT&#95;BITS&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &#40; &#40; unsigned portSHORT &#41; configKERNEL&#95;INTERRUPT&#95;PRIORITY &lt;&lt; &#40; unsigned portSHORT &#41; 5 &#41;
&#35;define portDISABLE&#95;INTERRUPTS&#40;&#41;&nbsp;&nbsp;&nbsp; SR |= portINTERRUPT&#95;BITS&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;

</div></div><div class="thread-post"><h3 class="thread-post-title">Upgrading from V4.1.3 to V5.0.3 for dsPic</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/davedoors">davedoors</a> on January 5, 2009</div><div class="thread-post-content">I&#8217;m not sure if the taskENABLE/DISABLE&#95;INTERRUPTS&#40;&#41; macros will completely disable and enable all interrupts or not, you will have to check their definition. Normally these macros are not used directly because they don&#8217;t keep track of the nesting depth like the ENTER/EXIT&#95;CRITICAL&#40;&#41; macros do.
If you want all interrupts to be disabled all the time then set configMAX&#95;SYSCALL&#95;INTERRUPT&#95;PRIORITY to be the highest priority there is. Otherwise, if the other macros don&#8217;t do what you want, then you can declare your own as you say.
