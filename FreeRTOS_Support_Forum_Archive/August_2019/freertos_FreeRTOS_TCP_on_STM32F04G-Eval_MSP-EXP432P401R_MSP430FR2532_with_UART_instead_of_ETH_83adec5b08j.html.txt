  <main class="main-content"><div class="thread-post"><h2 class="thread-post-title">FreeRTOS+TCP on (STM32F04G-Eval | MSP-EXP432P401R | MSP430FR2532) with UART instead of ETH</h2><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/dante-89">dante-89</a> on August 14, 2019</div><div class="thread-post-content">Hi,
for my project I want to find out, if I can change the FreeRTOS+TCP communication, which usualy is ethernet, to UART. My thoughts are:
<ul>
<li>put data into an ethernet frame</li>
<li>send it via UART to the MCU</li>
<li>write it in the recieve buffer for ethernet</li>
<li>run the FreeRTOS_recv(); function (i.e.) to use the conveniences of FreeRTOS+TCP</li>
<li>read the transmitt buffer for ethernet</li>
<li>send it via UART away from MCU</li>
</ul>
I&#8217;m new to (Free)RTOS, but already done a workshop on Udemy. I also have two eval&#8217;s here to play arround with (STM32F04G-Eval &amp; MSP-EXP432P401R). Actually I work with the STM32F04G-Eval and the preconfigured projects (EcheServer i.e.) to get into it. The goal for me is to evaluate the thoughts on the STM eval.-board, port it to the MSP432 LaunchPad and finally at the mentioned MSP430FR2532 (this is the one MCU i have developed my own PCB).
Later the purpose should be:
<ul>
<li>connect some of the MCU&#8217;s to a cluster</li>
<li>let them communicat via UART with the advantages of TCP/IP (DHCP) in addition to a RTOS</li>
</ul>
Now I&#8217;m not here that you guys make the project for me, but eventually someone can give me hints where the lever could be applied or can tell that this project is impossible?
FreeRTOS<em>recv(); leads me to pvBuffer (the buffer into which received data will be placed) via uxStreamBufferGet(); from StreamBuffer</em>t. Also I have reead the documentation for the NetworkBufferDescriptor_t. I think the <code>*</code>pucEthernetBuffer  is my entry point, but I dont get the link between these two structures&#8230;
Greetings,
Daniel
</div></div><div class="thread-post"><h3 class="thread-post-title">FreeRTOS+TCP on (STM32F04G-Eval | MSP-EXP432P401R | MSP430FR2532) with UART instead of ETH</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on August 15, 2019</div><div class="thread-post-content">There are some specific protocols for IP over serial, you can look up
SLIP and PPP.  Other than that I presume you can use the porting guide
to transmit and send over UART instead of Ethernet
https://www.freertos.org/FreeRTOS-Plus/FreeRTOS<em>Plus</em>TCP/FreeRTOS<em>TCP</em>Porting.html
which would be ok if you are sending point to point (so can basically
ignore the Ethernet addressing).
