</div></div><div class="thread-post"><h3 class="thread-post-title">usage of configUSE_TICKLESS_IDLE</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on August 19, 2019</div><div class="thread-post-content"><blockquote>

Which function?  Assuming you are using a Cortex-M3, M4F or M7 port,
then setting configUSE<em>TICKLESS</em>IDLE is 1 will the &#8216;supportess ticks and
yield&#8217; macro is called, which by default, calls
vPortSuppressTicksAndSleep() defined in the FreeRTOS port.c file.

</div></div><div class="thread-post"><h3 class="thread-post-title">usage of configUSE_TICKLESS_IDLE</h3><div class="thread-post-author">Posted by <a href="http://sourceforge.net/users/rtel">rtel</a> on August 23, 2019</div><div class="thread-post-content">In the source code you will see that vPortSuppressTicksAndSleep() is
called if the expected idle time goes above a threshold you configure
using the configEXPECTED<em>IDLE</em>TIME<em>BEFORE</em>SLEEP constant
FreeRTOSConfig.h &#8211; then inside vPortSuppressTicksAndSleep() you have the
following code which is where the pre and post sleep functions (which
are defined by the application) are executed.
configPRE<em>SLEEP</em>PROCESSING( xModifiableIdleTime );
if( xModifiableIdleTime > 0 )
{
  __asm volatile( &#8220;dsb&#8221; ::: &#8220;memory&#8221; );
  __asm volatile( &#8220;wfi&#8221; );
  __asm volatile( &#8220;isb&#8221; );
}
configPOST<em>SLEEP</em>PROCESSING( xExpectedIdleTime );
Which bit is not executing as you expect?  When you step through the
code in the debugger why is it not behaving as expected?
