 &#43; Search for the text &quot;STARTUP&#95;FROM&#95;RESET&quot;.
You will see that STARTUP&#95;FROM&#95;RESET redefines the reset vector depending on 
whether or not STARTUP&#95;FROM&#95;RESET is defiend in the project.&nbsp; If running in 
the debugger STARTUP&#95;FROM&#95;RESET is defined using the preprocessor, if 
running stand alone then STARTUP&#95;FROM&#95;RESET is not defined.
When STARTUP&#95;FROM&#95;RESET is defined then on reset you jump straight to &#95;start 
which is defined within thumb&#95;crt0.s, also in the same project.
Could you try doing the same in your project.&nbsp; I suspect it will fix your 
problem.
Let me know.
