In this case your use of NVIC&#95;PriorityGroupConfig&#40;NVIC&#95;PriorityGroup&#95;2&#41;; is <strong>definitely</strong> an error that had already been pointed out. You need to call NVIC&#95;PriorityGroupConfig&#40;NVIC&#95;PriorityGroup&#95;4&#41; &#40;as documented&#41;.  
If you are still pursuing this I suggest using FreeRTOS V7.5.2 with configASSERT&#40;&#41; defined because it will call assert&#40;&#41; if you have this setting wrong.
